# #066. クロスドッキングのバース割当と荷役・出発同期

<!-- section:scenario -->
クロスドッキング施設において、入荷用バース（ドア）と出荷用バースへのトラック割当と品目別積替計画を統合的に決定します。各入荷トラックはいずれか 1 つの入荷ドックへ、各出荷トラックはいずれか 1 つの出荷ドックへ（各ドックの収容台数上限内で）割り当てられ、入荷供給を各出荷トラックの需要へ過不足なく積み替えます。

入荷トラック $i$（ドック $r$）から出荷トラック $j$（ドック $s$）へ積荷を移す際、ドック対 $(r, s)$ に応じた単位荷役コストと横持ち移動時間が発生します。トラック $i$ から $j$ へ正の移動量があるときは、トラック $j$ の出発時刻がトラック $i$ の到着時刻＋移動時間 $\tau_{r,s}$ 以降でなければならず、目標納期を過ぎた分には遅延ペナルティが課されます。**総荷役コストと遅延ペナルティの和を最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `supplies` | `number[][]` | 入荷トラック別・品目別の積載量（$N_{\text{in}} \times K$） |
| `demands` | `number[][]` | 出荷トラック別・品目別の需要量（$N_{\text{out}} \times K$） |
| `arrivalTimes` | `number[]` | 入荷トラック $i$ の到着時刻 $a_i$ |
| `dueTimes` | `number[]` | 出荷トラック $j$ の目標出発期限 $d_j$ |
| `inDoorCaps` | `number[]` | 入荷ドック $r$ の最大受入台数 |
| `outDoorCaps` | `number[]` | 出荷ドック $s$ の最大配車台数 |
| `handlingCosts` | `number[][]` | ドック対 $(r, s)$ の 1 単位あたり荷役コスト $c_{r,s}$ |
| `transferTimes` | `number[][]` | ドック対 $(r, s)$ 間の移動所要時間 $\tau_{r,s}$ |
| `delayCost` | `number` | 出発遅延 1 単位時間あたりのペナルティ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `inDoor` | `number[]` | 各入荷トラックに割り当てた入荷ドック番号（$0 \dots R-1$） |
| `outDoor` | `number[]` | 各出荷トラックに割り当てた出荷ドック番号（$0 \dots S-1$） |
| `flows` | `number[][][]` | 品目別積替フロー（$N_{\text{in}} \times N_{\text{out}} \times K$） |
| `departures` | `number[]` | 各出荷トラックの出発時刻 $t_j \ge 0$ |
| `totalCost` | `number` | 最小化された総荷役＋遅延コスト |

<!-- section:example -->
**入力例**

```json
{
  "supplies": [
    [20, 15],
    [15, 25],
    [25, 10]
  ],
  "demands": [
    [15, 15],
    [25, 20],
    [20, 15]
  ],
  "arrivalTimes": [1, 3, 2],
  "dueTimes": [6, 8, 7],
  "inDoorCaps": [2, 2],
  "outDoorCaps": [2, 2],
  "handlingCosts": [
    [2, 5],
    [4, 2]
  ],
  "transferTimes": [
    [2, 5],
    [4, 2]
  ],
  "delayCost": 30
}
```

**出力例**

```json
{
  "inDoor": [0, 1, 1],
  "outDoor": [1, 1, 0],
  "flows": [
    [
      [0, 0],
      [0, 0],
      [20, 15]
    ],
    [
      [15, 5],
      [0, 20],
      [0, 0]
    ],
    [
      [0, 10],
      [25, 0],
      [0, 0]
    ]
  ],
  "departures": [5, 5, 3],
  "totalCost": 220
}
```

入荷 0 と出荷 2 をドック対 `(0, 0)` に、入荷 1・2 と出荷 0・1 をドック対 `(1, 1)` に組むと、110 単位すべてが荷役単価 2 かつ出発時刻 `[5, 5, 3] <= [6, 8, 7]`（遅延ゼロ）で処理でき、総コストは $110 \times 2 =$ **220** となります。
