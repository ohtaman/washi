# #059. 複数デポ配送計画問題 (MDVRP)

<!-- section:scenario -->
$D$ 個の地域デポ（`0..D-1`）から $C$ 箇所の顧客（`D..D+C-1`）へ商品を配送するネットワークを計画します。

- すべての顧客をちょうど 1 回ずつ、単一の配送ルートで訪問します。
- 各ルートは出発したデポと同じデポへ帰着しなければならず、異なるデポ間の移動はできません。
- 各デポから出発する車両台数は保有台数上限以下、担当する顧客需要の合計は供給容量上限以下に収めます。
- 各車両の積載量は常に `vehicleCapacity` 以下とします。

すべての制約を満たす配送ルートを設計し、**総移動距離を最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `dist` | `number[][]` | $(D+C) \times (D+C)$ の距離行列（`0..D-1` がデポ、`D..D+C-1` が顧客） |
| `demands` | `number[]` | 各頂点の需要量（デポは 0、顧客は正値） |
| `vehicleCapacity` | `number` | 車両 1 台あたりの積載容量上限 $Q$ |
| `depotMaxVehicles` | `number[]` | 各デポ `d` から出発できる最大車両台数 |
| `depotCapacities` | `number[]` | 各デポ `d` が供給できる顧客需要合計の上限 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `routes` | `number[][]` | 各車両の配送ルート配列（各ルートは同一デポ `[d, ..., d]`） |
| `totalDistance` | `number` | 最小化された全ルート総移動距離 |

<!-- section:example -->
**入力例**

```json
{
  "dist": [
    [0, 10, 3, 4, 9, 9],
    [10, 0, 9, 9, 4, 3],
    [3, 9, 0, 6, 7, 10],
    [4, 9, 6, 0, 8, 7],
    [9, 4, 7, 8, 0, 6],
    [9, 3, 10, 7, 6, 0]
  ],
  "demands": [0, 0, 4, 4, 4, 4],
  "vehicleCapacity": 9,
  "depotMaxVehicles": [1, 1],
  "depotCapacities": [8, 10]
}
```

**出力例**

```json
{
  "routes": [
    [0, 3, 2, 0],
    [1, 5, 4, 1]
  ],
  "totalDistance": 26
}
```

デポ 0 は顧客 `{2, 3}`（需要合計 8 ≤ 8、距離 $4 + 6 + 3 = 13$）、デポ 1 は `{4, 5}`（需要合計 8 ≤ 10、距離 $3 + 6 + 4 = 13$）を担当し、総移動距離は $13 + 13 =$ **26** となります。

<!-- section:hint1 -->
各デポ `d` と顧客集合 `{D..D+C-1}` のみを結ぶデポ添字付きの 0-1 枝変数（デポ間の枝は除外）と、各顧客の需要から `vehicleCapacity` までの連続累積積載量変数を定義します。全デポを通して各顧客が 1 回ずつ訪問されること、`(デポ, 顧客)` ごとのフロー保存則、および各デポの出庫台数上限と供給能力上限を制約してください。

<!-- section:hint2 -->
デポ添字のない単一の枝変数 `x[i][j]` を使うと、あるデポから別のデポへ抜ける開いたパスが許されてしまいます。枝変数をデポ `d` ごとに `{d} ∪ Customers` 上で定義すれば必ず出発デポへの帰着が保証され、顧客ペアには全デポ共通の容量ベース MTZ 制約（$u_i - u_j + Q \sum_d x_{ijd} \le Q - q_j$、ただし $q_j$ は顧客 $j$ の需要量）を課すことで部分巡回路を防げます。
