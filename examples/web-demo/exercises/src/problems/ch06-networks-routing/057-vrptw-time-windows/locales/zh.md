# #057. 带时间窗的车辆路径问题 (VRPTW)

<!-- section:scenario -->
最多 K 辆车于时刻 earliest[0] 从配送中心 0 出发，各自服务若干客户并在最晚时刻 latest[0] 前返回配送中心 0。每位客户都有允许开始服务的时间窗 [earliest[i], latest[i]] 与作业时长 service[i]；若车辆早到则需等待至 earliest[i]，但严禁晚于 latest[i] 开始服务。

请利用 Big-M 到达时间传递约束建立带时间窗的车辆路径混合整数规划模型，**最小化总行驶费用**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `dist` | `number[][]` | $(n+1) \times (n+1)$ 行驶时间与费用矩阵（`0` 为配送中心） |
| `earliest` | `number[]` | 各节点允许的最早开始服务时间（`earliest[0] = 0`） |
| `latest` | `number[]` | 客户最晚开工时间；`latest[0]` 为车辆返回场站的最晚时间 |
| `service` | `number[]` | 各节点的服务作业时长（`service[0] = 0`） |
| `maxVehicles` | `number` | 最多可从配送中心 `0` 派出的车辆数 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `routes` | `number[][]` | 车辆路径列表，每条均形如 `[0, ..., 0]` |
| `totalCost` | `number` | 最小化后的全部路径总行程费用 |

<!-- section:example -->
**输入示例**

```json
{
  "dist": [
    [0, 3, 6, 5, 4],
    [3, 0, 4, 4, 6],
    [6, 4, 0, 4, 8],
    [5, 4, 4, 0, 5],
    [4, 6, 8, 5, 0]
  ],
  "earliest": [0, 10, 4, 2, 12],
  "latest": [40, 16, 12, 8, 22],
  "service": [0, 2, 2, 3, 2],
  "maxVehicles": 2
}
```

**输出示例**

```json
{
  "routes": [
    [0, 1, 0],
    [0, 3, 2, 4, 0]
  ],
  "totalCost": 27
}
```

路径 `[0, 1, 0]` 在客户 1 处等待至 `t = 10` 开工（距离 6），路径 `[0, 3, 2, 4, 0]` 在 `t = [5, 12, 22]` 服务并在 `28 <= 40` 返回配送中心（距离 21），总费用为 $6 + 21 =$ **27**。
