# #010. 生産ライン稼働と固定費つき生産計画

<!-- section:scenario -->
ペットボトル飲料のボトリング工場で、複数の候補ラインのうちどれを稼働させ、どれだけ飲料を生産する（千本）かを決定します。各ラインを稼働させると固定の段取り費が発生し、そのラインの最大能力まで連続量で生産できるようになります（稼働させないラインでは生産できません）。

また、各ラインでの生産は 1 千本あたり一定の粗利益を生む一方で、工場全体で共有する樹脂ペレット（kg）の在庫を一定量ずつ消費します。樹脂ペレットの在庫上限を守りつつ、総粗利益から固定費の合計を引いた**純利益を最大化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `margins` | `number[]` | 各ラインの 1 千本あたりの粗利益 |
| `fixedCosts` | `number[]` | 各ラインを稼働させたときに発生する固定費 |
| `capacities` | `number[]` | 各ラインの最大生産能力 (千本) |
| `materialUsages` | `number[]` | 各ライン 1 千本あたりの樹脂ペレット消費量 (kg) |
| `materialCap` | `number` | 工場全体の樹脂ペレット在庫量 (kg) |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `open` | `number[]` | 各ラインの稼働選択（0 または 1） |
| `quantities` | `number[]` | 各ラインの生産量 (千本・連続値) |
| `netProfit` | `number` | 最大化された純利益（粗利合計 − 固定費合計） |

<!-- section:example -->
**入力例**

```json
{
  "margins": [50, 40, 35],
  "fixedCosts": [600, 300, 250],
  "capacities": [30, 40, 25],
  "materialUsages": [2, 1.5, 1],
  "materialCap": 70
}
```

**出力例**

```json
{
  "open": [0, 1, 1],
  "quantities": [0, 30, 25],
  "netProfit": 1525
}
```

`open = [0, 1, 1]`（0 始まりのライン 1・2 を稼働）、`quantities = [0, 30, 25]` とすると、稼働制約・能力上限と樹脂ペレットの上限（$30 \times 1.5 + 25 \times 1 = 70 \le 70$ kg）を満たし、純利益は $(40 \times 30 + 35 \times 25) - (300 + 250) =$ **1,525** となります。
