# #074. 资源受限项目调度问题 (RCPSP)

<!-- section:scenario -->
某土木建筑工程（包括土方开挖、基础施工、钢结构吊装、管道铺设与室内装修等）包含 $n$ 个不可抢占的整数工期任务，任务之间通过有向无环紧前关系相连：对每一组紧前关系，紧前任务必须完工后紧后任务才能开始。任务在执行期间会持续占用一种或多种共享可再生资源（如起重机与专业施工班组）。

任一时刻每种资源的总占用量都不能超过其容量上限。请为所有任务安排非负整数开工时间，使所有紧前关系与资源容量限制均成立且项目的最大完工时间最小。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `durations` | `number[]` | 各任务 $i$ 的整数工期 $d_i$（长度 $n$） |
| `demands` | `number[][]` | 任务 $i$ 对资源 $r$ 的占用需求 $q_{r,i}$（`demands[r][i]`，$R \times n$） |
| `capacities` | `number[]` | 各可再生资源 $r$ 的容量上限 $C_r$（长度 $R$） |
| `precedences` | `number[][]` | 从 0 开始的任务编号对 `[u, v]`，表示任务 `u` 完工后任务 `v` 才能开始 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `starts` | `number[]` | 各任务的非负整数开工时间 $S_i \ge 0$ |
| `makespan` | `number` | 最小化的项目总工期 $\max_i (S_i + d_i)$ |

<!-- section:example -->
**输入示例**

```json
{
  "durations": [3, 3, 4, 2, 2],
  "demands": [
    [2, 2, 2, 1, 2]
  ],
  "capacities": [3],
  "precedences": [[0, 1], [0, 3], [1, 4], [2, 4], [3, 4]]
}
```

**输出示例**

```json
{
  "starts": [0, 7, 3, 5, 10],
  "makespan": 12
}
```

各任务按 T0: [0,3)、T2: [3,7)、T3: [5,7)（并发资源需求 $2 + 1 = 3 \le 3$）、T1: [7,10)、T4: [10,12) 执行时满足全部紧前关系与资源容量限制，各任务完工时间为 [3, 10, 7, 7, 12]，总工期为 $\max(3, 10, 7, 7, 12) =$ **12**。

<!-- section:hint1 -->
使用约束规划，为每项任务定义一个整数开工时间变量。模型结合每条依赖边对应的有向无环紧前约束，以及每种可再生资源池对应的累积资源约束。

<!-- section:hint2 -->
使用 `{ solver: "pumpkin" }` 创建模型，并以所有任务工期之和作为 `horizon`，将每个 `m.integer(...)` 限制在 0 到 `horizon - d` 之间。针对每种资源 $r$，收集需求量为正的任务 `{ start, duration, demand }` 并施加 `cumulative(tasks, cap)`，最后无需离散化时间桶，直接对所有任务的完工时间最小化 `max(...)`。
