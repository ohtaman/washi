# #021. 极小化极大服务器负载均衡（上境图线性化）

<!-- section:scenario -->
集群运维人员正计划将提交到分布式计算集群的多个批处理任务（每个任务具有规定的工作量［负载单位］，可按任意比例切分）分配到各台服务器上。每个任务只能分配给兼容标志为 1 的服务器，不兼容服务器上的分配比例必须为 0。

在保证所有任务合计处理 100%（比例为 1）的前提下，运用“上境图线性化”思路——用一个上界变量从上方约束最大负载并对其进行最小化——求出能**最小化最繁忙服务器负载（峰值负载）**的分配比例。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `weights` | `number[]` | 每个任务 $i$ 的总工作量（负载单位） |
| `compatible` | `number[][]` | 若任务 $i$ 可分配给服务器 $j$ 则为 1，否则为 0 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `assignments` | `number[][]` | 任务 $i$ 分配给服务器 $j$ 的比例（`[0, 1]`） |
| `peakLoad` | `number` | 最小化后的最大服务器负载 |

<!-- section:example -->
**输入示例**

```json
{
  "weights": [10, 8, 6],
  "compatible": [
    [1, 0],
    [1, 1],
    [0, 1]
  ]
}
```

**输出示例**

```json
{
  "assignments": [
    [1, 0],
    [0.25, 0.75],
    [0, 1]
  ],
  "peakLoad": 12
}
```

任务 0 全部分配给服务器 0，任务 2 全部分配给服务器 1，并将任务 1 按 0.25 : 0.75 切分，使服务器 0 负载为 $10 + 8 \times 0.25 = 12$、服务器 1 负载为 $8 \times 0.75 + 6 = 12$，峰值负载为 **12**。


<!-- section:hint1 -->
创建一个按任务和服务器索引的连续分配比例矩阵，将每个条目的上界设为对应的兼容标志，从而自动把不兼容组合固定为零。再引入一个额外的连续标量变量，表示整个集群中的最大服务器负载。

<!-- section:hint2 -->
为了在不使用非线性 `max` 运算符的情况下线性化“最小化最大值”，可以采用上境图（epigraph）重构：用辅助标量峰值变量上界约束每台服务器的负载并直接最小化该标量。最小化会压低峰值直到至少一台服务器取等号，从而使最优标量等于真实的最大负载。
