# #073. ジョブショップ・スケジューリング（CP disjoint 制約）

<!-- section:scenario -->
精密切削加工工場にある複数の工作機械（旋盤・フライス盤・研削盤など）で、複数の部品加工ジョブを処理します。各ジョブには決められた工程順序があり、各工程は指定された機械上で所定の整数時間だけ中断せずに処理されます。

1 台の機械は同時に 1 つの工程しか処理できません。各ジョブ内の工程順序と各機械の非重複を守り、全工程が終わる最終完了時刻（メイクスパン）を最小化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `machines` | `number[][]` | ジョブ $j$ の工程 $o$ が使用する 0 始まりの機械番号（0 から $M - 1$） |
| `durations` | `number[][]` | ジョブ $j$ の工程 $o$ の処理時間（整数）$d_{j,o}$ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `starts` | `number[][]` | 各工程の開始時刻 $S_{j,o} \ge 0$（整数） |
| `makespan` | `number` | 最小化された最大完了時刻 $\max_{j,o} (S_{j,o} + d_{j,o})$ |

<!-- section:example -->
**入力例**

```json
{
  "machines": [
    [0, 1, 2],
    [0, 2, 1],
    [1, 2, 0]
  ],
  "durations": [
    [3, 2, 2],
    [2, 1, 4],
    [4, 3, 2]
  ]
}
```

**出力例**

```json
{
  "starts": [
    [2, 5, 7],
    [0, 2, 7],
    [0, 4, 7]
  ],
  "makespan": 11
}
```

各ジョブの工程順序は J0: $[2, 5) \to [5, 7) \to [7, 9)$、J1: $[0, 2) \to [2, 3) \to [7, 11)$、J2: $[0, 4) \to [4, 7) \to [7, 9)$ となり、各機械上の非重複もすべて満たします。各ジョブの最終工程完了時刻はそれぞれ $7 + 2 = 9$、$7 + 4 = 11$、$7 + 2 = 9$ となるため、メイクスパンは $\max(9, 11, 9) =$ **11** となります。

<!-- section:hint1 -->
制約プログラミングを用い、各ジョブの各工程に対して整数の開始時刻変数を用意します。モデルは、同一ジョブ内の連続工程間の先行制約と、各機械ごとの非重複グローバル制約で構成します。

<!-- section:hint2 -->
`{ solver: "pumpkin" }` を指定してモデルを作成し、全工程の処理時間合計を `horizon` として各 `m.integer(...)` を 0 から `horizon - d` に抑えます。同じ機械を使う工程を `{ start, duration }` としてまとめて `disjoint(...)` に渡し（工程が 2 つ未満の機械はスキップ可能です）、全工程の完了時刻に対して `max(...)` を最小化してください。
