# #075. シフト需要・勤務回数・希望休を満たす勤務表作成

<!-- section:scenario -->
大型カフェ店舗において、$N$ 人のバリスタ（スタッフ）を対象に、$D$ 日間・1 日 $S$ 種類（早番・遅番など）のシフト勤務表を作成します。各スタッフは 1 日につき最大 1 シフトまでしか入れず、事前に指定された休日には勤務できません。また、期間全体の勤務回数には個人ごとの下限と上限があります。

各日・各シフトには最低必要人数が定められており、スタッフとシフトの組ごとに人件費（コスト）が異なります。すべての必要人数と勤務回数・休日条件を満たしつつ、総人件費を最小化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[][]` | 日 $d$・シフト $s$ の最低必要人数（$D \times S$） |
| `shiftCosts` | `number[][]` | スタッフ $i$ がシフト $s$ に就く際のコスト（$N \times S$） |
| `minShifts` | `number[]` | 各スタッフの期間内最小勤務回数 |
| `maxShifts` | `number[]` | 各スタッフの期間内最大勤務回数 |
| `daysOff` | `number[][]` | 各スタッフの指定休日（日番号の配列） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `schedule` | `number[][]` | $N \times D$ 行列（休みは -1、勤務時はシフト番号 0〜S-1） |
| `totalCost` | `number` | 最小化された総シフトコスト |

<!-- section:example -->
**入力例**

```json
{
  "demands": [
    [1, 1],
    [1, 1],
    [1, 1]
  ],
  "shiftCosts": [
    [8, 12],
    [12, 14],
    [11, 18]
  ],
  "minShifts": [2, 2, 2],
  "maxShifts": [2, 3, 2],
  "daysOff": [[1], [], [2]]
}
```

**出力例**

```json
{
  "schedule": [
    [1, -1, 0],
    [-1, 1, 1],
    [0, 0, -1]
  ],
  "totalCost": 70
}
```

各スタッフが指定休（スタッフ 0 は日 1、スタッフ 2 は日 2）と勤務回数 [2, 2, 2] を守り、全日 [1, 1] のシフト需要を満たしたときの総費用は $(12 + 8) + (14 + 14) + (11 + 11) =$ **70** となります。

<!-- section:hint1 -->
スタッフ $i$ を日 $d$ のシフト $s$ に割り当てるかどうかを表す 3 次元の 0-1 決定変数を導入します。スタッフ・日ごとの 1 シフト上限制約と指定休制約、日別シフト需要制約、およびスタッフ別の総勤務回数上下限を組み合わせて定式化します。

<!-- section:hint2 -->
`daysOff` に含まれる日には、そのスタッフ・日の全シフト変数の和を 0（または各変数を 0）に固定します。シフト需要は $\ge$ 制約で表すことで `minShifts` を満たすための余剰配置も許容でき、求解後は各 `(i, d)` について割り当てられたシフト番号（いずれも 0 なら -1）を `schedule[i][d]` として復元します。
