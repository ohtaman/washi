# #093. 反復部分巡回路除去カット（DFJ 法 TSP）

<!-- section:scenario -->
$n$ 都市の対称距離行列が与えられたとき、すべての都市をちょうど 1 回ずつ訪問して出発点に戻る最短ハミルトン閉路を求めます。指数個ある部分巡回路除去制約を最初からすべて列挙する代わりに、各都市の次数が 2 になる 2 次マッチング緩和から開始してください。

反復ごとに整数計画を解き、得られた無向辺グラフから連結成分（閉路）を抽出します。部分巡回路が残っていれば各成分に対して Dantzig-Fulkerson-Johnson カットを追加して再求解し、1 つの連結巡回路になった時点で結果を返してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `distances` | `number[][]` | 対称な $n \times n$ 都市間距離行列（$n \in [5, 8]$） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `tour` | `number[]` | ハミルトン閉路の訪問順を表す $0 \dots n-1$ の順列 |
| `totalDistance` | `number` | 最小化された閉路総距離 |
| `iterations` | `number` | 反復 DFJ カットループで実行した MIP 求解回数 |

<!-- section:example -->
**入力例**

```json
{
  "distances": [
    [0, 3, 4, 25, 26, 27],
    [3, 0, 5, 24, 25, 26],
    [4, 5, 0, 26, 24, 25],
    [25, 24, 26, 0, 4, 3],
    [26, 25, 24, 4, 0, 5],
    [27, 26, 25, 3, 5, 0]
  ]
}
```

**出力例**

```json
{
  "tour": [0, 1, 3, 5, 4, 2],
  "totalDistance": 63,
  "iterations": 2
}
```

都市 `[0, 1, 3, 5, 4, 2]` を巡って `0` に戻る経路は全 6 都市を 1 回ずつ訪問し、総距離は $3 + 24 + 3 + 5 + 24 + 4 =$ **63**、反復回数は **2** 回となります。
