# #012. 固定成本运输网络设计

<!-- section:scenario -->
某果蔬批发商计划设计卡车运输路线，从多个产地集货中心向多家超市配送应季苹果（吨）。使用每条候选路线前，必须先支付一笔包车合同固定费用以开通该路线；路线开通后，可在其最大载重容量（吨）内进行连续量运输，而未开通的路线运输量必须为零。

请在满足各集货中心供货上限和各超市所需需求量的前提下，**最小化**所有开通路线的合同固定费用与按运量比例计算的可变运费之和。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `supplies` | `number[]` | 各集货中心 $i$ 的供货上限（吨） |
| `demands` | `number[]` | 各超市 $j$ 的所需需求量（吨） |
| `fixedCosts` | `number[][]` | 开通路线 $(i, j)$ 的合同固定费用 |
| `unitCosts` | `number[][]` | 路线 $(i, j)$ 每吨的运费 |
| `capacities` | `number[][]` | 路线 $(i, j)$ 开通后的最大载重容量（吨） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `open` | `number[][]` | 表示各路线是否开通的矩阵（0 或 1） |
| `shipments` | `number[][]` | 各路线 $(i, j)$ 的非负连续运输量（吨） |
| `totalCost` | `number` | 最小化后的合同固定费用＋运费总额 |

<!-- section:example -->
**输入示例**

```json
{
  "supplies": [65, 60],
  "demands": [30, 35, 25],
  "fixedCosts": [
    [120, 40, 260],
    [250, 280, 90]
  ],
  "unitCosts": [
    [4, 5, 8],
    [3, 2, 3]
  ],
  "capacities": [
    [40, 40, 30],
    [35, 45, 40]
  ]
}
```

**输出示例**

```json
{
  "open": [
    [1, 1, 0],
    [0, 0, 1]
  ],
  "shipments": [
    [30, 35, 0],
    [0, 0, 25]
  ],
  "totalCost": 620
}
```

开通路线 `(0, 0)`、`(0, 1)` 与 `(1, 2)` 满足载重容量上限、集货中心供货上限（$65 \le 65$、$25 \le 60$）以及超市需求 `[30, 35, 25]`，总成本为 $(120 + 40 + 90) + (30 \times 4 + 35 \times 5 + 25 \times 3) =$ **620**。

<!-- section:hint1 -->
每条路线 $(i, j)$ 都有一个二元开通变量和一个连续运输量变量。将各路线的运输量与开通决策关联，同时用行和表示集货中心供货上限、用列和表示超市需求下限。

<!-- section:hint2 -->
使用路线载重容量 `capacities[i][j]` 作为连接 `shipments[i][j]` 与 `open[i][j]` 的紧上界，使未开通路线的运输量强制为零。目标函数中需同时包含合同固定费用（`fixedCosts`）和单位运费（`unitCosts`）。
