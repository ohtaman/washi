# #074. 資源制約付きプロジェクト・スケジューリング (RCPSP)

<!-- section:scenario -->
有向非巡回グラフ（DAG）の先行関係で結ばれた複数のタスクからなるプロジェクトを計画します。各タスクは中断不可の整数期間をもち、実行中は 1〜2 種類の共有再生可能資源から一定量を消費します。

どの時刻においても各資源の同時使用量が容量上限を超えてはなりません。すべての先行制約と資源容量制約を満たす整数開始時刻を決定し、プロジェクト全体の完了時刻（メイクスパン）を最小化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `durations` | `number[]` | 各タスク $i$ の処理期間（整数）$d_i$ |
| `demands` | `number[][]` | 資源 $r$ におけるタスク $i$ の消費量 $q_{r,i}$ |
| `capacities` | `number[]` | 各再生可能資源 $r$ の利用可能上限 $C_r$ |
| `precedences` | `number[][]` | 先行制約 `[u, v]` のリスト（$S_u + d_u \le S_v$） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `starts` | `number[]` | 各タスクの開始時刻 $S_i \ge 0$（整数） |
| `makespan` | `number` | 最小化された最終完了時刻 $\max_i (S_i + d_i)$ |

<!-- section:example -->
**入力例**

```json
{
  "durations": [3, 3, 4, 2, 2],
  "demands": [
    [2, 2, 2, 1, 2]
  ],
  "capacities": [3],
  "precedences": [[0, 1], [0, 3], [1, 4], [2, 4], [3, 4]]
}
```

**出力例**

```json
{
  "starts": [0, 7, 3, 5, 10],
  "makespan": 12
}
```

`T0: [0,3)`、`T2: [3,7)`、`T3: [5,7)`（同時使用量 $2 + 1 = 3 \le 3$）、`T1: [7,10)`、`T4: [10,12)` と配置するとすべての先行制約と資源上限を満たし、メイクスパンは **12** となります。

<!-- section:hint1 -->
制約プログラミング（`{ solver: "pumpkin" }`）を用い、各タスクに対して整数の開始時刻変数を用意します。各依存ペアに対する有向非巡回グラフの先行制約と、各再生可能資源ごとの累積資源制約を組み合わせてモデル化します。

<!-- section:hint2 -->
全タスクの所要時間合計を `horizon` として各 `m.integer(...)` を `0` から `horizon - d` の範囲に抑えます。各資源 $r$ について需要が正のタスクを `{ start, duration, demand }` として集め `cumulative(tasks, cap)` を課した上で、時間を離散化せずに全タスク完了時刻の `max(...)` を最小化してください。
