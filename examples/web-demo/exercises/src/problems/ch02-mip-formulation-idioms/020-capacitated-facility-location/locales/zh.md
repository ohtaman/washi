# #020. 带容量约束的设施选址问题（CFLP）

<!-- section:scenario -->
某精品咖啡烘焙商需要同时决定开设哪些候选烘焙工坊，以及每月从已开设的烘焙工坊向各咖啡门店配送多少公斤烘焙咖啡豆。开设一座烘焙工坊会产生固定的运营费用，并允许在该工坊的月度发货能力（kg）以内发出咖啡豆（未开设的工坊发货量必须为零）。

请在满足每家咖啡门店月度需求（kg）的前提下，**最小化**已开设工坊的固定运营费与按发货量计算的配送费之和。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `fixedCosts` | `number[]` | 各候选烘焙工坊 $i$ 的固定运营费 |
| `capacities` | `number[]` | 各候选烘焙工坊 $i$ 的月度发货能力上限（kg） |
| `demands` | `number[]` | 各咖啡门店 $j$ 的所需需求量（kg） |
| `unitCosts` | `number[][]` | 从烘焙工坊 $i$ 到咖啡门店 $j$ 每公斤的配送费 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `open` | `number[]` | 各候选烘焙工坊是否开设的选择（0 或 1） |
| `shipments` | `number[][]` | 从烘焙工坊 $i$ 到咖啡门店 $j$ 的非负连续发货量（kg） |
| `totalCost` | `number` | 最小化后的固定运营费＋配送费总额 |

<!-- section:example -->
**输入示例**

```json
{
  "fixedCosts": [320, 260, 290],
  "capacities": [60, 50, 55],
  "demands": [25, 30, 20, 25],
  "unitCosts": [
    [4, 6, 9, 10],
    [7, 3, 5, 8],
    [10, 7, 4, 3]
  ]
}
```

**输出示例**

```json
{
  "open": [0, 1, 1],
  "shipments": [
    [0, 0, 0, 0],
    [20, 30, 0, 0],
    [5, 0, 20, 25]
  ],
  "totalCost": 985
}
```

开设烘焙工坊 1 与 2 后满足发货能力约束（$50 \le 50$、$50 \le 55$）与咖啡门店需求 25、30、20、25 kg，总成本为 $(260 + 290) + (20 \times 7 + 30 \times 3 + 5 \times 10 + 20 \times 4 + 25 \times 3) =$ **985**。

<!-- section:hint1 -->
将表示各烘焙工坊是否开设的二元变量与从烘焙工坊到咖啡门店的连续发货量矩阵结合起来。需要对每座工坊的总发货量建立发货能力耦合约束，并对每家咖啡门店的总收货量建立需求满足约束。

<!-- section:hint2 -->
将每座烘焙工坊 $i$ 的总发货量（对所有咖啡门店 $j$ 求和）限制在 `capacities[i] * open[i]` 以内，即可同时禁止未开设工坊发货并限制已开设工坊的发货上限。目标函数中需同时包含固定运营费（`fixedCosts`）和单位配送费（`unitCosts`）进行最小化。
