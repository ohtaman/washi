# #087. 带追索权的两阶段随机规划

<!-- section:scenario -->
在随机客户需求揭晓之前，分销商需要在公共仓库容量限制下提前确定多种产品的第一阶段连续订货量，并按单位订货成本预先采购。

随后，各需求情景按给定概率实现，系统执行第二阶段追索调整：对于需求超出订货量的缺口，需支付高额紧急补货罚金；对于未售出的多余库存，则可按较低残值回收部分收益。请确定非负的第一阶段订货量，以最小化预先采购成本与期望第二阶段净追索成本之和。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `orderCosts` | `number[]` | 各产品的第一阶段单位采购成本 |
| `shortageCosts` | `number[]` | 各产品第二阶段每单位缺货惩罚成本 |
| `salvageValues` | `number[]` | 各产品剩余库存每单位的回收残值 |
| `warehouseCap` | `number` | 第一阶段总订货量的仓库容量上限 |
| `probs` | `number[]` | 各情景 $s$ 的概率权重 $p_s$ |
| `demands` | `number[][]` | 情景需求矩阵（$S \times n$） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `orders` | `number[]` | 非负第一阶段订货量向量 |
| `expectedCost` | `number` | 所有情景下的最小化期望总成本 |

<!-- section:example -->
**输入示例**

```json
{
  "orderCosts": [4, 6],
  "shortageCosts": [14, 18],
  "salvageValues": [1, 2],
  "warehouseCap": 30,
  "probs": [0.5, 0.5],
  "demands": [
    [10, 8],
    [20, 16]
  ]
}
```

**输出示例**

```json
{
  "orders": [14, 16],
  "expectedCost": 184
}
```

订货 `[14, 16]` 满足仓库上限 $14 + 16 = 30 \le 30$，前期采购成本 $4(14) + 6(16) = 152$，情景 0 回收残值 $20$，情景 1 缺货罚金 $84$，期望总成本为 $152 + 0.5(-20) + 0.5(84) =$ **184**。


<!-- section:hint1 -->
构建包含全情景共享的非负第一阶段订货量向量，以及按情景索引的非负第二阶段短缺量与剩余库存向量的确定性等价线性规划。用仓库容量限制第一阶段总订货量，将每个情景的补偿变量与情景需求关联，并最小化初期订货成本与按概率加权的期望净补偿成本之和。

<!-- section:hint2 -->
注意两点：第一阶段订货量必须是不分情景的共享决策向量（非预期性）；在最小化目标中，残值回收收入必须带负号减去而非相加。由于 `shortageCosts` 高于 `salvageValues`，同一产品在同一情景下不会同时出现短缺与剩余。
