# #051. 最小费用流与全幺模性 (TU)

<!-- section:scenario -->
在包含供应点、中转枢纽与需求点的有向物流网络中运输货物。每个节点都有整数净供给量（供应点为正、需求点为负、中转点为零），每条有向边均有容量上限和单位运输成本。

请将其建模为纯连续线性规划（LP），在满足所有边容量限制和节点流量守恒的前提下 **最小化总运输费用**。由于有向图的节点-边关联矩阵具有全幺模性，当供需和容量全为整数时，纯连续 LP 的最优顶点解将自动为整数。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `supplies` | `number[]` | 各节点的整数净供给（正为供应、负为需求、0 为中转） |
| `edges` | `Array<{ from, to, cap, cost }>` | 有向边列表（起点 `from`、终点 `to`、容量 `cap`、单位费用 `cost`） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `flows` | `number[]` | 与 `edges` 一一对应的边流量（`0 <= flow <= cap`） |
| `totalCost` | `number` | 最小化后的总运输成本 |

<!-- section:example -->
**输入示例**

```json
{
  "supplies": [10, 0, 0, -10],
  "edges": [
    { "from": 0, "to": 1, "cap": 6, "cost": 2 },
    { "from": 0, "to": 2, "cap": 8, "cost": 4 },
    { "from": 1, "to": 2, "cap": 5, "cost": 1 },
    { "from": 1, "to": 3, "cap": 4, "cost": 3 },
    { "from": 2, "to": 3, "cap": 7, "cost": 2 }
  ]
}
```

**输出示例**

```json
{
  "flows": [6, 4, 2, 4, 6],
  "totalCost": 54
}
```

节点 0 净流出 $6 + 4 = 10$，中转节点 1 和 2 净收支为 0，节点 3 净流入 $4 + 6 = 10$，总运输成本为 $6\times 2 + 4\times 4 + 2\times 1 + 4\times 3 + 6\times 2 =$ **54**。

<!-- section:hint1 -->
为每条有向边定义一个以边容量为上界的非负连续流量变量。按节点组织流量守恒约束，使每个节点的流出总量减去流入总量等于该节点的净供给量，并最小化所有边的总运输费用。

<!-- section:hint2 -->
由于有向图的节点-边关联矩阵具有全幺模性，且供需与容量均为整数，纯连续 LP 的最优顶点解必然为整数——无需任何整数或二进制变量。直接返回连续解 `v.value!`（Python 中为 `float(pulp.value(v))`）而无需取整，必要时将 `-0` 规范化为 `0` 即可。
