# #018. 依存・排反制約つき多次元 0-1 ナップサック

<!-- section:scenario -->
開発チームが次期リリースに含める機能候補を選定しています。各機能にはユーザー価値が設定されており、開発工数・計算資源・検証枠といった複数の共有資源をそれぞれ消費します。

さらに技術要件として、ある機能を搭載するには前提となる基盤機能の搭載が必須である依存ペアと、設計上同時に搭載できない非両立ペアが定められています。すべての資源上限と依存・排反条件を守り、**獲得価値の合計を最大化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `values` | `number[]` | 各機能候補の獲得価値 |
| `weights` | `number[][]` | 各資源の消費量行列（`weights[k][j]` が資源 $k$ の機能 $j$ による消費量） |
| `capacities` | `number[]` | 各資源 $k$ の利用上限 |
| `prerequisites` | `number[][]` | ペア `[a, b]`（機能 `a` を選ぶなら `b` も選択必須） |
| `incompatibles` | `number[][]` | ペア `[c, d]`（両方を同時選択不可） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `selected` | `number[]` | 各機能の採択有無（`0` または `1`） |
| `totalValue` | `number` | 最大化された総価値 |

<!-- section:example -->
**入力例**

```json
{
  "values": [8, 24, 22, 19, 15],
  "weights": [
    [5, 6, 4, 5, 3],
    [3, 6, 5, 4, 6]
  ],
  "capacities": [13, 13],
  "prerequisites": [[3, 0]],
  "incompatibles": [[1, 2]]
}
```

**出力例**

```json
{
  "selected": [1, 0, 0, 1, 1],
  "totalValue": 42
}
```

機能 `{0, 3, 4}` を選ぶと、資源 0 は `5 + 5 + 3 = 13 <= 13`、資源 1 は `3 + 4 + 6 = 13 <= 13` で収まり、前提 `3 -> 0` と非両立 `[1, 2]` を満たして総価値は $8 + 19 + 15 =$ **42** となります。
