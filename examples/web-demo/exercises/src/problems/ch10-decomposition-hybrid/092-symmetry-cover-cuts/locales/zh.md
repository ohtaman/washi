# #092. 对称性破除与覆盖割平面

<!-- section:scenario -->
将一组带重量物品装入若干个相同容量的箱子中，目标是最小化所使用的箱子数量。由于箱子之间完全等价，标准 MIP 模型存在大量对称解，且连续 LP 松弛下界往往仅等于总重量除以箱容量。

请加入前缀启用顺序约束、将物品 0 放入箱 0 以及限制物品 i 仅能放入不大于 i 的箱子以破除对称性；再加入向上取整的全局容量割与扩展极小覆盖不等式收紧 LP 松弛，返回最终装箱方案、所用箱数和强化后的 LP 松弛下界。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `weights` | `number[]` | 每个物品 $i \in \{0, \dots, n-1\}$ 的重量 |
| `binCapacity` | `number` | 单个箱子允许的最大总重量 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `assignments` | `number[]` | 每个物品分配的箱号（从 0 开始连续编号且 `assignments[0] = 0`） |
| `binsUsed` | `number` | 最少使用的箱子总数 |
| `lpBound` | `number` | 加入对称性破除、容量割与覆盖割后的 LP 松弛目标值 |

<!-- section:example -->
**输入示例**

```json
{
  "weights": [6, 6, 6, 2],
  "binCapacity": 10
}
```

**输出示例**

```json
{
  "assignments": [0, 1, 2, 2],
  "binsUsed": 3,
  "lpBound": 3
}
```

将重量 `[6]`、`[6]`、`[6, 2]` 分别放入箱 `0, 1, 2`，各箱负载分别为 `6, 6, 8 <= 10`，箱号连续从 0 启用，共使用 **3** 个箱子且 LP 松弛下界达到 **3**。

<!-- section:hint1 -->
使用二元变量分别表示每个箱子是否启用以及每个物品是否放入某个箱子，以最小化启用箱子总数。除每个物品恰好放入一个箱子和箱容量约束外，还需加入箱子前缀顺序约束以及物品序号对箱号的上界限制。

<!-- section:hint2 -->
为破除对称性，要求箱子启用变量单调非增（$u_k \ge u_{k+1}$），并禁止将物品 $i$ 放入 $k > i$ 的箱子。为得到强化后的 LP 下界，加入向上取整的全局容量割 $\sum_k u_k \ge \lceil \sum_i w_i / B \rceil$，并对每个极小覆盖 $C$（$\sum_{i \in C} w_i > B$ 且去掉最轻物品后不超过 $B$）构造扩展集合 $E(C) = C \cup \{j : w_j \ge \max_{i \in C} w_i\}$，对每个箱 $k$ 添加 $\sum_{i \in E(C)} x_{ik} \le (|C| - 1) u_k$；最后在 `m.solve()` 之前通过 `m.relax()` 读取 `lpBound`。
