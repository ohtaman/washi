# #062. 多品目带产能约束批量计划 (CLSP)

<!-- section:scenario -->
某烘焙工坊使用同一台共享烤箱在多个周期内烤制多种点心（如费南雪和玛德琳等，各品目的期初库存均为零）。只要在某一期生产某种点心，就必须为该品目进行换产准备，产生固定开机成本并占用固定换产工时。

在每个周期，所有点心消耗的总加工工时与换产工时之和不能超过该期的烤箱可用总工时。请决策各期各品目的开机开关、连续生产量及期末库存量，在满足全部需求的前提下 **最小化总开机成本与库存持有成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `demands` | `number[][]` | 品目 $i$ 在周期 $t$ 的需求量 $d_{i,t}$ |
| `setupCosts` | `number[]` | 品目 $i$ 每次开机的固定成本 $F_i$ |
| `holdCosts` | `number[]` | 品目 $i$ 每单位每期的库存持有成本 $h_i$ |
| `unitTimes` | `number[]` | 品目 $i$ 单位产量的机台加工工时 $a_i$ |
| `setupTimes` | `number[]` | 品目 $i$ 开机一次占用的换产工时 $s_i$ |
| `capacities` | `number[]` | 周期 $t$ 的机台可用总工时上限 $H_t$ |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `setups` | `number[][]` | $I \times T$ 的 0/1 开机矩阵 |
| `production` | `number[][]` | $I \times T$ 的非负生产量矩阵 |
| `inventory` | `number[][]` | $I \times T$ 的非负期末库存矩阵 |
| `totalCost` | `number` | 最小化后的总开机与持有成本 |

<!-- section:example -->
**输入示例**

```json
{
  "demands": [
    [20, 30, 15, 25],
    [10, 25, 30, 15]
  ],
  "setupCosts": [120, 150],
  "holdCosts": [2, 2.5],
  "unitTimes": [1.5, 2.0],
  "setupTimes": [12, 15],
  "capacities": [110, 100, 115, 100]
}
```

**输出示例**

```json
{
  "setups": [
    [1, 1, 1, 1],
    [1, 1, 1, 1]
  ],
  "production": [
    [20, 30, 15, 25],
    [21, 14, 30, 15]
  ],
  "inventory": [
    [0, 0, 0, 0],
    [11, 0, 0, 0]
  ],
  "totalCost": 1107.5
}
```

在第 0 期提前多生产 11 件品目 1，使第 1 期机台负荷恰好为 $12 + 15 + 1.5(30) + 2.0(14) = 100 \le 100$，总成本为 $4(120 + 150) + 11 \times 2.5 =$ **1,107.5**。


<!-- section:hint1 -->
为每个品目和每个周期定义二元开机指示变量、连续生产量变量及非负期末库存变量，组织为 $I \times T$ 矩阵。模型将各品目独立的库存平衡链与每期共享的机器工时上限约束结合在一起。

<!-- section:hint2 -->
将品目产量与其开机变量关联时，应使用紧致的有效上界——例如从第 $t$ 期起的剩余累计需求——而不是随意选取大常数。在每期的机器产能约束中，需要同时累加所有品目的单位加工时间与固定开机时间。
