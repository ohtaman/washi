# #060. 连通辖区划分与枢纽巡回路径（章末综合）

<!-- section:scenario -->
区域服务规划需要将 n 个小区划分为 K 个互不相交的连通服务辖区，并在每个辖区选定一个枢纽中心小区。每个辖区在地理邻接图上必须保持连通（不允许出现孤立飞地），辖区总需求必须落在均衡上下界之内，同时内部还需运行一条服务该辖区所有小区的闭合巡回配送路线。

将 n 个小区划分为 K 个连通辖区——每个辖区选定一个枢纽、满足需求均衡上下界，并以单一闭合巡回服务区内所有小区——从而 **最小化枢纽开设成本与巡回行驶距离之和**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `numTerritories` | `number` | 需划分的连通辖区数量 $K$ |
| `demands` | `number[]` | 各小区 `0 .. n - 1` 的需求量 |
| `demandBounds` | `number[]` | 每个辖区的总需求均衡区间 `[minDemand, maxDemand]`（`minDemand > max(demands)`） |
| `hubCosts` | `number[]` | 在小区 `i` 设立枢纽的固定成本 |
| `adjEdges` | `number[][]` | 刻画地理相邻关系的无向邻接边 `[u, v]` 列表 |
| `dist` | `number[][]` | $n \times n$ 小区间巡回行驶距离矩阵 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `territories` | `Array<{ hub, tour }>` | $K$ 个辖区的枢纽 `hub` 与闭环路线 `[hub, ..., hub]` |
| `totalCost` | `number` | 最小化后的枢纽固定费用与巡回距离之和 |

<!-- section:example -->
**输入示例**

```json
{
  "numTerritories": 2,
  "demands": [3, 4, 3, 4, 3],
  "demandBounds": [6, 11],
  "hubCosts": [5, 12, 14, 10, 6],
  "adjEdges": [[0, 1], [1, 2], [2, 3], [3, 4], [1, 3]],
  "dist": [
    [0, 3, 6, 5, 8],
    [3, 0, 3, 3, 5],
    [6, 3, 0, 5, 5],
    [5, 3, 5, 0, 3],
    [8, 5, 5, 3, 0]
  ]
}
```

**输出示例**

```json
{
  "territories": [
    { "hub": 0, "tour": [0, 2, 1, 0] },
    { "hub": 4, "tour": [4, 3, 4] }
  ],
  "totalCost": 29
}
```

辖区 `{0, 1, 2}`（需求 `10 ∈ [6, 11]`，经 `0-1-2` 连通）选择枢纽 0（费用 5）与路线 `[0, 2, 1, 0]`（距离 12），辖区 `{3, 4}`（需求 `7 ∈ [6, 11]`，经 `3-4` 连通）选择枢纽 4（费用 6）与路线 `[4, 3, 4]`（距离 6），总成本为 $(5 + 6) + (12 + 6) =$ **29**。

<!-- section:hint1 -->
定义小区归属二进制变量与枢纽选址二进制变量（只有小区归属于某辖区时才能选作该辖区的枢纽），约束每个小区属于唯一辖区、每个辖区选出唯一枢纽且总需求落在 `demandBounds` 内。在此基础上耦合两层网络：沿 `adjEdges` 按辖区流动的单商品流层（保证地理连通）以及由有向巡回弧与访问顺序位势构成的辖区内 TSP 巡回层。

<!-- section:hint2 -->
对于辖区 `k` 的连通性，仅允许所选枢纽注入连续供给 $s_{ik} \le n h_{ik}$，并沿 `adjEdges` 向每个 $y_{ik} = 1$ 的小区输送 1 单位流量（边 `(u, v)` 上的流量需同时受 $y_{uk}$ 和 $y_{vk}$ 限制）。对于巡回路径，禁止跨辖区连边（$y_{ik} - y_{jk} \le 1 - x_{ij}$），并使用以各辖区枢纽为锚点的 MTZ 约束（$u_i + 1 - u_j \le n (1 - x_{ij} + \sum_k h_{jk})$），使位势仅在返回枢纽时重置，从而消除子环路。
