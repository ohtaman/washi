# #093. 迭代子环消除割平面（DFJ 法 TSP）

<!-- section:scenario -->
给定 $n$ 座城市的对称距离矩阵，使用迭代 Dantzig-Fulkerson-Johnson（DFJ）子环消除循环求解恰好访问每座城市一次并返回起点的最短哈密顿回路。为避免预先枚举指数级子环消除约束，求解器从 2-匹配松弛出发，反复分离断开的子环，直至得到单一连通巡回。

返回最优巡回顺序、总距离以及执行的 MIP 求解次数。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `distances` | `number[][]` | 对称的 $n \times n$ 城市距离矩阵（$n \in [5, 8]$） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `tour` | `number[]` | $0 \dots n-1$ 的一个排列，表示哈密顿回路访问顺序 |
| `totalDistance` | `number` | 最小化后的闭合回路总长度 |
| `iterations` | `number` | DFJ 迭代割平面循环执行的 MIP 求解次数 |

<!-- section:example -->
**输入示例**

```json
{
  "distances": [
    [0, 3, 4, 25, 26, 27],
    [3, 0, 5, 24, 25, 26],
    [4, 5, 0, 26, 24, 25],
    [25, 24, 26, 0, 4, 3],
    [26, 25, 24, 4, 0, 5],
    [27, 26, 25, 3, 5, 0]
  ]
}
```

**输出示例**

```json
{
  "tour": [0, 1, 3, 5, 4, 2],
  "totalDistance": 63,
  "iterations": 2
}
```

按 `[0, 1, 3, 5, 4, 2]` 顺序访问并返回 `0` 遍历了全部 6 座城市，总距离为 $3 + 24 + 3 + 5 + 24 + 4 =$ **63**，共迭代 **2** 轮。

<!-- section:hint1 -->
为每对不同城市的无向边引入一个二元选择变量并最小化总路径长度。将求解流程组织为迭代割平面循环：从仅含度数约束的松弛模型出发，每次检测并截断不连通的子环，直到只剩一条单一连通巡回为止。

<!-- section:hint2 -->
用满足 $i < j$ 的有序对 $(i, j)$ 索引无向边，并约束每座城市度数为 2。由于每个顶点度数均为 2，任何不连通的整数解都会分解为若干不相交的环 $S$。对每个满足 $|S| < n$ 的子环 $S$，向同一模型添加 DFJ 割 $\sum_{i, j \in S,\, i < j} x_{ij} \le |S| - 1$ 后重新求解，并在每次调用 `solve()` 时累加 `iterations`。
