# #009. 多期間生産・在庫計画（フロー保存則）

<!-- section:scenario -->
電動自転車の組立工場で、複数期（月ごと）にわたる通常生産・残業生産・期末在庫のスケジュールを計画します。期首在庫（台）が与えられており、各期では通常生産能力・残業生産能力・倉庫の保管容量の上限を守る必要があります。

各期において「前期在庫 ＋ 通常生産 ＋ 残業生産 − 需要 ＝ 期末在庫」の収支が成り立ち、さらに最終期の末には規定の安全在庫以上を残さなければなりません。各期の通常生産台数・残業生産台数・期末在庫台数を決めて、**通常生産費・残業費・保管費の合計コストを最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[]` | 各期 $t$ の自転車の需要台数 |
| `regCap` | `number[]` | 各期 $t$ の通常生産の能力上限 (台) |
| `otCap` | `number[]` | 各期 $t$ の残業生産の能力上限 (台) |
| `invCap` | `number` | 各期末に倉庫で保管できる台数の上限 |
| `initialInventory` | `number` | 期首（0期開始前）の初期在庫 (台) |
| `minFinalInventory` | `number` | 最終期末に残すべき最低安全在庫 (台) |
| `regCost` | `number` | 通常生産 1 台あたりのコスト |
| `otCost` | `number` | 残業生産 1 台あたりのコスト |
| `holdCost` | `number` | 在庫 1 台・1 期あたりの保管コスト |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `regular` | `number[]` | 各期の通常生産台数スケジュール |
| `overtime` | `number[]` | 各期の残業生産台数スケジュール |
| `inventory` | `number[]` | 各期の期末在庫台数スケジュール |
| `totalCost` | `number` | 最小化された総生産＋保管コスト |

<!-- section:example -->
**入力例**

```json
{
  "demands": [80, 140, 120, 70],
  "regCap": [100, 100, 100, 100],
  "otCap": [40, 40, 40, 40],
  "invCap": 60,
  "initialInventory": 10,
  "minFinalInventory": 10,
  "regCost": 20,
  "otCost": 32,
  "holdCost": 3
}
```

**出力例**

```json
{
  "regular": [100, 100, 100, 80],
  "overtime": [0, 10, 20, 0],
  "inventory": [30, 0, 0, 10],
  "totalCost": 8680
}
```

初期在庫 10 から各期の在庫収支と上下限（期末在庫 `[30, 0, 0, 10]` ≤ 60、最終在庫 10 ≥ 10）を満たし、総コストは $380 \times 20 + 30 \times 32 + 40 \times 3 =$ **8,680** となります。
