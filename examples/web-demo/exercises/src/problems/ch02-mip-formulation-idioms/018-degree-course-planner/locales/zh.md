# #018. 大学学位选课与先修课程规划

<!-- section:scenario -->
一名大学生正在规划下学期要选修的课程组合。每门候选课程都有一个兴趣分值，并会占用多个有限工作量类别（如每周学习时长、实验课时、学分等）的额度。

选课方案必须满足以下所有条件：
- **各类别上限**：学习时长、实验课时、学分等各工作量类别的总量不得超过各自的上限。
- **先修课程**：选修带有先修要求的课程时，必须同时选修其先修课程。
- **时间冲突**：上课时间重叠的课程对不能同时选修。

请在满足所有条件的前提下，选择课程子集以**最大化总兴趣分值**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `interest` | `number[]` | 每门候选课程的兴趣分值 |
| `requirements` | `number[][]` | 工作量矩阵，其中 `requirements[k][j]` 表示课程 $j$ 占用类别 $k$ 的量 |
| `caps` | `number[]` | 类别 $k$ 的上限 |
| `prerequisites` | `number[][]` | 先修对 `[prereq, course]`，选修 `course` 时必须同时选修 `prereq` |
| `timeConflicts` | `number[][]` | 上课时间冲突、不能同时选修的课程对 `[a, b]` |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `take` | `number[]` | 每门课程是否选修的二进制选择（0 或 1） |
| `totalInterest` | `number` | 最大化后的总兴趣分值 |

<!-- section:example -->
**输入示例**

```json
{
  "interest": [8, 24, 22, 19, 15],
  "requirements": [
    [5, 6, 4, 5, 3],
    [3, 6, 5, 4, 6]
  ],
  "caps": [13, 13],
  "prerequisites": [[0, 3]],
  "timeConflicts": [[1, 2]]
}
```

**输出示例**

```json
{
  "take": [1, 0, 0, 1, 1],
  "totalInterest": 42
}
```

选修课程 0、3、4 在类别 0 上消耗 $5 + 5 + 3 = 13 \le 13$，在类别 1 上消耗 $3 + 4 + 6 = 13 \le 13$，满足先修关系 $0 \to 3$ 并避开了时间冲突 (1, 2)，总兴趣分值为 $8 + 19 + 15 =$ **42**。

<!-- section:hint1 -->
每门候选课程对应一个二进制选择变量。该模型将每个工作量类别的背包容量约束与先修课程、时间冲突的成对逻辑约束结合在一起。

<!-- section:hint2 -->
矩阵的每一行 `requirements[k]` 对应一条不超过 `caps[k]` 的容量约束。先修对 `[prereq, course]` 线性化为 $x_{\text{course}} \le x_{\text{prereq}}$，时间冲突对 `[a, b]` 线性化为 $x_a + x_b \le 1$。
