# #088. CVaR（条件付きバリュー・アット・リスク）の線形計画最適化

<!-- section:scenario -->
運用担当者は、複数資産への投資比率を決定します。各資産の組入比率は 0 以上かつ個別の上限ウェイト以下であり、全資産の比率の合計はちょうど 1 になる必要があります。既知の確率で起こる各リターンシナリオにおいて、ポートフォリオ損失はリターンの符号を反転した値で定義されます。

非線形計算を使わずに極端な損失（テールリスク）を抑えるため、信頼水準 α における条件付きバリュー・アット・リスク（CVaR）を Rockafellar-Uryasev の線形計画定式化で表現し、資産配分ウェイト・補助 VaR しきい値・CVaR を求めてください。期待損失とリスク重み×CVaR の和を最小化する資産配分を求めます。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `returns` | `number[][]` | シナリオ別の資産リターン行列（$S \times n$） |
| `probs` | `number[]` | 各シナリオ $s$ の生起確率 $p_s$ |
| `alpha` | `number` | テール確率 $1 - \alpha$ を定める信頼水準 $\alpha \in (0, 1)$ |
| `riskWeight` | `number` | $\text{CVaR}_\alpha$ に掛けるリスク回避重み $\lambda$ |
| `maxWeight` | `number` | 1 資産あたりの最大組入比率上限 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `weights` | `number[]` | 合計が 1 になる資産配分ウェイト |
| `varThreshold` | `number` | 最適な補助 VaR しきい値 $\eta$ |
| `cvar` | `number` | ポートフォリオ損失の $\text{CVaR}_\alpha$ |
| `totalObjective` | `number` | 最小化された「期待損失 ＋ $\lambda \cdot \text{CVaR}_\alpha$」 |

<!-- section:example -->
**入力例**

```json
{
  "returns": [
    [0.14, 0.04, 0.01],
    [-0.12, 0.05, 0.02],
    [0.18, -0.02, 0.03],
    [-0.18, -0.06, -0.02]
  ],
  "probs": [0.25, 0.25, 0.25, 0.25],
  "alpha": 0.75,
  "riskWeight": 2.0,
  "maxWeight": 0.7
}
```

**出力例**

```json
{
  "weights": [0, 0.3, 0.7],
  "varThreshold": 0.032,
  "cvar": 0.032,
  "totalObjective": 0.05625
}
```

配分 `[0, 0.3, 0.7]` の各シナリオのリターンは `[0.019, 0.029, 0.015, -0.032]` となり、期待損失 `-0.00775`、最悪 25% テール損失 `0.032` から目的値は $-0.00775 + 2.0 \times 0.032 =$ **0.05625** となります。


<!-- section:hint1 -->
0 以上かつ上限ウェイト以下で合計が 1 になる資産配分ウェイト変数に加え、1 つのスカラー補助 VaR しきい値変数と、シナリオごとの非負テール超過変数を導入します。各シナリオのテール超過変数は、そのシナリオの損失が VaR しきい値をどれだけ上回るかを表します。

<!-- section:hint2 -->
陥りやすい点は VaR しきい値 $\eta$ を既定の非負変数のままにすることです。全シナリオのリターンが正のとき最適なしきい値は負になるため、WaSHI では `{ lb: -Infinity, ub: Infinity }`、PuLP では `lowBound=None, upBound=None` を指定して下界を外す必要があります。各シナリオの超過損失をヒンジ不等式で捉え、期待損失と `riskWeight` 倍の CVaR の和を最小化してください。
