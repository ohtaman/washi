# #090. 韧性规划与震后最小扰动恢复综合设计

<!-- section:scenario -->
电网规划师在第一阶段预先签订一组候选发电单元的二进制启用承诺，并支付对应的固定预留成本。正常情况下每个单元提供其名义容量，但在第一阶段鲁棒校验中，每个已承诺单元均可能出现其最大容量跌落量的 $[0, 1]$ 区间内任意比例的衰减（所有单元的衰减比例之和不超过给定的不确定性预算 `gamma`，可为小数），在该预算范围内最坏衰减下的留存总容量仍须不低于设定的鲁棒底线。

随后系统按既定概率进入若干突发冲击情景之一，每个情景对应实际需求量并强制部分单元停机。请在各情景中选择避开停机单元的二进制恢复调度方案（第二阶段运行的单元按其名义容量供电），为相对初始承诺开启或关闭的每个单元支付切换成本，并为每单位未满足需求支付缺口罚金，以**最小化第一阶段固定成本与期望恢复及缺口成本之和**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `fixedCosts` | `number[]` | 第一阶段各单元的固定预留成本 |
| `capacities` | `number[]` | 各单元的名义供应容量 |
| `dropAmounts` | `number[]` | 第一阶段鲁棒校验中各单元的最大容量跌落量 |
| `gamma` | `number` | 第一阶段容量跌落的不确定性预算（0 到单元总数之间，可为小数） |
| `robustMinCap` | `number` | 承受最坏预算内衰减后仍需满足的第一阶段最小留存容量 |
| `probs` | `number[]` | 各冲击情景的发生概率（总和为 1） |
| `demands` | `number[]` | 各情景下的实际需求量 |
| `offline` | `number[][]` | 按 [情景][单元] 索引的停机掩码矩阵（1 表示强制停机） |
| `disruptionCost` | `number` | 相对第一阶段承诺每切换一个单元状态的成本 |
| `shortfallPenalty` | `number` | 各情景中每单位未满足需求的缺口罚金 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `committed` | `number[]` | 第一阶段 0-1 预承诺启用方案 |
| `recovered` | `number[][]` | 按 [情景][单元] 索引的第二阶段 0-1 恢复调度矩阵 |
| `totalCost` | `number` | 最小化后的固定成本加期望恢复与缺口成本 |

<!-- section:example -->
**输入示例**

```json
{
  "fixedCosts": [120, 150, 90, 110],
  "capacities": [18, 22, 12, 16],
  "dropAmounts": [8, 10, 4, 6],
  "gamma": 1,
  "robustMinCap": 28,
  "probs": [0.6, 0.4],
  "demands": [24, 34],
  "offline": [
    [0, 0, 0, 0],
    [0, 1, 0, 0]
  ],
  "disruptionCost": 45,
  "shortfallPenalty": 30
}
```

**输出示例**

```json
{
  "committed": [0, 1, 0, 1],
  "recovered": [
    [0, 1, 0, 1],
    [1, 0, 0, 1]
  ],
  "totalCost": 296
}
```

预承诺 `[0, 1, 0, 1]` 的固定成本为 $150 + 110 = 260$ 且最坏单单元衰减后剩余容量为 $22 + 16 - 10 = 28 \ge 28$；情景 0 无需切换，情景 1 将单元 1 切换为单元 0（变更 2 处，容量 $34 \ge 34$），期望总成本为 $260 + 0.6(0) + 0.4(45 \times 2) =$ **296**。


<!-- section:hint1 -->
将第一阶段的二元预承诺向量及其 Bertsimas-Sim 对偶保护变量，与按情景索引的第二阶段二元恢复调度变量、连续切换指示变量以及非负需求短缺变量结合在一起。第一阶段确保最坏情况下的剩余容量不低于 `robustMinCap`，第二阶段则在各情景停机约束下调整调度并最小化期望切换成本与短缺惩罚之和。

<!-- section:hint2 -->
注意三个关键陷阱：(1) 第一阶段留存容量是下界鲁棒约束，因此应从名义容量中**减去**（而非加上）Bertsimas-Sim 对偶表示的最坏容量衰减；(2) 切换指示量 $|w_{s,j} - y_j|$ 可通过区间 $[0, 1]$ 上的连续变量配合正负两条差值不等式线性化；(3) 在各情景中将 `offline` 标记为 1 的单元固定为 0，并将二元输出 `committed` 与 `recovered` 规范取整为 0/1 整数。
