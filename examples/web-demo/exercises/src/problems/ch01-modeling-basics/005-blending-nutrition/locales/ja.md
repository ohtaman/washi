# #005. 精密合金の配合設計（混合比率制約）

<!-- section:scenario -->
ステンレス鋼の精錬所で、鉄・クロム・ニッケルなどを含む複数種類の地金を溶かし合わせ、ちょうど指定された目標バッチ重量の特殊合金を製造します。各原料地金には 1 kg あたりの材料単価・在庫量・各金属成分の含有率が決まっています。

品質基準として、完成した合金における各成分の重量比率は、それぞれ定められた下限と上限の範囲内に収まらなければなりません。在庫量の上限と品質基準をすべて満たしながら、**総材料費を最小化する各原料地金の使用量**を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `targetBatch` | `number` | 製造すべき合計バッチ重量 (kg) |
| `costs` | `number[]` | 原料地金 $i$ の単価 (/kg) |
| `availabilities` | `number[]` | 原料地金 $i$ の在庫量 (kg) |
| `compositions` | `number[][]` | `compositions[i][k]` は原料地金 $i$ に含まれる成分 $k$ の含有率 |
| `minRatios` | `number[]` | 成分 $k$ の必要最低含有率 |
| `maxRatios` | `number[]` | 成分 $k$ の許容最大含有率 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `amounts` | `number[]` | 各原料地金の使用量 (kg) |
| `totalCost` | `number` | 最小化された総材料コスト |

<!-- section:example -->
**入力例**

```json
{
  "targetBatch": 100,
  "costs": [300, 500, 400],
  "availabilities": [80, 60, 70],
  "compositions": [
    [0.2, 0.5, 0.1],
    [0.6, 0.2, 0.4],
    [0.4, 0.4, 0.2]
  ],
  "minRatios": [0.35, 0.3, 0],
  "maxRatios": [1, 1, 0.25]
}
```

**出力例**

```json
{
  "amounts": [62.5, 37.5, 0],
  "totalCost": 37500
}
```

原料地金 0 を 62.5 kg、原料地金 1 を 37.5 kg 配合すると合計 100 kg となり、成分 0 は $(0.2 \times 62.5 + 0.6 \times 37.5)/100 = 35\% \ge 35\%$、成分 1 は $(0.5 \times 62.5 + 0.2 \times 37.5)/100 = 38.75\% \ge 30\%$、成分 2 は $(0.1 \times 62.5 + 0.4 \times 37.5)/100 = 21.25\% \le 25\%$ で規格範囲内を満たします。そのとき総コストは $300 \times 62.5 + 500 \times 37.5 =$ **37,500** となります。
