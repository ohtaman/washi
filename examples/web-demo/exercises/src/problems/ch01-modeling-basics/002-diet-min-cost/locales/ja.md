# #002. 栄養バランスの配合（>= と最小化）

<!-- section:scenario -->
オーツ麦と豆類（どちらも 0 以上の連続量）を配合し、必要な栄養素の下限を満たしつつ総コストを最小化します。

- オーツ麦 1 単位：コスト 30、たんぱく質 2・食物繊維 1 を含む
- 豆類 1 単位：コスト 50、たんぱく質 1・食物繊維 3 を含む

必要下限 minProtein と minFiber を満たす最も安い配合を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `minProtein` | `number` | 必要なたんぱく質の最低量 |
| `minFiber` | `number` | 必要な食物繊維の最低量 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `oats` | `number` | オーツ麦の配合量（$\ge 0$） |
| `beans` | `number` | 豆類の配合量（$\ge 0$） |
| `totalCost` | `number` | 最小化された総コスト |

<!-- section:example -->
**入力例**

```json
{
  "minProtein": 8,
  "minFiber": 9
}
```

**出力例**

```json
{
  "oats": 3,
  "beans": 2,
  "totalCost": 190
}
```

オーツ麦 3・豆類 2 を配合すると、たんぱく質 8・食物繊維 9 の両方をちょうど満たし、総コスト `190` が最小になります。
