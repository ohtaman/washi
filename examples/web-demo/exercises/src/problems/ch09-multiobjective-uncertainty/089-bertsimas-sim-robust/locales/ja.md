# #089. 予算制約付きロバスト最適化（Bertsimas-Sim 双対定式化）

<!-- section:scenario -->
工場では、個別に最大生産上限を持つ複数製品の連続生産量を決定し、総利益を最大化します。各製品の資源消費量は通常はノミナル値ですが、実際には製品ごとに定められた最大上振れ幅だけ増加する恐れがあります。

すべての製品が同時に最悪値へ振れると想定する代わりに、同時に発生しうる変動の総予算を表すパラメータ Γ を定めます。Γ の範囲内で最悪の変動が起きても総資源消費量が容量上限を超えないようにしつつ、総利益を最大化する生産量を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `profits` | `number[]` | 各製品 1 単位あたりの利益 |
| `nominalUsages` | `number[]` | 各製品 1 単位あたりのノミナル資源消費量 |
| `deviations` | `number[]` | 各製品 1 単位あたりの最大資源上振れ幅 |
| `maxUnits` | `number[]` | 各製品の生産量上限 |
| `capacityCap` | `number` | 最悪ケースでも厳守すべき資源容量上限 |
| `gamma` | `number` | 不確実性予算 $\Gamma \in [0, n]$（小数値も可） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `quantities` | `number[]` | ロバスト制約を満たす各製品の生産量 |
| `totalProfit` | `number` | 最大化された総利益 |

<!-- section:example -->
**入力例**

```json
{
  "profits": [12, 16, 10],
  "nominalUsages": [2, 3, 2],
  "deviations": [1, 1, 0.5],
  "maxUnits": [8, 6, 8],
  "capacityCap": 30,
  "gamma": 1
}
```

**出力例**

```json
{
  "quantities": [3, 3, 6],
  "totalProfit": 144
}
```

生産量 `[3, 3, 6]` のノミナル消費量は $2(3) + 3(3) + 2(6) = 27$、$\Gamma = 1$ に対する最悪偏差は $\max(1 \cdot 3, 1 \cdot 3, 0.5 \cdot 6) = 3$ となり、合計 $30 \le 30$ を守りながら利益 $12(3) + 16(3) + 10(6) =$ **144** を達成します。


<!-- section:hint1 -->
上下界付きの連続生産量変数に加えて、不確実性予算 $\Gamma$ のもとでの最悪ケース保護部分問題を双対化するために、1 つの非負スカラー双対変数と製品ごとの非負双対変数ベクトルを導入します。これらにより容量制約の厳密な線形ロバスト対問題が得られます。

<!-- section:hint2 -->
鍵となるのは、不確実性予算 $\Gamma$ のもとで最悪ケースの消費増分を最大化する内側問題の LP 双対性です。双対化すると 1 つの非負しきい値変数と製品ごとの非負超過変数が現れ、各製品の最悪偏差を線形で抑えつつ、その双対目的値を容量制約の左辺へ直接足し込むことで内側最大化を消去できます。
