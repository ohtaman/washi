# #084. 公平性指標と凸二次計画法（QP）による負荷平準化

<!-- section:scenario -->
配送センターの運用管理者は、所定の総作業量（単位：トン）を複数の配送チームへ実数値（連続量）で配分します。各チームには 1 トンあたりの運用コストと配分量の下限・上限（トン）があり、全チームの配分量の合計は総需要に厳密に一致しなければなりません。

各チームへの負荷を平準化するため、1 トンあたりの線形運用コストに加えて、平均配分量からの差の二乗和に比例する二次ペナルティ（L2 公平性ペナルティ）を加えた総コストを最小化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `unitCosts` | `number[]` | 各チームの 1 トンあたり運用コスト |
| `minAlloc` | `number[]` | 各チームの最小配分量（トン） |
| `maxAlloc` | `number[]` | 各チームの最大配分量（トン） |
| `totalDemand` | `number` | 全チームで分担する総需要量（トン） |
| `fairnessWeight` | `number` | 平均配分量からの差の二乗和に掛ける非負のペナルティ重み |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `allocations` | `number[]` | 各チームへの配分量（非負の実数値、トン） |
| `totalCost` | `number` | 最小化された「線形コスト＋二次公平性ペナルティ」 |

<!-- section:example -->
**入力例**

```json
{
  "unitCosts": [10, 2, 6],
  "minAlloc": [0, 0, 0],
  "maxAlloc": [20, 20, 20],
  "totalDemand": 30,
  "fairnessWeight": 2
}
```

**出力例**

```json
{
  "allocations": [9, 11, 10],
  "totalCost": 176
}
```

`allocations = [9, 11, 10]` は総和 $9 + 11 + 10 = 30$（平均 $\bar{x} = 10$）を満たし、線形コスト $10(9) + 2(11) + 6(10) = 172$ と分散ペナルティ $2 \times ((9-10)^2 + (11-10)^2 + (10-10)^2) = 4$ の合計 **176** となります。


<!-- section:hint1 -->
各チームの配分量（上下限付きの連続変数）を定義し、総需要を満たしつつ運用コストとチーム間のばらつきペナルティを両立させるモデルを組みます。

<!-- section:hint2 -->
総需要が固定されているため、目標となる平均配分量は変数に依存しない既知の定数として扱えます。WaSHI の `expr` テンプレートタグは凸 2 次項を HiGHS QP 向けにそのままコンパイルできるため区分線形近似は不要であり、`m.objectiveValue!` には二乗展開に伴う定数項も含まれた値が返ります。
