# #054. 非对称旅行商问题 (TSP-MTZ)

<!-- section:scenario -->
配送车从城市 0 出发，必须恰好访问其余每座城市一次后再返回城市 0。受单行道和坡度等因素影响，从城市 i 前往城市 j 的通行代价不一定等于反向代价。

将非对称旅行商问题建模为混合整数规划，在消除互不相连的子环路的前提下寻找单一闭合巡回，以 **最小化总通行费用**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `dist` | `number[][]` | $n \times n$ 非对称通行费用矩阵（`dist[i][j]` 表示从 `i` 到 `j`） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `tour` | `number[]` | 从城市 `0` 出发访问全部 $n$ 座城市的顺序（`tour[0] = 0`） |
| `totalCost` | `number` | 最小化后的闭合回路总费用 |

<!-- section:example -->
**输入示例**

```json
{
  "dist": [
    [0, 12, 2, 9],
    [10, 0, 14, 2],
    [3, 7, 0, 11],
    [8, 3, 6, 0]
  ]
}
```

**输出示例**

```json
{
  "tour": [0, 2, 1, 3],
  "totalCost": 19
}
```

按 `0 -> 2 -> 1 -> 3 -> 0` 依次访问即可用单一闭合回路覆盖全部四座城市，总费用为 $2 + 7 + 2 + 8 =$ **19**。

<!-- section:hint1 -->
为每对不同城市的有序弧定义一个二进制选择变量，并为除起点城市外的每座城市定义一个连续的访问顺序位势变量。约束每座城市的入度和出度均为 1，并最小化总巡回距离。

<!-- section:hint2 -->
仅靠度数约束仍会产生互不相连的子环路。对非起点城市间的有向弧 `(i, j)` 添加 MTZ（Miller-Tucker-Zemlin）顺序约束 $u_i - u_j + n x_{ij} \le n - 1$，使 `x[i][j] == 1` 时强制 $u_i + 1 \le u_j$，从而只保留以城市 0 为锚点的单一巡回；求解后从城市 0 起沿选中的弧追踪重建 `tour`。
