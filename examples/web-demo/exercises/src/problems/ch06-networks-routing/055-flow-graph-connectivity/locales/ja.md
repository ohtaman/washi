# #055. 単一品種フローによる連結部分グラフ選択

<!-- section:scenario -->
根拠点 0 を起点として地域ネットワークを拡張します。拠点 0 は必ず稼働させ、各候補拠点には採用による報酬（負の場合もあります）が、各無向候補リンクには敷設コストが設定されています。リンクを敷設できるのは両端の拠点がともに稼働している場合のみです。

拠点 0 を含み、**孤立した飛び地（非連結成分）を作らない 1 つの連結部分グラフ** を選んで、採用拠点の報酬和から採用リンクのコスト和を引いた **純利益を最大化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `prizes` | `number[]` | 各頂点 `0 .. n - 1` を採用したときの報酬 |
| `edges` | `Array<{ u, v, cost }>` | 無向候補リンク（端点 `u`, `v` と敷設コスト `cost`） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `selectedNodes` | `number[]` | 各頂点の採否を表す 0-1 配列（`selectedNodes[0] = 1`） |
| `selectedEdges` | `number[]` | `edges` の各辺の採否を表す 0-1 配列 |
| `netValue` | `number` | 最大化された純利益（報酬和 − 辺コスト和） |

<!-- section:example -->
**入力例**

```json
{
  "prizes": [0, 3, 2, 12, 10],
  "edges": [
    { "u": 0, "v": 1, "cost": 6 },
    { "u": 0, "v": 2, "cost": 7 },
    { "u": 2, "v": 3, "cost": 3 },
    { "u": 3, "v": 4, "cost": 2 },
    { "u": 1, "v": 3, "cost": 9 }
  ]
}
```

**出力例**

```json
{
  "selectedNodes": [1, 0, 1, 1, 1],
  "selectedEdges": [0, 1, 1, 1, 0],
  "netValue": 12
}
```

頂点 `{0, 2, 3, 4}` と辺 `0-2-3-4` を選ぶと根頂点 `0` から単一の連結木になり、報酬 $0 + 2 + 12 + 10 = 24$ からコスト $7 + 3 + 2 = 12$ を引いた純利益は **12** となります。
