# #055. 基于单商品流的连通子图选择

<!-- section:scenario -->
以市政府主楼（节点 0）为起点，扩展连接社区活动中心和避难所的防灾光纤网络。节点 0 必须始终保持启用，每个候选设施（节点）都有接入带来的防灾效益奖励（也可能为负），每条无向候选光缆（边）都有铺设费用，且仅当两端设施同时启用时才能铺设。

请选择一组节点与边，使所有启用节点与根节点 0 构成单个连通子图（不允许出现孤立飞地），并**最大化净效益**（启用节点效益之和减去所选边铺设费用之和）。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `prizes` | `number[]` | 启用节点 `0 .. n - 1` 获得的防灾效益 |
| `edges` | `Array<{ u: number; v: number; cost: number }>` | 无向候选边（端点 `u`、`v` 取值 `0 .. n - 1`，`cost` 为铺设费用） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selectedNodes` | `number[]` | 节点启用标记（0 或 1，且 `selectedNodes[0] = 1`） |
| `selectedEdges` | `number[]` | 与 `edges` 对应的边启用标记（0 或 1） |
| `netValue` | `number` | 最大化后的净效益（节点效益和减去边铺设费用和） |

<!-- section:example -->
**输入示例**

```json
{
  "prizes": [0, 3, 2, 12, 10],
  "edges": [
    { "u": 0, "v": 1, "cost": 6 },
    { "u": 0, "v": 2, "cost": 7 },
    { "u": 2, "v": 3, "cost": 3 },
    { "u": 3, "v": 4, "cost": 2 },
    { "u": 1, "v": 3, "cost": 9 }
  ]
}
```

**输出示例**

```json
{
  "selectedNodes": [1, 0, 1, 1, 1],
  "selectedEdges": [0, 1, 1, 1, 0],
  "netValue": 12
}
```

启用节点 `{0, 2, 3, 4}` 及边 `0-2-3-4` 构成以节点 0 为根的连通树，节点效益之和为 $0 + 2 + 12 + 10 = 24$，扣除铺设费用 $7 + 3 + 2 = 12$ 后净效益为 **12**。

<!-- section:hint1 -->
为节点激活和无向边建设分别定义二进制变量，并将根节点 0 固定为激活状态。为保证与根节点的连通性，将每条无向边拆分为两个方向的连续流变量，从根 0 向每个被激活的非根节点输送单商品流。

<!-- section:hint2 -->
只有当边两端点均被激活时才允许建边（$w_e \le y_u, y_v$），且边 $e$ 上任一方向的流量仅在 $w_e = 1$ 时才可为正（上界为 $n - 1$）。根节点 0 为每个激活的非根节点发出 1 单位流量（$\text{outflow}(0) - \text{inflow}(0) = \sum_{v \ge 1} y_v$），而每个非根节点消耗 $y_v$ 单位流量（$\text{inflow}(v) - \text{outflow}(v) = y_v$），从而彻底杜绝高收益的孤立节点岛。
