# #024. 线性分式效率比最大化（Charnes-Cooper 变换）

<!-- section:scenario -->
运营部门需要在多项线性资源约束与各自上限内确定各活动的非负运行水平。管理层关注的不是单纯的绝对收益，而是分子（线性净收益加固定偏置）与分母（线性资源消耗加正基础开销）之比——**投资回报效率比**。

请在满足全部资源容量与活动上限的前提下，求解**最大化线性分式效率比**的原空间活动水平与最大比率。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `numCoeffs` | `number[]` | 分子边际收益系数向量 $c$ |
| `numConst` | `number` | 分子常数项 $c_0$ |
| `denCoeffs` | `number[]` | 非负分母成本系数向量 $d$ |
| `denConst` | `number` | 严格正分母基础常数 $d_0 > 0$ |
| `usages` | `number[][]` | 资源消耗矩阵 $A$ |
| `capacities` | `number[]` | 资源容量上限向量 $b$ |
| `upperBounds` | `number[]` | 各活动上界向量 $u$ |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `x` | `number[]` | 原问题尺度的活动水平向量 |
| `maxRatio` | `number` | 最大化后的效率比 $(c^\top x + c_0) / (d^\top x + d_0)$ |

<!-- section:example -->
**输入示例**

```json
{
  "numCoeffs": [12, 9],
  "numConst": 10,
  "denCoeffs": [4, 2],
  "denConst": 8,
  "usages": [
    [1, 1]
  ],
  "capacities": [8],
  "upperBounds": [5, 6]
}
```

**输出示例**

```json
{
  "x": [0, 6],
  "maxRatio": 3.2
}
```

取 `x = [0, 6]` 满足 $0 + 6 \le 8$ 与上界 `[5, 6]`，此时分子为 $9 \times 6 + 10 = 64$，分母为 $2 \times 6 + 8 = 20$，比率为 $64 / 20 =$ **3.2**。


<!-- section:hint1 -->
不要直接在原始活动变量中求解，而是应用 Charnes-Cooper 变换：引入一个表示分母倒数的非负标量齐次化变量，以及一组表示该标量与原活动变量乘积的非负缩放变量。

<!-- section:hint2 -->
最常见的陷阱是忘记把原问题的单变量上界约束一起齐次化：在缩放后的模型中，不仅资源约束，每个活动的上界也必须乘以分母标量变量，而不能保留原来的常数上界。由于分母常数项保证了缩放标量严格为正，求解后即可通过除法还原原始活动量。
