# #075. 满足班次需求、班次上下限与指定休假的排班

<!-- section:scenario -->
某科室需要为 $N$ 名员工安排横跨 $D$ 天、每天 $S$ 种班次的排班表。每位员工每天至多只能上一个班次，在事先批准的指定休假日不得排班，且整个周期内的总工作班次数必须介于个人最小与最大配额之间。

每天的每个班次均有最低人力需求，不同员工担任不同班次有各自的人力成本。请在满足全部人力需求与个人约束的前提下最小化总排班成本。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `demands` | `number[][]` | 第 $d$ 天班次 $s$ 的最低需求人数（$D \times S$） |
| `shiftCosts` | `number[][]` | 员工 $i$ 担任班次 $s$ 的单位成本（$N \times S$） |
| `minShifts` | `number[]` | 每位员工的最低总班次数 |
| `maxShifts` | `number[]` | 每位员工的最高总班次数 |
| `daysOff` | `number[][]` | 每位员工必须休息的日期索引列表 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `schedule` | `number[][]` | $N \times D$ 矩阵，`-1` 表示休息，`0..S-1` 表示所排班次 |
| `totalCost` | `number` | 最小化的总排班成本 |

<!-- section:example -->
**输入示例**

```json
{
  "demands": [
    [1, 1],
    [1, 1],
    [1, 1]
  ],
  "shiftCosts": [
    [8, 12],
    [12, 14],
    [11, 18]
  ],
  "minShifts": [2, 2, 2],
  "maxShifts": [2, 3, 2],
  "daysOff": [[1], [], [2]]
}
```

**输出示例**

```json
{
  "schedule": [
    [1, -1, 0],
    [-1, 1, 1],
    [0, 0, -1]
  ],
  "totalCost": 70
}
```

三位员工均工作 2 班（满足上下限并避开各自休假日），每天 `[1, 1]` 的班次需求均被满足，总成本为 $(12 + 8) + (14 + 14) + (11 + 11) =$ **70**。
