# #074. 資源制約付きプロジェクト・スケジューリング (RCPSP)

<!-- section:scenario -->
土木建設プロジェクト（掘削・基礎工事・鉄骨組立・配管・内装など）において、有向非巡回グラフ（DAG）の先行関係で結ばれた $n$ 個の作業タスクを計画します。各タスクは一度開始すると中断できない整数期間のタスクであり、先行関係がある組では先行タスクの完了後にのみ後続タスクを開始できます。また、実行中は 1 種類以上の共有再生可能資源（クレーンや専門作業班など）から一定量を消費します。

どの時刻においても各資源の同時使用量が容量上限を超えてはなりません。すべての先行制約と資源容量制約を満たす非負の整数開始時刻を決定し、プロジェクト全体の完了時刻（メイクスパン）を最小化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `durations` | `number[]` | 各タスク $i$ の処理期間（整数）$d_i$（長さ $n$） |
| `demands` | `number[][]` | 資源 $r$ におけるタスク $i$ の消費量 $q_{r,i}$（`demands[r][i]`、$R \times n$） |
| `capacities` | `number[]` | 各再生可能資源 $r$ の利用可能上限 $C_r$（長さ $R$） |
| `precedences` | `number[][]` | タスク `u` の完了後にタスク `v` を開始する 0 始まりのタスク番号ペア `[u, v]` |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `starts` | `number[]` | 各タスクの非負整数開始時刻 $S_i \ge 0$ |
| `makespan` | `number` | 最小化された最終完了時刻 $\max_i (S_i + d_i)$ |

<!-- section:example -->
**入力例**

```json
{
  "durations": [3, 3, 4, 2, 2],
  "demands": [
    [2, 2, 2, 1, 2]
  ],
  "capacities": [3],
  "precedences": [[0, 1], [0, 3], [1, 4], [2, 4], [3, 4]]
}
```

**出力例**

```json
{
  "starts": [0, 7, 3, 5, 10],
  "makespan": 12
}
```

T0: [0,3)、T2: [3,7)、T3: [5,7)（同時使用量 $2 + 1 = 3 \le 3$）、T1: [7,10)、T4: [10,12) と配置するとすべての先行制約と資源上限を満たし、各タスクの完了時刻は [3, 10, 7, 7, 12] となるため、メイクスパンは $\max(3, 10, 7, 7, 12) =$ **12** となります。

<!-- section:hint1 -->
制約プログラミングを用い、各タスクに対して整数の開始時刻変数を用意します。各依存ペアに対する有向非巡回グラフの先行制約と、各再生可能資源ごとの累積資源制約を組み合わせてモデル化します。

<!-- section:hint2 -->
`{ solver: "pumpkin" }` でモデルを作成し、全タスクの所要時間合計を `horizon` として各 `m.integer(...)` を 0 から `horizon - d` の範囲に抑えます。各資源 $r$ について需要が正のタスクを `{ start, duration, demand }` として集め `cumulative(tasks, cap)` を課した上で、時間を離散化せずに全タスク完了時刻の `max(...)` を最小化してください。
