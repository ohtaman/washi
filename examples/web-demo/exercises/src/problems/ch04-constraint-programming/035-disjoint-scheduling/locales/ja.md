# #035. 排他機械スケジューリング（disjoint）

<!-- section:scenario -->
半導体製造工場の生産計画担当者は、複数のウェハ加工工程（洗浄・露光・エッチングなど）を中断なしで各担当装置上で実行するスケジュールを立てています。各工程には処理時間（分）、最早開始可能時刻（分）、担当装置番号が指定されています。

同じ装置を使う工程どうしは時間帯が重なってはならず、先行制約が指定された工程の組では先行工程が完全に終わってから後続工程を始める必要があります。最大完了時刻（メイクスパン、分）を最小化する各工程の開始時刻を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `durations` | `number[]` | 各工程の処理時間（整数、分） |
| `releaseTimes` | `number[]` | 各工程の最早開始可能時刻（分） |
| `machines` | `number[]` | 各工程が使用する 0 始まりの装置番号 |
| `precedences` | `number[][]` | 工程 `u` の完了後に工程 `v` を開始しなければならない先行ペア `[u, v]` |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `starts` | `number[]` | 各工程の開始時刻（整数、分） |
| `makespan` | `number` | 最小化された最大完了時刻 `max(starts[i] + durations[i])`（分） |

<!-- section:example -->
**入力例**

```json
{
  "durations": [4, 3, 5, 2],
  "releaseTimes": [0, 2, 0, 4],
  "machines": [0, 0, 0, 0],
  "precedences": [
    [0, 3]
  ]
}
```

**出力例**

```json
{
  "starts": [0, 6, 9, 4],
  "makespan": 14
}
```

装置 0 上で工程 0（[0, 4)）→ 工程 3（[4, 6)）→ 工程 1（[6, 9)）→ 工程 2（[9, 14)）と重なりなく処理され、最早開始可能時刻と先行関係 0 → 3 を満たします。最大完了時刻は $\max(0 + 4, 6 + 3, 9 + 5, 4 + 2) = \max(4, 9, 14, 6) =$ **14** 分になります。

<!-- section:hint1 -->
各工程に対して最早開始可能時刻以上 `horizon - durations[i]` 以下の整数開始時刻変数を定義します。先行制約に加えて、担当装置ごとに工程をグループ化し、各装置に対して非重複（排他）制約を適用します。

<!-- section:hint2 -->
各装置に割り当てられた工程の `{ start: starts[i], duration: input.durations[i] }` を集めて `disjoint(tasks)` を追加してください。目的関数は各工程の完了時刻 `starts[i] + durations[i]` に対する `minimize(max(...))` とし、`solver: "pumpkin"` で解きます。
