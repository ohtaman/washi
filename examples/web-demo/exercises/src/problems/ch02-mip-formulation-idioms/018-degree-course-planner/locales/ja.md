# #018. 大学の履修計画と前提科目パズル

<!-- section:scenario -->
大学生が次学期に履修する科目の組み合わせを計画しています。各候補科目には興味スコアがあり、週あたりの学習時間、実験枠、単位上限など、2つ以上の異なる負荷区分を消費します。

さらに履修規則として、ある科目の履修に前提科目の履修を必須とする前提ペアと、時間帯が重複して同時に履修できない時間割重複ペアが定められています。すべての区分上限、前提条件、時間割重複を満たしながら、**興味スコアの合計を最大化**する履修計画を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `interest` | `number[]` | 各候補科目の興味スコア |
| `requirements` | `number[][]` | 負荷行列（`requirements[k][j]` は科目 $j$ が消費する区分 $k$ の負荷） |
| `caps` | `number[]` | 各負荷区分 $k$ の上限 |
| `prerequisites` | `number[][]` | `course` を履修するなら `prereq` の履修が必要なペア `[prereq, course]` |
| `timeConflicts` | `number[][]` | 時間割が重複し同時に履修できないペア `[a, b]` |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `take` | `number[]` | 各科目を履修するかどうかのバイナリ値（0 または 1） |
| `totalInterest` | `number` | 最大化された興味スコアの合計 |

<!-- section:example -->
**入力**

```json
{
  "interest": [8, 24, 22, 19, 15],
  "requirements": [
    [5, 6, 4, 5, 3],
    [3, 6, 5, 4, 6]
  ],
  "caps": [13, 13],
  "prerequisites": [[0, 3]],
  "timeConflicts": [[1, 2]]
}
```

**出力**

```json
{
  "take": [1, 0, 0, 1, 1],
  "totalInterest": 42
}
```

科目 `{0, 3, 4}` を履修すると、区分0は `5 + 5 + 3 = 13 <= 13`、区分1は `3 + 4 + 6 = 13 <= 13` となり、前提 `0 -> 3` と重複回避 `[1, 2]` を満たし、興味スコア合計は $8 + 19 + 15 =$ **42** となります。

<!-- section:hint1 -->
各候補科目を0-1のバイナリ変数で表します。このモデルは、負荷区分ごとのナップサック容量制約と、前提科目・時間割重複を表すペアごとの論理制約を組み合わせたものです。

<!-- section:hint2 -->
各行 `requirements[k]` ごとに `caps[k]` を上限とする容量制約を立てます。前提ペア `[prereq, course]` は $x_{\text{course}} \le x_{\text{prereq}}$、時間割重複 `[a, b]` は $x_a + x_b \le 1$ として線形化できます。
