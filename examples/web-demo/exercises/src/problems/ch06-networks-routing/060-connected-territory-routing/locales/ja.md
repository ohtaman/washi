# #060. 連結テリトリー設計とハブ巡回配送（章末総合）

<!-- section:scenario -->
n 個の区画を K 個の連結な担当地区（テリトリー）に分割し、各地区に 1 つのハブ区画を開設して地区内の全区画を 1 周する巡回配送ルートを運用します。各テリトリーは隣接グラフ上で単一の連結成分をなす（飛び地を許さない）必要があり、各テリトリーの総需要も上下限の範囲内にバランスさせる必要があります。

n 個の区画を K 個の連結な担当地区に分割し、各地区に 1 つのハブを選定して需要バランス上下限を満たしつつ地区内全区画を巡回する単一の閉路を設計し、**ハブ開設費と総巡回距離の合計を最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `numTerritories` | `number` | 分割する連結テリトリー数 $K$ |
| `demands` | `number[]` | 各区画 `0 .. n - 1` の需要量 |
| `demandBounds` | `number[]` | 各テリトリーの総需要許容範囲 `[minDemand, maxDemand]`（`minDemand > max(demands)`） |
| `hubCosts` | `number[]` | 区画 `i` をハブとして開設する固定費 |
| `adjEdges` | `number[][]` | テリトリーの連結性を定義する無向隣接辺 `[u, v]` のリスト |
| `dist` | `number[][]` | $n \times n$ の区画間移動コスト行列 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `territories` | `Array<{ hub, tour }>` | 各テリトリーの選択ハブ `hub` と閉路 `[hub, ..., hub]` の配列 |
| `totalCost` | `number` | 最小化されたハブ開設費と巡回距離の総和 |

<!-- section:example -->
**入力例**

```json
{
  "numTerritories": 2,
  "demands": [3, 4, 3, 4, 3],
  "demandBounds": [6, 11],
  "hubCosts": [5, 12, 14, 10, 6],
  "adjEdges": [[0, 1], [1, 2], [2, 3], [3, 4], [1, 3]],
  "dist": [
    [0, 3, 6, 5, 8],
    [3, 0, 3, 3, 5],
    [6, 3, 0, 5, 5],
    [5, 3, 5, 0, 3],
    [8, 5, 5, 3, 0]
  ]
}
```

**出力例**

```json
{
  "territories": [
    { "hub": 0, "tour": [0, 2, 1, 0] },
    { "hub": 4, "tour": [4, 3, 4] }
  ],
  "totalCost": 29
}
```

地区 `{0, 1, 2}`（需要 10 ∈ [6, 11]、0-1-2 で連結）はハブ 0（費用 5）＋巡回 `[0, 2, 1, 0]`（距離 12）、地区 `{3, 4}`（需要 7 ∈ [6, 11]、3-4 で連結）はハブ 4（費用 6）＋巡回 `[4, 3, 4]`（距離 6）となり、総コストは $(5 + 6) + (12 + 6) =$ **29** となります。

<!-- section:hint1 -->
各区画の地区割り当て 0-1 変数とハブ選択 0-1 変数（ある区画をハブにできるのはその区画が属する地区のみ）を定義し、各区画が 1 地区に属すること、各地区にハブが 1 つあること、総需要が `demandBounds` に収まることを課します。さらに、地理的連結性のための `adjEdges` 上の地区別単一品種フロー層と、地区内 TSP のための有向巡回枝・訪問順序ポテンシャル層の 2 層を組み合わせてください。

<!-- section:hint2 -->
地区 `k` の連結性では、選ばれたハブだけが連続供給量 $s_{ik} \le n h_{ik}$ を注入し、$y_{ik} = 1$ の各区画へ `adjEdges` 経由で 1 単位ずつフローを届けます（辺 `(u, v)` のフロー上限は $y_{uk}$ と $y_{vk}$ の両方で制限）。巡回ルートでは地区を跨ぐ枝を禁じ（$y_{ik} - y_{jk} \le 1 - x_{ij}$）、ハブ帰着時のみリセットされるハブ基準の MTZ 制約（$u_i + 1 - u_j \le n (1 - x_{ij} + \sum_k h_{jk})$）で部分巡回路を排除してください。
