# #066. 交叉转运月台指派与货流时间同步

<!-- section:scenario -->
某交叉转运中心需要为进站卸货卡车与出站装货卡车分配专用泊位，并同步匹配多种商品的转运货流。每辆进站卡车与每辆出站卡车必须各自指派至一个对应泊位且不得超出泊位容量上限，同时满足全部出站卡车对各品类商品的需求。

从位于进站泊位 $r$ 的进站卡车 $i$ 向位于出站泊位 $s$ 的出站卡车 $j$ 搬运货物时，按泊位对 $(r,s)$ 产生单位搬运费用并耗费搬运时间；只要两者之间存在正货流，出站卡车 $j$ 的发车时刻就不得早于进站卡车 $i$ 的到站时刻加上泊位间搬运耗时，超出目标交期的部分将计入延迟罚金。请统筹规划泊位指派、转运流与发车时刻以 **最小化搬运与延迟总成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `supplies` | `number[][]` | 进站卡车各品类供货量（$N_{\text{in}} \times K$） |
| `demands` | `number[][]` | 出站卡车各品类需求量（$N_{\text{out}} \times K$） |
| `arrivalTimes` | `number[]` | 进站卡车 $i$ 的到站时间 $a_i$ |
| `dueTimes` | `number[]` | 出站卡车 $j$ 的目标交期 $d_j$ |
| `inDoorCaps` | `number[]` | 进站泊位 $r$ 可停靠的最大车辆数 |
| `outDoorCaps` | `number[]` | 出站泊位 $s$ 可停靠的最大车辆数 |
| `handlingCosts` | `number[][]` | 泊位对 $(r, s)$ 间的单位搬运成本 $c_{r,s}$ |
| `transferTimes` | `number[][]` | 泊位对 $(r, s)$ 间的货物搬运耗时 $\tau_{r,s}$ |
| `delayCost` | `number` | 超出目标发车时间每单位时间的延误惩罚 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `inDoor` | `number[]` | 每辆进站卡车分配的进站泊位编号（$0 \dots R-1$） |
| `outDoor` | `number[]` | 每辆出站卡车分配的出站泊位编号（$0 \dots S-1$） |
| `flows` | `number[][][]` | 非负转运货流张量（$N_{\text{in}} \times N_{\text{out}} \times K$） |
| `departures` | `number[]` | 每辆出站卡车的非负发车时刻 $t_j$ |
| `totalCost` | `number` | 最小化后的搬运及延迟总成本 |

<!-- section:example -->
**输入示例**

```json
{
  "supplies": [
    [20, 15],
    [15, 25],
    [25, 10]
  ],
  "demands": [
    [15, 15],
    [25, 20],
    [20, 15]
  ],
  "arrivalTimes": [1, 3, 2],
  "dueTimes": [6, 8, 7],
  "inDoorCaps": [2, 2],
  "outDoorCaps": [2, 2],
  "handlingCosts": [
    [2, 5],
    [4, 2]
  ],
  "transferTimes": [
    [2, 5],
    [4, 2]
  ],
  "delayCost": 30
}
```

**输出示例**

```json
{
  "inDoor": [0, 1, 1],
  "outDoor": [1, 1, 0],
  "flows": [
    [
      [0, 0],
      [0, 0],
      [20, 15]
    ],
    [
      [15, 5],
      [0, 20],
      [0, 0]
    ],
    [
      [0, 10],
      [25, 0],
      [0, 0]
    ]
  ],
  "departures": [5, 5, 3],
  "totalCost": 220
}
```

将进站 0 与出站 2 配对在泊位 `(0, 0)`，进站 1、2 与出站 0、1 配对在泊位 `(1, 1)`，全部 110 件货均以单价 2 完成转运且发车时间 `[5, 5, 3] <= [6, 8, 7]` 零延误，总成本为 $110 \times 2 =$ **220**。
