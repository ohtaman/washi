# #013. 带基数约束的项目组合选择

<!-- section:scenario -->
某投资委员会需在共享总预算限制下，从若干候选项目中全额立项或放弃各项目。除总预算约束外，内部治理规则还要求满足三类分组数量限制：同一互斥分组中至多立项一个项目，精确计数分组中必须立项恰好指定数量的项目，必选覆盖分组中至少立项一个项目。

请选出满足预算与全部基数规则的项目子集，以**最大化总战略价值**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `budget` | `number` | 可用总预算 |
| `costs` | `number[]` | 各候选项目的所需成本 |
| `values` | `number[]` | 各项目带来的战略价值 |
| `mutexGroups` | `number[][]` | 互斥分组列表，每组内至多选 1 项 |
| `exactGroups` | `{ indices: number[]; count: number }[]` | 精确计数分组列表，要求从 `indices` 中恰好选 `count` 项 |
| `atLeastOneGroups` | `number[][]` | 必选覆盖分组列表，每组内至少选 1 项 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selected` | `number[]` | 各项目是否立项的二进制结果（`0` 或 `1`） |
| `totalValue` | `number` | 最大化后的总价值 |

<!-- section:example -->
**输入示例**

```json
{
  "budget": 16,
  "costs": [5, 6, 4, 3, 7, 4],
  "values": [14, 17, 10, 8, 19, 11],
  "mutexGroups": [[0, 1]],
  "exactGroups": [{ "indices": [2, 3, 4], "count": 2 }],
  "atLeastOneGroups": [[4, 5]]
}
```

**输出示例**

```json
{
  "selected": [0, 1, 0, 1, 1, 0],
  "totalValue": 44
}
```

选择项目 `{1, 3, 4}` 的总成本为 $6 + 3 + 7 = 16 \le 16$，分别在互斥组 `[0, 1]` 中选 1 项、精确组 `[2, 3, 4]` 中选 2 项、必选组 `[4, 5]` 中选 1 项，总价值为 $17 + 8 + 19 =$ **44**。

<!-- section:hint1 -->
为每个项目建立一个二元选择变量。预算上限以及三类分组规则（互斥、精确数量、至少选一项）都可以表示为这些二元变量子集上的线性约束。

<!-- section:hint2 -->
由于每个二元变量仅取 $0$ 或 $1$，任意组内被选中的项目数就是对应下标 `selected[i]` 之和；分别将该和约束为 $\le 1$、$= \text{count}$ 或 $\ge 1$ 即可。读取求解结果时记得对二元变量取整。
