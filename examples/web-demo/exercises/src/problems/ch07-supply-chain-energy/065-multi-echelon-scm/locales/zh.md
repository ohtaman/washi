# #065. 多级供应链网络设计

<!-- section:scenario -->
某企业需要规划一个包含候选工厂、候选配送中心（DC）和客户需求点的两级供应链分销网络。启用任意工厂或 DC 均需支付一次性固定开设成本，并解锁至其产能上限的流通能力；未启用的设施不允许有任何物流经过。

每个 DC 严格作为中转节点，来自工厂的总入库量必须等于发往客户的总出库量，且所有客户需求都必须得到满足。请决策各设施的开闭状态以及两级运输流量，以 **最小化固定成本与运输成本总和**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `plantFixedCosts` | `number[]` | 工厂 $p$ 的固定开设成本 $F^P_p$ |
| `plantCaps` | `number[]` | 工厂 $p$ 的最大供应产能 $C^P_p$ |
| `dcFixedCosts` | `number[]` | DC $d$ 的固定开设成本 $F^D_d$ |
| `dcCaps` | `number[]` | DC $d$ 的最大中转吞吐能力 $C^D_d$ |
| `demands` | `number[]` | 客户 $c$ 的需求量 $D_c$ |
| `plantDcCosts` | `number[][]` | 工厂 $p$ 到 DC $d$ 的单位运费 $c_{p,d}$ |
| `dcCustomerCosts` | `number[][]` | DC $d$ 到客户 $c$ 的单位运费 $c'_{d,c}$ |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `openPlants` | `number[]` | 工厂启用决策（`0` 或 `1`） |
| `openDcs` | `number[]` | DC 启用决策（`0` 或 `1`） |
| `plantToDc` | `number[][]` | 工厂到 DC 的非负流量矩阵（$P \times D$） |
| `dcToCustomer` | `number[][]` | DC 到客户的非负流量矩阵（$D \times C$） |
| `totalCost` | `number` | 最小化后的固定与运输总成本 |

<!-- section:example -->
**输入示例**

```json
{
  "plantFixedCosts": [500, 420],
  "plantCaps": [120, 100],
  "dcFixedCosts": [250, 200, 280],
  "dcCaps": [90, 80, 100],
  "demands": [30, 40, 35, 25],
  "plantDcCosts": [
    [4, 6, 8],
    [7, 5, 3]
  ],
  "dcCustomerCosts": [
    [3, 5, 9, 7],
    [6, 2, 4, 8],
    [8, 7, 3, 2]
  ]
}
```

**输出示例**

```json
{
  "openPlants": [1, 1],
  "openDcs": [1, 0, 1],
  "plantToDc": [
    [70, 0, 0],
    [0, 0, 60]
  ],
  "dcToCustomer": [
    [30, 40, 0, 0],
    [0, 0, 0, 0],
    [0, 0, 35, 25]
  ],
  "totalCost": 2355
}
```

开启两家工厂以及 DC 0 和 DC 2，满足全部能力与 DC 中转平衡（`70 == 30+40`、`60 == 35+25`），总成本为 $1450 + 460 + 445 =$ **2,355**。


<!-- section:hint1 -->
为每个候选工厂和每个候选配送中心（DC）引入二元开设决策变量，同时引入从工厂到 DC 以及从 DC 到客户的非负连续运输量矩阵。整个网络通过配送中心将两级供应链耦合在一起。

<!-- section:hint2 -->
用“工厂产能 × 工厂开设变量”限制每个工厂的总流出量，同样用“DC 吞吐能力 × DC 开设变量”限制每个 DC 的总处理量。每个 DC 还必须满足严格的流量守恒（来自工厂的总流入等于发往客户的总流出），同时每个客户收到的总货量必须满足其需求。
