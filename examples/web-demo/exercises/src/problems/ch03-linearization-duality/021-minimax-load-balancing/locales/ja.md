# #021. ミニマックス負荷分散（エピグラフ線形化）

<!-- section:scenario -->
分散計算クラスタに、任意の比率で分割可能なバッチジョブが複数投入されます。各ジョブは対応フラグが立っているサーバーにのみ振り分けることができ、非対応サーバーへの割当割合はゼロでなければなりません。

すべてのジョブを合計 100% 処理するという条件のもとで、**最も忙しいサーバーの負荷（ピーク負荷）を最小化**する割当比率を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `weights` | `number[]` | 各ジョブ $i$ の総負荷量 |
| `compatible` | `number[][]` | ジョブ $i$ をサーバー $j$ に割当可能なら `1`、不可なら `0` |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `assignments` | `number[][]` | ジョブ $i$ からサーバー $j$ への割当比率（`[0, 1]`） |
| `peakLoad` | `number` | 最小化された最大サーバー負荷 |

<!-- section:example -->
**入力例**

```json
{
  "weights": [10, 8, 6],
  "compatible": [
    [1, 0],
    [1, 1],
    [0, 1]
  ]
}
```

**出力例**

```json
{
  "assignments": [
    [1, 0],
    [0.25, 0.75],
    [0, 1]
  ],
  "peakLoad": 12
}
```

ジョブ 0 をサーバー 0 へ、ジョブ 2 をサーバー 1 へ全量割り当て、ジョブ 1 を `0.25 : 0.75` に分割すると、サーバー 0 の負荷は $10 + 8 \times 0.25 = 12$、サーバー 1 の負荷は $8 \times 0.75 + 6 = 12$ となり、ピーク負荷は **12** になります。
