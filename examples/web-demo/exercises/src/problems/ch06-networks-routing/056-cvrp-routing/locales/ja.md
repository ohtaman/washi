# #056. 容量制約付き配送計画問題 (CVRP)

<!-- section:scenario -->
最大 K 台の同一配送車がデポ 0 に待機しており、各車両には共通の積載容量上限が定められています。各顧客には正の配送需要があり、すべての顧客をちょうど 1 回ずつ訪問する必要があります。各ルートはデポ 0 を出発してデポ 0 へ戻り、積載需要の合計は車両容量以下でなければなりません。

積載量追跡型の部分巡回路排除制約を用いた混合整数計画（MIP）として定式化し、すべての顧客を配送しつつ **総移動距離を最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `dist` | `number[][]` | $(n+1) \times (n+1)$ の距離行列（`0` がデポ、`1..n` が顧客） |
| `demands` | `number[]` | 各頂点の需要量（`demands[0] = 0`、顧客は正値） |
| `capacity` | `number` | 車両 1 台あたりの積載容量上限 $Q$ |
| `maxVehicles` | `number` | デポ `0` から出発できる最大車両台数 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `routes` | `number[][]` | 各車両の配送ルート配列（各ルートは `[0, ..., 0]`） |
| `totalDistance` | `number` | 最小化された全ルート総移動距離 |

<!-- section:example -->
**入力例**

```json
{
  "dist": [
    [0, 5, 7, 5, 6],
    [5, 0, 3, 6, 9],
    [7, 3, 0, 9, 12],
    [5, 6, 9, 0, 4],
    [6, 9, 12, 4, 0]
  ],
  "demands": [0, 4, 5, 4, 5],
  "capacity": 10,
  "maxVehicles": 2
}
```

**出力例**

```json
{
  "routes": [
    [0, 1, 2, 0],
    [0, 3, 4, 0]
  ],
  "totalDistance": 30
}
```

ルート `[0, 1, 2, 0]` は積載量 $4 + 5 = 9 \le 10$・距離 $5 + 3 + 7 = 15$、ルート `[0, 3, 4, 0]` も積載量 $9 \le 10$・距離 $5 + 4 + 6 = 15$ となり、総移動距離は **30** です。
