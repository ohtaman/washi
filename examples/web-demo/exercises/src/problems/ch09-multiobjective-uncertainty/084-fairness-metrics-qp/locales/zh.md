# #084. 公平性指标与凸二次规划（QP）负载均衡

<!-- section:scenario -->
配送中心的运营主管需要将规定的总作业量（单位：吨）以连续实数值分配给多个配送团队。每个团队有每吨的运营成本以及最小、最大分配上下限（吨），且所有团队的分配量之和必须严格等于总需求。

为使各团队的负荷更加均衡，请在线性运营成本之外加上与各团队偏离平均分配量的平方和成正比的二次惩罚（L2 公平性惩罚），最小化总成本。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `unitCosts` | `number[]` | 各团队每吨的运营成本 |
| `minAlloc` | `number[]` | 各团队的最小分配量（吨） |
| `maxAlloc` | `number[]` | 各团队的最大分配量（吨） |
| `totalDemand` | `number` | 全团队共同分担的总需求量（吨） |
| `fairnessWeight` | `number` | 施加在各团队偏离平均分配量的平方和上的非负惩罚权重 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `allocations` | `number[]` | 分配给各团队的工作量（非负实数值，吨） |
| `totalCost` | `number` | 最小化后的“线性成本 + 二次公平性惩罚” |

<!-- section:example -->
**输入示例**

```json
{
  "unitCosts": [10, 2, 6],
  "minAlloc": [0, 0, 0],
  "maxAlloc": [20, 20, 20],
  "totalDemand": 30,
  "fairnessWeight": 2
}
```

**输出示例**

```json
{
  "allocations": [9, 11, 10],
  "totalCost": 176
}
```

分配方案 `allocations = [9, 11, 10]` 总和为 $9 + 11 + 10 = 30$（均值 $\bar{x} = 10$），线性成本为 $10(9) + 2(11) + 6(10) = 172$，方差惩罚为 $2 \times ((9 - 10)^2 + (11 - 10)^2 + (10 - 10)^2) = 4$，总目标值为 **176**。


<!-- section:hint1 -->
为每个团队引入一个带上下界的连续工作量分配变量，在满足总需求的同时权衡运营成本与团队间的方差惩罚。

<!-- section:hint2 -->
由于总需求是固定的，目标平均分配量是一个已知常数而非依赖变量的表达式。WaSHI 的 `expr` 模板标签可直接将凸二次项编译给 HiGHS QP 求解器而无需手动分段线性化，且 `m.objectiveValue!` 会自动包含平方项展开后的常数偏置。
