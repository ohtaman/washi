# #023. 残業・不足ペナルティの正部線形化

<!-- section:scenario -->
サービスセンターの運営管理者は、複数期間にわたり、予測需要（人時）をまかなう通常稼働時間（人時）を計画しています。各期には契約上の最低稼働時間と設備上限があり、さらに全期間を通じた通常稼働時間の合計にも上限が定められています。

通常稼働時間がその期の需要を下回った不足分に対してのみ 1 人時あたりの残業・外注ペナルティ（円）が発生し、逆に需要を上回っても余剰分の返金やプラス評価はありません。この「0 と差分の大きい方（正部）」を不等式で線形に表す手法（正部線形化）を用いて、すべての制約を満たしながら**通常稼働コストと残業ペナルティの総和（円）を最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[]` | 各期 $t$ の需要 $d_t$（人時） |
| `minRegular` | `number[]` | 各期 $t$ の最低保証通常稼働時間 $L_t$（人時） |
| `maxRegular` | `number[]` | 各期 $t$ の最大通常稼働能力 $U_t$（人時） |
| `regularCosts` | `number[]` | 各期 $t$ の通常稼働単価 $r_t$（円/人時） |
| `overtimePenalties` | `number[]` | 不足量 $\max(0, d_t - x_t)$ あたりの残業ペナルティ $p_t$（円/人時） |
| `totalRegularCap` | `number` | 全期間の通常稼働時間合計 $\sum_t x_t$ の上限（人時） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `regular` | `number[]` | 各期の通常稼働時間 $x_t$（人時） |
| `shortage` | `number[]` | 各期の不足残業時間 $\max(0, d_t - x_t)$（人時） |
| `totalCost` | `number` | 最小化された総コスト（円） |

<!-- section:example -->
**入力例**

```json
{
  "demands": [40, 60, 50],
  "minRegular": [10, 10, 10],
  "maxRegular": [50, 50, 50],
  "regularCosts": [20, 25, 18],
  "overtimePenalties": [50, 45, 55],
  "totalRegularCap": 100
}
```

**出力例**

```json
{
  "regular": [40, 10, 50],
  "shortage": [0, 50, 0],
  "totalCost": 4200
}
```

通常稼働時間 [40, 10, 50] は合計 100 $\le$ 100 人時かつ各期の上下界を満たし、不足時間は [0, 50, 0] となるため、総コストは $(20 \times 40 + 25 \times 10 + 18 \times 50) + (45 \times 50) =$ **4,200** 円となります。


<!-- section:hint1 -->
各期について最小保証水準と最大容量で上下限を設けた連続の通常稼働変数と、残業で補う未充足需要を表す非負の連続不足変数を宣言します。

<!-- section:hint2 -->
片側ヒンジ $\max(0, d_t - x_t)$ を線形化するには、等式ではなく不等式 $s_t \ge d_t - x_t$ と $s_t \ge 0$ を用います。等式にすると（最低稼働制約などにより）通常稼働が需要を上回る期に $s_t < 0$ が強制されて実行不能になります。また符号の向き（$x_t - d_t$ ではなく $d_t - x_t$）に注意し、全期間の通常稼働合計に対する上限制約も忘れないでください。残業ペナルティが正で総コストを最小化するため、最適解では各 $s_t$ が自動的に $\max(0, d_t - x_t)$ に一致します。
