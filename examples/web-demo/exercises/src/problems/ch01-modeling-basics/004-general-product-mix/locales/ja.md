# #004. 一般形プロダクトミックス（m × n 行列）

<!-- section:scenario -->
ジェラート工房で、複数種類のフレーバーを製造します。各フレーバーを 1 リットル生産するごとに決められた利益が得られますが、同時に牛乳や生クリームなどの材料や、冷凍庫の稼働時間といった設備を一定量ずつ消費します。

フレーバーの種類数や利用する材料・設備の数は入力データによって変わります。すべての材料や設備の利用上限を超えない範囲で各フレーバーの生産量（リットル・非負の連続量）を決め、**総利益を最大化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `margins` | `number[]` | フレーバー $j$ 1 リットルあたりの利益 |
| `usages` | `number[][]` | `usages[k][j]` がフレーバー $j$ 1 リットルあたりの材料・設備 $k$ の消費量 |
| `capacities` | `number[]` | 材料・設備 $k$ の利用上限 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `quantities` | `number[]` | 各フレーバーの生産量（リットル・非負の連続値） |
| `totalProfit` | `number` | 最大化された総利益 |

<!-- section:example -->
**入力例**

```json
{
  "margins": [500, 300],
  "usages": [
    [3, 1],
    [1, 2]
  ],
  "capacities": [90, 80]
}
```

**出力例**

```json
{
  "quantities": [20, 30],
  "totalProfit": 19000
}
```

生産量を `[20, 30]` とすると消費量は材料・設備 0 が $3 \times 20 + 1 \times 30 = 90 \le 90$、材料・設備 1 が $1 \times 20 + 2 \times 30 = 80 \le 80$ となり、総利益は $500 \times 20 + 300 \times 30 =$ **19,000** となります。
