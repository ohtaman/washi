# #024. 线性分式效率比最大化（Charnes-Cooper 变换）

<!-- section:scenario -->
精密零件工厂的生产计划负责人需要在原材料、加工工时等共享资源容量以及各零件生产上限的约束下，决定多种精密零件的产量（个，非负）。本次关注的目标并非利润总额本身，而是含固定收入在内的“总净回报（万元）”与含基本维护费在内的“总投入成本（万元）”之比——**投资效率比的最大化**。

请运用以分母倒数整体缩放并线性化的 Charnes-Cooper 变换思路，在满足所有资源约束与生产上限的同时，求出**最大化效率比**的产量与最大比率。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `numCoeffs` | `number[]` | 分子的单个零件净回报系数向量 $c$（万元/个） |
| `numConst` | `number` | 分子的固定收入项 $c_0$（万元） |
| `denCoeffs` | `number[]` | 分母的单个零件投入成本系数向量 $d$（万元/个，非负） |
| `denConst` | `number` | 分母的正基本维护费 $d_0 > 0$（万元） |
| `usages` | `number[][]` | 单个零件的资源消耗矩阵 $A$ |
| `capacities` | `number[]` | 共享资源的容量上限向量 $b$ |
| `upperBounds` | `number[]` | 各零件的生产上限 $u$（个） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `x` | `number[]` | 原尺度下的零件产量向量（个） |
| `maxRatio` | `number` | 最大化后的效率比 $(c^\top x + c_0) / (d^\top x + d_0)$ |

<!-- section:example -->
**输入示例**

```json
{
  "numCoeffs": [12, 9],
  "numConst": 10,
  "denCoeffs": [4, 2],
  "denConst": 8,
  "usages": [
    [1, 1]
  ],
  "capacities": [8],
  "upperBounds": [5, 6]
}
```

**输出示例**

```json
{
  "x": [0, 6],
  "maxRatio": 3.2
}
```

当 `x` 为 [0, 6] 时，满足资源消耗 $0 + 6 \le 8$ 与个体上限 [5, 6]，此时分子为 $9 \times 6 + 10 = 64$，分母为 $2 \times 6 + 8 = 20$，效率比为 $64 / 20 =$ **3.2**。


<!-- section:hint1 -->
不要直接在原始活动变量中求解，而是应用 Charnes-Cooper 变换：引入一个表示分母倒数的非负标量齐次化变量，以及一组表示该标量与原活动变量乘积的非负缩放变量。

<!-- section:hint2 -->
最常见的陷阱是忘记把原问题的单变量上界约束一起齐次化：在缩放后的模型中，不仅资源约束，每个活动的上界也必须乘以分母标量变量，而不能保留原来的常数上界。由于分母常数项保证了缩放标量严格为正，求解后即可通过除法还原原始活动量。
