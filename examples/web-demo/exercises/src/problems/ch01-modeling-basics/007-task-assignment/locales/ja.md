# #007. 1対1の配送エリア割当問題

<!-- section:scenario -->
ある宅配営業所では、同じ数の配送員と担当エリア（北区・東区・南区など）があり、どの配送員にどのエリアを任せるかに応じて配送コスト（千円）が決まっています。

すべての配送員がちょうど 1 つの担当エリアを受け持ち、かつすべての担当エリアがちょうど 1 人の配送員に割り当てられるように 1 対 1 で割り当てて、**合計コストを最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `costs` | `number[][]` | $n \times n$ の割当コスト行列（千円、`costs[i][j]` は配送員 $i$ がエリア $j$ を担当するコスト） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `assignment` | `number[]` | 長さ $n$ の配列（`assignment[i]` は配送員 $i$ に割り当てるエリア番号） |
| `totalCost` | `number` | 最小化された合計コスト（千円） |

<!-- section:example -->
**入力例**

```json
{
  "costs": [
    [9, 2, 7],
    [6, 4, 3],
    [5, 8, 1]
  ]
}
```

**出力例**

```json
{
  "assignment": [1, 0, 2],
  "totalCost": 9
}
```

割当 `[1, 0, 2]` では各配送員に 1 エリアずつ、重複なく割り当てられており（各行・各列の割当数がいずれも 1）、合計コストは $2 + 6 + 1 =$ **9** となります。
