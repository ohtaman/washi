# #004. 一般形プロダクトミックス（m × n 行列）

<!-- section:scenario -->
ジェラート工房で、複数種類のフレーバーを製造します。各フレーバーを 1 リットル生産するごとに、所定の利益が得られますが、同時に共有の原材料や設備資源を一定量ずつ消費します。

すべての資源の利用上限を超えない範囲で各フレーバーの生産量を決め、**総利益を最大化**してください。各フレーバーの生産量は、非負の連続量です。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `margins` | `number[]` | フレーバー $j$ の単位利益 |
| `usages` | `number[][]` | `usages[k][j]` が製品 $j$ 1 リットルあたりの資源 $k$ の消費量 |
| `capacities` | `number[]` | 資源 $k$ の利用上限 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `quantities` | `number[]` | 各フレーバーの生産量（非負の連続値） |
| `totalProfit` | `number` | 最大化された総利益 |

<!-- section:example -->
**入力例**

```json
{
  "margins": [500, 300],
  "usages": [
    [3, 1],
    [1, 2]
  ],
  "capacities": [90, 80]
}
```

**出力例**

```json
{
  "quantities": [20, 30],
  "totalProfit": 19000
}
```

`[20, 30]` を生産すると資源消費量は資源 0 が $3 \times 20 + 1 \times 30 = 90$、資源 1 が $1 \times 20 + 2 \times 30 = 80$（いずれも上限以内）となり、総利益は $500 \times 20 + 300 \times 30 =$ **19,000** となります。
