# #092. 对称性破除与覆盖割平面

<!-- section:scenario -->
物流仓库的出货负责人需要将带有重量的零件箱等货物（单位：kg）装入相同容量的集装箱（箱子，载重上限单位：kg）中，目标是最小化使用的箱子数量。由于箱子之间完全等价，简单的 MIP 建模会产生大量对称解，且连续 LP 松弛下界也仅停留在“总重量 ÷ 箱容量”的弱分数值。

请引入以下约束与强化割平面，并返回分配结果、使用的箱子数量和强化后的 LP 松弛目标值：
- **对称性破除**：按编号顺序从第 0 个箱子开始依次启用，且每件货物只能放入编号不超过自身编号的箱子（第一件货物固定在首个箱子）。
- **总容量割平面**：加入“总重量 ÷ 箱容量”向上取整得到的最小箱数下界约束。
- **扩展极小覆盖不等式**：利用超容极小货物集合，并加入不轻于该集合中最重货物的货物，构造覆盖不等式以强化 LP 松弛。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `weights` | `number[]` | 各货物 $i \in \{0, \dots, n-1\}$ 的重量（kg） |
| `binCapacity` | `number` | 单个箱子允许装入的重量上限（kg） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `assignments` | `number[]` | 各货物分配的箱子编号（从 0 开始、`assignments[0] = 0` 的连续前缀编号） |
| `binsUsed` | `number` | 使用的箱子最小数量 |
| `lpBound` | `number` | 应用对称性破除、容量割与覆盖割后的 LP 松弛目标值 |

<!-- section:example -->
**输入示例**

```json
{
  "weights": [6, 6, 6, 2],
  "binCapacity": 10
}
```

**输出示例**

```json
{
  "assignments": [0, 1, 2, 2],
  "binsUsed": 3,
  "lpBound": 3
}
```

将重量 `[6]`、`[6]`、`[6, 2]` 分别放入箱子 0、1、2，各箱负载满足 $6, 6, 8 \le 10$，箱号从 0 连续启用，共使用 **3** 个箱子且 LP 松弛下界达到 **3**。

<!-- section:hint1 -->
使用二元变量分别表示每个箱子是否启用以及每件货物是否放入某个箱子，以最小化启用箱子总数。除每件货物恰好放入一个箱子和箱容量约束外，还需加入箱子前缀顺序约束以及货物序号对箱号的上界限制。

<!-- section:hint2 -->
为破除对称性，要求箱子启用变量单调非增（$y_k \ge y_{k+1}$），并禁止将货物 $i$ 放入 $k > i$ 的箱子。为强化 LP 下界，加入向上取整的全局容量割 $\sum_k y_k \ge \lceil \sum_i w_i / B \rceil$，并对每个极小覆盖 $C$ 加入不轻于其最重货物的货物构成扩展集 $E(C)$，对每个箱子 $k$ 添加 $\sum_{i \in E(C)} x_{ik} \le (|C| - 1) y_k$。在 WaSHI 中先调用 `m.relax()` 读取 `lpBound` 再调用 `m.solve()`；在 PuLP 中则分别求解二元变量松弛至 $[0, 1]$ 的连续模型与 MIP。
