# #021. ミニマックス負荷分散（エピグラフ線形化）

<!-- section:scenario -->
クラスタ運用担当者は、分散計算クラスタに投入される複数のバッチジョブ（それぞれ所定の負荷量［負荷単位］を持ち、任意の比率で分割可能）を各サーバーへ振り分ける計画を立てています。各ジョブは対応フラグが立っているサーバーにのみ割り当てることができ、非対応サーバーへの割当比率は 0 でなければなりません。

すべてのジョブを合計 100%（比率 1）処理するという条件のもとで、最大負荷を 1 つの上限変数で上から抑えて最小化する「エピグラフ線形化」の考え方を用い、**最も忙しいサーバーの負荷（ピーク負荷）を最小化**する割当比率を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `weights` | `number[]` | 各ジョブ $i$ の総負荷量（負荷単位） |
| `compatible` | `number[][]` | ジョブ $i$ をサーバー $j$ に割当可能なら 1、不可なら 0 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `assignments` | `number[][]` | ジョブ $i$ からサーバー $j$ への割当比率（`[0, 1]`） |
| `peakLoad` | `number` | 最小化された最大サーバー負荷 |

<!-- section:example -->
**入力例**

```json
{
  "weights": [10, 8, 6],
  "compatible": [
    [1, 0],
    [1, 1],
    [0, 1]
  ]
}
```

**出力例**

```json
{
  "assignments": [
    [1, 0],
    [0.25, 0.75],
    [0, 1]
  ],
  "peakLoad": 12
}
```

ジョブ 0 をサーバー 0 へ、ジョブ 2 をサーバー 1 へ全量割り当て、ジョブ 1 を 0.25 : 0.75 に分割すると、サーバー 0 の負荷は $10 + 8 \times 0.25 = 12$、サーバー 1 の負荷は $8 \times 0.75 + 6 = 12$ となり、ピーク負荷は **12** になります。


<!-- section:hint1 -->
ジョブとサーバーで添字付けられた連続値の割当率行列を用意し、互換性フラグ `compatible` の値をそのまま各要素の上限（`ub`）に設定することで非互換ペアを自動的にゼロに固定します。さらに、クラスター全体の最大サーバー負荷を表す連続スカラー変数を 1 つ追加します。

<!-- section:hint2 -->
目的関数に `max` を直接書かずにサーバー負荷の最大値を最小化するには、各サーバーの負荷を補助スカラー変数で上から抑え、そのスカラー変数を最小化します（**エピグラフ定式化**と呼ばれる手法です）。最小化によって少なくとも 1 台のサーバーで等号が成立するまで値が押し下げられるため、最適値が真の最大負荷と一致します。
