# #031. 加权 N 皇后问题

<!-- section:scenario -->
在 N×N 的国际象棋棋盘上每行恰好放置一个皇后，共放置 N 个皇后。每个皇后占据 0 到 N - 1 之间的某一列，且任意两个皇后不能位于同一列或同一条对角线上。

将第 r 行的皇后放在第 c 列会产生棋盘代价 costMatrix[r][c]。请找出互不攻击的合法放置方案，使所选格子的总代价最小。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `costMatrix` | `number[][]` | `N × N` 代价矩阵，`costMatrix[r][c]` 为第 `r` 行皇后放在第 `c` 列的代价 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `cols` | `number[]` | 每行皇后所分配的列号（位于 `[0, N - 1]`） |
| `totalCost` | `number` | 最小化的所选格子权重之和 |

<!-- section:example -->
**输入**

```json
{
  "costMatrix": [
    [7, 2, 5, 9],
    [9, 4, 8, 1],
    [3, 7, 4, 6],
    [5, 8, 2, 7]
  ]
}
```

**输出**

```json
{
  "cols": [1, 3, 0, 2],
  "totalCost": 8
}
```

位于 `(0, 1)`、`(1, 3)`、`(2, 0)`、`(3, 2)` 的皇后互不共列且互不共对角线，总代价为 $2 + 1 + 3 + 2 =$ **8**。

<!-- section:hint1 -->
为每一行引入一个整数决策变量表示该行皇后所在的列号。除了列号互不相同外，还需对两条方向不同的对角线分别施加互异约束，并将每行选中格子的代价相加最小化。

<!-- section:hint2 -->
使用 `distinct(cols)` 限制列互异，并对移位后的表达式数组 `cols[r] + r` 与 `cols[r] - r` 分别施加 `distinct(...)` 以限制两条对角线。使用 `at(costMatrix[r], cols[r])` 索引每行代价，用 `sum(...)` 汇总并调用 `minimize(...)` 与 `solver: "pumpkin"` 求解。
