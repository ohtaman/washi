# #099. Fix-and-Optimize 法（ローリングウィンドウ MIP）

<!-- section:scenario -->
射出成形部品メーカーの工場において、複数期間にわたるプラスチック部品（単位：ケース）の生産計画を立案します。
- 初期在庫は 0 とし、各期は前期末在庫と当期生産量で需要を満たして欠品は許さず、余剰分は期末在庫として次期へ繰り越す。
- 各期で生産を行うには金型交換などの 0-1 段取りを実施する必要があり、生産量は段取り実施時はその期の生産容量上限以内、未実施時は 0 とする。
- 固定段取り費・単位生産費・期末在庫保管費の合計（円）を最小化する。

期間が長くなると単一の巨大 MIP では探索が停滞しやすいため、与えられた初期段取り計画とウィンドウ幅からローリングウィンドウの Fix-and-Optimize 法を実行し、1 周してもコストが改善しなくなるまでロットサイズ計画を反復改善して最終的な段取り・生産量・在庫量・総コストを返してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[]` | 第 $t$ 期の必要需要量（ケース） |
| `setupCosts` | `number[]` | 第 $t$ 期に段取りを行う場合の固定段取りコスト（円） |
| `prodCosts` | `number[]` | 第 $t$ 期の 1 ケースあたり生産コスト（円） |
| `holdCost` | `number` | 期末在庫 1 ケースあたりの在庫保管コスト（円） |
| `capacities` | `number[]` | 第 $t$ 期の段取り実施時における生産容量上限（ケース） |
| `initialPlan` | `number[]` | 実行可能な初期 0/1 段取りベクトル |
| `windowSize` | `number` | 各 Fix-and-Optimize 部分問題で同時に解放する連続期間数 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `setups` | `number[]` | 全期間の 0/1 段取りベクトル |
| `production` | `number[]` | 各期の生産量（非負の実数値、ケース） |
| `inventory` | `number[]` | 期末在庫量（初期在庫は 0 とする、ケース） |
| `totalCost` | `number` | 固定段取り費・生産費・在庫保管費の合計（円） |

<!-- section:example -->
**入力例**

```json
{
  "demands": [20, 25, 15, 30, 20, 25],
  "setupCosts": [120, 120, 120, 120, 120, 120],
  "prodCosts": [4, 4, 4, 4, 4, 4],
  "holdCost": 1,
  "capacities": [60, 60, 60, 60, 60, 60],
  "initialPlan": [1, 1, 1, 1, 1, 1],
  "windowSize": 3
}
```

**出力例**

```json
{
  "setups": [1, 0, 0, 1, 0, 1],
  "production": [60, 0, 0, 50, 0, 25],
  "inventory": [40, 15, 0, 20, 0, 0],
  "totalCost": 975
}
```

各期の生産量（`60`, `50`, `25` $\le 60$）は段取り実施時の容量上限と在庫収支を満たし、段取り費 $120 \times 3 = 360$、生産費 $4 \times 135 = 540$、在庫保管費 $1 \times (40 + 15 + 0 + 20 + 0 + 0) = 75$ の合計は $360 + 540 + 75 =$ **975** となります。

<!-- section:hint1 -->
`initialPlan` で初期化した現在の段取りベクトルを保持し、長さ `windowSize` の重なり合うウィンドウを計画期間全体で走査します。各部分問題では現在のウィンドウ内の段取り変数だけを自由な二値変数とし、ウィンドウ外の段取りは固定したまま全期間の生産量変数・在庫量変数（いずれも非負の連続変数）を自由に調整させます。

<!-- section:hint2 -->
各部分 MIP では全期間にわたって生産上限 $0 \le p_t \le C_t y_t$ と在庫収支 $I_{t-1} + p_t - d_t = I_t$（$I_{-1} = 0$）を課し、$t \notin [\text{start}, \text{start} + \text{windowSize})$ については $y_t = \bar{y}_t$ と固定します。暫定解より厳密に（$10^{-6}$ 以上）コストが下がったときだけ解を更新し、1 周して改善がなければ終了します。
