# #032. Element 制約（at）による機械・作業割当

<!-- section:scenario -->
自動車部品工場の生産管理者は、レーザー切断や歯車切削など複数の加工作業を、作業数以上の台数がある候補 CNC 加工機へ割り当てます。各作業にはそれぞれ異なる 1 台の CNC 加工機を割り当て、同じ機械を複数の作業で共有することはできません。

作業と機械の組み合わせごとに整数の段取りコスト（千円）が定められています。すべての作業が相異なる機械を受け持つように割当先を決め、総段取りコスト（千円）を最小化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `costs` | `number[][]` | `n × m` の整数段取りコスト行列（`costs[i][j]` は作業 `i` を機械 `j` に割り当てるコスト［千円］、`1 <= n <= m`） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `assignment` | `number[]` | 長さ `n` の配列。`assignment[i]` は作業 `i` に割り当てた 0 始まりの機械番号（`0` 〜 `m - 1`） |
| `totalCost` | `number` | 最小化された総段取りコスト（千円） |

<!-- section:example -->
**入力例**

```json
{
  "costs": [
    [10, 22, 30],
    [12, 25, 18],
    [16, 14, 24]
  ]
}
```

**出力例**

```json
{
  "assignment": [0, 2, 1],
  "totalCost": 42
}
```

割当 [0, 2, 1] は 3 つの異なる機械を選び、総コストは `costs[0][0] + costs[1][2] + costs[2][1]` $= 10 + 18 + 14 =$ **42** 千円となります。

<!-- section:hint1 -->
$n \times m$ のバイナリ行列を作る代わりに、各作業に対して `[0, numMachines - 1]` の機械番号を表す整数変数を 1 つずつ定義します。すべての作業が相異なる機械を使うように制約します。

<!-- section:hint2 -->
機械の重複を防ぐために `distinct(assignment)` を追加します。各作業のコストは Element 制約 `at(row, assignment[i])` で参照できるため、`sum(input.costs.map((row, i) => at(row, assignment[i])))` を `minimize` し、`solver: "pumpkin"` で解いてください。
