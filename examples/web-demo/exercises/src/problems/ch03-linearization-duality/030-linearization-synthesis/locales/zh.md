# #030. 线性化技巧综合实战（多集群服务部署与平准化）

<!-- section:scenario -->
平台基础设施团队正从候选微服务集合中选择一个子集进行部署，使总交付价值不低于最低要求。每个服务都有基础成本并会给各区域带来负载，此外，同时部署特定服务对会产生协同降本（负系数）或资源冲突开销（正系数）。

总运维成本由四部分之和定义：基础成本、交互对成本、所有区域峰值负载的加权成本，以及各区域偏离目标负载的加权 L1 偏差。请确定部署的服务、成对同时运行标志与峰值负载，以**最小化总运维成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `baseCosts` | `number[]` | 服务 $i$ 的基础部署成本 $c_i$ |
| `values` | `number[]` | 服务 $i$ 的能力价值 $v_i$ |
| `minValue` | `number` | 要求的最低总能力 $\sum_i v_i x_i$ |
| `loads` | `number[][]` | `loads[r][i]` 为服务 $i$ 上线后对区域 $r$ 施加的负载 |
| `targets` | `number[]` | 区域 $r$ 的目标负载 $\tau_r$ |
| `devWeights` | `number[]` | 区域 $r$ 每单位 L1 偏差的惩罚权重 $\beta_r$ |
| `peakWeight` | `number` | 所有区域峰值负载 $\max_r L_r$ 的成本权重 $\alpha$ |
| `pairs` | `number[][]` | 交互对列表 `[i, j, s]`（同时部署 $i, j$ 时计入成本 $s$） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selected` | `number[]` | 各服务的 0-1 部署选择 $x_i$ |
| `pairProducts` | `number[]` | 每个配对的二元乘积 $w_k = x_i x_j$ |
| `peakLoad` | `number` | 所有区域中的峰值负载 $\max_r L_r$ |
| `totalCost` | `number` | 最小化后的总运维成本 |

<!-- section:example -->
**输入示例**

```json
{
  "baseCosts": [40, 50, 35, 45],
  "values": [30, 35, 25, 30],
  "minValue": 60,
  "loads": [
    [12, 8, 10, 6],
    [6, 14, 8, 12]
  ],
  "targets": [16, 16],
  "devWeights": [4, 4],
  "peakWeight": 6,
  "pairs": [
    [0, 1, -25],
    [1, 3, 30],
    [2, 3, -15]
  ]
}
```

**输出示例**

```json
{
  "selected": [1, 0, 0, 1],
  "pairProducts": [0, 0, 0],
  "peakLoad": 18,
  "totalCost": 209
}
```

部署服务 0 与 3（[1, 0, 0, 1]）提供价值 $30 + 30 = 60 \ge 60$，配对乘积为 [0, 0, 0]，各区域负载为 [18, 18]（峰值 18，偏离目标 16 的偏差分别为 2 和 2），总成本为 $(40 + 45) + 6 \times 18 + 4(2 + 2) =$ **209**。


<!-- section:hint1 -->
在一个 MIP 中组合三种线性化模式：用于服务选择的二元变量、用于成对交互乘积的 $[0, 1]$ 连续变量、用于区域峰值负载的标量连续上镜图变量，以及用于各区域 L1 目标跟踪的非负正负偏差变量对。

<!-- section:hint2 -->
每个区域的负载 $L_r = \sum_i \text{loads}_{r,i} x_i$ 同时进入上镜图上限（$L_r \le \text{peakLoad}$）与 L1 拆分（$L_r - \tau_r = d_r^+ - d_r^-$）。对于每个交互对 `[i, j, s]`，由于交互成本 $s$ 既可能为负（协同节省，需要上界约束）也可能为正（干扰开销，需要下界约束），必须同时施加全部三条 McCormick 不等式（$w_k \le x_i$、$w_k \le x_j$、$w_k \ge x_i + x_j - 1$）。同时别忘了最低能力要求约束，并在输出时对 `selected` 与 `pairProducts` 取整。
