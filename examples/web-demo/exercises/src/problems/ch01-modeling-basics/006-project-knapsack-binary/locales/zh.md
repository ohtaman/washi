# #006. 防灾设备采购计划（0-1 二进制变量）

<!-- section:scenario -->
某地方政府需要在有限的总预算（万日元）内，从多个候选防灾设备（如监控摄像头、应急电源、AED 等）中挑选要采购安装的设备。每项设备都无法只安装一半，只能二选一：“安装”或“不安装”。安装后的设备会消耗各自所需的费用（万日元），并带来预期的防灾效果（评分）。

请在不超出总预算的前提下，**最大化所选设备的总评分**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `budget` | `number` | 可用总预算（万日元） |
| `costs` | `number[]` | 各防灾设备所需费用（万日元） |
| `values` | `number[]` | 各防灾设备的预期评分 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selected` | `number[]` | 各设备的安装标志（0 或 1） |
| `totalValue` | `number` | 最大化后的总评分 |

<!-- section:example -->
**输入示例**

```json
{
  "budget": 15,
  "costs": [4, 5, 7, 3, 6],
  "values": [10, 12, 16, 8, 13]
}
```

**输出示例**

```json
{
  "selected": [0, 1, 1, 1, 0],
  "totalValue": 36
}
```

选择设备 1、2、3（`[0, 1, 1, 1, 0]`）时，总费用为 $5 + 7 + 3 = 15 \le 15$（预算以内），总评分为 $12 + 16 + 8 =$ **36**。
