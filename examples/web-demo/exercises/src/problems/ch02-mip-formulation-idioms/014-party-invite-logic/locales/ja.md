# #014. パーティー招待と論理パズル

<!-- section:scenario -->
あなたはディナーパーティーを企画しており、総予算内で誰を招待し、招待した各ゲストにいくらのギフト予算を割り当てるかを決定します。ゲストを招待すると基本の楽しさスコアに加えてギフト予算1単位あたりのボーナスが得られ、招待されたゲストには最小額以上・最大額以下のギフト予算を割り当てる必要があります（招待しない場合は0）。

人間関係のルールとして、あるゲストを招待するなら別のゲストも必ず招待する含意ペア、同時に招待できない競合ペア、指定されたグループから少なくとも一定人数以上を招待するグループ下限ルールが課されます。すべてのルールを満たしながら、**楽しさの合計を最大化**する招待計画を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `budget` | `number` | 全ゲスト合計のギフト予算上限 |
| `baseEnjoyment` | `number[]` | 各ゲストを招待したときの基本の楽しさ |
| `bonusRates` | `number[]` | 各ゲストのギフト予算1単位あたりの追加の楽しさ |
| `minSpend` | `number[]` | 招待したときのギフト予算の下限 |
| `maxSpend` | `number[]` | 招待したときのギフト予算の上限 |
| `implications` | `number[][]` | ゲスト `a` を招待するならゲスト `b` も招待すべきペア `[a, b]` |
| `conflicts` | `number[][]` | 同時に招待できないペア `[u, v]` |
| `groupRules` | `{ guests: number[]; minCount: number }[]` | `guests` から少なくとも `minCount` 人以上を招待する制約 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `invite` | `number[]` | 各ゲストを招待するかどうかのバイナリ値（`0` または `1`） |
| `giftBudget` | `number[]` | 各ゲストに割り当てる連続値のギフト予算 |
| `totalEnjoyment` | `number` | 最大化された楽しさの合計 |

<!-- section:example -->
**入力**

```json
{
  "budget": 55,
  "baseEnjoyment": [10, 25, 30, 15, 22],
  "bonusRates": [2, 5, 6, 3, 4],
  "minSpend": [8, 12, 10, 10, 14],
  "maxSpend": [15, 20, 18, 14, 22],
  "implications": [[1, 0]],
  "conflicts": [[2, 4]],
  "groupRules": [
    { "guests": [0, 2, 3], "minCount": 1 }
  ]
}
```

**出力**

```json
{
  "invite": [1, 1, 1, 1, 0],
  "giftBudget": [8, 19, 18, 10, 0],
  "totalEnjoyment": 329
}
```

ゲスト `{0, 1, 2, 3}` を招待し `giftBudget = [8, 19, 18, 10, 0]` とすると、含意 `1 -> 0`、競合 `[2, 4]` の回避、グループ `{0, 2, 3}` から `3 >= 1` 人の招待、総予算 $8 + 19 + 18 + 10 = 55 \le 55$ をすべて満たし、楽しさの合計は $(10 + 25 + 30 + 15) + (16 + 95 + 108 + 30) =$ **329** となります。

<!-- section:hint1 -->
各ゲストについて、招待するかどうかのバイナリ変数と、ギフト予算を表す連続変数を組にします。各ゲストのギフト予算の範囲を招待フラグに連動させ、合計予算の上限と、3種類の論理ルール（含意・競合・グループ下限）をバイナリ変数の線形不等式として表現します。

<!-- section:hint2 -->
`giftBudget[i]` と `invite[i]` の連動には、インスタンス固有のタイトな上下界（`minSpend[i]` と `maxSpend[i]`）を使います。論理ルールは、含意 $a \implies b$ を $y_a \le y_b$、競合を $y_u + y_v \le 1$、グループ下限を `rule.guests` に含まれるバイナリ変数の和が `rule.minCount` 以上として線形化します。
