# #004. 一般形プロダクトミックス（m × n 行列）

<!-- section:scenario -->
**#001** では 2 種類の製品を手書きで記述しましたが、実務では製品数も資源数もデータによって変わります。

複数のフレーバー（連続値・非負の生産量）を作り、それぞれから単位利益が得られます。各製品の 1 単位生産には複数の共有原材料・資源が一定量ずつ消費され、各資源には利用上限があります。すべての資源上限を満たしつつ **総利益を最大化する各製品の生産量** を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `margins` | `number[]` | 製品 $j$ の単位利益 |
| `usages` | `number[][]` | `usages[k][j]` が製品 $j$ 1 単位あたりの資源 $k$ の消費量 |
| `capacities` | `number[]` | 資源 $k$ の利用上限 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `quantities` | `number[]` | 各製品の非負生産量（連続値） |
| `totalProfit` | `number` | 最大化された総利益 |

<!-- section:example -->
**入力例**

```json
{
  "margins": [500, 300],
  "usages": [
    [3, 1],
    [1, 2]
  ],
  "capacities": [90, 80]
}
```

**出力例**

```json
{
  "quantities": [20, 30],
  "totalProfit": 19000
}
```

`[20, 30]` を生産すると資源消費量は資源 0 が $3 \times 20 + 1 \times 30 = 90$、資源 1 が $1 \times 20 + 2 \times 30 = 80$（いずれも上限以内）となり、総利益は $500 \times 20 + 300 \times 30 =$ **19,000** となります。
