# #063. バックオーダーと機会損失を許す在庫計画

<!-- section:scenario -->
ある精密機器メーカー（ワイヤレスイヤホンの製造元）で、既知の期首在庫と初期バックオーダーゼロの状態から、複数期間にわたる生産量・出荷販売量・期末在庫・バックオーダー（遅延出荷残）・ロストセールス（機会損失）を計画します。

各期において、実在庫は「前期在庫 ＋ 当期生産 − 当期出荷」で推移し、当期需要は「当期出荷 ＋ バックオーダー増減 ＋ 機会損失」に分解されます（ただし機会損失はその期の需要以下、かつ最終期末のバックオーダーは必ずゼロに解消します）。出荷 1 単位あたりの売価から、生産費・在庫保管費・バックオーダーペナルティ・機会損失ペナルティを差し引いた **純利益を最大化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[]` | 各期 $t$ の顧客需要 $d_t$ |
| `capacities` | `number[]` | 各期 $t$ の最大生産能力 $C_t$ |
| `prodCosts` | `number[]` | 各期 $t$ の単位生産コスト $c_t$ |
| `unitPrice` | `number` | 出荷 1 単位あたりの販売単価 $r$ |
| `holdCost` | `number` | 期末在庫 1 単位・1 期あたりの保管費 $h$ |
| `backorderCost` | `number` | 期末バックオーダー 1 単位・1 期あたりの遅延ペナルティ $p_b$ |
| `lostSalePenalty` | `number` | 機会損失 1 単位あたりのペナルティ $p_l$ |
| `initialInventory` | `number` | 第 0 期開始前の初期在庫 $I_{-1}$ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `production` | `number[]` | 各期の生産量 $x_t \in [0, C_t]$ |
| `sales` | `number[]` | 各期の出荷販売量 $s_t \ge 0$ |
| `inventory` | `number[]` | 各期の期末実在庫 $I_t \ge 0$ |
| `backlog` | `number[]` | 各期の期末バックオーダー $b_t \ge 0$（$b_{T-1} = 0$） |
| `lostSales` | `number[]` | 各期の機会損失量 $l_t \in [0, d_t]$ |
| `netProfit` | `number` | 最大化された純利益 |

<!-- section:example -->
**入力例**

```json
{
  "demands": [30, 50, 20, 25],
  "capacities": [35, 30, 40, 30],
  "prodCosts": [10, 12, 10, 11],
  "unitPrice": 22,
  "holdCost": 1.5,
  "backorderCost": 3,
  "lostSalePenalty": 5,
  "initialInventory": 5
}
```

**出力例**

```json
{
  "production": [35, 30, 30, 25],
  "sales": [30, 40, 30, 25],
  "inventory": [10, 0, 0, 0],
  "backlog": [0, 10, 0, 0],
  "lostSales": [0, 0, 0, 0],
  "netProfit": 1420
}
```

第 0 期に 10 単位先行生産し、第 1 期で不足する 10 単位を第 2 期へバックオーダーすると、両方の収支式と最終バックオーダー 0 を満たし、純利益は $125(22) - (350 + 360 + 300 + 275) - 10(1.5) - 10(3) =$ **1,420** となります。


<!-- section:hint1 -->
各期ごとに、生産量、実出荷量（売上）、期末実在庫、期末バックオーダー（受注残）、および逸失需要の 5 種類の非負連続変数を定義します。通常のロットサイズ問題とは異なり、物理的な実在庫と顧客の注文残高を 2 つの独立した収支連鎖として追跡します。

<!-- section:hint2 -->
実在庫は前期末在庫（$t = 0$ では `initialInventory`）に生産量を加え実出荷量を引いた値となり、バックオーダーは初期残高ゼロから始まり新規需要を加えて実出荷量と逸失需要を引いた値になります。`lostSales[t]` を `demands[t]` 以下に抑え、最終期のバックオーダー $b_{T-1} = 0$ を課して期末までに受注残をすべて解消してください。
