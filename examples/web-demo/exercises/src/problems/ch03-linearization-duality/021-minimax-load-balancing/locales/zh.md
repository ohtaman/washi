# #021. 极小化极大服务器负载均衡（上镜图线性化）

<!-- section:scenario -->
某分布式计算集群需要处理一批可连续切分的批处理任务，每个任务都有已知的总工作量。每个任务只能分配给标记为兼容的服务器集合，不兼容服务器上的分配比例必须为零。

请在保证每个任务都被完整分配（比例之和为 100%）的前提下，**最小化所有服务器中的最高负载（峰值负载）**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `weights` | `number[]` | 每个任务 $i$ 的工作量 |
| `compatible` | `number[][]` | 若任务 $i$ 可运行在服务器 $j$ 上则为 `1`，否则为 `0` |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `assignments` | `number[][]` | 任务 $i$ 分配给服务器 $j$ 的比例（`[0, 1]`） |
| `peakLoad` | `number` | 最小化后的最大服务器负载 |

<!-- section:example -->
**输入示例**

```json
{
  "weights": [10, 8, 6],
  "compatible": [
    [1, 0],
    [1, 1],
    [0, 1]
  ]
}
```

**输出示例**

```json
{
  "assignments": [
    [1, 0],
    [0.25, 0.75],
    [0, 1]
  ],
  "peakLoad": 12
}
```

任务 0 全部分配给服务器 0，任务 2 全部分配给服务器 1，并将任务 1 按 `0.25` / `0.75` 切分，使服务器 0 负载为 $10 + 8 \times 0.25 = 12$、服务器 1 负载为 $8 \times 0.75 + 6 = 12$，峰值负载为 **12**。
