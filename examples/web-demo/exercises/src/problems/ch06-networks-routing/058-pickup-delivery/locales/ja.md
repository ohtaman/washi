# #058. 集荷・配達付き配送計画問題 (PDP)

<!-- section:scenario -->
最大 K 台の車両がデポ 0 を拠点として、集荷地点と配達地点がペアになった複数の輸送依頼を処理します。各依頼の集荷と配達は必ず同じ車両が担当し、集荷を配達より先に訪問しなければなりません。また、どの瞬間も車両積載量は容量上限以下であり、各車両の訪問地点数も上限以下に収める必要があります。

集荷・配達ペアリング制約、先行順序制約、積載量追跡を組み込んだ混合整数計画（MIP）を定式化し、**総移動距離を最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `dist` | `number[][]` | $N \times N$ の距離行列（`0` がデポ、`1..N-1` が集荷・配達地点） |
| `requests` | `Array<{ pickup, delivery, demand }>` | 集荷点 `pickup`・配達点 `delivery`・荷物量 `demand` の依頼リスト |
| `capacity` | `number` | 車両 1 台あたりの積載容量上限 $Q$ |
| `maxVehicles` | `number` | 使用できる最大車両台数 |
| `maxStopsPerVehicle` | `number` | 1 台の車両が立ち寄れるデポ以外の最大地点数 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `routes` | `number[][]` | 各車両の配送ルート配列（`[0, ..., 0]`） |
| `totalDistance` | `number` | 最小化された全ルート総移動距離 |

<!-- section:example -->
**入力例**

```json
{
  "dist": [
    [0, 2, 7, 4, 8],
    [2, 0, 5, 1, 6],
    [7, 5, 0, 4, 1],
    [4, 1, 4, 0, 5],
    [8, 6, 1, 5, 0]
  ],
  "requests": [
    { "pickup": 1, "delivery": 2, "demand": 3 },
    { "pickup": 3, "delivery": 4, "demand": 4 }
  ],
  "capacity": 7,
  "maxVehicles": 1,
  "maxStopsPerVehicle": 4
}
```

**出力例**

```json
{
  "routes": [
    [0, 1, 3, 2, 4, 0]
  ],
  "totalDistance": 16
}
```

ルート `[0, 1, 3, 2, 4, 0]` は地点 1（積載 3）と地点 3（積載 7 ≤ 7）で順次集荷した後に地点 2・4 で配達を行い、全制約を満たして距離 $2 + 1 + 4 + 1 + 8 =$ **16** を達成します。

<!-- section:hint1 -->
同一車両による集荷・配達のペアリングを直接記述できるよう、0-1 の枝選択変数を車両 `k` ごとに添字付けします。また各地点に連続の訪問順序変数と累積積載量変数を用意し、全顧客の 1 回訪問、車両ごとのフロー保存則、および 1 台あたりの訪問地点数上限 `maxStopsPerVehicle` を課してください。

<!-- section:hint2 -->
集荷で積載量が増え配達で減るため、通常の単調な容量ベース MTZ だけでは部分巡回路を排除できません。訪問順序変数 $t_i$（$t_0 = 0$）を別に持って部分巡回路排除と集荷・配達の前後関係（$t_p + 1 \le t_d$）を強制し、積載量変数 $L_i \in [0, Q]$（$L_0 = 0$）は使用された枝上で集荷時に $+q_r$・配達時に $-q_r$ だけ増減するよう Big-M で連結してください。
