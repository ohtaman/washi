# #020. 容量制約つき施設配置問題（CFLP）

<!-- section:scenario -->
物流ネットワークにおいて、候補となる配送拠点の中からどれを開設するかと、開設した拠点から各顧客エリアへどれだけ出荷するかを同時に決定します。拠点を開設すると固定の運営費が発生し、その拠点の出荷容量上限まで商品を送り出せるようになります（開設しない拠点からの出荷量はゼロです）。

各顧客エリアの必要需要をすべて満たしながら、開設拠点の固定費と出荷量に応じた輸送費の合計を**最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `fixedCosts` | `number[]` | 各候補施設 $i$ の固定開設費 |
| `capacities` | `number[]` | 各候補施設 $i$ の総出荷容量上限 |
| `demands` | `number[]` | 各顧客エリア $j$ の必要需要量 |
| `unitCosts` | `number[][]` | 施設 $i$ から顧客 $j$ への 1 単位あたりの輸送費 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `open` | `number[]` | 各候補施設の開設選択（`0` または `1`） |
| `shipments` | `number[][]` | 施設 $i$ から顧客 $j$ への非負連続輸送量 |
| `totalCost` | `number` | 最小化された固定費＋輸送費の合計 |

<!-- section:example -->
**入力例**

```json
{
  "fixedCosts": [320, 260, 290],
  "capacities": [60, 50, 55],
  "demands": [25, 30, 20, 25],
  "unitCosts": [
    [4, 6, 9, 10],
    [7, 3, 5, 8],
    [10, 7, 4, 3]
  ]
}
```

**出力例**

```json
{
  "open": [0, 1, 1],
  "shipments": [
    [0, 0, 0, 0],
    [20, 30, 0, 0],
    [5, 0, 20, 25]
  ],
  "totalCost": 985
}
```

施設 1・2 を開設すると、容量制約（`50 <= 50`、`50 <= 55`）と顧客需要 `[25, 30, 20, 25]` を満たし、総コストは $(260 + 290) + (20 \times 7 + 30 \times 3 + 5 \times 10 + 20 \times 4 + 25 \times 3) =$ **985** となります。

<!-- section:hint1 -->
各施設の開設有無を表すバイナリ変数と、施設から顧客への輸送量を表す連続変数行列を組み合わせます。施設ごとの行和に対する容量連結制約と、顧客ごとの列和に対する需要充足制約が必要です。

<!-- section:hint2 -->
各施設 $i$ からの総出荷量（全顧客 $j$ にわたる和）を `capacities[i] * open[i]` 以下に抑えることで、未開設施設からの出荷を禁じつつ開設施設の容量上限を課せます。目的関数には固定開設費（`fixedCosts`）と輸送単価（`unitCosts`）の両方を含めて最小化してください。
