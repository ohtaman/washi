# #020. 容量制約つき施設配置問題（CFLP）

<!-- section:scenario -->
スペシャルティコーヒーのロースターが、複数の焙煎所候補の中からどこを開設し、各カフェ店舗へ毎月何 kg の焙煎豆を出荷するかを決定します。焙煎所を開設すると固定の運営費が発生し、その焙煎所の月間出荷能力（kg）まで豆を送り出せるようになります（開設しない焙煎所からの出荷量はゼロです）。

各カフェ店舗の月間需要（kg）をすべて満たしながら、開設した焙煎所の固定運営費と出荷量に応じた配送費の合計を**最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `fixedCosts` | `number[]` | 各候補焙煎所 $i$ の固定運営費 |
| `capacities` | `number[]` | 各候補焙煎所 $i$ の月間出荷能力上限（kg） |
| `demands` | `number[]` | 各カフェ店舗 $j$ の必要需要量（kg） |
| `unitCosts` | `number[][]` | 焙煎所 $i$ からカフェ店舗 $j$ への 1 kg あたりの配送費 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `open` | `number[]` | 各候補焙煎所の開設選択（0 または 1） |
| `shipments` | `number[][]` | 焙煎所 $i$ からカフェ店舗 $j$ への非負連続出荷量（kg） |
| `totalCost` | `number` | 最小化された固定運営費＋配送費の合計 |

<!-- section:example -->
**入力例**

```json
{
  "fixedCosts": [320, 260, 290],
  "capacities": [60, 50, 55],
  "demands": [25, 30, 20, 25],
  "unitCosts": [
    [4, 6, 9, 10],
    [7, 3, 5, 8],
    [10, 7, 4, 3]
  ]
}
```

**出力例**

```json
{
  "open": [0, 1, 1],
  "shipments": [
    [0, 0, 0, 0],
    [20, 30, 0, 0],
    [5, 0, 20, 25]
  ],
  "totalCost": 985
}
```

焙煎所 1・2 を開設すると、出荷能力制約（`50 <= 50`、`50 <= 55`）とカフェ店舗需要 `[25, 30, 20, 25]` を満たし、総コストは $(260 + 290) + (20 \times 7 + 30 \times 3 + 5 \times 10 + 20 \times 4 + 25 \times 3) =$ **985** となります。

<!-- section:hint1 -->
各焙煎所の開設有無を表すバイナリ変数と、焙煎所からカフェ店舗への出荷量を表す連続変数行列を組み合わせます。焙煎所ごとの行和に対する出荷能力連結制約と、カフェ店舗ごとの列和に対する需要充足制約が必要です。

<!-- section:hint2 -->
各焙煎所 $i$ からの総出荷量（全カフェ店舗 $j$ にわたる和）を `capacities[i] * open[i]` 以下に抑えることで、未開設の焙煎所からの出荷を禁じつつ開設焙煎所の出荷能力上限を課せます。目的関数には固定運営費（`fixedCosts`）と配送単価（`unitCosts`）の両方を含めて最小化してください。
