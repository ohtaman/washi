# #039. 带区域和约束的拉丁方谜题

<!-- section:scenario -->
在一个 N 乘 N 的整数网格中填入 1 到 N 的数字，使每一行和每一列都恰好包含 1 到 N 各一次。

givens 中的提示固定了对应单元格的数值，而 cages 中的每个区域要求所含单元格内数字互不相同且总和等于 targetSum。请将此题作为无目标函数的纯可行性问题求解。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `size` | `number` | 网格阶数 `N`（单元格填入 `1..N`） |
| `givens` | `number[][]` | 已知提示格 `[row, col, value]`（行列索引从 `0` 开始） |
| `cages` | `CageClue[]` | 区域和线索 `{ cells, targetSum }`（区域内数字互异且求和等于 `targetSum`） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `grid` | `number[][]` | 满足所有拉丁方与区域线索的 `N × N` 二维数组 |

<!-- section:example -->
**输入示例**

```json
{
  "size": 4,
  "givens": [[0, 0, 1], [1, 1, 4], [2, 3, 3]],
  "cages": [
    { "cells": [[0, 1], [0, 2]], "targetSum": 5 },
    { "cells": [[0, 3], [1, 3]], "targetSum": 6 },
    { "cells": [[1, 0], [2, 0], [2, 1]], "targetSum": 6 },
    { "cells": [[1, 2], [2, 2]], "targetSum": 5 },
    { "cells": [[3, 0], [3, 1]], "targetSum": 7 },
    { "cells": [[3, 2], [3, 3]], "targetSum": 3 }
  ]
}
```

**输出示例**

```json
{
  "grid": [
    [1, 2, 3, 4],
    [3, 4, 1, 2],
    [2, 1, 4, 3],
    [4, 3, 2, 1]
  ]
}
```

每行每列均为 `{1, 2, 3, 4}` 的排列，满足全部提示格与区域和约束（例如 `2 + 3 = 5`、`3 + 2 + 1 = 6`）。
