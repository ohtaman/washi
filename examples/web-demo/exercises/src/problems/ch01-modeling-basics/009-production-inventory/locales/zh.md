# #009. 多周期生产与库存平滑（流守恒）

<!-- section:scenario -->
某电动自行车装配工厂需要基于已知的期初库存（辆），对连续多个周期（按月）的正常班生产、加班生产以及期末库存进行统筹排程。

- 每个周期的正常产量、加班产量与期末库存均为非负连续值，且分别不超过各期的正常产能上限、加班产能上限和仓库库容上限。
- 每个周期均需满足物料平衡：上期期末库存加本期正常产量和加班产量，减去本期需求，等于本期期末库存。
- 最后一个周期结束时，期末库存不少于规定的最低安全库存下限。

请制定各期的正常产量、加班产量与期末库存计划，以**最小化总生产与库存保管成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `demands` | `number[]` | 各周期 $t$ 的自行车需求量（辆） |
| `regCap` | `number[]` | 各周期 $t$ 的正常产能上限（辆） |
| `otCap` | `number[]` | 各周期 $t$ 的加班产能上限（辆） |
| `invCap` | `number` | 每期仓库最大存储容量（辆） |
| `initialInventory` | `number` | 期初（0期开始前）的初始库存（辆） |
| `minFinalInventory` | `number` | 最后一期末最低安全库存下限（辆） |
| `regCost` | `number` | 正常生产每辆成本 |
| `otCost` | `number` | 加班生产每辆成本 |
| `holdCost` | `number` | 每辆每期库存保管费 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `regular` | `number[]` | 各周期正常班产量计划（辆） |
| `overtime` | `number[]` | 各周期加班产量计划（辆） |
| `inventory` | `number[]` | 各周期期末库存计划（辆） |
| `totalCost` | `number` | 最小化后的总生产与保管成本 |

<!-- section:example -->
**输入示例**

```json
{
  "demands": [80, 140, 120, 70],
  "regCap": [100, 100, 100, 100],
  "otCap": [40, 40, 40, 40],
  "invCap": 60,
  "initialInventory": 10,
  "minFinalInventory": 10,
  "regCost": 20,
  "otCost": 32,
  "holdCost": 3
}
```

**输出示例**

```json
{
  "regular": [100, 100, 100, 80],
  "overtime": [0, 10, 20, 0],
  "inventory": [30, 0, 0, 10],
  "totalCost": 8680
}
```

从初始库存 10 出发，各期满足产销平衡与库存上下限（期末库存 `[30, 0, 0, 10]` ≤ 60，期末 10 ≥ 10），总成本为 $380 \times 20 + 30 \times 32 + 40 \times 3 =$ **8,680**。
