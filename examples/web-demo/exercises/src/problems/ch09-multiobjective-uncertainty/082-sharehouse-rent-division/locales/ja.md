# #082. シェアハウスの部屋割り・公平家賃分割

<!-- section:scenario -->
同じ数の個室があるシェアハウスに複数人の住人が入居し、月間の合計家賃を全員で分担します。各住人はそれぞれの部屋に対して評価額を持っており、割り当てられた部屋の評価額からその部屋の家賃を引いた値が余剰となります。

第1段階では、各住人に異なる部屋を1つずつ割り当てて**住人全体の評価額合計を最大化**します。第2段階では、その最適な部屋割りを保ったまま、どの住人も他の部屋とその家賃の組み合わせを羨まない（無羨望性）非負の家賃配分を合計家賃と一致するように決め、**最小の住人余剰を最大化**してできるだけ公平な家賃分割を求めます。なお、各問題インスタンスは第1段階の最適割り当てのもとで非負の無羨望家賃配分が存在することが保証されています。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `valuations` | `number[][]` | 住人 `i` の部屋 `r` に対する評価額 `valuations[i][r]` の行列 |
| `totalRent` | `number` | 全部屋で分担する合計家賃 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `assignment` | `number[]` | 各住人に割り当てられた部屋番号（0始まり） |
| `rents` | `number[]` | 各部屋に設定された非負の家賃 |
| `totalValuation` | `number` | 第1段階で最大化された部屋割りの評価額合計 |
| `minSurplus` | `number` | 第2段階で最大化された全住人の最小余剰 |

<!-- section:example -->
**入力例**

```json
{
  "valuations": [
    [800, 500, 400],
    [600, 700, 450],
    [550, 500, 600]
  ],
  "totalRent": 1500
}
```

**出力例**

```json
{
  "assignment": [0, 1, 2],
  "rents": [600, 500, 400],
  "totalValuation": 2100,
  "minSurplus": 200
}
```

住人 $i$ に部屋 $i$ を割り当てると評価額合計は $800 + 700 + 600 = 2100$ となり、家賃を $[600, 500, 400]$ とすると合計 $1500$ で全住人が無羨望かつ余剰 **200** を得られます。

<!-- section:hint1 -->
問題を2つの連続したモデルに分けます。第1段階は各住人に各部屋を1対1で割り当てて評価額合計を最大化する割当問題です。第2段階ではその部屋割りを固定したうえで、各部屋の家賃と補助変数である最小余剰を決定する連続線形計画問題を解きます。

<!-- section:hint2 -->
なぜ第1段階を先に解く必要があるのでしょうか。無羨望な家賃ベクトルが存在するのは評価額合計を最大化する部屋割りのときに限られ、最適でない割り当てでは第2段階が無羨望制約により実行不可能になります。第2段階では `rents` に下限 0（`lb: 0` / `lowBound=0`）を、`minSurplus` には非負制約を外した自由変数（WaSHI では `lb: -Infinity, ub: Infinity`、PuLP では `lowBound=None`）を設定し、各住人の余剰が `minSurplus` 以上かつ他の全部屋での余剰以上になる制約を加えます。
