# #091. 紧致 Big-M 与模型尺度优化

<!-- section:scenario -->
某饮料制造商的生产计划负责人需要决定开启哪些灌装工厂以及各工厂的产量（单位：箱），在满足总需求（箱）的同时最小化固定成本与变动生产成本之和。当部分工厂的物理最大产能远超总需求时，若直接采用极大常数或原始工厂产能作为 Big-M，会严重削弱连续 LP 松弛的下界。

请利用可从输入数据推导出的各工厂最紧致上界（紧致 Big-M）来建立开机与产量的关联约束，并同时返回整数最优解以及该紧致模型的 LP 松弛目标值。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `fixedCosts` | `number[]` | 工厂 $i$ 开机运行产生的固定成本 |
| `unitCosts` | `number[]` | 工厂 $i$ 每箱的生产成本 |
| `capacities` | `number[]` | 工厂 $i$ 的物理最大产能（箱） |
| `demand` | `number` | 必须满足的总需求量（箱） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `open` | `number[]` | 各工厂的开机选择（0 或 1） |
| `quantities` | `number[]` | 各工厂的产量（非负实数值，箱） |
| `totalCost` | `number` | 最小化总成本（固定成本加单位成本） |
| `lpBound` | `number` | 紧致 Big-M 模型的连续 LP 松弛目标值 |

<!-- section:example -->
**输入示例**

```json
{
  "fixedCosts": [1000, 200, 450],
  "unitCosts": [10, 12, 11],
  "capacities": [500, 40, 80],
  "demand": 60
}
```

**输出示例**

```json
{
  "open": [0, 0, 1],
  "quantities": [0, 0, 60],
  "totalCost": 1110,
  "lpBound": 1050
}
```

仅开启工厂 2 并生产 $60 \le 80$ 单位满足总需求 $60$，总成本为 $450 + 11 \times 60 =$ **1,110**，紧致 Big-M 的 LP 松弛下界为 **1,050**。

<!-- section:hint1 -->
为每座工厂建立二元开启决策变量和非负连续产量变量。在满足总需求并将每座工厂产量与其开启指示变量关联的约束下，最小化固定启用成本与变动生产成本之和。

<!-- section:hint2 -->
任何单座工厂都不需要生产超过总需求的数量，因此工厂 $i$ 最紧致的 Big-M 应取 $M_i = \min(\text{capacities}[i], \text{demand})$，而非原始产能或任意大常数。在 WaSHI 中构建一次 MIP 并在 `await m.solve()` 之前调用 `await m.relax()` 读取 `lpBound`；在 PuLP 中则分别求解连续松弛（二元变量松弛至 $[0, 1]$）和 MIP。
