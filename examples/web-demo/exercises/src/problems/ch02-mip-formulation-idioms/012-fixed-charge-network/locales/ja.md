# #012. 固定費つき輸送ネットワーク設計

<!-- section:scenario -->
青果卸売業者が複数の産地集荷場から複数のスーパーマーケットへ旬のりんご（トン）を配送するために、候補の中から利用するトラック輸送ルートを選んで配送網を設計します。各ルートを使うには最初にチャーター契約の固定費を支払ってルートを開設する必要があり、開設したルートではその積載容量上限（トン）まで連続量で輸送できます。逆に、開設しないルートの輸送量はゼロでなければなりません。

各集荷場の出荷上限と各スーパーの必要需要を満たしつつ、すべての開設ルートにかかる契約固定費と輸送量に比例する変動輸送費の合計を**最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `supplies` | `number[]` | 各集荷場 $i$ の出荷上限（トン） |
| `demands` | `number[]` | 各スーパー $j$ の必要需要量（トン） |
| `fixedCosts` | `number[][]` | ルート $(i, j)$ を開設する契約固定費 |
| `unitCosts` | `number[][]` | ルート $(i, j)$ の 1 トンあたりの輸送費 |
| `capacities` | `number[][]` | ルート $(i, j)$ 開設時の最大積載容量（トン） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `open` | `number[][]` | 各ルートを開設するかどうかの行列（0 または 1） |
| `shipments` | `number[][]` | 各ルート $(i, j)$ の非負連続輸送量（トン） |
| `totalCost` | `number` | 最小化された契約固定費＋輸送費の合計 |

<!-- section:example -->
**入力例**

```json
{
  "supplies": [65, 60],
  "demands": [30, 35, 25],
  "fixedCosts": [
    [120, 40, 260],
    [250, 280, 90]
  ],
  "unitCosts": [
    [4, 5, 8],
    [3, 2, 3]
  ],
  "capacities": [
    [40, 40, 30],
    [35, 45, 40]
  ]
}
```

**出力例**

```json
{
  "open": [
    [1, 1, 0],
    [0, 0, 1]
  ],
  "shipments": [
    [30, 35, 0],
    [0, 0, 25]
  ],
  "totalCost": 620
}
```

ルート `(0, 0)`・`(0, 1)`・`(1, 2)` を開設すると、積載容量上限・集荷場の出荷上限（$65 \le 65$、$25 \le 60$）・スーパー需要 `[30, 35, 25]` をすべて満たし、総コストは $(120 + 40 + 90) + (30 \times 4 + 35 \times 5 + 25 \times 3) =$ **620** となります。

<!-- section:hint1 -->
各ルート $(i, j)$ には開設を表すバイナリ変数と輸送量を表す連続変数があります。各ルートの輸送量を開設判断と連結しつつ、行方向の和で集荷場の出荷上限を、列方向の和でスーパーの需要下限を表します。

<!-- section:hint2 -->
`shipments[i][j]` と `open[i][j]` を連結するタイトな上界としてルート積載容量 `capacities[i][j]` を用いると、未開設ルートの輸送量は強制的にゼロになります。目的関数には契約固定費（`fixedCosts`）と単位輸送費（`unitCosts`）の両方を含めてください。
