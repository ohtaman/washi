# #015. 最小コスト集合被覆問題

<!-- section:scenario -->
セキュリティ運用チームが、複数の重要コンポーネントをすべて監視するために候補監視パッケージから導入するものを選択します。各パッケージには導入コストが設定されており、監視対象となるコンポーネントの部分集合が定まっています（複数のパッケージで監視対象が重複しても構いません）。

全コンポーネントのそれぞれが、選ばれたパッケージのうち**少なくとも 1 つ以上**によって監視されるように選択し、**総コストを最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `numElements` | `number` | 対象要素数（インデックス `0` 〜 `numElements - 1`） |
| `costs` | `number[]` | 各候補集合の導入コスト |
| `sets` | `number[][]` | 各候補集合 $j$ がカバーする要素インデックスの配列 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `selected` | `number[]` | 各候補集合の採択有無（`0` または `1`） |
| `totalCost` | `number` | 最小化された総コスト |

<!-- section:example -->
**入力例**

```json
{
  "numElements": 5,
  "costs": [7, 4, 5, 6, 8],
  "sets": [
    [0, 1, 2],
    [0, 3],
    [1, 2, 4],
    [2, 3, 4],
    [0, 1, 3, 4]
  ]
}
```

**出力例**

```json
{
  "selected": [0, 1, 1, 0, 0],
  "totalCost": 9
}
```

集合 1（`[0, 3]`）と集合 2（`[1, 2, 4]`）を選ぶと、全要素 `{0, 1, 2, 3, 4}` をすべてカバーしつつ総コストは $4 + 5 =$ **9** となります。

<!-- section:hint1 -->
各候補パッケージをバイナリ選択変数で表します。要素ごとに 1 本の被覆制約を設け、その要素を含むパッケージが少なくとも 1 つ選ばれるようにしながら、総コストを最小化します。

<!-- section:hint2 -->
包含関係の向きを転置して考えます。`sets[j]` を回すのではなく、各要素 $i \in \{0, \dots, \text{numElements} - 1\}$ ごとに $i$ を含むすべてのパッケージ $j$ の `selected[j]` を集め、その和が $\ge 1$ となるように制約してください。
