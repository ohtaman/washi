# #001. ベーカリーの生産計画（上限制約と最大化）

<!-- section:scenario -->

あるベーカリーでは、小麦粉とバターを使ってクロワッサンと食パンを作り、販売しています。材料の在庫を最大限に活かして、利益を最大化したいと考えています。

小麦粉の在庫 `flourCap` とバターの在庫 `butterCap` を超えない範囲で、利益が最大になる各商品の生産量を求めてください。各商品の利益と必要な材料の量は以下のとおりです。

* **クロワッサン 1 個**：利益 `40`（小麦粉 `2`、バター `1` を使用）
* **食パン 1 斤**：利益 `70`（小麦粉 `3`、バター `2` を使用）

初期コードでは、バターの在庫制約だけが未実装となっています。なお、各商品の生産量は連続値として扱って構いません。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `flourCap` | `number` | 小麦粉の在庫量 |
| `butterCap` | `number` | バターの在庫量 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `croissants` | `number` | クロワッサンの生産量（$\ge 0$） |
| `loaves` | `number` | 食パンの生産量（$\ge 0$） |
| `totalProfit` | `number` | 最大化された総利益 |

<!-- section:example -->
**入力例**

```json
{
  "flourCap": 120,
  "butterCap": 70
}
```

**出力例**

```json
{
  "croissants": 30,
  "loaves": 20,
  "totalProfit": 2600
}
```

クロワッサン 30・食パン 20 を作ると、小麦粉使用量は$2\times 30 + 3\times 20 = 120 \leq 120$ 、バター使用量は $30 + 2\times 20 = 70 \leq 70$ となり、制約を満たします。そのとき総利益は `40\times30 + 70\times20=2600` となります。
