# #029. OR 制約と凸包定式化（離散的な運転モード）

<!-- section:scenario -->
工場の運転管理者は、複数の生産ユニットを稼働させて合計で目標需要量（t/h）以上を供給する計画を立てています。

運転計画は次の条件をすべて満たす必要があります。
- **排他的な運転モード（バンド）**: 各ユニットは「停止（出力 0）」「低負荷エコ運転」「高負荷ターボ運転」など複数のバンドからちょうど 1 つを選んで稼働する
- **出力区間と空白区間**: 各バンドには決まった出力範囲があり、隣り合うバンドの間には運転できない出力区間（空白区間）がある
- **総需要の充足**: 全ユニットの出力の合計が目標需要量以上であること

各バンドには固有の固定費（万円）と単位変動費（万円/(t/h)）が設定されています。複数の排他的なバンドから 1 つを選ぶ選言（OR）条件を凸包定式化で表現し、需要を満たしながら**固定費と変動費の合計（万円）を最小化**するバンド選択と出力水準を求めてください。

<!-- section:io -->
### 入力

すべてのユニットでバンド数は共通であり、各 2 次元配列は `[unit][band]` の順に格納されます。

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demand` | `number` | 全ユニット合計の最低必要出力（t/h） |
| `bandLbs` | `number[][]` | 各 `[unit][band]` の出力下限（t/h） |
| `bandUbs` | `number[][]` | 各 `[unit][band]` の出力上限（t/h） |
| `fixedCosts` | `number[][]` | 各 `[unit][band]` を選んだときの固定費（万円） |
| `unitCosts` | `number[][]` | 各 `[unit][band]` における単位変動費（万円/(t/h)） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `modes` | `number[]` | 各ユニットが選んだバンド番号（0 始まり） |
| `outputs` | `number[]` | 各ユニットの選択バンド範囲内の出力（t/h） |
| `totalCost` | `number` | 最小化された総コスト（万円） |

<!-- section:example -->
**入力例**

```json
{
  "demand": 42,
  "bandLbs": [
    [0, 10, 30],
    [0, 8, 25]
  ],
  "bandUbs": [
    [0, 20, 45],
    [0, 18, 40]
  ],
  "fixedCosts": [
    [0, 120, 260],
    [0, 90, 220]
  ],
  "unitCosts": [
    [0, 18, 12],
    [0, 20, 14]
  ]
}
```

**出力例**

```json
{
  "modes": [2, 0],
  "outputs": [42, 0],
  "totalCost": 764
}
```

ユニット 0 をバンド 2（[30, 45]）で出力 42 t/h、ユニット 1 を停止バンド 0（[0, 0]）で出力 0 t/h とすると需要 $42 + 0 \ge 42$ t/h を満たし、総コストは $260 + 12 \times 42 =$ **764** 万円になります。


<!-- section:hint1 -->
ユニットとバンドの双方で添字付けられた分解型凸包（disaggregated convex-hull）定式化を用います。各ユニット・バンドの組に対して、そのバンドが選択されたかを表すバイナリ変数と、そのバンドでの出力を表す非負の連続変数を宣言します。

<!-- section:hint2 -->
各ユニットでちょうど 1 つのバンドが選ばれるよう $\sum_k y_{ik} = 1$ を課し、各バンドの出力区間 $[L_{ik}, U_{ik}]$ を指示変数 $y_{ik}$ でスケールします（$L_{ik} y_{ik} \le x_{ik} \le U_{ik} y_{ik}$）。これにより非選択バンドでは $x_{ik} = 0$ となり、選択バンドでは $[L_{ik}, U_{ik}]$ に厳密に収まるため、緩い Big-M を避けつつバンド間の禁止された出力区間に入るのを防げます。全ユニット・全バンドの $x_{ik}$ の和で `demand` を満たし、出力時は各ユニットの選択バンド番号と総出力 $\sum_k x_{ik}$ を復元してください。
