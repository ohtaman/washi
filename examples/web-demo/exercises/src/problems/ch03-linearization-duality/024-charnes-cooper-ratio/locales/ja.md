# #024. 線形分数計画の比率最大化（Charnes-Cooper 変換）

<!-- section:scenario -->
精密部品工場の生産計画担当者は、原材料や加工時間などの共有資源容量および各部品の生産上限のもとで、複数種類の精密部品の生産量（個、非負の連続量・小数可）を決定します。今回は利益額そのものではなく、符号付きの固定純リターン項（万円、固定収入なら正・固定費なら負）を含む「総純リターン」と、正の基本維持費（万円）を含む「総投入コスト」の比率である**投資効率比を最大化**したいと考えています。

Charnes-Cooper 変換を用いて、すべての資源制約と各部品の生産上限を満たしながら効率比を最大化する生産量と最大比率を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `numCoeffs` | `number[]` | 部品 $j$ の 1 個あたり純リターン $c_j$（万円/個） |
| `numConst` | `number` | 符号付き固定純リターン項 $c_0$（万円、固定収入なら正・固定費なら負） |
| `denCoeffs` | `number[]` | 部品 $j$ の 1 個あたり投入コスト $d_j$（万円/個、非負） |
| `denConst` | `number` | 正の基本維持費 $d_0 > 0$（万円） |
| `usages` | `number[][]` | 資源消費行列 $A$（`usages[k][j]` は部品 $j$ を 1 個生産するときの資源 $k$ の消費量） |
| `capacities` | `number[]` | 共有資源 $k$ の容量上限 $b_k$ |
| `upperBounds` | `number[]` | 部品 $j$ の生産上限 $u_j$（個） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `x` | `number[]` | 各部品の生産量（個） |
| `maxRatio` | `number` | 最大化された効率比 $(c^\top x + c_0) / (d^\top x + d_0)$ |

<!-- section:example -->
**入力例**

```json
{
  "numCoeffs": [12, 9],
  "numConst": 10,
  "denCoeffs": [4, 2],
  "denConst": 8,
  "usages": [
    [1, 1]
  ],
  "capacities": [8],
  "upperBounds": [5, 6]
}
```

**出力例**

```json
{
  "x": [0, 6],
  "maxRatio": 3.2
}
```

`x` が [0, 6] のとき、資源消費 $0 + 6 \le 8$ および個別上限 [5, 6] を満たし、分子 $9 \times 6 + 10 = 64$、分母 $2 \times 6 + 8 = 20$ から効率比は $64 / 20 =$ **3.2** となります。


<!-- section:hint1 -->
元の部品生産量変数で直接解く代わりに Charnes-Cooper 変換を適用します。分母の逆数を表す非負のスケーリング変数と、その値を各部品の生産量に掛けた非負のスケール済み変数群を導入します。

<!-- section:hint2 -->
陥りやすい点は、各部品の生産上限をスケールし忘れることです。変換後のモデルでは分母を 1 に正規化するのに加え、共有資源容量だけでなく各部品の生産上限にもスケーリング変数 $t$ を掛ける必要があり、元の定数上限のままにしてはなりません。元の実行可能領域が有界（$0 \le x \le u$）かつ分母が常に正（$d \ge 0, d_0 > 0$）であるため、変換後の任意の実行可能解で $t > 0$ が成り立ち、$x = y / t$ で元の生産量を厳密に復元できます。
