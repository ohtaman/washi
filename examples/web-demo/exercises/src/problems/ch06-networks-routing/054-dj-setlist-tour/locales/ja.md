# #054. DJセットリスト順の最適化

<!-- section:scenario -->
DJはオープニング曲0からライブセットを始め、手持ちの他のすべての曲をちょうど1回ずつ再生し、最後にアンコールとして曲0へ戻って締めくくります。テンポの上下やキーの相性、エネルギーの流れは曲順の向きに依存するため、曲iの直後に曲jを流すときの違和感コストは逆向きと異なる場合があります。

分断された小ループを許さず全曲を1つの閉じた巡回順へ並べ、**総違和感コストを最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `transitions` | `number[][]` | $n \times n$ の非対称な曲間違和感コスト行列（`transitions[i][j]` は曲 `i` から `j` への遷移コスト） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `setlist` | `number[]` | 曲 0 から始まる全 $n$ 曲の再生順（`setlist[0] = 0`） |
| `totalCost` | `number` | 最小化された閉巡回セットリストの総違和感コスト |

<!-- section:example -->
**入力**

```json
{
  "transitions": [
    [0, 11, 3, 8],
    [9, 0, 12, 2],
    [2, 6, 0, 10],
    [7, 4, 5, 0]
  ]
}
```

**出力**

```json
{
  "setlist": [0, 2, 1, 3],
  "totalCost": 18
}
```

`0 -> 2 -> 1 -> 3 -> 0` の順に流すと全4曲を1つの巡回で網羅でき、総違和感コストは $3 + 6 + 2 + 7 =$ **18** になります。

<!-- section:hint1 -->
異なる2曲の順序対ごとに1つのバイナリ遷移変数を置き、さらにオープニング曲以外の各曲に対して連続の再生順ポテンシャル変数を用意します。各曲の入次数と出次数がちょうど1になるように制約し、総遷移コストを最小化してください。

<!-- section:hint2 -->
次数制約だけでは互いに孤立した部分巡回路が生まれます。オープニング曲以外の遷移 $(i, j)$ に対して Miller-Tucker-Zemlin (MTZ) 制約 $u_i - u_j + n x_{ij} \le n - 1$ を課し、$x_{ij} = 1$ のときに $u_i + 1 \le u_j$ となるようにすれば、曲0を含む単一の巡回路のみが実行可能になります。最後に曲0から採用された遷移をたどって `setlist` を復元してください。
