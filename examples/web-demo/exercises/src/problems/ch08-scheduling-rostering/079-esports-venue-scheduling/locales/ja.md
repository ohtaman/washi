# #079. e-Sportsリーグの試合会場・タイムスロット割当

<!-- section:scenario -->
e-Sports リーグが、$M$ 件の試合候補を $V$ 個の会場と $S$ 個のタイムスロットに編成します。

編成は次の条件に従います。
- **試合の条件と選択的実施**: 各試合には必要な配信時間、実施時に得られる視聴スコア、開催できる会場の条件があり、各試合は高々 1 回のみ実施できる（未実施とすることもでき、その場合はスコア 0）。
- **会場・スロット枠と延長**: 複数の試合を同じ `(venue, slot)` 枠に配置できるが、合計配信時間はその枠の通常配信時間（`regularLength`）と延長時間（上限 `maxOvertime`）の和を超えてはならず、延長には 1 単位あたりの線形ペナルティがかかる。
- **目的**: 各試合を開催可能な `(venue, slot)` 枠に割り当て、合計視聴スコアから合計延長コストを引いた純スコアを最大化する。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `durations` | `number[]` | 各試合 $m$ の配信時間 |
| `scores` | `number[]` | 試合 $m$ を実施したときに得られる視聴スコア |
| `compatible` | `number[][]` | 試合 $m$ が会場 $v$ で開催可能かを表す $M \times V$ の 0/1 行列 |
| `numSlots` | `number` | 各会場のタイムスロット数 $S$ |
| `regularLength` | `number` | 各 `(venue, slot)` 枠の通常配信時間 |
| `maxOvertime` | `number` | 各 `(venue, slot)` 枠で許容される最大延長時間 |
| `overtimeCost` | `number` | 通常配信時間を超えた延長 1 単位あたりのペナルティコスト |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `assignedVenue` | `number[]` | 各試合に割り当てた会場番号 0〜$V-1$（未実施は -1） |
| `assignedSlot` | `number[]` | 各試合に割り当てたスロット番号 0〜$S-1$（未実施は -1） |
| `overtime` | `number[][]` | 各 `(venue, slot)` で使用した非負の延長時間（$V \times S$） |
| `netScore` | `number` | 最大化された合計視聴スコアから延長コストを引いた純スコア |

<!-- section:example -->
**入力例**

```json
{
  "durations": [2, 4, 3, 3, 2],
  "scores": [55, 95, 70, 65, 18],
  "compatible": [
    [1, 1],
    [1, 0],
    [0, 1],
    [1, 1],
    [1, 1]
  ],
  "numSlots": 2,
  "regularLength": 3,
  "maxOvertime": 1,
  "overtimeCost": 25
}
```

**出力例**

```json
{
  "assignedVenue": [1, 0, 1, 0, -1],
  "assignedSlot": [1, 0, 0, 1, -1],
  "overtime": [
    [1, 0],
    [0, 0]
  ],
  "netScore": 260
}
```

試合 0〜3 はそれぞれ適合会場（`compatible[m][v] = 1`）に配置され、会場 0 の負荷 [4, 3] と会場 1 の負荷 [3, 2] は通常配信時間 3＋延長 [[1, 0], [0, 0]]（`maxOvertime = 1` 以内）に収まり、試合 4 は未実施（-1）で純スコア $(55 + 95 + 70 + 65) - 25 \times 1 =$ **260** となります。

<!-- section:hint1 -->
各試合をどの会場・どのスロットに割り当てるかを表す 3 次元のバイナリ決定変数と、各会場・スロット枠の延長時間を表す上限付きの非負連続変数を組み合わせます。各試合は適合する会場に高々 1 回だけ割り当てられ、各枠の合計配信時間は通常配信時間と延長時間の和以下に収まる必要があります。

<!-- section:hint2 -->
`overtimeCost` が正で `netScore` を最大化しているため、連続変数（`m.continuous` / `pulp.LpVariable`）の延長時間は追加のバイナリ指標変数なしで自動的に `regularLength` を超えた超過分と一致します。不適合な `(m, v)` への割当を 0 に固定することと、未実施の試合を `assignedVenue`・`assignedSlot` の両方で -1 と出力することを忘れないでください。
