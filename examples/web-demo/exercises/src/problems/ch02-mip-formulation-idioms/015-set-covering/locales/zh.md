# #015. 最小成本集合覆盖问题

<!-- section:scenario -->
某安全运维中心需要采购若干监控服务包以保护所有关键系统组件。每个候选服务包具有固定采购成本，并可监测一组指定组件，允许不同已选服务包的监测范围发生重叠。

请选择一组监控服务包，使得每一个关键组件都**至少被一个**所选服务包覆盖，同时**最小化总采购成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `numElements` | `number` | 待覆盖组件数量（编号 0 到 `numElements - 1`） |
| `costs` | `number[]` | 选择每个候选服务包的采购成本 |
| `sets` | `number[][]` | 每个候选服务包所监测的组件编号列表 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selected` | `number[]` | 各候选服务包是否入选（0 或 1） |
| `totalCost` | `number` | 最小化后的总采购成本 |

<!-- section:example -->
**输入示例**

```json
{
  "numElements": 5,
  "costs": [7, 4, 5, 6, 8],
  "sets": [
    [0, 1, 2],
    [0, 3],
    [1, 2, 4],
    [2, 3, 4],
    [0, 1, 3, 4]
  ]
}
```

**输出示例**

```json
{
  "selected": [0, 1, 1, 0, 0],
  "totalCost": 9
}
```

选择服务包 1（`[0, 3]`）与服务包 2（`[1, 2, 4]`）可覆盖全部组件 `{0, 1, 2, 3, 4}`，总采购成本为 $4 + 5 =$ **9**。

<!-- section:hint1 -->
为每个候选服务包设置一个二元选择变量。模型对每个组件建立一条覆盖约束，保证至少选中一个包含该组件的服务包，同时最小化总采购成本。

<!-- section:hint2 -->
将包含关系转置来看：不要按 `sets[j]` 遍历，而是对每个组件 $i \in \{0, \dots, \text{numElements} - 1\}$ 收集所有包含 $i$ 的服务包 $j$ 对应的 `selected[j]`，并约束其和 $\ge 1$。
