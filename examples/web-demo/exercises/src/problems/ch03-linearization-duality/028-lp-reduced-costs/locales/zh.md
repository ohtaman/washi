# #028. LP 检验数（Reduced Cost）与入基门槛

<!-- section:scenario -->
某化工厂通过组合多种非负生产工艺来满足最低产出指标，并使总成本最小。在当前工艺单价下，部分成本过高的候选工艺在最优方案中的投入量为零。

工艺团队希望知道：每种未被选用的工艺需要降价多少才具备进入最优配比的竞争力（即强行从零增加 1 单位该工艺所导致的最小成本增量）。请将问题建模为最小化 LP，并返回各工艺投入量、各变量的检验数以及最小总成本。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `costs` | `number[]` | 工艺 $j$ 的单位成本 $c_j$ |
| `yields` | `number[][]` | 产出矩阵 $A$，$A_{kj}$ 为单位工艺 $j$ 对指标 $k$ 的贡献 |
| `minRequirements` | `number[]` | 最低指标要求 $r_k$（$\sum_j A_{kj} x_j \ge r_k$） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `quantities` | `number[]` | 各工艺的非负投入量 $x_j$ |
| `reducedCosts` | `number[]` | 各变量 $x_j$ 的检验数 $\bar{c}_j$ |
| `optimalCost` | `number` | 最小化后的总成本 $z^*$ |

<!-- section:example -->
**输入示例**

```json
{
  "costs": [10, 14, 24, 30],
  "yields": [
    [1, 2, 2, 3],
    [2, 1, 3, 1]
  ],
  "minRequirements": [17, 16]
}
```

**输出示例**

```json
{
  "quantities": [5, 6, 0, 0],
  "reducedCosts": [0, 0, 6, 10],
  "optimalCost": 134
}
```

投入量 `[5, 6, 0, 0]` 恰好满足要求 `[17, 16]` 且成本为 $10 \times 5 + 14 \times 6 =$ **134**，对偶解 `[6, 2]` 对应两个未选用工艺的检验数分别为 `24 - (6*2 + 2*3) = 6` 与 `30 - (6*3 + 2*1) = 10`。


<!-- section:hint1 -->
为每个工艺引入一个非负连续决策变量，表示该工艺的运行水平。

<!-- section:hint2 -->
求解 LP 后，通过 WaSHI 的 `v.reducedCost!`（或 PuLP 的 `v.dj`）读取各变量的检验数。不要直接使用原始单价或手动取反：在带非负变量的最小化 LP 中，正基变量的检验数为 `0`，而未启用变量的检验数为非负值，表示该变量进入基所需降低的成本幅度。请直接返回求解器的精确结果，不要人为舍入。
