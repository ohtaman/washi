# #038. 含对称破缺的图着色

<!-- section:scenario -->
无线电频谱规划师正针对由相互干扰的无线基站（顶点）构成的无向图，从固定数量的可用频段信道（从 0 开始依次编号的整数）中为各基站分配信道。任何相互干扰（有边相连）的两个基站必须分配不同的信道编号。

请在所有满足干扰约束的着色方案中，最小化所使用的不同信道（颜色）总数。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `numNodes` | `number` | 基站（顶点）数量（`0` 到 `numNodes - 1`） |
| `maxColors` | `number` | 可用信道（颜色）编号的数量（`0` 到 `maxColors - 1`） |
| `edges` | `number[][]` | 相互干扰的基站对列表（从 0 开始的无向边 `[u, v]`） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `colors` | `number[]` | 每个顶点分配的颜色编号（位于 `[0, maxColors - 1]`） |
| `usedColors` | `number` | 使用的不同颜色数量的最小值 |

<!-- section:example -->
**输入**

```json
{
  "numNodes": 5,
  "maxColors": 5,
  "edges": [
    [0, 1],
    [1, 2],
    [2, 0],
    [2, 3],
    [3, 4]
  ]
}
```

**输出**

```json
{
  "colors": [0, 1, 2, 0, 2],
  "usedColors": 3
}
```

所有边 (0, 1)、(1, 2)、(2, 0)、(2, 3)、(3, 4) 的两端信道编号均不相同，共使用了 {0, 1, 2} 这 **3** 种信道。

<!-- section:hint1 -->
为每个顶点声明一个整数颜色变量，并用一个整数变量追踪已使用的最大颜色编号。由于颜色编号可以任意置换而保持合法性，通过强制顶点按顺序无跳号地引入新颜色来打破值对称，然后最小化所用的颜色总数。

<!-- section:hint2 -->
对每条边施加 `colors[u] != colors[v]`。通过 `colors[0] == 0` 以及对 `i >= 1` 施加 `colors[i] <= 1 + max(colors.slice(0, i))` 打破颜色置换对称性；再约束所有 `colors[i] <= maxColor`，并用 `solver: "pumpkin"` 最小化 `maxColor + 1`。
