# #035. 互斥机器调度（disjoint 全局约束）

<!-- section:scenario -->
半导体制造工厂的生产计划负责人正在为多项晶圆加工任务（清洗、光刻、刻蚀等）制定调度方案，使各项任务在各自负责的机器上不中断地连续执行。每项任务都指定了加工时长（分钟）、最早可开始时间（释放时间，分钟）以及负责机器编号。

使用同一台机器的任务在时间上不能重叠，且对于给定了先后约束的任务对，必须等前置任务完全结束后才能开始后继任务。请确定各项任务的开始时间，以最小化整体完工时间（makespan，分钟）。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `durations` | `number[]` | 各任务的加工时长（整数，分钟） |
| `releaseTimes` | `number[]` | 各任务的释放时间（非负整数，分钟） |
| `machines` | `number[]` | 各任务使用的机器编号（`0` 到 `M - 1`，`M` 为机器数量） |
| `precedences` | `number[][]` | 从 0 开始的先后顺序任务对 `[u, v]` 列表（任务 `u` 完成后才能开始任务 `v`） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `starts` | `number[]` | 各任务的开始时间（整数，分钟） |
| `makespan` | `number` | 最小化后的最大完工时间（分钟） |

<!-- section:example -->
**输入示例**

```json
{
  "durations": [4, 3, 5, 2],
  "releaseTimes": [0, 2, 0, 4],
  "machines": [0, 0, 0, 0],
  "precedences": [
    [0, 3]
  ]
}
```

**输出示例**

```json
{
  "starts": [0, 6, 9, 4],
  "makespan": 14
}
```

机器 0 上依次无重叠地执行任务 0（[0, 4)）→ 任务 3（[4, 6)）→ 任务 1（[6, 9)）→ 任务 2（[9, 14)），同时满足释放时间与先后关系 0 → 3。最大完工时间为 $\max(0 + 4, 6 + 3, 9 + 5, 4 + 2) = \max(4, 9, 14, 6) =$ **14** 分钟。

<!-- section:hint1 -->
为每个任务定义一个下界为释放时间、上界为 `horizon - durations[i]` 的整数开始时间变量。除先后约束外，按所属机器对任务分组，并对每台机器施加不重叠析取约束。

<!-- section:hint2 -->
对每台机器收集其任务列表 `{ start: starts[i], duration: input.durations[i] }`，若非空则施加 `disjoint(tasks)` 约束。以 ``minimize(max(starts.map((s, i) => expr`${s} + ${input.durations[i]}`)))`` 为目标，并通过 `solver: "pumpkin"` 求解。
