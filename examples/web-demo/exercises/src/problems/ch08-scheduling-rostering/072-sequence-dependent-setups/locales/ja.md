# #072. 段取り時間依存の単一機械スケジューリング

<!-- section:scenario -->
自動車部品の塗装ライン 1 基で、時刻 0 から複数の部品ロット（ジョブ）を連続処理します（先頭ジョブの前の初期段取り時間は 0 です）。各ジョブには正の処理時間と納期があり、あるジョブの直後に別のジョブへ切り替える際には、その順序ペアに応じた段取り替え時間が発生します。処理時間・段取り替え時間・納期はいずれも小数を取り得ます。

完了時刻が納期を超えると超過分だけ納期遅れが発生します（納期以前に完了した場合は 0 です）。すべてのジョブを処理する順序（順列）と各ジョブの完了時刻を定め、全ジョブの納期遅れの総和を最小化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `processingTimes` | `number[]` | 各ジョブの処理時間 $p_j$ |
| `setupMatrix` | `number[][]` | ジョブ $i$ の直後にジョブ $j$ を処理する際の段取り時間 $s_{ij}$ |
| `dueDates` | `number[]` | 各ジョブの納期 $d_j$ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `order` | `number[]` | 処理するジョブ番号 `0..n-1` の順列 |
| `completions` | `number[]` | 各ジョブ $j$ の完了時刻 $C_j$（`order` の位置ではなく元のジョブ番号 $j$ 順） |
| `totalTardiness` | `number` | 最小化された総納期遅れ $\sum_j \max(0, C_j - d_j)$ |

<!-- section:example -->
**入力例**

```json
{
  "processingTimes": [3, 4, 2],
  "setupMatrix": [
    [0, 5, 1],
    [2, 0, 4],
    [3, 1, 0]
  ],
  "dueDates": [6, 8, 5]
}
```

**出力例**

```json
{
  "order": [0, 2, 1],
  "completions": [3, 11, 6],
  "totalTardiness": 4
}
```

ジョブを $0 \to 2 \to 1$ の順に処理すると $C_0 = 3$（遅れ 0）、$C_2 = 3 + 1 + 2 = 6$（遅れ 1）、$C_1 = 6 + 1 + 4 = 11$（遅れ 3）となり、総納期遅れは $0 + 1 + 3 =$ **4** となります。

<!-- section:hint1 -->
ジョブの順序を、全ジョブに加えてスケジュールの始点・終点を表すダミーのデポノードを通る 1 本の有向巡回路としてモデル化します。ノード間の 0-1 アーク選択変数に加え、各ジョブの連続値の完了時刻変数と非負の納期遅れ変数を用意します。

<!-- section:hint2 -->
デポを含む全ノードの出次数・入次数を 1 にしてサイクル被覆を作った上で、ジョブ間の有向アークに沿って Big-M 時間伝播制約で完了時刻を結びます。処理時間が正であるため、時間伝播によって段取り替え時間の加算と部分巡回路（サブツアー）の排除を同時に達成できます。上界 $H = \sum_j p_j + (n - 1)\max s_{ij}$ から $M = H + \max s_{ij}$ を取り、デポの次のノードから順に辿って `order` を復元してください。
