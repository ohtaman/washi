# #007. 一对一配送区域指派问题

<!-- section:scenario -->
某快递营业所拥有数量相同的配送员和负责区域（如北区、东区、南区等），每位配送员负责不同区域都有对应的配送成本（千日元）。

请制定一个一对一指派方案，使每位配送员恰好负责 1 个区域，且每个区域恰好分配给 1 位配送员，从而**最小化总成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `costs` | `number[][]` | $n \times n$ 指派成本矩阵（千日元，`costs[i][j]` 为配送员 $i$ 负责区域 $j$ 的成本） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `assignment` | `number[]` | 长度为 $n$ 的数组（`assignment[i]` 为分配给配送员 $i$ 的区域编号） |
| `totalCost` | `number` | 最小化后的总成本（千日元） |

<!-- section:example -->
**输入示例**

```json
{
  "costs": [
    [9, 2, 7],
    [6, 4, 3],
    [5, 8, 1]
  ]
}
```

**输出示例**

```json
{
  "assignment": [1, 0, 2],
  "totalCost": 9
}
```

指派方案 `[1, 0, 2]` 为每位配送员分配了互不重复的 1 个区域（每行与每列的分配数均为 1），总成本为 $2 + 6 + 1 =$ **9**。
