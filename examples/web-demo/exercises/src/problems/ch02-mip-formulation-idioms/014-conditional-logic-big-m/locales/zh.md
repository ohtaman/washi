# #014. 逻辑条件与紧 Big-M 激活规划

<!-- section:scenario -->
某基础设施团队需要在总规模预算约束下，决定启用哪些候选设施以及各启用设施的连续运行规模。启用任意设施需支付固定成本，且其连续规模必须落在给定的上下限之间；未启用设施的运行规模必须为零。

同时业务策略包含三类逻辑依赖：前置依赖规定启用前项时必须启用后项，合取触发规定当两个指定设施同时启用时必须连带启用第三个配套设施，冲突互斥则禁止同一对设施同时启用。请在满足所有规则与预算上限的前提下，**最大化净利润**（总收益减去固定成本之和）。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `budget` | `number` | 全部设施连续运行规模之和的上限 |
| `unitReturns` | `number[]` | 各设施单位运行规模的收益 |
| `fixedCosts` | `number[]` | 各设施启用时的固定成本 |
| `minLevels` | `number[]` | 各设施启用时的最小运行规模 |
| `maxLevels` | `number[]` | 各设施启用时的最大运行规模 |
| `prerequisites` | `number[][]` | 前置对 `[a, b]`，表示启用 `a` 则必须启用 `b` |
| `conjunctions` | `number[][]` | 三元组 `[a, b, c]`，表示同时启用 `a` 与 `b` 则必须启用 `c` |
| `conflicts` | `number[][]` | 互斥对 `[u, v]`，表示两者不能同时启用 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `active` | `number[]` | 各设施的启用开关（`0` 或 `1`） |
| `levels` | `number[]` | 各设施的连续运行规模 |
| `netProfit` | `number` | 最大化后的净利润 |

<!-- section:example -->
**输入示例**

```json
{
  "budget": 55,
  "unitReturns": [6, 22, 24, 10, 20],
  "fixedCosts": [90, 80, 75, 110, 95],
  "minLevels": [10, 15, 14, 12, 16],
  "maxLevels": [18, 22, 20, 14, 24],
  "prerequisites": [[1, 0]],
  "conjunctions": [[1, 2, 3]],
  "conflicts": [[2, 4]]
}
```

**输出示例**

```json
{
  "active": [1, 1, 0, 0, 1],
  "levels": [10, 22, 0, 0, 23],
  "netProfit": 739
}
```

启用设施 `{0, 1, 4}` 并令 `levels = [10, 22, 0, 0, 23]` 满足前置 `1 -> 0`、互斥 `[2, 4]`、合取触发与预算 $10 + 22 + 23 = 55 \le 55$，净利润为 $(60 + 484 + 460) - (90 + 80 + 95) =$ **739**。
