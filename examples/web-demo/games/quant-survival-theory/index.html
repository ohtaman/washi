凸二次計画法（Convex QP）＆ 確率的リスク管理モデリング解説

『QUANT SURVIVAL』の裏側：
破綻確率の最小化（Safety-First基準）とマーコウィッツの平均・分散モデル

対象読者：線形計画・二次計画および確率統計の基礎（期待値・分散・共分散）に関心のある方。
初期資金 $100M から毎期の市場ショックを乗り越えて資産を複利成長させる『QUANT SURVIVAL』が、どのように破綻確率（Ruin Probability）を定式化し、ライバルAI WaSHI-QP がブラウザ内で凸二次計画問題（Convex QP）を解いているのかを解説します。

1. なぜ「一番儲かる銘柄に100%集中投資」すると必ず破綻するのか

1ラウンド限りのギャンブルであれば、期待リターンが最大の銘柄（たとえば TECH: 期待リターン +16%, ボラティリティ 24%）に資金を100%投じる戦略でも勝てるかもしれません。しかし、資産が毎期引き継がれるエンドレス複利サバイバルでは事情が一変します。

仮に1四半期あたりのロスカット退場（破綻）確率が 18% あるポートフォリオを組み続けた場合、10四半期後まで生き残れる確率は次のように急減します。

複数期にまたがる生存確率の減衰 P(10期生存) = (1 - 0.18)^10 ≈ 0.137 (わずか 13.7%)

一方、逆相関のヘッジ資産を組み合わせて1期あたりの破綻確率を 1.2% まで引き下げれば、10期生存確率は (1 - 0.012)^10 ≈ 88.6% となり、複利効果によって着実に資産を拡大できます。これは年金基金・機関投資家・ヘッジファンドが直面する実務課題そのものです。

2. ロイの Safety-First 基準と「破綻確率の最小化」

投資対象となる N 個の資産に対する投資比率（ウェイト）を決定変数ベクトル w = (w_1, ..., w_N)^T と置きます。空売りなし（w_i >= 0）かつ全額投資（Σ w_i = 1）のとき、ポートフォリオ全体の期待リターン μ_p(w) と分散 σ_p^2(w) は次式で与えられます。

ポートフォリオの期待リターンと分散（二次形式） μ_p(w) = Σ_{i=1..N} w_i * μ_i = μ^T w
σ_p^2(w) = Σ_{i=1..N} Σ_{j=1..N} w_i * w_j * Σ_{ij} = w^T Σ w

ここで Σ_{ij} = σ_i * σ_j * ρ_{ij} は資産 i と資産 j の共分散、ρ_{ij} ∈ [-1, 1] は相関係数です。

今期のロスカット退場ライン（許容下限リターン）を r_floor（例：-5.5%）としたとき、ポートフォリオ収益率 R_p ~ N(μ_p(w), σ_p^2(w)) が r_floor を下回る破綻確率（Ruin Probability）は、標準正規分布の累積分布関数 Φ(z) を用いて次のように表せます。

破綻確率 P_ruin(w) と Safety-First 比率 SF(w) = (μ_p(w) - r_floor) / σ_p(w)
P_ruin(w) = Pr(R_p <= r_floor) = Φ(-SF(w))
💡 破綻確率の最小化と「二次計画法（QP）」の関係 標準正規分布の累積分布関数 Φ(-z) は z に関して厳密に単調減少します。したがって、期待リターンを μ^T w = μ_target と等式で固定した条件下では、破綻確率 P_ruin(w) を最小化することは、分母の分散 w^T Σ w を最小化する凸二次計画問題（マーコウィッツの平均・分散モデル）と数学的に同値になります。
一方、ゲーム内の WaSHI-QP は μ^T w >= μ_target（下限付き）の制約で分散を最小化しています。この場合は分子 μ_p - r_floor もポートフォリオごとに変わるため、分散がわずかに大きくても期待リターンが高く、破綻確率はより低いポートフォリオが存在し得ます。つまり WaSHI-QP は「破綻確率の厳密な最小化」ではなく、目標リターンを満たす最小分散ポートフォリオというベンチマークです。

3. 逆相関ヘッジ（ρ < 0）がリスクを消し去る仕組み

2資産（例：TECH と GOLD）の分散展開式を見ると、なぜ相関係数 ρ_{12} < 0 のペアを混ぜると破綻確率が激減するのかが一目でわかります。

2資産ポートフォリオの分散 σ_p^2 = w_1^2 * σ_1^2 + w_2^2 * σ_2^2 + 2 * w_1 * w_2 * σ_1 * σ_2 * ρ_{12}

第3項の交差項 2 w_1 w_2 σ_1 σ_2 ρ_{12} に注目してください。TECH と GOLD のように相関係数が負（例：ρ_{12} = -0.62）である場合、この交差項が大きなマイナスの値となり、各資産が本来持っていた変動リスク σ_1^2, σ_2^2 を内側から相殺します。

4. WaSHI + HiGHS による凸二次計画問題（QP）の実装

ゲーム内のライバル WaSHI-QP は、毎期のスタート時に以下の凸二次計画問題をブラウザ内の HiGHS ソルバーで実際に解いています。

WaSHI-QP の最適化モデル minimize    Σ_{i=1..N} Σ_{j=1..N} Σ_{ij} * w_i * w_j  -  ε * Σ_{i=1..N} μ_i * w_i
subject to   Σ_{i=1..N} w_i == 1               (全額投資制約)
             Σ_{i=1..N} μ_i * w_i >= μ_target  (目標期待リターン制約)
             0 <= w_i <= w_max             (空売り禁止・単一銘柄集中上限) 
const model = new Model(`QuantQP_Q${regime.quarter}`);
const wVars = regime.assets.map((_, i) =>
  model.continuous(`w_${i}`, { lb: 0, ub: regime.maxWeightPerAsset })
);

// 1. 全額投資制約: sum(w_i) == 1
model.constraint(sum(wVars).eq(1), "full_investment");

// 2. 目標期待リターン制約: sum(mu_i * w_i) >= targetReturn
const returnTerms = wVars.map((v, i) => v.mul(regime.assets[i].expectedReturn));
model.constraint(sum(returnTerms).ge(target), "target_return");

// 3. 二次目的関数: ポートフォリオ分散 w^T Sigma w の最小化
let quadObj = wVars[0].mul(wVars[0]).mul(regime.covariance[0][0]);
for (let i = 0; i < n; i++) {
  for (let j = i; j < n; j++) {
    if (i === 0 && j === 0) continue;
    const coeff = i === j ? regime.covariance[i][j] : 2 * regime.covariance[i][j];
    if (Math.abs(coeff) > 1e-9) {
      quadObj = quadObj.add(wVars[i].mul(wVars[j]).mul(coeff));
    }
  }
}
model.objective(minimize(quadObj));
await model.solve(HiGHS);

5. コレスキー分解による60営業日の相関相場シミュレーション

[MARKET OPEN] を押した後に走る60営業日のチャートバトルでは、各銘柄がバラバラに乱数で動くのではなく、共分散行列 Σ のコレスキー分解（Cholesky Decomposition: Σ = L L^T）を使って相関付きの多次元正規乱数を生成しています。

相関を持つ日次リターンベクトルの生成 r_t = (1 / 60) * μ + (1 / √60) * L * z_t + shock_t   (z_t ~ N(0, I))

これにより、ハイテク株が急落するショック日には逆相関のゴールドや防衛株が実際に買われて反発するという、理論通りのヘッジ効果がリアルタイムの波形として再現されます。

Convex Quadratic Programming (QP) & Stochastic Risk Modeling Guide

Behind "QUANT SURVIVAL":
Minimizing Ruin Probability via Roy's Safety-First Criterion and Markowitz QP

Target Audience: Readers interested in mathematical optimization (LP/QP) and quantitative portfolio theory.
This article explains how "QUANT SURVIVAL" formulates Ruin Probability across an endless compounding survival run, and how the rival AI WaSHI-QP solves a live Convex Quadratic Program (QP) in the browser using HiGHS.

1. Why Going 100% into the Highest-Return Asset Leads to Ruin

In a single-shot gamble, putting 100% of your capital into the asset with the highest expected return (such as TECH: +16% expected return, 24% volatility) might pay off. In an endless compounding survival game where capital carries over from quarter to quarter, that strategy is a mathematical trap.

If your portfolio carries an 18% probability of breaching the liquidation floor each quarter, your probability of surviving 10 consecutive quarters decays exponentially:

Multi-Quarter Survival Probability Decay P(Survive 10 Quarters) = (1 - 0.18)^10 ≈ 0.137 (only 13.7%)

By contrast, blending negatively correlated hedge assets to compress single-quarter ruin probability down to 1.2% raises 10-quarter survival probability to (1 - 0.012)^10 ≈ 88.6%, allowing compound growth to work in your favor.

2. Roy's Safety-First Criterion and Ruin Probability

Let w = (w_1, ..., w_N)^T denote the portfolio weights across N investable assets, subject to no short-selling (w_i >= 0) and full investment (Σ w_i = 1). The portfolio expected return μ_p(w) and variance σ_p^2(w) are:

Portfolio Expected Return and Quadratic Variance μ_p(w) = Σ_{i=1..N} w_i * μ_i = μ^T w
σ_p^2(w) = Σ_{i=1..N} Σ_{j=1..N} w_i * w_j * Σ_{ij} = w^T Σ w

Given a quarterly liquidation floor r_floor (for example, -5.5%), the probability that the quarterly return R_p ~ N(μ_p(w), σ_p^2(w)) falls below r_floor is given by the standard normal CDF Φ(z):

Ruin Probability P_ruin(w) and Safety-First Ratio SF(w) = (μ_p(w) - r_floor) / σ_p(w)
P_ruin(w) = Pr(R_p <= r_floor) = Φ(-SF(w))
💡 Relationship to Markowitz Minimum-Variance QP Because Φ(-z) is strictly decreasing in z, minimizing the ruin probability P_ruin(w) while the expected return is fixed by equality (μ^T w = μ_target) is mathematically equivalent to minimizing the quadratic variance w^T Σ w via Convex Quadratic Programming.
The in-game WaSHI-QP, however, minimizes variance under the inequality μ^T w >= μ_target. There the numerator μ_p - r_floor also varies across feasible portfolios, so a portfolio with slightly higher variance but higher expected return can have a lower shortfall probability. WaSHI-QP is therefore a minimum-variance benchmark under a return floor, not an exact Safety-First optimizer.

3. How Negative Correlation (ρ < 0) Cancels Volatility

Expanding the variance of a two-asset portfolio reveals why pairing negatively correlated assets (such as TECH and GOLD with ρ_{12} = -0.62) dramatically reduces ruin probability:

Two-Asset Variance Expansion σ_p^2 = w_1^2 * σ_1^2 + w_2^2 * σ_2^2 + 2 * w_1 * w_2 * σ_1 * σ_2 * ρ_{12}

When ρ_{12} < 0, the cross-covariance term 2 w_1 w_2 σ_1 σ_2 ρ_{12} is negative, subtracting directly from the standalone variances of the individual assets.

4. Solving the Convex QP in the Browser with WaSHI + HiGHS

At the start of every quarter, the rival engine WaSHI-QP formulates and solves the following Convex Quadratic Program using WaSHI and HiGHS: 

const model = new Model(`QuantQP_Q${regime.quarter}`);
const wVars = regime.assets.map((_, i) =>
  model.continuous(`w_${i}`, { lb: 0, ub: regime.maxWeightPerAsset })
);

// 1. Full investment constraint: sum(w_i) == 1
model.constraint(sum(wVars).eq(1), "full_investment");

// 2. Target expected return constraint: sum(mu_i * w_i) >= targetReturn
const returnTerms = wVars.map((v, i) => v.mul(regime.assets[i].expectedReturn));
model.constraint(sum(returnTerms).ge(target), "target_return");

// 3. Quadratic objective: minimize portfolio variance w^T Sigma w
let quadObj = wVars[0].mul(wVars[0]).mul(regime.covariance[0][0]);
for (let i = 0; i < n; i++) {
  for (let j = i; j < n; j++) {
    if (i === 0 && j === 0) continue;
    const coeff = i === j ? regime.covariance[i][j] : 2 * regime.covariance[i][j];
    if (Math.abs(coeff) > 1e-9) {
      quadObj = quadObj.add(wVars[i].mul(wVars[j]).mul(coeff));
    }
  }
}
model.objective(minimize(quadObj));
await model.solve(HiGHS);

凸二次规划（Convex QP）与随机风险管理建模解说

《量化生存战 QUANT SURVIVAL》背后的数学模型：
爆仓概率最小化（Safety-First准则）与马科维茨均值-方差模型

目标读者：对线性规划、二次规划及概率统计基础（期望值、方差、协方差）感兴趣的读者。
本文将解析《量化生存战》如何将爆仓概率（Ruin Probability）转化为数学模型，以及对手 WaSHI-QP 如何在浏览器内使用 HiGHS 实时求解凸二次规划问题（Convex QP）。

1. 为什么“全仓单一最高收益资产”在复利生存战中必然爆仓

如果只赌一局，全仓预期回报最高的资产（例如 TECH：预期收益 +16%，波动率 24%）或许能靠运气取胜。但在净值逐季复利累积的无尽生存模式中，若单季触发强平爆仓线的概率为 18%，连续存活10个季度的概率将迅速衰减：

多季度存活概率的指数衰减 P(存活10个季度) = (1 - 0.18)^10 ≈ 0.137 (仅 13.7%)

反之，若利用负相关资产进行对冲，将单季爆仓概率压缩至 1.2%，连续10个季度的存活率将提升至 (1 - 0.012)^10 ≈ 88.6%，从而稳健享受复利增长。

2. Roy 的 Safety-First 准则与爆仓概率最小化

设 N 项资产的权重向量为 w = (w_1, ..., w_N)^T（满足禁空令 w_i >= 0 与满仓约束 Σ w_i = 1）。投资组合的预期收益率 μ_p(w) 与方差 σ_p^2(w) 为：

投资组合预期收益与二次型方差 μ_p(w) = Σ_{i=1..N} w_i * μ_i = μ^T w
σ_p^2(w) = Σ_{i=1..N} Σ_{j=1..N} w_i * w_j * Σ_{ij} = w^T Σ w

设本季强平爆仓线为 r_floor（例如 -5.5%），则组合收益率 R_p ~ N(μ_p(w), σ_p^2(w)) 跌破 r_floor 的爆仓概率可通过标准正态分布累积分布函数 Φ(z) 表示为：

爆仓概率 P_ruin(w) 与 Safety-First 比率 SF(w) = (μ_p(w) - r_floor) / σ_p(w)
P_ruin(w) = Pr(R_p <= r_floor) = Φ(-SF(w))
💡 最小化爆仓概率与凸二次规划（QP）的关系 由于 Φ(-z) 关于 z 严格单调递减，在以等式固定预期收益（μ^T w = μ_target）的条件下，最小化爆仓概率 P_ruin(w) 在数学上等价于最小化投资组合方差 w^T Σ w（马科维茨均值-方差模型）。
而游戏中的 WaSHI-QP 是在不等式 μ^T w >= μ_target 约束下最小化方差。此时分子 μ_p - r_floor 也会随组合变化，方差略大但预期收益更高的组合可能拥有更低的爆仓概率。因此 WaSHI-QP 是满足收益下限的最小方差基准，而非严格的 Safety-First 最优解。

3. 负相关对冲（ρ < 0）如何抵消波动风险

展开两项资产的方差公式即可看出，当相关系数 ρ_{12} < 0（如 TECH 与 GOLD 的相关系数为 -0.62）时，交叉项 2 w_1 w_2 σ_1 σ_2 ρ_{12} 为负值，能够直接抵消单一资产自身的波动方差：

双资产组合方差展开式 σ_p^2 = w_1^2 * σ_1^2 + w_2^2 * σ_2^2 + 2 * w_1 * w_2 * σ_1 * σ_2 * ρ_{12}
