# #022. 加权 L1 偏差线性化（目标追踪）

<!-- section:scenario -->
电力公司的调度运行人员需要决定多个发电机组（火电、燃气、水电等）的发电出力分配（MW，非负）。在各发电机组出力不超过额定上限且总成本（万元）不超过预算上限的条件下，必须使总出力严格等于指定的需求值（MW）。由于各发电机组的理想目标值可能与预算约束或总出力条件无法直接兼顾，需要对部分机组进行增减调整。

偏离目标出力的上方与下方偏差都会按各发电机组给定的权重受到惩罚。请在满足所有约束的同时，求出**最小化与目标值偏差的加权绝对值之和（加权 L1 偏差）**的出力分配方案。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `targets` | `number[]` | 各发电机组 $i$ 的目标出力 $\tau_i$（MW） |
| `weights` | `number[]` | 偏离目标出力每 1 MW 的惩罚权重 $w_i$ |
| `upperBounds` | `number[]` | 各发电机组 $i$ 的最大额定出力上限 $u_i$（MW） |
| `costs` | `number[]` | 各发电机组 $i$ 的单位发电成本 $c_i$（万元/MW） |
| `budget` | `number` | 允许的总成本上限（万元） |
| `totalOutput` | `number` | 所需的总出力之和（MW） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `allocations` | `number[]` | 各发电机组的出力分配 $x_i$（MW） |
| `totalDeviation` | `number` | 最小化后的加权 L1 偏差 $\sum_i w_i \lvert x_i - \tau_i \rvert$ |

<!-- section:example -->
**输入示例**

```json
{
  "targets": [40, 30, 30],
  "weights": [3, 2, 1],
  "upperBounds": [60, 60, 60],
  "costs": [5, 2, 1],
  "budget": 230,
  "totalOutput": 100
}
```

**输出示例**

```json
{
  "allocations": [25, 30, 45],
  "totalDeviation": 60
}
```

出力分配 [25, 30, 45] 合计为 100 MW，总成本满足 $5 \times 25 + 2 \times 30 + 1 \times 45 = 230 \le 230$ 万元，加权 L1 偏差为 $3 \lvert 25 - 40 \rvert + 2 \lvert 30 - 30 \rvert + 1 \lvert 45 - 30 \rvert =$ **60**。


<!-- section:hint1 -->
为每个发电机组声明一个从 0 到上限的连续出力变量。为了在不使用二元变量的情况下线性化绝对偏差，还需为每个发电机组准备一对表示高于目标的正偏差（超额）和低于目标的负偏差（不足）的非负辅助变量。

<!-- section:hint2 -->
将每个发电机组相对目标的有符号偏差表示为正偏差变量与负偏差变量之差，并在目标函数中惩罚二者之和。由于惩罚权重非负，在最优解处两个辅助变量中至少有一个会自动为 0，从而无需二元变量即可线性化绝对值。
