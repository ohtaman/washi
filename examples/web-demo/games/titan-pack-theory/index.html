2D STRIP / BIN PACKING MILP & FAULT-LINE FREE

『TITAN PACK』の数理モデル解説 — 2次元板金パッキングと非重複制約の線形化

最先端チタン板金のレーザー加工を題材としたパズルゲーム『TITAN PACK』の背後にある、混合整数線形計画法（MILP）による2次元ストリップパッキング問題の定式化と、知恵の輪のように噛み合う「断層ゼロ（Fault-Line Free）」アルゴリズムの仕組みを解説します。

1. 2次元パッキング問題（2D Packing Problem）とは

2次元パッキング問題は、与えられた母材プレート（長方形のシート）の中に、異なる寸法を持つ複数の長方形パーツを「互いに重ならず」「はみ出さず」配置する組合せ最適化問題です。板金加工、木工、半導体フロアプランニングなど実産業で広く応用されています。

すべてのパーツを隙間なくぴったり詰め込み、端材（材料ロス）を 0% にできるか判定する問題は NP 困難であることが知られています。

2. 幾何学的非重複制約の線形化（Big-M 定式化）

2つの長方形パーツ $i$ と $j$（位置 $(x_i, y_i)$、幅 $w_i$、高さ $h_i$）が互いに重ならないための条件は、本来「排他的論理和（OR）」を含む非線形な条件です：

$$x_i + w_i \le x_j \quad \text{または} \quad x_j + w_j \le x_i \quad \text{または} \quad y_i + h_i \le y_j \quad \text{または} \quad y_j + h_j \le y_i$$

混合整数線形計画法（MILP）では、4つのバイナリ変数 $\delta_{ij,1}, \delta_{ij,2}, \delta_{ij,3}, \delta_{ij,4} \in \{0, 1\}$ と十分大きな定数 $M$ を用いて以下のように線形制約へ変換します：

$$\begin{aligned} x_i + w_i &\le x_j + M(1 - \delta_{ij,1}) \\ x_j + w_j &\le x_i + M(1 - \delta_{ij,2}) \\ y_i + h_i &\le y_j + M(1 - \delta_{ij,3}) \\ y_j + h_j &\le y_i + M(1 - \delta_{ij,4}) \\ \delta_{ij,1} + \delta_{ij,2} + \delta_{ij,3} + \delta_{ij,4} &\ge 1 \end{aligned}$$

3. 断層禁止（Fault-Line Free）の幾何学的保証

単にパーツを長方形に分割するだけでは、端から端まで貫通する直線（ギロチン切断線）が生じ、パズルが「ただの小分けの寄せ集め」になってしまいます。

TITAN PACK では、すべての垂直境界 $c \in \{1, \dots, W-1\}$ および水平境界 $r \in \{1, \dots, H-1\}$ について、少なくとも1つのパーツがその境界を跨ぐ（$x_i < c < x_i + w_i$）構造を保証するMulti-Scale Interlocking & Core Partitioning アルゴリズムを採用し、知恵の輪のように有機的に噛み合う良問を無限に生成しています。

4. WaSHI による実装コード例

TypeScript 数理最適化モデリングライブラリ @ohtaman/washi を使ってこの 2D パッキングモデルを構築するコードは以下の通りです： 

import { Model } from "@ohtaman/washi";

const model = new Model("TitanPacking2D");
const M = Math.max(plateW, plateH) + 1;

// 1. 各パーツの座標変数
const x = parts.map((p, i) => model.addVar({ lb: 0, ub: plateW - p.w, name: `x_${i}` }));
const y = parts.map((p, i) => model.addVar({ lb: 0, ub: plateH - p.h, name: `y_${i}` }));

// 2. ペアごとの非重複制約 (Big-M)
for (let i = 0; i < parts.length; i++) {
  for (let j = i + 1; j < parts.length; j++) {
    const d1 = model.addVar({ type: "binary", name: `d_${i}_${j}_left` });
    const d2 = model.addVar({ type: "binary", name: `d_${i}_${j}_right` });
    const d3 = model.addVar({ type: "binary", name: `d_${i}_${j}_below` });
    const d4 = model.addVar({ type: "binary", name: `d_${i}_${j}_above` });

    model.addConstr(x[i].add(parts[i].w).sub(x[j]).sub(M * (1 - d1)).le(0));
    model.addConstr(x[j].add(parts[j].w).sub(x[i]).sub(M * (1 - d2)).le(0));
    model.addConstr(y[i].add(parts[i].h).sub(y[j]).sub(M * (1 - d3)).le(0));
    model.addConstr(y[j].add(parts[j].h).sub(y[i]).sub(M * (1 - d4)).le(0));
    model.addConstr(d1.add(d2).add(d3).add(d4).ge(1));
  }
}

const solution = await model.solve({ backend: "highs" });
console.log("Status:", solution.status);
