# #073. ジョブショップ・スケジューリング（CP disjoint 制約）

<!-- section:scenario -->
複数の機械からなる工場で、複数のジョブを処理します。各ジョブには決められた工程順序があり、各工程は指定された機械上で所定の整数時間だけ中断せずに処理されます。

1 台の機械は同時に 1 つの工程しか処理できません。各ジョブ内の工程順序と各機械の非重複を守り、全工程が終わる最終完了時刻（メイクスパン）を最小化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `machines` | `number[][]` | ジョブ $j$ の第 $o$ 工程が使用する機械番号 |
| `durations` | `number[][]` | ジョブ $j$ の第 $o$ 工程の処理時間（整数）$d_{j,o}$ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `starts` | `number[][]` | 各工程の開始時刻 $S_{j,o} \ge 0$（整数） |
| `makespan` | `number` | 最小化された最大完了時刻 $\max_{j,o} (S_{j,o} + d_{j,o})$ |

<!-- section:example -->
**入力例**

```json
{
  "machines": [
    [0, 1, 2],
    [0, 2, 1],
    [1, 2, 0]
  ],
  "durations": [
    [3, 2, 2],
    [2, 1, 4],
    [4, 3, 2]
  ]
}
```

**出力例**

```json
{
  "starts": [
    [2, 5, 7],
    [0, 2, 7],
    [0, 4, 7]
  ],
  "makespan": 11
}
```

各ジョブの工程順序（`J0: [2,5)->[5,7)->[7,9)`, `J1: [0,2)->[2,3)->[7,11)`, `J2: [0,4)->[4,7)->[7,9)`）と各機械上の非重複をすべて満たし、メイクスパンは **11** となります。

<!-- section:hint1 -->
制約プログラミング（`{ solver: "pumpkin" }`）を用い、各ジョブの各工程に対して整数の開始時刻変数を用意します。モデルは、同一ジョブ内の連続工程間の先行制約と、各機械ごとの非重複グローバル制約で構成します。

<!-- section:hint2 -->
全工程の処理時間合計を `horizon` として各 `m.integer(...)` を `0` から `horizon - d` に抑え、同じ機械を使う工程を `{ start, duration }` としてまとめて `disjoint(...)` に渡します（工程が2つ未満の機械はスキップ可能です）。全工程の完了時刻に対して `max(...)` を最小化し、結果の整数値は `Math.round(...)` で取り出してください。
