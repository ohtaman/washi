# #030. 線形化テクニック総まとめ（サービス配置・平準化計画）

<!-- section:scenario -->
プラットフォーム基盤チームは、候補となるマイクロサービスの集合から、提供価値の合計が最低要件以上となる部分集合を選んで配備します。各サービスには基本コストと各リージョンへの負荷があり、さらに特定のサービス対を同時に配備すると相乗効果によるコスト削減（負の係数）または競合オーバーヘッド（正の係数）が発生します。

総運用コストは「基本コスト」「ペア相互作用コスト」「全リージョン中のピーク負荷に対する重み付きコスト」「各リージョンの目標負荷からの重み付き L1 偏差」の 4 つの和で定義されます。配備するサービス・ペア同時稼働フラグ・ピーク負荷を決定し、**総運用コストを最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `baseCosts` | `number[]` | サービス $i$ の基本コスト $c_i$ |
| `values` | `number[]` | サービス $i$ の提供価値 $v_i$ |
| `minValue` | `number` | 必要な合計価値の下限 $\sum_i v_i x_i$ |
| `loads` | `number[][]` | `loads[r][i]` はサービス $i$ 稼働時のゾーン $r$ への負荷 |
| `targets` | `number[]` | ゾーン $r$ の目標負荷 $\tau_r$ |
| `devWeights` | `number[]` | ゾーン $r$ の単位 L1 偏差ペナルティ $\beta_r$ |
| `peakWeight` | `number` | 最大ゾーン負荷 $\max_r L_r$ にかかるコスト重み $\alpha$ |
| `pairs` | `number[][]` | `[i, j, s]` のリスト（両方採用時にコスト $s$ を加算） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `selected` | `number[]` | 各サービスの 0-1 配備選択 $x_i$ |
| `pairProducts` | `number[]` | 各ペアの同時採用積 $w_k = x_i x_j$ |
| `peakLoad` | `number` | 全ゾーンの最大負荷 $\max_r L_r$ |
| `totalCost` | `number` | 最小化された総運用コスト |

<!-- section:example -->
**入力例**

```json
{
  "baseCosts": [40, 50, 35, 45],
  "values": [30, 35, 25, 30],
  "minValue": 60,
  "loads": [
    [12, 8, 10, 6],
    [6, 14, 8, 12]
  ],
  "targets": [16, 16],
  "devWeights": [4, 4],
  "peakWeight": 6,
  "pairs": [
    [0, 1, -25],
    [1, 3, 30],
    [2, 3, -15]
  ]
}
```

**出力例**

```json
{
  "selected": [1, 0, 0, 1],
  "pairProducts": [0, 0, 0],
  "peakLoad": 18,
  "totalCost": 209
}
```

サービス 0 と 3 を配備（`[1, 0, 0, 1]`）すると価値は $30 + 30 = 60 \ge 60$、ペア積は `[0, 0, 0]`、各ゾーン負荷は `[18, 18]`（ピーク `18`、目標 `16` からの偏差 `2` と `2`）となり、総コストは $(40 + 45) + 6 \times 18 + 4(2 + 2) =$ **209** です。


<!-- section:hint1 -->
1 つの MIP に 3 つの線形化パターンを組み合わせます。サービス選択のバイナリ変数、ペア相互作用積の $[0, 1]$ 連続変数、ピークゾーン負荷のスカラー連続エピグラフ変数、および各ゾーンの L1 目標追従のための非負の正負偏差変数ペアを用意します。

<!-- section:hint2 -->
各ゾーンの負荷 $L_r = \sum_i \text{loads}_{r,i} x_i$ は、エピグラフ上限（$L_r \le \text{peakLoad}$）と L1 分解（$L_r - \tau_r = d_r^+ - d_r^-$）の双方に入ります。各ペア `[i, j, s]` については、相互作用コスト $s$ が負（シナジー節約：上界が必要）にも正（干渉コスト：下界が必要）にもなり得るため、McCormick の 3 本の不等式（$w_k \le x_i$、$w_k \le x_j$、$w_k \ge x_i + x_j - 1$）すべてを課してください。最小提供能力の制約を忘れずに加え、`selected` と `pairProducts` は整数に丸めて返してください。
