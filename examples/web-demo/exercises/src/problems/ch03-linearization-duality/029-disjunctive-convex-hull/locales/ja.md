# #029. 選言制約と凸包定式化（離散稼働バンド）

<!-- section:scenario -->
工場の複数の生産ユニットを運転し、合計で目標需要量以上を供給します。各ユニットは「停止（出力 0）」「低負荷エコ運転」「高負荷ターボ運転」など互いに排他的な複数バンドのいずれか 1 つを選んで稼働し、隣り合うバンドの間には運転禁止の空白区間が存在します。

各バンドには固有の固定起動費と単位変動費が設定されています。需要を満たしながら、**固定費と変動費の合計を最小化**するバンド選択と出力水準を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demand` | `number` | 全ユニット合計の最低必要出力 |
| `bandLbs` | `number[][]` | ユニット $i$・バンド $k$ の出力下限 $L_{ik}$ |
| `bandUbs` | `number[][]` | ユニット $i$・バンド $k$ の出力上限 $U_{ik}$ |
| `fixedCosts` | `number[][]` | ユニット $i$ がバンド $k$ を選んだときの固定費 $F_{ik}$ |
| `unitCosts` | `number[][]` | ユニット $i$・バンド $k$ における単位変動費 $c_{ik}$ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `modes` | `number[]` | 各ユニットが選んだ稼働バンド番号 $k \in \{0, \dots, K-1\}$ |
| `outputs` | `number[]` | 各ユニットの出力 $x_i \in [L_{ik}, U_{ik}]$ |
| `totalCost` | `number` | 最小化された総コスト |

<!-- section:example -->
**入力例**

```json
{
  "demand": 42,
  "bandLbs": [
    [0, 10, 30],
    [0, 8, 25]
  ],
  "bandUbs": [
    [0, 20, 45],
    [0, 18, 40]
  ],
  "fixedCosts": [
    [0, 120, 260],
    [0, 90, 220]
  ],
  "unitCosts": [
    [0, 18, 12],
    [0, 20, 14]
  ]
}
```

**出力例**

```json
{
  "modes": [2, 0],
  "outputs": [42, 0],
  "totalCost": 764
}
```

ユニット 0 をバンド 2（`[30, 45]`）で出力 `42`、ユニット 1 を停止バンド 0（`[0, 0]`）で出力 `0` とすると需要 $42 + 0 \ge 42$ を満たし、総コストは $260 + 12 \times 42 =$ **764** になります。


<!-- section:hint1 -->
ユニットと運転バンドの双方で添字付けられた分解型凸包（disaggregated convex-hull）定式化を用います。各ユニット・バンドの組に対して、そのバンドが選択されたかを表すバイナリ変数と、そのバンドでの出力を表す非負の連続変数を宣言します。

<!-- section:hint2 -->
各ユニットでちょうど 1 つのバンドが選ばれるよう $\sum_k y_{ik} = 1$ を課し、各バンドの出力区間を指示変数でスケールします（$L_{ik} y_{ik} \le x_{ik} \le U_{ik} y_{ik}$）。これにより非選択バンドでは $x_{ik} = 0$ となり、選択バンドでは $[L_{ik}, U_{ik}]$ に厳密に収まるため、緩い Big-M を避けつつバンド間の禁止ギャップを防げます。全ユニット・全バンドの $x_{ik}$ の和で `demand` を満たし、出力時は各ユニットの選択バンド添字と総出力 $\sum_k x_{ik}$ を復元してください。
