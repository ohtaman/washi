# #027. LP 对偶变量与影子价格

<!-- section:scenario -->
电力公司的运行分析师正在求解一个发电出力分配计划，需要决定各台发电机组的发电量（MW，非负连续量），以最小化总发电成本（万元）。每台发电机组均有每 MW 的发电单价，并以机组特有的每 MW 贡献率向各地区电力需求供能，同时以特有的每 MW 消耗率占用各项燃料/排放配额上限。

发电调度计划须同时满足以下三项运行条件：
- **机组出力上限**：每台发电机组的发电量非负，且不超过其额定出力上限（MW）。
- **地区最低需求**：所有发电机组对各地区的贡献总和须达到或超过对应的最低电力需求（MW）。
- **燃料/排放配额上限**：所有发电机组对各项燃料/排放配额的消耗总和不得超过对应上限。

除了求得成本最低的各机组发电量外，还需要知道当每项需求目标或配额上限（即约束的右端项）增加 1 单位时，最优成本会变化多少（即影子价格）。请求解该最小化 LP，并返回各发电机组的发电量、按最低需求约束在前且燃料/排放配额上限约束在后排列的影子价格，以及最小总成本。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `costs` | `number[]` | 各发电机组的发电单价（万元/MW） |
| `capacities` | `number[]` | 各发电机组的额定出力上限（MW） |
| `yields` | `number[][]` | 每 MW 的地区需求贡献系数矩阵（按 `[region][generator]` 索引） |
| `minRequirements` | `number[]` | 各地区的最低电力需求（MW） |
| `resourceUsages` | `number[][]` | 每 MW 的燃料/排放配额消耗系数矩阵（按 `[cap][generator]` 索引） |
| `maxResources` | `number[]` | 各项燃料/排放配额上限 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `quantities` | `number[]` | 各发电机组的最优发电量（MW） |
| `duals` | `number[]` | 影子价格 $\partial z^* / \partial \text{rhs}$（依次为 `minRequirements` 与 `maxResources`） |
| `optimalCost` | `number` | 最小化后的总发电成本 $z^*$（万元） |

<!-- section:example -->
**输入示例**

```json
{
  "costs": [10, 14, 25],
  "capacities": [12, 20, 25],
  "yields": [
    [1, 2, 3],
    [2, 1, 2]
  ],
  "minRequirements": [30, 22],
  "resourceUsages": [
    [2, 1, 1]
  ],
  "maxResources": [20]
}
```

**输出示例**

```json
{
  "quantities": [4, 10, 2],
  "duals": [6, 5, -3],
  "optimalCost": 230
}
```

发电量 [4, 10, 2] 满足全部最低需求 [30, 22] 与上限 20，总成本达到 $10 \times 4 + 14 \times 10 + 25 \times 2 =$ **230** 万元，且与影子价格 [6, 5, -3] 的对偶评估值 $30(6) + 22(5) + 20(-3) = 230$ 一致。


<!-- section:hint1 -->
为每台发电机组声明一个界于 0 和其出力容量上限之间的连续变量。向模型添加最低需求约束和燃料/排放配额上限约束时，保留对这些约束对象的引用，以便在求解后读取它们的对偶值。

<!-- section:hint2 -->
求解最小化 LP 后，按先需求约束、后上限约束的顺序读取 WaSHI 中的 `c.dual!`（或 PuLP 中的 `c.pi`）。WaSHI 和 PuLP 均采用灵敏度约定 $\partial z^* / \partial \text{rhs}$：提高 $\ge$ 需求不会降低最小成本（故其对偶值 $\ge 0$），放宽 $\le$ 上限不会升高最小成本（故其对偶值 $\le 0$），而存在正松弛的约束其对偶值为 0。请直接保留求解器返回的带符号影子价格，不要自行取反。
