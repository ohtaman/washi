# #082. 合租房分房与公平租金分配

<!-- section:scenario -->
几位合租室友准备入住一间房间数与人数相等的合租房，并共同分摊固定的月总租金。每位室友对每个房间都有自己的估值，其剩余定义为所分得房间的估值减去该房间所需承担的租金。

请按以下两个阶段确定分房方案与租金分配：

- **第一阶段**：为每位室友分配一个互不相同的房间，以**最大化所有室友的总估值**。
- **第二阶段**：在保持该最优分房方案的前提下，为各房间设定总和等于月总租金的非负租金，保证没有室友会羡慕其他室友的房间及其对应租金（无嫉妒性），并**最大化所有室友中的最小剩余**以实现最公平的租金分摊。

所有测试算例均保证在第一阶段最优分房下存在非负的无嫉妒租金分配。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `valuations` | `number[][]` | 估值矩阵，`valuations[i][r]` 表示室友 `i` 对房间 `r` 的估值 |
| `totalRent` | `number` | 需要分摊到各房间的总租金 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `assignment` | `number[]` | 每位室友 `i` 分得的从 0 开始的房间编号 |
| `rents` | `number[]` | 每个房间 `r` 对应的非负租金（按房间编号索引） |
| `totalValuation` | `number` | 第一阶段所选分房方案的总估值 |
| `minSurplus` | `number` | 第二阶段最大化后的所有室友最小剩余 |

<!-- section:example -->
**输入示例**

```json
{
  "valuations": [
    [800, 500, 400],
    [600, 700, 450],
    [550, 500, 600]
  ],
  "totalRent": 1500
}
```

**输出示例**

```json
{
  "assignment": [0, 1, 2],
  "rents": [600, 500, 400],
  "totalValuation": 2100,
  "minSurplus": 200
}
```

将室友 $i$ 分配给房间 $i$ 可获得总估值 $800 + 700 + 600 = 2100$，租金 `[600, 500, 400]` 的总和为 $600 + 500 + 400 = 1500$，且每位室友都满足无嫉妒条件并获得剩余 **200**。

<!-- section:hint1 -->
将问题拆分为两个顺序求解的模型。第一阶段是一个一对一二元指派问题，选择分房方案以最大化总估值；第二阶段在固定该分房方案的基础上，求解关于各房间租金与辅助变量最小剩余的连续线性规划。

<!-- section:hint2 -->
为什么必须先求解第一阶段？只有当分房方案最大化总估值时，无嫉妒租金向量才存在；任何次优分房都会使无嫉妒约束无解。在第二阶段中，将 `rents` 设为下界 0（`lb: 0` / `lowBound=0`），将 `minSurplus` 设为无界连续变量（WaSHI 中使用 `lb: -Infinity, ub: Infinity`，PuLP 中使用 `lowBound=None`），并约束每位室友在所分房间的剩余不低于 `minSurplus` 且不低于其在其他任何房间所能获得的剩余。
