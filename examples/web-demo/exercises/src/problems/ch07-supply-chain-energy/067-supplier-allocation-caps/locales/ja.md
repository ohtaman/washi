# #067. 発注シェア上限と取引量上下限つきサプライヤー配分

<!-- section:scenario -->
複数の焙煎工場を運営するコーヒーメーカーが、候補サプライヤー（生豆商社）群からのコーヒー生豆調達を計画します。

- **需要充足**: 各工場への納入量の合計は、その工場の需要量以上を満たす必要があります。
- **半連続発注制約**: サプライヤーを採用すると固定契約費が発生し、全工場向け合計発注量は規定の最小発注量以上・最大供給能力以下に収める必要があります（不採用なら発注量ゼロ）。
- **工場別シェア上限**: 各工場の需要に対し、単一サプライヤーからの調達比率は規定の上限割合以下に抑える必要があります。
- **採用社数の範囲**: 採用するサプライヤー総数は、指定された下限以上・上限以内に収める必要があります。

採用サプライヤーと各工場への発注量を決定し、**固定契約費と調達・輸送費の合計を最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[]` | 各工場のコーヒー生豆需要量（単位） |
| `unitCosts` | `number[][]` | 各サプライヤーから各工場への 1 単位あたり調達・輸送費（サプライヤー × 工場、`[s][p]`） |
| `fixedCosts` | `number[]` | 各サプライヤーを採用する際の固定契約費 |
| `minOrders` | `number[]` | 各サプライヤー採用時の全工場向け最小合計発注量（単位） |
| `maxOrders` | `number[]` | 各サプライヤー採用時の最大合計供給能力（単位） |
| `maxShare` | `number` | 各工場で 1 社から調達できる需要比率の上限（(0, 1] の範囲） |
| `minSuppliers` | `number` | 採用サプライヤー社数の下限 |
| `maxSuppliers` | `number` | 採用サプライヤー社数の上限 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `active` | `number[]` | 各サプライヤーの採用有無（0 または 1） |
| `allocations` | `number[][]` | 各サプライヤーから各工場への非負連続発注量（単位、サプライヤー × 工場、`[s][p]`） |
| `totalCost` | `number` | 最小化された総コスト（固定契約費＋調達・輸送費） |

<!-- section:example -->
**入力例**

```json
{
  "demands": [100, 80, 120],
  "unitCosts": [
    [12, 15, 18],
    [14, 11, 16],
    [16, 14, 12],
    [13, 13, 14]
  ],
  "fixedCosts": [300, 260, 320, 280],
  "minOrders": [60, 50, 70, 50],
  "maxOrders": [160, 140, 170, 130],
  "maxShare": 0.6,
  "minSuppliers": 2,
  "maxSuppliers": 3
}
```

**出力例**

```json
{
  "active": [0, 0, 1, 1],
  "allocations": [
    [0, 0, 0],
    [0, 0, 0],
    [50, 48, 72],
    [50, 32, 48]
  ],
  "totalCost": 4674
}
```

サプライヤー 2・3 の 2 社を採用すると、各工場の 60% 上限（[60, 48, 72]）と各社の発注範囲（170 は [70, 170]、130 は [50, 130]）を満たし、総コストは $(320 + 280) + 4074 =$ **4,674** となります。


<!-- section:hint1 -->
各サプライヤーを採用するかどうかのバイナリ変数と、発注量を表す連続値のサプライヤー×工場の行列を定義します。サプライヤー単位の半連続発注量制約と、工場単位の調達分散（シェア上限）制約を同時に表現します。

<!-- section:hint2 -->
単一サプライヤーのシェア上限は、各 `allocations[s][p]` の変数上界 `maxShare * demands[p]` として直接表現できます。各サプライヤーの全工場向け合計発注量を `active[s]` に結び付けて下界（`minOrders[s] * active[s]`）と上界（`maxOrders[s] * active[s]`）の両方を課し、採用サプライヤー総数を `minSuppliers` 以上 `maxSuppliers` 以下に制限してください。
