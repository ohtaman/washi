📖 2次元パッキングの数理最適化

2次元ストリップパッキング (2D Strip/Bin Packing Problem) は、長方形の板材から無駄なくパーツを切り出すNP困難な代表的組合せ最適化問題です。

Washi では、各パーツの座標 $(x_i, y_i)$、回転判定 $r_i$、および2パーツが重ならない条件（非重複制約）を**Big-M 定式化**の混合整数計画問題（MILP）として定式化し、HiGHS ソルバーで厳密に解くことができます： 

// 2パーツ (i, j) が互いに重ならない条件
x[i] + w[i] <= x[j] + M * (1 - delta[i][j][0])
x[j] + w[j] <= x[i] + M * (1 - delta[i][j][1])
y[i] + h[i] <= y[j] + M * (1 - delta[i][j][2])
y[j] + h[j] <= y[i] + M * (1 - delta[i][j][3])
delta[i][j][0] + delta[i][j][1] + delta[i][j][2] + delta[i][j][3] >= 1

このゲームの「⚡ Washiで最適配置を解く」機能は、まさにこの数理最適化アルゴリズムをバックボーンに動作しています。
