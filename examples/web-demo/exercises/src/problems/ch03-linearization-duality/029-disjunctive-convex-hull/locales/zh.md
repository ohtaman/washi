# #029. 析取运行区间与凸包重构

<!-- section:scenario -->
工厂需要调度多台机组，使总产出不低于目标需求量。每台机组必须从若干互不相交的运行区间（例如停机零出力、低负荷经济区间或高负荷区间）中恰好选择一个区间运行，各区间之间存在禁止运行的间隙。

每个运行区间具有各自不同的固定启停成本与线性边际单位成本。请为每台机组选择运行区间及连续出力水平，在满足需求的前提下**最小化总成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `demand` | `number` | 全部机组的最低总产出要求 |
| `bandLbs` | `number[][]` | 机组 $i$ 在区间 $k$ 的输出下限 $L_{ik}$ |
| `bandUbs` | `number[][]` | 机组 $i$ 在区间 $k$ 的输出上限 $U_{ik}$ |
| `fixedCosts` | `number[][]` | 机组 $i$ 启用区间 $k$ 的固定成本 $F_{ik}$ |
| `unitCosts` | `number[][]` | 机组 $i$ 在区间 $k$ 内的单位可变成本 $c_{ik}$ |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `modes` | `number[]` | 每台机组选择的区间索引 $k \in \{0, \dots, K-1\}$ |
| `outputs` | `number[]` | 每台机组的连续输出量 $x_i \in [L_{ik}, U_{ik}]$ |
| `totalCost` | `number` | 最小化后的总成本 |

<!-- section:example -->
**输入示例**

```json
{
  "demand": 42,
  "bandLbs": [
    [0, 10, 30],
    [0, 8, 25]
  ],
  "bandUbs": [
    [0, 20, 45],
    [0, 18, 40]
  ],
  "fixedCosts": [
    [0, 120, 260],
    [0, 90, 220]
  ],
  "unitCosts": [
    [0, 18, 12],
    [0, 20, 14]
  ]
}
```

**输出示例**

```json
{
  "modes": [2, 0],
  "outputs": [42, 0],
  "totalCost": 764
}
```

机组 0 运行在区间 2（`[30, 45]`）输出 `42`，机组 1 停机在区间 0（`[0, 0]`）输出 `0`，总产出 $42 + 0 \ge 42$，总成本为 $260 + 12 \times 42 =$ **764**。
