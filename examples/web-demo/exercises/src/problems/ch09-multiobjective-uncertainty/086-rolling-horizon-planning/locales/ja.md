# #086. ローリングホライズン計画（モデル予測制御 MPC）

<!-- section:scenario -->
ある飲料ボトリング工場では、モデル予測制御（MPC）を用いて多期間にわたるペットボトル飲料（単位：ケース）の生産・在庫運用を行います。各期の開始時点で現在の実在庫（ケース）を確認し、直近の予測ウィンドウ（計画期間の末尾で打ち切り）を対象に、各期の生産能力上限（ケース）と在庫・欠品収支のもとで、生産費・期末在庫の保管費（円／ケース）・欠品ペナルティ（円／ケース）の合計を最小化する先読み線形計画問題を解きます。

ただし、各ステップで確定・実行するのは当期の生産量のみです。その後、当期の実需が確定し、未充足の需要はバックオーダーとして繰り越さず機会損失となるため、実在庫は非負に保たれ欠品量は次期へ引き継がれません。ウィンドウを 1 期先へずらしながら同様に繰り返し、実行された各期の生産量・実在庫・欠品量と累積実績コストの合計を返してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `actualDemands` | `number[]` | 生産決定後に観測される各期の実需要（ケース） |
| `forecastDemands` | `number[]` | 先読み計画内で参照する各期の予測需要（ケース） |
| `prodCosts` | `number[]` | 各期の生産単価（円／ケース） |
| `prodCap` | `number` | 1 期あたりの最大生産能力（ケース） |
| `holdCost` | `number` | 期末在庫 1 ケースあたりの保管コスト（円） |
| `shortfallPenalty` | `number` | 未充足需要 1 ケースあたりの欠品ペナルティ（円） |
| `initialInventory` | `number` | 第 0 期開始前の初期在庫（ケース） |
| `windowLen` | `number` | 各ステップで参照する先読みウィンドウ長（期数、計画期間の末尾で打ち切り） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `produced` | `number[]` | 各期で確定した生産量（ケース） |
| `inventories` | `number[]` | 各期の実需適用後の実在庫（ケース） |
| `shortfalls` | `number[]` | 各期の実需に対する欠品量（ケース） |
| `totalCost` | `number` | 累積された実績生産費・保管費・欠品ペナルティの総和（円） |

<!-- section:example -->
**入力例**

```json
{
  "actualDemands": [10, 10, 30, 10],
  "forecastDemands": [10, 10, 30, 10],
  "prodCosts": [9, 13, 25, 11],
  "prodCap": 20,
  "holdCost": 2,
  "shortfallPenalty": 100,
  "initialInventory": 0,
  "windowLen": 2
}
```

**出力例**

```json
{
  "produced": [20, 20, 10, 10],
  "inventories": [10, 20, 0, 0],
  "shortfalls": [0, 0, 0, 0],
  "totalCost": 860
}
```

ウィンドウ長 `windowLen = 2` で各期を順次実行すると生産量 `[20, 20, 10, 10]`・在庫 `[10, 20, 0, 0]`・欠品ゼロとなり、実績総コストは $(20 \times 9 + 20 \times 13 + 10 \times 25 + 10 \times 11) + 2 \times (10 + 20) =$ **860** となります。


<!-- section:hint1 -->
実在庫を次の期へ繰り越しながら、計画期間を 1 期ずつ順にシミュレーションします。各期では、有界な先読みウィンドウ内の各期に対する生産量・期末在庫・欠品量の決定変数を持つ新しい LP を構築して解きます。

<!-- section:hint2 -->
各ステップの先読み LP では（計画期間末尾で打ち切った）`forecastDemands` のみを使い、`actualDemands` を先読みしてはなりません。LP の解からは先頭期の生産量だけを確定採用し、その期の真の期末在庫・欠品量・実績コストは `actualDemands[t]` を使って更新・集計してください。
