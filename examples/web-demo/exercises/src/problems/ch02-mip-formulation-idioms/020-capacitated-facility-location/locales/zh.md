# #020. 带容量约束的设施选址问题（CFLP）

<!-- section:scenario -->
某物流网络需要协同决策开设哪些候选配送中心，以及如何从已开设的设施向各客户区域调拨货物。开设一座设施需要支付一笔固定运营成本并解锁其总发货产能；未开设设施的发货量必须为零。

在满足每一位客户需求的前提下，同时决定设施开关与连续配送流向，以**最小化固定开设成本与运输成本之和**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `fixedCosts` | `number[]` | 各候选设施 $i$ 的固定开设成本 |
| `capacities` | `number[]` | 各候选设施 $i$ 的最大总供货产能 |
| `demands` | `number[]` | 各客户区域 $j$ 的需求量 |
| `unitCosts` | `number[][]` | 从设施 $i$ 运往客户 $j$ 的单位运费 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `open` | `number[]` | 各候选设施是否开设（`0` 或 `1`） |
| `shipments` | `number[][]` | 设施 $i$ 到客户 $j$ 的非负连续运量 |
| `totalCost` | `number` | 最小化后的固定成本与运费之和 |

<!-- section:example -->
**输入示例**

```json
{
  "fixedCosts": [320, 260, 290],
  "capacities": [60, 50, 55],
  "demands": [25, 30, 20, 25],
  "unitCosts": [
    [4, 6, 9, 10],
    [7, 3, 5, 8],
    [10, 7, 4, 3]
  ]
}
```

**输出示例**

```json
{
  "open": [0, 1, 1],
  "shipments": [
    [0, 0, 0, 0],
    [20, 30, 0, 0],
    [5, 0, 20, 25]
  ],
  "totalCost": 985
}
```

开设设施 1 与 2 后分别发出 `50 <= 50` 与 `50 <= 55` 单位并满足客户需求 `[25, 30, 20, 25]`，总成本为 $(260 + 290) + (20 \times 7 + 30 \times 3 + 5 \times 10 + 20 \times 4 + 25 \times 3) =$ **985**。
