# #013. 基数制約つきポートフォリオ選択

<!-- section:scenario -->
投資委員会が、共通の総予算のもとで複数の候補プロジェクト（店舗改装、屋上太陽光発電、倉庫自動化など）から採択するものを決めます。各プロジェクトは全額一括で採択するか見送るかの二択であり、次の 4 つの条件をすべて満たす必要があります。

- **総予算**: 採択したプロジェクトの合計コストは利用可能な総予算を超えてはなりません。
- **排反グループ**: 各排反グループからは高々 1 件までしか採択できません。
- **指定数グループ**: 各指定数グループからはちょうど指定された件数を採択しなければなりません。
- **必須グループ**: 各必須グループからは最低 1 件を採択しなければなりません。

すべての条件を満たすプロジェクトの組み合わせを選び、**総価値を最大化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `budget` | `number` | 利用可能な総予算 |
| `costs` | `number[]` | 各プロジェクトの実施コスト |
| `values` | `number[]` | 各プロジェクトの獲得価値 |
| `mutexGroups` | `number[][]` | 合計で高々 1 件のみ選択できるインデックス群 |
| `exactGroups` | `{ indices: number[]; count: number }[]` | `indices` からちょうど `count` 件を選択すべきルール群 |
| `atLeastOneGroups` | `number[][]` | 合計で最低 1 件以上選択すべきインデックス群 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `selected` | `number[]` | 各プロジェクトの採択有無（0 または 1） |
| `totalValue` | `number` | 最大化された総価値 |

<!-- section:example -->
**入力例**

```json
{
  "budget": 16,
  "costs": [5, 6, 4, 3, 7, 4],
  "values": [14, 17, 10, 8, 19, 11],
  "mutexGroups": [[0, 1]],
  "exactGroups": [{ "indices": [2, 3, 4], "count": 2 }],
  "atLeastOneGroups": [[4, 5]]
}
```

**出力例**

```json
{
  "selected": [0, 1, 0, 1, 1, 0],
  "totalValue": 44
}
```

プロジェクト `{1, 3, 4}` を選ぶと、予算 $6 + 3 + 7 = 16 \le 16$、排反グループ `[0, 1]` で 1 件、指定数グループ `[2, 3, 4]` で 2 件、必須グループ `[4, 5]` で 1 件の条件をすべて満たし、総価値は $17 + 8 + 19 =$ **44** となります。

<!-- section:hint1 -->
各プロジェクトをバイナリ選択変数でモデル化します。予算上限と 3 種類のグループ規則（排反・指定数・少なくとも 1 つ）は、いずれもこれらのバイナリ変数の部分集合に対する線形制約として表せます。

<!-- section:hint2 -->
各バイナリ変数は 0 または 1 をとるため、任意のグループ内で選ばれたプロジェクト数は対応する添字の `selected[i]` の和（WaSHI では `sum(...)`、PuLP では `pulp.lpSum(...)`）になります。この和をそれぞれ $\le 1$、$= \text{count}$、$\ge 1$ として制約してください。
