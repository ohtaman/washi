# #073. 作业车间调度问题 (JSSP / CP Disjoint)

<!-- section:scenario -->
车间拥有多台机器与多项作业。每项作业必须按照给定顺序依次完成若干道工序，每道工序需要在指定机器上连续加工固定的整数时长。

每台机器同一时刻至多加工一道工序。请为每道工序确定非负整数开工时间，使所有工序都完工的最大完工时间最小。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `machines` | `number[][]` | 作业 $j$ 第 $o$ 道工序所需的机器编号 |
| `durations` | `number[][]` | 作业 $j$ 第 $o$ 道工序的整数加工时长 $d_{j,o}$ |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `starts` | `number[][]` | 各工序的整数开工时间 $S_{j,o} \ge 0$ |
| `makespan` | `number` | 最小化的最大完工时间 $\max_{j,o} (S_{j,o} + d_{j,o})$ |

<!-- section:example -->
**输入示例**

```json
{
  "machines": [
    [0, 1, 2],
    [0, 2, 1],
    [1, 2, 0]
  ],
  "durations": [
    [3, 2, 2],
    [2, 1, 4],
    [4, 3, 2]
  ]
}
```

**输出示例**

```json
{
  "starts": [
    [2, 5, 7],
    [0, 2, 7],
    [0, 4, 7]
  ],
  "makespan": 11
}
```

每项作业严格按工序先后执行（`J0: [2,5)->[5,7)->[7,9)`，`J1: [0,2)->[2,3)->[7,11)`，`J2: [0,4)->[4,7)->[7,9)`），各机器上无任何时间冲突，最大完工时间为 **11**。

<!-- section:hint1 -->
使用约束规划（`{ solver: "pumpkin" }`），为每项作业的每道工序定义一个整数开工时间变量。模型由同一作业相邻工序之间的紧前约束，以及每台机器上的不重叠全局约束两部分组成。

<!-- section:hint2 -->
以所有工序时长之和作为 `horizon`，将每个 `m.integer(...)` 的范围限制在 `0` 到 `horizon - d`；按机器编号分组工序，并将 `{ start, duration }` 列表传入 `disjoint(...)`（工序数不足两道的机器可跳过）。对所有工序的完工时间最小化 `max(...)`，并用 `Math.round(...)` 提取整数结果。
