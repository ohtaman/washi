# #030. 线性化技巧综合实战（多集群服务部署与平准化）

<!-- section:scenario -->
平台架构团队需要从若干候选微服务中选择一个部署子集，使总交付能力达到最低门槛。每个上线的服务会产生基础成本并给各区域集群带来负载，而某些成对服务同时上线时会触发协同降本（负成本项）或资源干扰开销（正成本项）。

总运维成本由四部分组成：基础成本、交互对成本、所有区域集群峰值负载的加权惩罚，以及各区域实际负载偏离目标负载的加权 L1 偏差惩罚。请确定部署选择、精确配对乘积与峰值负载，以**最小化总运维成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `baseCosts` | `number[]` | 服务 $i$ 的基础部署成本 $c_i$ |
| `values` | `number[]` | 服务 $i$ 的能力价值 $v_i$ |
| `minValue` | `number` | 要求的最低总能力 $\sum_i v_i x_i$ |
| `loads` | `number[][]` | `loads[r][i]` 为服务 $i$ 上线后对区域 $r$ 施加的负载 |
| `targets` | `number[]` | 区域 $r$ 的目标负载 $\tau_r$ |
| `devWeights` | `number[]` | 区域 $r$ 每单位 L1 偏差的惩罚权重 $\beta_r$ |
| `peakWeight` | `number` | 所有区域峰值负载 $\max_r L_r$ 的成本权重 $\alpha$ |
| `pairs` | `number[][]` | 交互对列表 `[i, j, s]`（同时部署 $i, j$ 时计入成本 $s$） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selected` | `number[]` | 各服务的 0-1 部署选择 $x_i$ |
| `pairProducts` | `number[]` | 每个配对的二元乘积 $w_k = x_i x_j$ |
| `peakLoad` | `number` | 所有区域中的峰值负载 $\max_r L_r$ |
| `totalCost` | `number` | 最小化后的总运维成本 |

<!-- section:example -->
**输入示例**

```json
{
  "baseCosts": [40, 50, 35, 45],
  "values": [30, 35, 25, 30],
  "minValue": 60,
  "loads": [
    [12, 8, 10, 6],
    [6, 14, 8, 12]
  ],
  "targets": [16, 16],
  "devWeights": [4, 4],
  "peakWeight": 6,
  "pairs": [
    [0, 1, -25],
    [1, 3, 30],
    [2, 3, -15]
  ]
}
```

**输出示例**

```json
{
  "selected": [1, 0, 0, 1],
  "pairProducts": [0, 0, 0],
  "peakLoad": 18,
  "totalCost": 209
}
```

部署服务 0 与 3（`[1, 0, 0, 1]`）提供能力 $30 + 30 = 60 \ge 60$，配对项均为 `0`，各区域负载为 `[18, 18]`（峰值 `18`，偏差均为 `2`），总成本为 $(40 + 45) + 6 \times 18 + 4(2 + 2) =$ **209**。
