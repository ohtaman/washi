# #014. 派对邀请与逻辑谜题

<!-- section:scenario -->
你正在筹备一场晚宴，需要在总预算内决定邀请哪些候选宾客，并为每位受邀宾客分配多少礼物预算。邀请某位宾客可获得基础愉悦度，每增加一单位礼物预算还会带来额外愉悦度加成；受邀宾客的礼物预算必须落在其最低与最高消费限额之间，未受邀宾客的礼物预算必须为零。

社交礼仪施加了三条逻辑规则：蕴含关系对（邀请第一位宾客时必须同时邀请第二位）、冲突对（两位宾客不能同时受邀）以及分组下限规则（指定子集中至少要邀请一定数量的宾客）。请选择受邀名单与礼物预算分配方案，以**最大化总愉悦度**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `budget` | `number` | 所有宾客的礼物总预算上限 |
| `baseEnjoyment` | `number[]` | 邀请每位宾客获得的基础愉悦度 |
| `bonusRates` | `number[]` | 每位宾客每单位礼物预算带来的额外愉悦度 |
| `minSpend` | `number[]` | 宾客受邀时的最低礼物预算 |
| `maxSpend` | `number[]` | 宾客受邀时的最高礼物预算 |
| `implications` | `number[][]` | 蕴含对 `[a, b]`，表示邀请宾客 `a` 时必须同时邀请宾客 `b` |
| `conflicts` | `number[][]` | 不能同时受邀的宾客冲突对 `[u, v]` |
| `groupRules` | `{ guests: number[]; minCount: number }[]` | 分组下限规则，要求 `guests` 中至少邀请 `minCount` 位宾客 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `invite` | `number[]` | 每位宾客是否受邀的二进制标志（`0` 或 `1`） |
| `giftBudget` | `number[]` | 分配给每位宾客的连续礼物预算 |
| `totalEnjoyment` | `number` | 最大化后的总愉悦度 |

<!-- section:example -->
**输入**

```json
{
  "budget": 55,
  "baseEnjoyment": [10, 25, 30, 15, 22],
  "bonusRates": [2, 5, 6, 3, 4],
  "minSpend": [8, 12, 10, 10, 14],
  "maxSpend": [15, 20, 18, 14, 22],
  "implications": [[1, 0]],
  "conflicts": [[2, 4]],
  "groupRules": [
    { "guests": [0, 2, 3], "minCount": 1 }
  ]
}
```

**输出**

```json
{
  "invite": [1, 1, 1, 1, 0],
  "giftBudget": [8, 19, 18, 10, 0],
  "totalEnjoyment": 329
}
```

邀请宾客 `{0, 1, 2, 3}` 并分配 `giftBudget = [8, 19, 18, 10, 0]`，满足蕴含规则 `1 -> 0`，避开了冲突 `[2, 4]`，在 `{0, 2, 3}` 中邀请了 3 位（不少于 1 位）宾客，总支出 $8 + 19 + 18 + 10 = 55 \le 55$，总愉悦度为 $(10 + 25 + 30 + 15) + (16 + 95 + 108 + 30) =$ **329**。

<!-- section:hint1 -->
每位宾客对应一个二进制邀请变量和一个连续礼物预算变量。模型将每位宾客的礼物预算区间与其邀请标志绑定，用总预算限制所有礼物支出之和，并将三条社交规则（蕴含、冲突和分组下限）转化为二进制变量上的线性不等式。

<!-- section:hint2 -->
使用问题给出的紧凑上下界（`minSpend[i]` 和 `maxSpend[i]`）将 `giftBudget[i]` 与 `invite[i]` 关联。对于逻辑规则，蕴含 $a \implies b$ 写作 $y_a \le y_b$，冲突写作 $y_u + y_v \le 1$，而至少 $k$ 人规则将 `rule.guests` 对应的二进制变量求和并限制其不少于 `rule.minCount`。
