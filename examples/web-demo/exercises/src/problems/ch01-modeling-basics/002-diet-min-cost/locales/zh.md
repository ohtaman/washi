# #002. 低成本营养配比（下限约束与最小化）

<!-- section:scenario -->
一家食品厂商正在研发一款营养棒，计划混合燕麦与豆类，在满足每根营养棒最低营养标准的条件下最小化原料成本。请选择燕麦与豆类的用量（均为非负连续值），两种原料的单位成本与营养含量如下：

- 1 份燕麦：成本 30，提供蛋白质 2、膳食纤维 1
- 1 份豆类：成本 50，提供蛋白质 1、膳食纤维 3

在给定每根营养棒的最低要求 `minProtein` 和 `minFiber` 的条件下，求出最省钱的配比。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `minProtein` | `number` | 所需蛋白质下限 |
| `minFiber` | `number` | 所需膳食纤维下限 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `oats` | `number` | 燕麦用量（$\ge 0$） |
| `beans` | `number` | 豆类用量（$\ge 0$） |
| `totalCost` | `number` | 最小化后的总成本 |

<!-- section:example -->
**输入示例**

```json
{
  "minProtein": 8,
  "minFiber": 9
}
```

**输出示例**

```json
{
  "oats": 3,
  "beans": 2,
  "totalCost": 190
}
```

使用 3 份燕麦和 2 份豆类时，蛋白质为 $2\times 3 + 1\times 2 = 8 \ge 8$，膳食纤维为 $1\times 3 + 3\times 2 = 9 \ge 9$，满足所有约束；此时总成本为 $30\times 3 + 50\times 2 = 190$。
