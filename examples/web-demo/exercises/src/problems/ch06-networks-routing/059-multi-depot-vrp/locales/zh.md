# #059. 多车场车辆路径问题 (MDVRP)

<!-- section:scenario -->
配送网络由 $D$ 座区域车场（`0..D-1`）组成，负责服务 $C$ 位客户（`D..D+C-1`）：

- 每位客户必须恰好被一条车辆路径服务一次。
- 每条路径都必须从同一座车场出发并返回该车场，不得跨车场起止。
- 每座车场的发车数不得超过其可派车辆上限，承担的客户总需求不得超过其供货容量上限。
- 每辆车单趟承载的总需求不得超过 `vehicleCapacity`。

请规划各车场的配送路径，**最小化总行驶距离**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `dist` | `number[][]` | $(D+C) \times (D+C)$ 距离矩阵（`0..D-1` 为车场，`D..D+C-1` 为客户） |
| `demands` | `number[]` | 各节点需求量（车场为 0，客户为正） |
| `vehicleCapacity` | `number` | 单车最大载重上限 $Q$ |
| `depotMaxVehicles` | `number[]` | 各车场 `d` 允许派出的最大车辆数 |
| `depotCapacities` | `number[]` | 各车场 `d` 可承担的客户总需求上限 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `routes` | `number[][]` | 路径列表，每条路径以原出发车场 `d` 起止（`[d, ..., d]`） |
| `totalDistance` | `number` | 最小化后的全部路径总里程 |

<!-- section:example -->
**输入示例**

```json
{
  "dist": [
    [0, 10, 3, 4, 9, 9],
    [10, 0, 9, 9, 4, 3],
    [3, 9, 0, 6, 7, 10],
    [4, 9, 6, 0, 8, 7],
    [9, 4, 7, 8, 0, 6],
    [9, 3, 10, 7, 6, 0]
  ],
  "demands": [0, 0, 4, 4, 4, 4],
  "vehicleCapacity": 9,
  "depotMaxVehicles": [1, 1],
  "depotCapacities": [8, 10]
}
```

**输出示例**

```json
{
  "routes": [
    [0, 3, 2, 0],
    [1, 5, 4, 1]
  ],
  "totalDistance": 26
}
```

车场 0 服务 `{2, 3}`（总需求 `8 <= 8`，里程 $4 + 6 + 3 = 13$），车场 1 服务 `{4, 5}`（总需求 `8 <= 10`，里程 $3 + 6 + 4 = 13$），总行驶距离为 $13 + 13 =$ **26**。

<!-- section:hint1 -->
为每个车场 `d` 仅在 `{d}` 与客户集合 `{D..D+C-1}` 之间定义带车场下标的二进制弧变量（排除车场之间的弧），并为每位客户定义以自身需求和 `vehicleCapacity` 为界的连续累计载荷变量。约束每位客户在所有车场中恰好被访问一次、按 `(车场, 客户)` 保持流量守恒，并限制每个车场的发车数与总配送需求。

<!-- section:hint2 -->
切勿使用不带车场下标的单一弧变量 `x[i][j]`——那样会允许从一个车场出发、停靠在另一个车场的开放路径！按车场 `d` 在 `{d} ∪ Customers` 上索引弧变量可确保每条路径必返回始发车场；对客户对施加跨车场共享的载荷 MTZ 约束（$u_i - u_j + Q \sum_d x_{ijd} \le Q - q_j$，其中 $q_j$ 为客户 $j$ 的需求量）即可消除客户子环路。
