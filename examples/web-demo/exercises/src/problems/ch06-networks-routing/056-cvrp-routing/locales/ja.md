# #056. 容量制約付き配送計画問題 (CVRP)

<!-- section:scenario -->
デポ 0 に待機している同一の配送車を使って、それぞれ正の配送需要を持つすべての顧客へ荷物を届けます。次の条件を満たすように配送ルートを計画してください。

- デポ 0 から出発できるルートは最大 `maxVehicles` 本までです。
- すべてのルートはデポ 0 を出発してデポ 0 へ戻ります。
- すべての顧客をちょうど 1 回ずつ訪問します。
- 各ルートで配送する顧客の需要合計は車両の積載容量以下でなければなりません。

すべての条件を満たしつつ、**総移動距離を最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `dist` | `number[][]` | $n \times n$ の距離行列（0 がデポ、`1 .. n - 1` が顧客） |
| `demands` | `number[]` | 各頂点の需要量（`demands[0] = 0`、顧客は正値） |
| `capacity` | `number` | 車両 1 台あたりの積載容量上限 $Q$ |
| `maxVehicles` | `number` | デポ 0 から出発できる最大車両台数 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `routes` | `number[][]` | 各車両の配送ルート配列（各ルートは `[0, ..., 0]`） |
| `totalDistance` | `number` | 最小化された全ルート総移動距離 |

<!-- section:example -->
**入力例**

```json
{
  "dist": [
    [0, 5, 7, 5, 6],
    [5, 0, 3, 6, 9],
    [7, 3, 0, 9, 12],
    [5, 6, 9, 0, 4],
    [6, 9, 12, 4, 0]
  ],
  "demands": [0, 4, 5, 4, 5],
  "capacity": 10,
  "maxVehicles": 2
}
```

**出力例**

```json
{
  "routes": [
    [0, 1, 2, 0],
    [0, 3, 4, 0]
  ],
  "totalDistance": 30
}
```

ルート `[0, 1, 2, 0]` は積載量 $4 + 5 = 9 \le 10$・距離 $5 + 3 + 7 = 15$、ルート `[0, 3, 4, 0]` も積載量 $4 + 5 = 9 \le 10$・距離 $5 + 4 + 6 = 15$ となり、総移動距離は $15 + 15 =$ **30** です。

<!-- section:hint1 -->
異なる頂点の順序対ごとに 0-1 の枝選択変数を、各顧客にその顧客の需要量から車両容量までを範囲とする連続の累積積載量変数を定義します。すべての顧客で出次数・入次数を 1 にし、デポの出次数と入次数が一致して `maxVehicles` 以下になるよう制約してください。

<!-- section:hint2 -->
顧客間の枝に対して容量ベースの MTZ 制約（異なる顧客 $i, j$ に対し $u_i - u_j + Q x_{ij} \le Q - d_j$）を導入して累積需要を追跡します。この制約群だけで切り離された部分巡回路の排除と各ルートの積載上限 $Q$ の遵守を同時に保証でき、解いた後はデポ 0 から出る各枝を順に辿って 0 に戻るルートを復元できます。
