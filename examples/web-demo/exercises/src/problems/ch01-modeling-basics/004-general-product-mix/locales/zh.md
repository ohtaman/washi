# #004. 通用产品组合规划（m × n 矩阵）

<!-- section:scenario -->
在 **#001** 中我们手写了固定两种产品的模型；但在实际业务中，产品数量与共享资源种类都会随输入规模变化。

工坊计划生产若干种口味（非负连续产量），每种产品带来各自单位利润，并按给定配比消耗多种共享原材料或设备产能。请在不超出任何资源可用上限的前提下，决策每种产品的产量以 **最大化总利润**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `margins` | `number[]` | 产品 $j$ 的单位利润 |
| `usages` | `number[][]` | 资源消耗矩阵，`usages[k][j]` 为生产 1 单位产品 $j$ 消耗的资源 $k$ |
| `capacities` | `number[]` | 资源 $k$ 的总可用上限 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `quantities` | `number[]` | 各产品的非负连续产量数组 |
| `totalProfit` | `number` | 最大化后的总利润 |

<!-- section:example -->
**输入示例**

```json
{
  "margins": [500, 300],
  "usages": [
    [3, 1],
    [1, 2]
  ],
  "capacities": [90, 80]
}
```

**输出示例**

```json
{
  "quantities": [20, 30],
  "totalProfit": 19000
}
```

生产 `[20, 30]` 时，资源 0 消耗量为 $3 \times 20 + 1 \times 30 = 90$、资源 1 为 $1 \times 20 + 2 \times 30 = 80$（均未超上限），总利润为 $500 \times 20 + 300 \times 30 =$ **19,000**。
