# #077. スキル要件・リーダー必置・NG ペア制約付きシフト

<!-- section:scenario -->
$N$ 人のスタッフを対象に、$D$ 日間・$S$ シフトの勤務表を作成します（各スタッフは 1 日最大 1 シフト）。稼働する各日・各シフトでは、総人数の需要を満たすだけでなく、シニアリーダーを少なくとも 1 名配置し、さらに $K$ 種類の資格スキルごとの必要人数も確保しなければなりません。

また、指定された組み合わせ（NG ペア）の 2 名を同じ日の同じシフトに同時配置することは禁止されています。すべての要件を満たす最小コストのシフト表を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[][]` | 日 $d$・シフト $s$ の総必要人数（$D \times S$） |
| `isSenior` | `number[]` | 各スタッフがシニアリーダーか（`0`/`1`） |
| `staffSkills` | `number[][]` | スタッフ $i$ がスキル $k$ を持つか（$N \times K$ の `0`/`1` 行列） |
| `skillDemands` | `number[][]` | シフト $s$ で必要なスキル $k$ 保有者の最低人数（$S \times K$） |
| `ngPairs` | `number[][]` | 同一の `(d, s)` に同時配置できないペア `[a, b]` のリスト |
| `shiftCosts` | `number[][]` | スタッフ $i$ がシフト $s$ に就く際のコスト（$N \times S$） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `schedule` | `number[][]` | $N \times D$ 行列（`-1`: 休み、`0..S-1`: 担当シフト番号） |
| `totalCost` | `number` | 最小化された総シフトコスト |

<!-- section:example -->
**入力例**

```json
{
  "demands": [
    [2, 1],
    [2, 1]
  ],
  "isSenior": [1, 1, 0, 0],
  "staffSkills": [
    [1, 0],
    [0, 1],
    [1, 1],
    [0, 1]
  ],
  "skillDemands": [
    [1, 1],
    [1, 0]
  ],
  "ngPairs": [[0, 2], [1, 3]],
  "shiftCosts": [
    [15, 20],
    [16, 18],
    [10, 14],
    [11, 15]
  ]
}
```

**出力例**

```json
{
  "schedule": [
    [1, 1],
    [0, 0],
    [0, 0],
    [-1, -1]
  ],
  "totalCost": 92
}
```

両日ともシフト 0 は NG ペア `[0, 2]` を避けてシニア 1 とスタッフ 2 を組み、シフト 1 はスキル 0 を持つシニア 0 を配置することで全条件を満たし、総費用は $(20+20) + (16+16) + (10+10) =$ **92** となります。
