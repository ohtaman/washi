# #079. 手術室（OR）の症例割当と延長時間最適化

<!-- section:scenario -->
病院で、候補となる複数の手術症例を $R$ 室の手術室と 1 日 $S$ 枠のセッションに割り当てます。各症例には所要時間、実施時の優先度スコア、使用可能な手術室の適合条件が設定されており、未実施のまま見送ることも可能です。

各手術室・各枠には定時容量が定められており、一定の延長上限の範囲内であれば時間単価のペナルティを払って延長できます。適合性と時間制約を守り、総優先度スコアから総延長コストを引いた純スコアを最大化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `durations` | `number[]` | 各症例 $c$ の手術所要時間 $d_c$ |
| `priorities` | `number[]` | 各症例 $c$ を実施した際の優先度スコア $p_c$ |
| `compatible` | `number[][]` | 症例 $c$ が手術室 $r$ で実施可能か（$C \times R$ の `0`/`1` 行列） |
| `numSessions` | `number` | 各手術室あたりのセッション枠数 $S$ |
| `regularCapacity` | `number` | 各 `(手術室, 枠)` ブロックの定時容量 $B$ |
| `maxOvertime` | `number` | 各 `(手術室, 枠)` ブロックで許容される最大延長時間 $O_{\max}$ |
| `overtimeCost` | `number` | 延長時間 1 単位あたりのコスト |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `assignedRoom` | `number[]` | 各症例に割り当てた手術室番号 `0..R-1`（未実施は `-1`） |
| `assignedSession` | `number[]` | 各症例に割り当てた枠番号 `0..S-1`（未実施は `-1`） |
| `overtime` | `number[][]` | 各 `(手術室, 枠)` の非負延長時間 $o_{r,s}$（$R \times S$） |
| `netScore` | `number` | 最大化された純スコア（優先度合計 − 延長コスト） |

<!-- section:example -->
**入力例**

```json
{
  "durations": [3, 4, 2, 3, 2],
  "priorities": [60, 85, 45, 70, 20],
  "compatible": [
    [1, 1],
    [1, 0],
    [0, 1],
    [1, 1],
    [1, 1]
  ],
  "numSessions": 2,
  "regularCapacity": 3,
  "maxOvertime": 1,
  "overtimeCost": 25
}
```

**出力例**

```json
{
  "assignedRoom": [0, 0, 1, 1, -1],
  "assignedSession": [1, 0, 1, 0, -1],
  "overtime": [
    [1, 0],
    [0, 0]
  ],
  "netScore": 235
}
```

症例 0〜3 はいずれも適合する手術室（`compatible[c][r] = 1`）に割り当てられ、各枠の負荷は手術室 0 が `[4, 3]`、手術室 1 が `[3, 2]` となって定時容量 `3` と延長時間 `[[1, 0], [0, 0]]`（上限 `1`）を満たし、症例 4 は未実施（`-1`）、純スコアは $(60 + 85 + 45 + 70) - 25 \times 1 =$ **235** となります。

<!-- section:hint1 -->
症例 $c$・手術室 $r$・枠 $s$ の3次元2値割当変数と、`maxOvertime` を上界とする各 `(手術室, 枠)` ブロックの非負連続な延長時間変数を組み合わせます。各症例は適合する手術室のたかだか1枠に割り当て、各枠の合計所要時間を定時容量と延長時間の和以下に抑えます。

<!-- section:hint2 -->
`overtimeCost` が正であり目的関数で純スコアを最大化するため、2値フラグを追加しなくても延長時間変数は最適解において自然に $\max(0, \text{負荷} - B)$ に一致します。不適合な `(c, r)` ペアの変数は 0 に固定し、未割当の症例は `assignedRoom` と `assignedSession` の両方を `-1` として出力してください。
