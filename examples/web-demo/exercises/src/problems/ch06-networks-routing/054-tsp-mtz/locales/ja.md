# #054. 非対称巡回セールスマン問題 (TSP・MTZ 定式化)

<!-- section:scenario -->
配送車が拠点の都市 0 を出発し、他のすべての都市をちょうど 1 回ずつ訪問して都市 0 へ戻ります。一方通行や坂道の影響により、都市 i から都市 j への移動コストと逆向きの移動コストは一般には異なります。

部分巡回路（切り離された小ループ）のない単一の閉路として非対称巡回セールスマン問題を混合整数計画で定式化し、**総移動コストを最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `dist` | `number[][]` | $n \times n$ の非対称移動コスト行列（`dist[i][j]` は `i -> j` のコスト） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `tour` | `number[]` | 都市 `0` から始まる全 $n$ 都市の訪問順配列（`tour[0] = 0`） |
| `totalCost` | `number` | 最小化された閉路の総移動コスト |

<!-- section:example -->
**入力例**

```json
{
  "dist": [
    [0, 12, 2, 9],
    [10, 0, 14, 2],
    [3, 7, 0, 11],
    [8, 3, 6, 0]
  ]
}
```

**出力例**

```json
{
  "tour": [0, 2, 1, 3],
  "totalCost": 19
}
```

`0 -> 2 -> 1 -> 3 -> 0` の順に巡回すると 4 都市すべてを 1 つの輪で訪問でき、総コストは $2 + 7 + 2 + 8 =$ **19** となります。

<!-- section:hint1 -->
異なる都市の順序対ごとに 0-1 の枝選択変数を、都市 0 以外の各都市に連続の訪問順序ポテンシャル変数をそれぞれ用意します。全都市で入次数と出次数がともに 1 になるよう制約を課し、総移動距離を最小化してください。

<!-- section:hint2 -->
次数制約だけでは切り離された部分巡回路が生じてしまいます。都市 0 を除く枝 `(i, j)` に MTZ（Miller-Tucker-Zemlin）の順序制約 $u_i - u_j + n x_{ij} \le n - 1$ を加えて `x[i][j] == 1` のとき $u_i + 1 \le u_j$ を強制すれば、都市 0 を起点とする単一のハミルトン閉路のみが実行可能になります。解いた後は都市 0 から選択された枝を辿って `tour` を復元してください。
