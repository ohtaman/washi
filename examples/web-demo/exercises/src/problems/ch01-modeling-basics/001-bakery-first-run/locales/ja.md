# #001. ベーカリーの生産計画（<= と最大化）

<!-- section:scenario -->
ベーカリーでクロワッサンと食パン（どちらも 0 以上の連続量）を焼き、総利益を最大化します。

- クロワッサン 1 個：利益 40、小麦粉 2・バター 1 を消費
- 食パン 1 個：利益 70、小麦粉 3・バター 2 を消費

在庫上限 flourCap と butterCap を超えない範囲で利益が最大になる生産量を求めてください（初期コードではバターの制約だけが抜けています）。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `flourCap` | `number` | 小麦粉の在庫上限 |
| `butterCap` | `number` | バターの在庫上限 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `croissants` | `number` | クロワッサンの生産量（$\ge 0$） |
| `loaves` | `number` | 食パンの生産量（$\ge 0$） |
| `totalProfit` | `number` | 最大化された総利益 |

<!-- section:example -->
**入力例**

```json
{
  "flourCap": 120,
  "butterCap": 70
}
```

**出力例**

```json
{
  "croissants": 30,
  "loaves": 20,
  "totalProfit": 2600
}
```

クロワッサン 30・食パン 20 を作ると、小麦粉 $2\times 30 + 3\times 20 = 120$ とバター $30 + 2\times 20 = 70$ をちょうど使い切り、総利益 `2600` が最大になります。
