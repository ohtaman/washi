# #003. 荷物パッキングと整数変数

<!-- section:scenario -->
総重量の上限が決まっている機内持ち込みバッグに、手元にある複数種類の旅行用品（モバイルバッテリーやカメラ、折りたたみ傘などのアイテム）を詰めて持ち運びます。各アイテムには 1 個あたりの重さ・価値・手元にある数（持ち込み個数の上限値）が設定されています。バッグの総重量制限を守りつつ、**合計価値を最大化** してください。

現在の初期コードには 2 つの欠陥があるので、修正してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `maxWeight` | `number` | バッグの最大積載重量 |
| `weights` | `number[]` | 各アイテム 1 個あたりの重さ |
| `values` | `number[]` | 各アイテム 1 個あたりの価値 |
| `maxCounts` | `number[]` | 各アイテムの最大許容個数 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `counts` | `number[]` | 各アイテムの積載個数（すべて整数） |
| `totalValue` | `number` | 最大化された合計価値 |

<!-- section:example -->
**入力例**

```json
{
  "maxWeight": 10,
  "weights": [3, 4, 2],
  "values": [40, 55, 22],
  "maxCounts": [2, 2, 3]
}
```

**出力例**

```json
{
  "counts": [2, 1, 0],
  "totalValue": 135
}
```

この例では、アイテム 0 を 2 個・アイテム 1 を 1 個選ぶと総重量が $2 \times 3 + 1 \times 4 = 10 \le 10$ となり、合計価値は $40 \times 2 + 55 \times 1 = 135$ となります。
