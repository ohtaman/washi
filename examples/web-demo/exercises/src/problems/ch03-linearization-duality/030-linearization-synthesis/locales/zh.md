# #030. 线性化技巧综合实战（多区域服务部署与平准化）

<!-- section:scenario -->
平台基础设施团队正从候选微服务集合中选择一个子集进行部署。

部署方案需满足以下条件与成本结构：
- **最低交付价值**：所部署服务的总价值不低于最低要求。
- **基础成本与区域负载**：每个服务都有基础成本，并会给各区域带来负载。
- **成对交互**：同时部署特定服务对会产生协同降本（负系数）或冲突额外开销（正系数）。
- **总运维成本**：由基础成本、交互对成本、所有区域峰值负载的加权成本，以及各区域偏离目标负载的加权 L1 偏差四部分之和组成。

请确定部署的服务、成对同时运行标志与峰值负载，以**最小化总运维成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `baseCosts` | `number[]` | 服务 `i` 的基础部署成本 |
| `values` | `number[]` | 服务 `i` 的能力价值 |
| `minValue` | `number` | 所需的最低总交付价值 |
| `loads` | `number[][]` | 服务 `i` 上线后对区域 `r` 施加的非负负载 `loads[r][i]` |
| `targets` | `number[]` | 区域 `r` 的目标负载 |
| `devWeights` | `number[]` | 区域 `r` 实际负载与目标负载绝对偏差（L1 偏差）每单位对应的非负惩罚权重 |
| `peakWeight` | `number` | 所有区域峰值负载每单位对应的正成本权重 |
| `pairs` | `number[][]` | 交互对列表 `[i, j, s]`（`i, j` 为从 0 开始的服务索引；同时部署两个服务时计入成本 `s`） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selected` | `number[]` | 各服务的 0-1 部署选择（部署为 1，否则为 0） |
| `pairProducts` | `number[]` | `pairs` 中各配对的同时部署指示（两者均部署为 1，否则为 0） |
| `peakLoad` | `number` | 所有区域中的峰值负载 |
| `totalCost` | `number` | 最小化后的总运维成本 |

<!-- section:example -->
**输入示例**

```json
{
  "baseCosts": [40, 50, 35, 45],
  "values": [30, 35, 25, 30],
  "minValue": 60,
  "loads": [
    [12, 8, 10, 6],
    [6, 14, 8, 12]
  ],
  "targets": [16, 16],
  "devWeights": [4, 4],
  "peakWeight": 6,
  "pairs": [
    [0, 1, -25],
    [1, 3, 30],
    [2, 3, -15]
  ]
}
```

**输出示例**

```json
{
  "selected": [1, 0, 0, 1],
  "pairProducts": [0, 0, 0],
  "peakLoad": 18,
  "totalCost": 209
}
```

部署服务 0 与 3（[1, 0, 0, 1]）提供价值 $30 + 30 = 60 \ge 60$，配对乘积为 [0, 0, 0]，各区域负载为 [18, 18]（峰值 18，偏离目标 16 的偏差分别为 2 和 2），总成本为 $(40 + 45) + 6 \times 18 + 4(2 + 2) =$ **209**。


<!-- section:hint1 -->
在一个 MIP 中组合三种线性化模式：用于服务选择的二元变量、用于成对交互乘积的 $[0, 1]$ 连续变量、用于区域峰值负载的标量连续上境图变量，以及用于各区域 L1 目标跟踪的非负正负偏差变量对。

<!-- section:hint2 -->
每个区域的负载 $L_r = \sum_i \text{loads}_{r,i} x_i$（其中 $x_i \in \{0, 1\}$ 为服务选择）同时进入上境图上限（$L_r \le \text{peakLoad}$）与 L1 拆分（$L_r - \text{targets}[r] = d_r^+ - d_r^-$）。对于每个交互对 `[i, j, s]`，由于交互成本 $s$ 既可能为负（协同降本，需要上界约束）也可能为正（冲突额外开销，需要下界约束），必须对配对乘积变量 $w_k$ 同时施加全部三条 McCormick 不等式（$w_k \le x_i$、$w_k \le x_j$、$w_k \ge x_i + x_j - 1$）。同时别忘了最低能力要求约束，并在输出时对 `selected` 与 `pairProducts` 取整。
