# #089. 予算制約付きロバスト最適化（Bertsimas-Sim 双対定式化）

<!-- section:scenario -->
化学プラントでは、個別に最大生産上限（単位：トン）を持つ複数製品（樹脂ペレット・溶剤・添加剤など）の生産量（0 以上の連続値、トン）を決定し、総利益を最大化します。各製品 1 トンあたりの共有設備の稼働時間（時間／トン）は通常は基準値（ノミナル値）ですが、原料品質のばらつき等により製品ごとに定められた最大上振れ幅だけ増加する恐れがあります。

同時に発生しうる上振れ件数の上限（不確実性予算）を定め、その範囲内で最悪の変動が起きても総稼働時間が設備容量の上限を超えないようにしつつ、総利益を最大化する生産量を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `profits` | `number[]` | 各製品 1 トンあたりの利益 |
| `nominalUsages` | `number[]` | 各製品 1 トンあたりの基準（ノミナル）稼働時間 |
| `deviations` | `number[]` | 各製品 1 トンあたりの最大稼働時間上振れ幅 |
| `maxUnits` | `number[]` | 各製品の生産量上限（トン） |
| `capacityCap` | `number` | 最悪ケースでも厳守すべき設備総稼働時間の上限 |
| `gamma` | `number` | 不確実性予算 $\Gamma \in [0, n]$（小数値も可） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `quantities` | `number[]` | ロバスト制約を満たす各製品の生産量（トン） |
| `totalProfit` | `number` | 最大化された総利益 |

<!-- section:example -->
**入力例**

```json
{
  "profits": [12, 16, 10],
  "nominalUsages": [2, 3, 2],
  "deviations": [1, 1, 0.5],
  "maxUnits": [8, 6, 8],
  "capacityCap": 30,
  "gamma": 1
}
```

**出力例**

```json
{
  "quantities": [3, 3, 6],
  "totalProfit": 144
}
```

生産量 `[3, 3, 6]` のノミナル消費量は $2(3) + 3(3) + 2(6) = 27$、$\Gamma = 1$ に対する最悪偏差は $\max(1 \cdot 3, 1 \cdot 3, 0.5 \cdot 6) = 3$ となり、合計 $30 \le 30$ を守りながら利益 $12(3) + 16(3) + 10(6) =$ **144** を達成します。


<!-- section:hint1 -->
上下界付きの生産量変数（連続値）に加えて、不確実性予算 $\Gamma$ のもとでの最悪ケース保護部分問題を双対化するために、1 つの非負スカラー双対変数と製品ごとの非負双対変数ベクトルを導入します。これらにより容量制約の厳密な線形ロバスト対問題が得られます。

<!-- section:hint2 -->
鍵となるのは、不確実性予算 $\Gamma$ のもとで最悪ケースの消費増分を最大化する内側問題の LP 双対性です。双対化すると 1 つの非負しきい値変数と製品ごとの非負超過変数が現れ、各製品の最悪偏差を線形で抑えつつ、その双対目的値を容量制約の左辺へ直接足し込むことで内側最大化を消去できます。
