# #018. 带依赖与互斥约束的多维 0-1 背包

<!-- section:scenario -->
某研发团队需要规划下一版本中上线的候选功能。每个功能可带来固定业务价值，并同时消耗研发工时、算力预算或测试槽位等两项及以上有限资源。

同时，架构约束要求某些功能必须在启用其前置基础功能后才能上线，另一些成对功能由于冲突不能同时上线。请在全部资源容量上限与依赖互斥规则下，选择上线功能子集以**最大化总价值**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `values` | `number[]` | 各候选功能提供的价值 |
| `weights` | `number[][]` | 资源消耗矩阵，`weights[k][j]` 为功能 $j$ 对资源 $k$ 的消耗 |
| `capacities` | `number[]` | 各项资源 $k$ 的可用容量上限 |
| `prerequisites` | `number[][]` | 前置依赖对 `[a, b]`，表示选 `a` 时必须选 `b` |
| `incompatibles` | `number[][]` | 互斥冲突对 `[c, d]`，表示两者不能同时选 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selected` | `number[]` | 各功能是否入选（`0` 或 `1`） |
| `totalValue` | `number` | 最大化后的总价值 |

<!-- section:example -->
**输入示例**

```json
{
  "values": [8, 24, 22, 19, 15],
  "weights": [
    [5, 6, 4, 5, 3],
    [3, 6, 5, 4, 6]
  ],
  "capacities": [13, 13],
  "prerequisites": [[3, 0]],
  "incompatibles": [[1, 2]]
}
```

**输出示例**

```json
{
  "selected": [1, 0, 0, 1, 1],
  "totalValue": 42
}
```

选择功能 `{0, 3, 4}` 占用资源 0 为 `5 + 5 + 3 = 13 <= 13`、资源 1 为 `3 + 4 + 6 = 13 <= 13`，且满足前置 `3 -> 0` 与互斥 `[1, 2]`，总价值为 $8 + 19 + 15 =$ **42**。
