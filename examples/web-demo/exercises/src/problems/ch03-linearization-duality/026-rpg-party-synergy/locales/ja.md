# #026. RPG パーティのシナジー最大化

<!-- section:scenario -->
冒険者は候補となるヒーローの一覧からダンジョン攻略パーティを編成しようとしています。各ヒーローには基本戦力と雇用コストが設定されており、パーティ全体の雇用コストが予算以内、かつ人数が編成枠上限以内に収まる必要があります。さらに、特定のヒーロー同士を同時に仲間にすると、相乗効果によるボーナス（正の値）や対立によるペナルティ（負の値）が発生します。

予算と人数上限を守りながら、各ヒーローの採用有無と各ペアの同時採用フラグを決定し、**基本戦力とペア効果の合計を最大化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `power` | `number[]` | ヒーロー $i$ の基本戦力 $p_i$ |
| `costs` | `number[]` | ヒーロー $i$ の雇用コスト $c_i$ |
| `budget` | `number` | 総予算上限 $B$ |
| `maxPartySize` | `number` | パーティ人数の上限 $K$ |
| `pairs` | `number[][]` | `[i, j, s]` のリスト（$s > 0$ はシナジーボーナス、$s < 0$ は対立ペナルティ） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `selected` | `number[]` | ヒーローごとの 0-1 採用フラグ $x_i$ |
| `pairProducts` | `number[]` | 各ペアの同時採用フラグ $w_k = x_i x_j$ |
| `totalValue` | `number` | 最大化されたパーティ総戦力 |

<!-- section:example -->
**入力例**

```json
{
  "power": [40, 35, 30, 25],
  "costs": [25, 25, 20, 15],
  "budget": 60,
  "maxPartySize": 2,
  "pairs": [
    [0, 1, 25],
    [1, 2, -20],
    [0, 3, 10],
    [2, 3, 15]
  ]
}
```

**出力例**

```json
{
  "selected": [1, 1, 0, 0],
  "pairProducts": [1, 0, 0, 0],
  "totalValue": 100
}
```

ヒーロー 0 と 1 を採用（`[1, 1, 0, 0]`）すると、人数は $2 \le 2$、コストは $25 + 25 = 50 \le 60$、同時採用ペアは `(0, 1)` のみ（`pairProducts = [1, 0, 0, 0]`）となり、総戦力は $40 + 35 + 25 =$ **100** になります。

<!-- section:hint1 -->
各ヒーロー候補に対してバイナリ決定変数を 1 つ、相互作用ペアごとに $[0, 1]$ の連続補助変数を 1 つ宣言します。ヒーローの採用有無がバイナリであるため、McCormick 不等式によりペア変数は追加のバイナリ指定なしでも厳密に `0` または `1` に定まります。

<!-- section:hint2 -->
予算上限と人数上限の制約に加えて、$w_k = x_i x_j$ に対する厳密な McCormick 包絡制約を課します。2 本の上界制約（$w_k \le x_i$ と $w_k \le x_j$）は両ヒーローが選ばれない限り $w_k$ を 0 に抑え、下界制約（$w_k \ge x_i + x_j - 1$）は両方が選ばれたときに $w_k = 1$ を強制します。ペアの重み $s$ は正（シナジー：上界がないと $w_k$ が過大評価される）にも負（対立：下界がないと $w_k$ が 0 に逃げられる）にもなり得るため、上下両方の制約が不可欠です。整数出力として返す際は `pairProducts` を丸めてください。
