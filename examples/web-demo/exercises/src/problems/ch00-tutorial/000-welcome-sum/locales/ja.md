# #000. 練習問題：2つの数の和を返す

<!-- section:scenario -->
2 つの数値 `a`, `b` が与えられます。その和 `a + b` を返す `solve` 関数を実装してください。

この問題集では、どの問題でも以下の形式で解答となる `solve` 関数を実装し、その戻り値によって採点します（この練習問題ではまだ最適化ソルバーは使わず、足し算の結果をそのまま返します）。

- TypeScript の場合：solve 関数は P000Input 形式の入力を受け取り、P000Output 形式のオブジェクトを返すものとします。
- Python の場合：solve 関数は入力仕様に対応する辞書 input_data を受け取り、出力仕様に対応する辞書（dict）を返すものとします。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `a` | `number` | 1 つ目の整数 |
| `b` | `number` | 2 つ目の整数 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `sum` | `number` | 合計値 `a + b` |

<!-- section:example -->
**入力例**

```json
{
  "a": 2,
  "b": 3
}
```

**出力例**

```json
{
  "sum": 5
}
```
