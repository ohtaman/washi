# #055. 単一品種フローによる連結部分グラフ選択

<!-- section:scenario -->
市役所本庁舎（頂点 0）を起点として、地域の公民館や避難所を結ぶ防災光ファイバー網を拡張します。頂点 0 は必ず稼働させ、各候補施設（頂点）には接続による防災効果報酬（負の場合もあります）が、各無向候補ケーブル（辺）には敷設コストが設定されています。ケーブルを敷設できるのは両端の施設がともに稼働している場合のみです。

頂点 0 を含み、**孤立した飛び地（非連結成分）を作らない 1 つの連結部分グラフ** を選んで、採用頂点の報酬和から採用辺のコスト和を引いた **純利益を最大化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `prizes` | `number[]` | 各頂点 `0 .. n - 1` を採用したときの報酬 |
| `edges` | `Array<{ u, v, cost }>` | 無向候補リンク（端点 `u`, `v` と敷設コスト `cost`） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `selectedNodes` | `number[]` | 各頂点の採否を表す 0-1 配列（`selectedNodes[0] = 1`） |
| `selectedEdges` | `number[]` | `edges` の各辺の採否を表す 0-1 配列 |
| `netValue` | `number` | 最大化された純利益（報酬和 − 辺コスト和） |

<!-- section:example -->
**入力例**

```json
{
  "prizes": [0, 3, 2, 12, 10],
  "edges": [
    { "u": 0, "v": 1, "cost": 6 },
    { "u": 0, "v": 2, "cost": 7 },
    { "u": 2, "v": 3, "cost": 3 },
    { "u": 3, "v": 4, "cost": 2 },
    { "u": 1, "v": 3, "cost": 9 }
  ]
}
```

**出力例**

```json
{
  "selectedNodes": [1, 0, 1, 1, 1],
  "selectedEdges": [0, 1, 1, 1, 0],
  "netValue": 12
}
```

頂点 `{0, 2, 3, 4}` と辺 `0-2-3-4` を選ぶと根頂点 0 から単一の連結木になり、報酬 $0 + 2 + 12 + 10 = 24$ からコスト $7 + 3 + 2 = 12$ を引いた純利益は **12** となります。

<!-- section:hint1 -->
頂点の採用と無向枝の建設を表す 0-1 変数を定義し、根頂点 0 は常に採用済みに固定します。根への連結性を保証するため、各無向枝に対して双方向の連続フロー変数を導入し、根 0 から他の採用頂点へ単一品種のフローを流す構造にしてください。

<!-- section:hint2 -->
辺を建設するには両端点が採用されている必要があり（$w_e \le y_u, y_v$）、各方向のフローは $w_e = 1$ のときのみ最大 $n - 1$ まで流せます。根 0 が採用された非根頂点の数だけフローを送り出し（$\text{outflow}(0) - \text{inflow}(0) = \sum_{v \ge 1} y_v$）、各頂点 $v \ge 1$ が $y_v$ 単位を消費する（$\text{inflow}(v) - \text{outflow}(v) = y_v$）ことで、孤立した高報酬の島は実行不可能になります。
