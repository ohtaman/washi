# #054. DJ 演出歌单编排

<!-- section:scenario -->
一位 DJ 从开场曲目 0 开始现场演出，必须将曲库中的其余每首曲目恰好播放一次，最后再衔接回曲目 0 作为返场结束。由于节奏落差、调性冲突和情绪起伏取决于播放方向，紧接着曲目 i 播放曲目 j 的衔接违和感代价可能与反向不同。

请将全部曲目编排成一条不含孤立小环的单一闭合循环，**最小化总衔接违和感代价**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `transitions` | `number[][]` | $n \times n$ 非对称衔接违和感矩阵（`transitions[i][j]` 为曲目 `i` 接到 `j` 的代价） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `setlist` | `number[]` | 从 0 开始的全部 $n$ 首曲目的播放顺序（`setlist[0] = 0`） |
| `totalCost` | `number` | 最小化的闭合循环总衔接代价 |

<!-- section:example -->
**输入**

```json
{
  "transitions": [
    [0, 11, 3, 8],
    [9, 0, 12, 2],
    [2, 6, 0, 10],
    [7, 4, 5, 0]
  ]
}
```

**输出**

```json
{
  "setlist": [0, 2, 1, 3],
  "totalCost": 18
}
```

按 `0 -> 2 -> 1 -> 3 -> 0` 播放可将四首曲目连成单一循环，总违和感代价为 $3 + 6 + 2 + 7 =$ **18**。

<!-- section:hint1 -->
为每对不同曲目的有序组合建立一个二元衔接变量，并为除开场曲外的每首曲目建立一个连续的播放顺位势能变量。约束每首曲目的入度与出度均为 1，并最小化总衔接代价。

<!-- section:hint2 -->
仅靠度数约束会允许互不连通的子环。对非开场曲目之间的衔接 `(i, j)` 添加 Miller-Tucker-Zemlin (MTZ) 顺序约束 $u_i - u_j + n x_{ij} \le n - 1$，确保当 `x[i][j] == 1` 时满足 $u_i + 1 \le u_j$，从而只允许包含曲目 0 的单一巡回可行；最后从曲目 0 出发沿着选中的衔接边还原 `setlist`。
