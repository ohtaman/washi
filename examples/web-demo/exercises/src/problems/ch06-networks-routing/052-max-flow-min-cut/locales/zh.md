# #052. 最大流与最小 s-t 割

<!-- section:scenario -->
在带容量的有向通信网络中，需要从指定源点向指定汇点传输尽可能大的流量。每条边上的流量不能超过其容量上限，除源点与汇点外的每个中间节点都必须保持流入量等于流出量。

请使用线性规划（LP）求出从源点到汇点的最大流量，并同时提取一组最小 s-t 割边索引，使其容量之和等于最大流且切断所有从源点到汇点的有向路径。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `nodeCount` | `number` | 节点数（`0 .. nodeCount - 1`） |
| `source` | `number` | 源点编号 $s$ |
| `sink` | `number` | 汇点编号 $t$ |
| `edges` | `Array<{ from, to, cap }>` | 带容量有向边列表 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `flows` | `number[]` | 每条边的非负流量（`0 <= flow <= cap`） |
| `cutEdges` | `number[]` | 构成最小 s-t 割的无重复边索引数组 |
| `maxFlow` | `number` | 最大流量（等于 `cutEdges` 的容量之和） |

<!-- section:example -->
**输入示例**

```json
{
  "nodeCount": 4,
  "source": 0,
  "sink": 3,
  "edges": [
    { "from": 0, "to": 1, "cap": 10 },
    { "from": 0, "to": 2, "cap": 5 },
    { "from": 1, "to": 2, "cap": 4 },
    { "from": 1, "to": 3, "cap": 4 },
    { "from": 2, "to": 3, "cap": 10 }
  ]
}
```

**输出示例**

```json
{
  "flows": [8, 5, 4, 4, 9],
  "cutEdges": [1, 2, 3],
  "maxFlow": 13
}
```

源点 0 净流出为 $8 + 5 =$ **13**，中间节点 1 与 2 保持流入等于流出，移除 `cutEdges = [1, 2, 3]` 可阻断从 `0` 到 `3` 的全部路径且割容量之和为 $5 + 4 + 4 =$ **13**。
