# #071. 単一機械の重み付き納期遅れ最小化（到着時刻あり）

<!-- section:scenario -->
プリント基板実装工場の 1 台の自動検査装置（中断不可）で、複数の基板検査ジョブを処理します。各ジョブには開始可能となる到着時刻、処理時間、目標納期、および単位時間あたりの遅延ペナルティ重みが与えられます。

同じ機械上で複数のジョブが同時に実行されることはできません。すべてのジョブについて到着時刻制約と非重複制約を満たす開始時刻を決め、重み付き納期遅れの総和を最小化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `releaseDates` | `number[]` | 各ジョブの最早開始時刻（到着時刻）$r_j$ |
| `processingTimes` | `number[]` | 各ジョブの中断不可な処理時間 $p_j$ |
| `dueDates` | `number[]` | 各ジョブの納期 $d_j$ |
| `weights` | `number[]` | 各ジョブの単位納期遅れあたりの重み $w_j$ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `starts` | `number[]` | 各ジョブの開始時刻 $S_j$（$S_j \ge r_j$） |
| `totalWeightedTardiness` | `number` | 最小化された重み付き納期遅れ和 $\sum_j w_j \max(0, S_j + p_j - d_j)$ |

<!-- section:example -->
**入力例**

```json
{
  "releaseDates": [0, 2, 1],
  "processingTimes": [4, 3, 2],
  "dueDates": [5, 5, 6],
  "weights": [1, 5, 2]
}
```

**出力例**

```json
{
  "starts": [7, 2, 5],
  "totalWeightedTardiness": 8
}
```

ジョブ 1 を $[2, 5)$、ジョブ 2 を $[5, 7)$、ジョブ 0 を $[7, 11)$ に配置すると到着時刻と非重複を満たし、各納期遅れは $[6, 0, 1]$ となって重み付き納期遅れ和は $1 \times 6 + 5 \times 0 + 2 \times 1 =$ **8** となります。

<!-- section:hint1 -->
各ジョブに対して到着時刻を下界とする連続値の開始時刻変数と、非負連続値の納期遅れ変数を用意します。到着時刻や処理時間は小数になり得るため、時刻離散化ではなく、異なる 2 ジョブのペアごとにどちらが先かを決める 0-1 の順序変数で非重複をモデル化します。

<!-- section:hint2 -->
$i < j$ の各ペア $(i, j)$ に対し、0-1 変数で「$i$ が先」または「$j$ が先」のいずれか一方の順序制約だけを有効にする 2 本の Big-M 選言制約（disjunctive constraints）を記述します。インスタンスから導出できるタイトな上界 $H = \max_k r_k + \sum_k p_k$ を用いて開始時刻の上界を $H - p_j$ とすれば、$M = H$ で非選択側の制約を安全に無効化しつつ緩和を過度に緩めずに済みます。
