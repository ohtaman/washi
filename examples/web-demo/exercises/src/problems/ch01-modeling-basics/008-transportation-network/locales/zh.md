# #008. 运输调拨问题（二分图供需模型）

<!-- section:scenario -->
考虑一个将咖啡豆（kg）从多个烘焙工厂配送到多家咖啡门店的物流网络。每座烘焙工厂都有可供发货的库存上限，每家咖啡门店都有各自的需求量，且每条从工厂到门店的路线都设定了每公斤的单位运费。

请在不超出任何工厂发货上限的前提下满足所有门店的需求，求出**最小化总运输成本的各路线配送量**（非负连续值）。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `supplies` | `number[]` | 各烘焙工厂 $i$ 的可供发货量 (kg) |
| `demands` | `number[]` | 各咖啡门店 $j$ 的所需需求量 (kg) |
| `unitCosts` | `number[][]` | 从工厂 $i$ 运往门店 $j$ 的每公斤运费单价 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `shipments` | `number[][]` | 从工厂 $i$ 运往门店 $j$ 的非负配送量矩阵（kg，尺寸与 `unitCosts` 相同） |
| `totalCost` | `number` | 最小化后的总运输成本 |

<!-- section:example -->
**输入示例**

```json
{
  "supplies": [60, 80],
  "demands": [40, 50, 40],
  "unitCosts": [
    [4, 6, 8],
    [5, 3, 2]
  ]
}
```

**输出示例**

```json
{
  "shipments": [
    [40, 10, 0],
    [0, 40, 40]
  ],
  "totalCost": 420
}
```

两座烘焙工厂的发货量分别为 $40 + 10 = 50 \le 60$ 与 $40 + 40 = 80 \le 80$，各咖啡门店到货量为 `[40, 50, 40]` 满足需求，总运费为 $4 \times 40 + 6 \times 10 + 3 \times 40 + 2 \times 40 =$ **420**。
