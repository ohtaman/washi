# #078. 大学時間割編成（教室容量・教員・学年コホート競合回避）

<!-- section:scenario -->
大学で $C$ 個の講義を $R$ 個の教室と $T$ 個の時限に割り当てます。各講義は受講者数以上の定員をもつ教室と時限の組に必ず 1 回割り当てられ、同じ教室・同じ時限には最大 1 講義しか入れません。

さらに、同じ担当教員の講義どうし、または共通の受講コホートを含む講義どうしは同一の時限に配置できません。すべての制約を満たしつつ、時限選好スコアの合計を最大化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `courseSizes` | `number[]` | 各講義 $c$ の受講者数 |
| `roomCapacities` | `number[]` | 各教室 $r$ の収容定員 |
| `teachers` | `number[]` | 各講義 $c$ の担当教員 ID |
| `cohorts` | `number[][]` | 各講義 $c$ を受講する学生コホート ID の配列 |
| `slotScores` | `number[][]` | 講義 $c$ を時限 $t$ に置いたときの選好スコア（$C \times T$） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `rooms` | `number[]` | 各講義に割り当てた教室番号 `0..R-1` |
| `slots` | `number[]` | 各講義に割り当てた時限番号 `0..T-1` |
| `totalScore` | `number` | 最大化された選好スコア合計 |

<!-- section:example -->
**入力例**

```json
{
  "courseSizes": [45, 25, 30, 20],
  "roomCapacities": [50, 30],
  "teachers": [0, 0, 1, 2],
  "cohorts": [[0], [1], [0], [1]],
  "slotScores": [
    [10, 6, 4],
    [9, 8, 5],
    [10, 7, 3],
    [8, 9, 6]
  ]
}
```

**出力例**

```json
{
  "rooms": [0, 0, 1, 1],
  "slots": [1, 0, 0, 1],
  "totalScore": 34
}
```

時限 0 に講義 1（教室 0・教員 0・コホート 1）と講義 2（教室 1・教員 1・コホート 0）、時限 1 に講義 0 と講義 3 を配置することで定員・非重複をすべて満たし、総スコアは $6 + 9 + 10 + 9 =$ **34** となります。
