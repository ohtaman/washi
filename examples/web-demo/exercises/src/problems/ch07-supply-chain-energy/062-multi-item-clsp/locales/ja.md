# #062. 多品目容量制約付きロットサイズ計画 (CLSP)

<!-- section:scenario -->
ある工場では、1 台の共有機械を用いて複数品目を複数期間にわたり生産します（全品目の初期在庫はゼロです）。ある期間にある品目を少しでも生産するには、その品目用の段取りが必要となり、品目固有の固定段取り費と段取り時間が発生します。

各期間では、全品目の「加工時間（生産量×単位加工時間）＋段取り時間」の合計がその期の機械稼働可能時間を超えてはなりません。全品目・全期間の需要を満たしつつ、**段取り費と在庫保管費の合計を最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[][]` | 品目 $i$・期間 $t$ の需要量 $d_{i,t}$ |
| `setupCosts` | `number[]` | 品目 $i$ の 1 回あたり固定段取り費 $F_i$ |
| `holdCosts` | `number[]` | 品目 $i$ の 1 単位・1 期あたり保管費 $h_i$ |
| `unitTimes` | `number[]` | 品目 $i$ の 1 単位あたり機械加工時間 $a_i$ |
| `setupTimes` | `number[]` | 品目 $i$ の段取りに要する機械時間 $s_i$ |
| `capacities` | `number[]` | 各期 $t$ の共有機械稼働可能時間 $H_t$ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `setups` | `number[][]` | 各品目・各期の段取り有無（$I \times T$ の `0`/`1` 行列） |
| `production` | `number[][]` | 各品目・各期の非負生産量（$I \times T$） |
| `inventory` | `number[][]` | 各品目・各期の非負期末在庫（$I \times T$） |
| `totalCost` | `number` | 最小化された総コスト（段取り費＋保管費） |

<!-- section:example -->
**入力例**

```json
{
  "demands": [
    [20, 30, 15, 25],
    [10, 25, 30, 15]
  ],
  "setupCosts": [120, 150],
  "holdCosts": [2, 2.5],
  "unitTimes": [1.5, 2.0],
  "setupTimes": [12, 15],
  "capacities": [110, 100, 115, 100]
}
```

**出力例**

```json
{
  "setups": [
    [1, 1, 1, 1],
    [1, 1, 1, 1]
  ],
  "production": [
    [20, 30, 15, 25],
    [21, 14, 30, 15]
  ],
  "inventory": [
    [0, 0, 0, 0],
    [11, 0, 0, 0]
  ],
  "totalCost": 1107.5
}
```

第 0 期に品目 1 を 11 単位先行生産することで、第 1 期の機械時間を $12 + 15 + 1.5(30) + 2.0(14) = 100 \le 100$ に収め、総コストは $4(120 + 150) + 11 \times 2.5 =$ **1,107.5** となります。
