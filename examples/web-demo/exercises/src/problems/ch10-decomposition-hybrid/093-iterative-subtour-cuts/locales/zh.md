# #093. 迭代子环消除割平面（DFJ 法 TSP）

<!-- section:scenario -->
给定 $n$ 座城市的对称距离矩阵，求解一条恰好访问每座城市一次并返回起点的最短哈密顿回路。为避免预先枚举指数级的子环消除约束，请从要求每座城市度数为 2 的 2-匹配松弛模型出发。

在每一轮迭代中求解整数规划并检查选中的无向边构成的连通分量；若存在多个独立子环，则为每个子环添加 Dantzig-Fulkerson-Johnson 割平面并重新求解，直至得到单一连通巡回为止。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `distances` | `number[][]` | 对称的 $n \times n$ 城市距离矩阵（$n \in [5, 8]$） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `tour` | `number[]` | $0 \dots n-1$ 的一个排列，表示哈密顿回路访问顺序 |
| `totalDistance` | `number` | 最小化后的闭合回路总长度 |
| `iterations` | `number` | DFJ 迭代割平面循环执行的 MIP 求解次数 |

<!-- section:example -->
**输入示例**

```json
{
  "distances": [
    [0, 3, 4, 25, 26, 27],
    [3, 0, 5, 24, 25, 26],
    [4, 5, 0, 26, 24, 25],
    [25, 24, 26, 0, 4, 3],
    [26, 25, 24, 4, 0, 5],
    [27, 26, 25, 3, 5, 0]
  ]
}
```

**输出示例**

```json
{
  "tour": [0, 1, 3, 5, 4, 2],
  "totalDistance": 63,
  "iterations": 2
}
```

按 `[0, 1, 3, 5, 4, 2]` 顺序访问并返回 `0` 遍历了全部 6 座城市，总距离为 $3 + 24 + 3 + 5 + 24 + 4 =$ **63**，共迭代 **2** 轮。
