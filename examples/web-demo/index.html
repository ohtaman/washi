Mathematical Optimization Modeler for TypeScript & JavaScript

Algebraic modeling elegance of PuLP and JuMP for modern web and Node.js applications. Formulate LP, MIP, QP, and SMT models using natural equations and solve them client-side in WebAssembly—with zero server costs and zero native build dependencies.

TypeScript / JS のための
直感的な数理最適化モデラー

Python の PuLP や Julia の JuMP のような自然な数式記述をモダンな TypeScript / JavaScript へ。線形計画 (LP)・混合整数計画 (MIP)・凸二次計画 (QP)・SMT論理制約を WebAssembly でクライアントサイド完結求解。サーバー代ゼロ・外部データ送信ゼロ・C++コンパイル不要。

Launch Interactive Demo → インタラクティブ デモを起動 → View Documentation ドキュメントを見る npm @ohtaman/washi
quickstart.ts 
import { Model, expr, c } from "@ohtaman/washi";

// 1. Create model & decision variables
const m = new Model({ sense: "Maximize" });
const chairs = m.integer("chairs", { lb: 0 });
const tables = m.integer("tables", { lb: 0 });

// 2. Natural algebraic objective & constraints
m.maximize(expr`30 * ${chairs} + 50 * ${tables}`);
m.constrain(c`${chairs} + 2 * ${tables} <= 40`, "wood");
m.constrain(c`2 * ${chairs} + ${tables} <= 50`, "labor");

// 3. Solve instantly with HiGHS WASM
await m.solve();

console.log(`Chairs: ${chairs.value}, Tables: ${tables.value}`);
console.log(`Max Profit: $${m.objectiveValue}`); // $1,100

1. Mixed-Integer Linear Programming (MIP)
▶ Run in Demo

Formulate resource allocation problems with integer or continuous variables. Define constraints using tagged template literals (c`${x} + ${y} <= 50`) or fluent expression chaining.

整数変数や実数変数を用いたリソース配分問題。テンプレートリテラル記法（c`${x} + ${y} <= 50`）または流れるようなメソッドチェーンで直感的に制約を記述できます。 

import { Model, expr, c } from "@ohtaman/washi";

const m = new Model({ name: "FactoryPlanning", sense: "Maximize" });

// Decision variables (integer, non-negative)
const chairs = m.integer("chairs", { lb: 0 });
const tables = m.integer("tables", { lb: 0 });

// Natural objective & constraints
m.maximize(expr`30 * ${chairs} + 50 * ${tables}`);
m.constrain(c`${chairs} + 2 * ${tables} <= 40`, "wood_limit");
m.constrain(c`2 * ${chairs} + ${tables} <= 50`, "labor_limit");

// Solve natively in browser WebAssembly
const status = await m.solve();

console.log(`Status: ${status}`); // "Optimal"
console.log(`Profit: $${m.objectiveValue}`); // 1100
console.log(`Chairs: ${chairs.value}, Tables: ${tables.value}`); // 20, 10
2. Convex Quadratic Programming (QP: Portfolio)
▶ Run in Demo

Minimize investment variance risk under covariance matrix correlations subject to expected return targets:

資産間の相関関係（共分散行列）に基づく投資リスク（分散）を、目標期待リターンと資金配分制約の下で最小化します： 

import { Model, QuadExpr, sum } from "@ohtaman/washi";

const m = new Model({ name: "Portfolio", sense: "Minimize" });
const assets = ["Tech", "Bonds", "RealEstate"];
const returns = [0.14, 0.04, 0.08];

// Decision variables: allocation weight (0.0 - 1.0)
const w = assets.map(a => m.continuous(`w_${a}`, { lb: 0, ub: 1 }));

// 1. Full budget constraint (sum of weights = 1.0)
m.constrain(sum(w).eq(1.0), "budget");

// 2. Minimum expected portfolio return: >= 8.5%
m.constrain(sum(w.map((v, i) => v.mul(returns[i]))).ge(0.085), "min_return");

// 3. Covariance Matrix risk objective: w^T * Cov * w
const cov = [
  [0.040, 0.002, 0.015],
  [0.002, 0.005, 0.002],
  [0.015, 0.002, 0.025],
];
let risk = new QuadExpr();
for (let i = 0; i < assets.length; i++) {
  for (let j = 0; j < assets.length; j++) {
    risk = risk.add(w[i].mul(w[j]).mul(cov[i][j]));
  }
}
m.minimize(risk);

await m.solve();
console.log(`Variance: ${m.objectiveValue?.toFixed(6)}`);
3. Conflict Diagnosis & Unsat Core (Z3 Engine)
▶ Run in Demo

When business rules clash, automatically isolate a subset of contradictory constraints (unsat core; minimality is not guaranteed) causing infeasibility:

業務ルール群が矛盾して実行不能になった際、矛盾の原因となっている制約の部分集合（Unsat Core。最小性は保証しません）を特定してデバッグします： 

import { Model } from "@ohtaman/washi";
import "@ohtaman/washi/solvers/z3";

const m = new Model({ solver: "z3" });
const engineers = m.integer("engineers", { lb: 0 });
const budget = m.continuous("budget", { lb: 0 });
const rush = m.bool("rush");

// Conflicting business rules
m.constrain(engineers.mul(8000).le(budget), "budget_limit");
m.constrain(rush, "rush_required");
m.constrain(rush.implies(engineers.ge(8)), "rush_staffing");
m.constrain(budget.le(50000), "strict_board_budget_cap"); // 8 * 8000 = 64k > 50k!

// Solve & diagnose
const res = await m.check({ solver: "z3" });
console.log("Status:", res.status); // "Unsat"
console.log("Conflicting Rules:", res.unsatCore);
// Output: ["budget_limit", "rush_required", "rush_staffing", "strict_board_budget_cap"]
4. Natural Domain Modeling & Vector Expressions 4. 自然なドメインモデリングとベクトル演算

Create structured multi-variable maps and formulate clean algebraic constraints using domain types (integer, continuous, dot, expr):

多変数の構造化マップを定義し、ドメイン型（integer, continuous, dot, expr）を用いて直感的に制約を記述できます： 

import { Model, expr, dot } from "@ohtaman/washi";

const m = new Model({ name: "Woodworking" });
const items = ["chairs", "tables"] as const;
const profits = { chairs: 30, tables: 50 };
const woodCost = { chairs: 1, tables: 2 };

// Multi-variable mapping
const x = m.integer(items, { lb: 0 });

// Dot product & natural constraints
m.maximize(dot(profits, x));
m.constrain(expr`${dot(woodCost, x)} <= 40`, "wood_limit");
m.constrain(expr`2 * ${x.chairs} + ${x.tables} <= 50`, "labor_limit");

await m.optimize();
console.log(`Profit: $${m.objectiveValue}`); // 1100
console.log(`Solution:`, m.getValues(x)); // { chairs: 20, tables: 10 }
