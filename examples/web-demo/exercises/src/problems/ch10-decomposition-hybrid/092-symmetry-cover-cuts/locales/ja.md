# #092. 対称性除去とカバーカット

<!-- section:scenario -->
物流倉庫の出荷担当者は、重み付きの部品箱などの荷物（単位：kg）を同一積載上限（kg）の配送コンテナ（ビン）に詰め込み、使用するコンテナ数を最小化します。コンテナ同士は互いに区別がつかないため、単純な MIP 定式化では膨大な対称解が生じ、LP 緩和下界も総重量割る積載上限という弱い分数値に留まります。

コンテナの使用順を先頭から詰める制約、および各荷物を自身の番号以下のコンテナ番号にのみ割り当てて（最初の荷物は先頭のコンテナに固定される）対称性を除去する制約を導入してください。さらに総重量を積載上限で割って切り上げた最小コンテナ数の下界（切り上げ総容量カット）と、容量を超える極小の荷物組にそれ以上の重さの荷物を加えた「拡張極小カバー不等式」を加えて LP 緩和を強化し、割当結果・使用コンテナ数・強化後の LP 緩和目的値を返してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `weights` | `number[]` | 各荷物 $i \in \{0, \dots, n-1\}$ の重み（kg） |
| `binCapacity` | `number` | 1 つのコンテナに入れられる重みの上限（kg） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `assignments` | `number[]` | 各荷物を割り当てたコンテナ番号（0 始まり、`assignments[0] = 0` の先頭連続番号） |
| `binsUsed` | `number` | 使用したコンテナの最小個数 |
| `lpBound` | `number` | 対称性除去・容量カット・カバーカット適用後の LP 緩和目的値 |

<!-- section:example -->
**入力例**

```json
{
  "weights": [6, 6, 6, 2],
  "binCapacity": 10
}
```

**出力例**

```json
{
  "assignments": [0, 1, 2, 2],
  "binsUsed": 3,
  "lpBound": 3
}
```

重み `[6]`、`[6]`、`[6, 2]` をコンテナ 0, 1, 2 に配置すると各コンテナの合計重みは積載上限 10 以下（$6, 6, 8 \le 10$）かつ先頭連続順序を満たし、使用コンテナ数 **3**、LP 緩和値 **3** となります。

<!-- section:hint1 -->
各コンテナが使用されるかを表す二値変数と、各荷物がどのコンテナに割り当てられるかを表す二値変数を用意し、使用コンテナ数の合計を最小化します。各荷物の単一割当制約と積載上限制約に加え、使用コンテナの先頭連続順序と荷物番号に応じたコンテナ番号の上限を課します。

<!-- section:hint2 -->
対称性除去としてコンテナ使用変数を非増加（$u_k \ge u_{k+1}$）にし、$k > i$ となるコンテナへの荷物 $i$ の割当を禁止します。LP 緩和下界を強化するため、切り上げ総容量カット $\sum_k u_k \ge \lceil \sum_i w_i / B \rceil$ に加え、各極小カバー $C$（$\sum_{i \in C} w_i > B$ かつ最軽量荷物を除くと $B$ 以下）に対して $E(C) = C \cup \{j : w_j \ge \max_{i \in C} w_i\}$ を作り、各コンテナ $k$ に $\sum_{i \in E(C)} x_{ik} \le (|C| - 1) u_k$ を追加します。`m.solve()` の前に `m.relax()` で `lpBound` を取得してください。
