# #062. 多品目容量制約付きロットサイズ計画 (CLSP)

<!-- section:scenario -->
ある菓子工房では、1 台の共有オーブン（生産ライン）を用いて複数の焼き菓子（フィナンシェやマドレーヌなど）を複数期間にわたり生産します（全品目の初期在庫はゼロです）。ある期間にある品目を少しでも生産するには、その品目用の段取りが必要となり、品目固有の固定段取り費と段取り時間が発生します。

各期間では、全品目の「加工時間（生産量×単位加工時間）＋段取り時間」の合計がその期のオーブン稼働可能時間を超えてはなりません。全品目・全期間の需要を満たしつつ、**段取り費と在庫保管費の合計を最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[][]` | 品目 $i$・期間 $t$ の需要量 $d_{i,t}$ |
| `setupCosts` | `number[]` | 品目 $i$ の 1 回あたり固定段取り費 $F_i$ |
| `holdCosts` | `number[]` | 品目 $i$ の 1 単位・1 期あたり保管費 $h_i$ |
| `unitTimes` | `number[]` | 品目 $i$ の 1 単位あたり加工時間 $a_i$ |
| `setupTimes` | `number[]` | 品目 $i$ の段取りに要する時間 $s_i$ |
| `capacities` | `number[]` | 各期 $t$ の共有オーブン稼働可能時間 $H_t$ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `setups` | `number[][]` | 各品目・各期の段取り有無（$I \times T$ の 0/1 行列） |
| `production` | `number[][]` | 各品目・各期の非負生産量（$I \times T$） |
| `inventory` | `number[][]` | 各品目・各期の非負期末在庫（$I \times T$） |
| `totalCost` | `number` | 最小化された総コスト（段取り費＋保管費） |

<!-- section:example -->
**入力例**

```json
{
  "demands": [
    [20, 30, 15, 25],
    [10, 25, 30, 15]
  ],
  "setupCosts": [120, 150],
  "holdCosts": [2, 2.5],
  "unitTimes": [1.5, 2.0],
  "setupTimes": [12, 15],
  "capacities": [110, 100, 115, 100]
}
```

**出力例**

```json
{
  "setups": [
    [1, 1, 1, 1],
    [1, 1, 1, 1]
  ],
  "production": [
    [20, 30, 15, 25],
    [21, 14, 30, 15]
  ],
  "inventory": [
    [0, 0, 0, 0],
    [11, 0, 0, 0]
  ],
  "totalCost": 1107.5
}
```

第 0 期に品目 1 を 11 単位先行生産することで、第 1 期の機械時間を $12 + 15 + 1.5(30) + 2.0(14) = 100 \le 100$ に収め、総コストは $4(120 + 150) + 11 \times 2.5 =$ **1,107.5** となります。


<!-- section:hint1 -->
各品目・各期に対して、バイナリの段取り変数、連続生産量変数、および非負の期末在庫変数を $I \times T$ 行列として定義します。品目ごとに独立した在庫収支バランスと、各期で全品目が共有する機械稼働時間の上限制約を組み合わせてモデル化します。

<!-- section:hint2 -->
生産量と段取り変数を結び付ける際には、任意の大きな定数ではなく、期 $t$ 以降の残余累積需要など有効な最小の上界を用いると緩和が強くなります。各期の機械能力制約では、全品目にわたる単位加工時間の合計と固定段取り時間の合計の両方を加算してください。
