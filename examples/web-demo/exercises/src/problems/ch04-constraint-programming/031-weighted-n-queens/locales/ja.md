# #031. 重み付き N-クイーン

<!-- section:scenario -->
パズル設計者は、盤面サイズ N 行 N 列のチェス盤の各行に 1 つずつ、合計 N 個のクイーンを配置しようとしています。各クイーンの列番号は 0 から盤面サイズ未満の整数であり、どの 2 つのクイーンも同じ列や同じ対角線（斜め方向）にあってはなりません。

各マスには固有の整数配置コストが設定されています。互いに攻撃しない配置の中で、配置したマスのコスト合計を最小にしてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `costMatrix` | `number[][]` | 行 `r`・列 `c` にクイーンを置くコスト `costMatrix[r][c]` を表す `N × N` 行列 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `cols` | `number[]` | 各行 `r` のクイーンの列番号（`[0, N - 1]`） |
| `totalCost` | `number` | 選択したマスの重み合計の最小値 |

<!-- section:example -->
**入力**

```json
{
  "costMatrix": [
    [7, 2, 5, 9],
    [9, 4, 8, 1],
    [3, 7, 4, 6],
    [5, 8, 2, 7]
  ]
}
```

**出力**

```json
{
  "cols": [1, 3, 0, 2],
  "totalCost": 8
}
```

(0, 1)・(1, 3)・(2, 0)・(3, 2) の配置は列・対角線の衝突がなく、合計コストは $2 + 1 + 3 + 2 =$ **8** になります。

<!-- section:hint1 -->
各行のクイーンが置かれる列番号を表す整数決定変数を 1 つずつ用意します。列どうしの重複禁止に加えて 2 種類の対角線それぞれでも重複を禁止し、各行で選ばれたマスの重みを合計して最小化します。

<!-- section:hint2 -->
列の制約に `distinct(cols)`、2 方向の対角線制約に `cols[r] + r` と `cols[r] - r` の配列に対する `distinct(...)` を課します。各行の重みは `at(costMatrix[r], cols[r])` で参照し、その `sum(...)` を `minimize(...)` して `solver: "pumpkin"` で解きます。
