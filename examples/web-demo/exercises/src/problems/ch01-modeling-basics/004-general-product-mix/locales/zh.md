# #004. 通用产品组合规划（m × n 矩阵）

<!-- section:scenario -->
一家意式冰淇淋工坊计划生产多种口味的冰淇淋。每生产 1 升某种口味都能获得固定的单位利润，同时也会按定额消耗牛奶、鲜奶油等共享原料以及冷冻机运转时长等设备产能。

口味种类数和共享原料或设备的数量随输入数据变化。请在不超出任何原料或设备可用上限的前提下，决定每种口味的产量（单位：升，非负连续量），以**最大化总利润**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `margins` | `number[]` | 口味 $j$ 每升的利润 |
| `usages` | `number[][]` | 消耗矩阵，`usages[k][j]` 为生产 1 升口味 $j$ 所消耗的原料或设备 $k$ 的数量 |
| `capacities` | `number[]` | 原料或设备 $k$ 的可用上限 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `quantities` | `number[]` | 各口味的产量（单位：升，非负连续值） |
| `totalProfit` | `number` | 最大化后的总利润 |

<!-- section:example -->
**输入示例**

```json
{
  "margins": [500, 300],
  "usages": [
    [3, 1],
    [1, 2]
  ],
  "capacities": [90, 80]
}
```

**输出示例**

```json
{
  "quantities": [20, 30],
  "totalProfit": 19000
}
```

各口味生产 `[20, 30]` 升时，原料或设备 0 的消耗量为 $3 \times 20 + 1 \times 30 = 90$、原料或设备 1 为 $1 \times 20 + 2 \times 30 = 80$（均未超上限），总利润为 $500 \times 20 + 300 \times 30 =$ **19,000**。
