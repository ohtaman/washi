# #019. 区分ボリュームディスカウント発注（全量割引）

<!-- section:scenario -->
調達チームが、複数の候補サプライヤーから原材料を合計で必要需要量以上購入する計画を立てます。各サプライヤーは注文数量に応じた複数の割引価格帯（ティア）を設定しています。あるサプライヤーに発注する場合は価格帯を **1 つ**選び、その価格帯の最小数量から最大数量までの範囲で連続量を発注します。そのサプライヤーからの**購入全量**に、選んだ価格帯の単価が適用されます。

まったく発注しないサプライヤーはどの価格帯も選ばず発注量をゼロにします。必要需要以上を確保しつつ、**総調達コストを最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demand` | `number` | 全サプライヤー合計で確保すべき最低調達量 |
| `suppliers` | `{ minQty: number; maxQty: number; unitPrice: number }[][]` | 各サプライヤー $s$ の価格帯リスト |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `tierSelected` | `number[][]` | 各サプライヤー $s$・価格帯 $k$ の選択（0 または 1） |
| `tierQuantities` | `number[][]` | 各価格帯での連続発注量 |
| `totalCost` | `number` | 最小化された総調達コスト |

<!-- section:example -->
**入力例**

```json
{
  "demand": 60,
  "suppliers": [
    [
      { "minQty": 10, "maxQty": 30, "unitPrice": 11 },
      { "minQty": 35, "maxQty": 50, "unitPrice": 8.5 }
    ],
    [
      { "minQty": 5, "maxQty": 20, "unitPrice": 10 },
      { "minQty": 25, "maxQty": 45, "unitPrice": 8.8 }
    ]
  ]
}
```

**出力例**

```json
{
  "tierSelected": [[0, 1], [0, 1]],
  "tierQuantities": [[0, 35], [0, 25]],
  "totalCost": 517.5
}
```

両社の第 1 価格帯を選んで 35（範囲 $[35, 50]$）と 25（範囲 $[25, 45]$）を発注すると、総量 $35 + 25 = 60 \ge 60$ を満たし、総調達コストは $35 \times 8.5 + 25 \times 8.8 =$ **517.5** となります。

<!-- section:hint1 -->
各サプライヤーと価格帯の組 $(s, k)$ に対して、選択を表すバイナリ変数と発注量を表す連続変数を用意します。サプライヤーごとに選択できる価格帯を最大 1 つに制限し、各価格帯の発注量をその選択変数に連結したうえで、全体の発注合計が需要を満たすようにします。

<!-- section:hint2 -->
各価格帯 $(s, k)$ を半連続変数として扱い、`tierQuantities[s][k]` を `minQty` と `maxQty` に `tierSelected[s][k]` を掛けた範囲で挟むと、未選択時は 0、選択時は価格帯の範囲内に強制されます。各サプライヤーで最大 1 つの価格帯しか選ばれないため、全 $(s, k)$ にわたる `unitPrice * tierQuantities[s][k]` の和がそのまま全量割引コストを線形に表します。
