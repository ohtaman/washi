# #078. 大学课程排课表编排

<!-- section:scenario -->
某高校需要将 $C$ 门课程安排至 $R$ 间教室与 $T$ 个周内时间片。每门课程必须恰好被安排进一间容量不小于其选课人数的教室和一个时间片，且同一教室在同一时间片内至多容纳一门课程。

此外，由同一位教师授课或包含共同学生群组的课程不能安排在同一时间片。请在满足全部容量与冲突限制下，最大化所有课程的时间片偏好总分。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `courseSizes` | `number[]` | 每门课程 $c$ 的选课人数 |
| `roomCapacities` | `number[]` | 每间教室 $r$ 的座位数上限 |
| `teachers` | `number[]` | 每门课程 $c$ 的授课教师编号 |
| `cohorts` | `number[][]` | 选修课程 $c$ 的学生群组编号列表 |
| `slotScores` | `number[][]` | 课程 $c$ 安排在时间片 $t$ 获得的偏好得分（$C \times T$） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `rooms` | `number[]` | 每门课程分配到的教室编号 `0..R-1` |
| `slots` | `number[]` | 每门课程分配到的时间片编号 `0..T-1` |
| `totalScore` | `number` | 最大化的偏好得分总和 |

<!-- section:example -->
**输入示例**

```json
{
  "courseSizes": [45, 25, 30, 20],
  "roomCapacities": [50, 30],
  "teachers": [0, 0, 1, 2],
  "cohorts": [[0], [1], [0], [1]],
  "slotScores": [
    [10, 6, 4],
    [9, 8, 5],
    [10, 7, 3],
    [8, 9, 6]
  ]
}
```

**输出示例**

```json
{
  "rooms": [0, 0, 1, 1],
  "slots": [1, 0, 0, 1],
  "totalScore": 34
}
```

时段 0 安排课程 1（教室 0、教师 0、群组 1）与课程 2（教室 1、教师 1、群组 0），时段 1 安排课程 0 与课程 3，均满足容量且无任何冲突，偏好总分为 $6 + 9 + 10 + 9 =$ **34**。
