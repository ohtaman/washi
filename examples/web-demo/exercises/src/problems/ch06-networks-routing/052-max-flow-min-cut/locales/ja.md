# #052. 最大流・最小カット定理

<!-- section:scenario -->
容量付きの有向通信ネットワークにおいて、始点から終点へ最大限の流量を送る問題を考えます。各枝の流量は容量上限以下でなければならず、始点・終点以外の中間頂点では流入量と流出量が一致する必要があります。

線形計画（LP）により始点から終点への最大流量を求めるとともに、始点から終点へのすべての有向パスを遮断し、かつ容量合計が最大流量と一致する最小 s-t カット辺集合を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `nodeCount` | `number` | 頂点数（`0 .. nodeCount - 1`） |
| `source` | `number` | 始点インデックス $s$ |
| `sink` | `number` | 終点インデックス $t$ |
| `edges` | `Array<{ from, to, cap }>` | 容量付き有向枝の配列 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `flows` | `number[]` | 各枝の非負フロー量（`0 <= flow <= cap`） |
| `cutEdges` | `number[]` | 最小 s-t カットを構成する重複なしの枝インデックス配列 |
| `maxFlow` | `number` | 最大流量（`cutEdges` の容量合計と一致） |

<!-- section:example -->
**入力例**

```json
{
  "nodeCount": 4,
  "source": 0,
  "sink": 3,
  "edges": [
    { "from": 0, "to": 1, "cap": 10 },
    { "from": 0, "to": 2, "cap": 5 },
    { "from": 1, "to": 2, "cap": 4 },
    { "from": 1, "to": 3, "cap": 4 },
    { "from": 2, "to": 3, "cap": 10 }
  ]
}
```

**出力例**

```json
{
  "flows": [8, 5, 4, 4, 9],
  "cutEdges": [1, 2, 3],
  "maxFlow": 13
}
```

始点 0 からの流出は $8 + 5 =$ **13**、中間頂点 1・2 は収支 0 を満たし、`cutEdges = [1, 2, 3]` を除くと `0` から `3` への道がすべて遮断され、カット容量和も $5 + 4 + 4 =$ **13** となります。
