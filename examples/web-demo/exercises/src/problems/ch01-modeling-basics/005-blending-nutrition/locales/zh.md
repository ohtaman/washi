# #005. 精密合金配比（比例上下界约束）

<!-- section:scenario -->
某金属精炼厂需要将多种合金原料锭熔炼混合成特种合金。每种合金原料锭本身都是由铁、铬、镍等多种化学元素组成的合金，各自具有每公斤单价（/kg）、可用库存上限（kg）以及各元素的质量分数。

请在满足以下全部条件的前提下，决定每种合金原料锭的投入重量（kg），以**最小化总材料成本**：

- **库存上限**：每种合金原料锭的投入重量（kg）不得超过其可用库存（kg）。
- **精确批次重量**：所有合金原料锭的投入总重量（kg）必须恰好等于指定的目标批次重量（kg）。
- **元素含量上下界**：成品合金中每种化学元素的质量占比都必须落在各自的最低与最高允许区间内。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `targetBatch` | `number` | 必须恰好生产的总批次重量 (kg) |
| `costs` | `number[]` | 合金原料锭 $i$ 的每公斤单价 (/kg) |
| `availabilities` | `number[]` | 合金原料锭 $i$ 的库存上限 (kg) |
| `compositions` | `number[][]` | `compositions[i][k]` 为合金原料锭 $i$ 中元素 $k$ 的质量分数（0 到 1 的小数） |
| `minRatios` | `number[]` | 元素 $k$ 的最低允许含量比例（0 到 1 的小数） |
| `maxRatios` | `number[]` | 元素 $k$ 的最高允许含量比例（0 到 1 的小数） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `amounts` | `number[]` | 各合金原料锭的投入重量 (kg) |
| `totalCost` | `number` | 最小化后的总材料成本 |

<!-- section:example -->
**输入示例**

```json
{
  "targetBatch": 100,
  "costs": [300, 500, 400],
  "availabilities": [80, 60, 70],
  "compositions": [
    [0.2, 0.5, 0.1],
    [0.6, 0.2, 0.4],
    [0.4, 0.4, 0.2]
  ],
  "minRatios": [0.35, 0.3, 0],
  "maxRatios": [1, 1, 0.25]
}
```

**输出示例**

```json
{
  "amounts": [62.5, 37.5, 0],
  "totalCost": 37500
}
```

混合 62.5 kg 合金原料锭 0 与 37.5 kg 合金原料锭 1 共计 100 kg，各元素比例分别为 35%、38.75%、21.25%（均符合规格范围），总成本为 $300 \times 62.5 + 500 \times 37.5 =$ **37,500**。
