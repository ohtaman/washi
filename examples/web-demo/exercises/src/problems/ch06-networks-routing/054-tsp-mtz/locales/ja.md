# #054. 非対称巡回セールスマン問題 (TSP・MTZ 定式化)

<!-- section:scenario -->
配送車が拠点の都市 0 を出発し、他のすべての都市をちょうど 1 回ずつ訪問して都市 0 へ戻ります。一方通行や坂道の影響により、都市 i から都市 j への移動コストと逆向きの移動コストは一般には異なります。

部分巡回路（切り離された小ループ）を禁止するために MTZ（Miller-Tucker-Zemlin）の位置ポテンシャル制約を導入し、全都市を 1 つの閉路で結ぶ **総移動コストの最小化** を行ってください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `dist` | `number[][]` | $n \times n$ の非対称移動コスト行列（`dist[i][j]` は `i -> j` のコスト） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `tour` | `number[]` | 都市 `0` から始まる全 $n$ 都市の訪問順配列（`tour[0] = 0`） |
| `totalCost` | `number` | 最小化された閉路の総移動コスト |

<!-- section:example -->
**入力例**

```json
{
  "dist": [
    [0, 12, 2, 9],
    [10, 0, 14, 2],
    [3, 7, 0, 11],
    [8, 3, 6, 0]
  ]
}
```

**出力例**

```json
{
  "tour": [0, 2, 1, 3],
  "totalCost": 19
}
```

`0 -> 2 -> 1 -> 3 -> 0` の順に巡回すると 4 都市すべてを 1 つの輪で訪問でき、総コストは $2 + 7 + 2 + 8 =$ **19** となります。
