# #029. 析取运行区间与凸包重构

<!-- section:scenario -->
工厂的运行管理员正在制定计划，需要调度多台生产机组以提供不低于目标需求量（t/h）的产出。

运行计划必须满足以下所有条件：
- **互斥运行模式**：每台机组只能从“停机（出力 0）”、“低负荷经济运行”、“高负荷强力运行”等互斥模式中恰好选择一个。
- **输出区间与空白地带**：每种模式都有固定的出力范围，相邻模式之间存在禁止运行的空白输出区间。
- **满足总需求**：所有机组的出力总和不得低于目标需求量。

每种模式都设有固有的固定启动费（万元）和单位可变费（万元/(t/h)）。请运用“凸包重构”方法（在拆分后的出力变量与模式指示变量空间中，将从多个互斥模式中择一的 OR 约束表示为最小凸集），在满足需求的前提下，求出**最小化固定费与可变费总和（万元）**的模式选择与出力水平。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `demand` | `number` | 全部机组的最低总产出需求（t/h） |
| `bandLbs` | `number[][]` | 机组 $i$、区间 $k$ 的出力下限 $L_{ik}$（t/h） |
| `bandUbs` | `number[][]` | 机组 $i$、区间 $k$ 的出力上限 $U_{ik}$（t/h） |
| `fixedCosts` | `number[][]` | 机组 $i$ 选择区间 $k$ 时的固定费 $F_{ik}$（万元） |
| `unitCosts` | `number[][]` | 机组 $i$、区间 $k$ 的单位可变费 $c_{ik}$（万元/(t/h)） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `modes` | `number[]` | 每台机组选择的运行区间编号 $k \in \{0, \dots, K-1\}$ |
| `outputs` | `number[]` | 每台机组的出力 $x_i \in [L_{ik}, U_{ik}]$（t/h） |
| `totalCost` | `number` | 最小化后的总成本（万元） |

<!-- section:example -->
**输入示例**

```json
{
  "demand": 42,
  "bandLbs": [
    [0, 10, 30],
    [0, 8, 25]
  ],
  "bandUbs": [
    [0, 20, 45],
    [0, 18, 40]
  ],
  "fixedCosts": [
    [0, 120, 260],
    [0, 90, 220]
  ],
  "unitCosts": [
    [0, 18, 12],
    [0, 20, 14]
  ]
}
```

**输出示例**

```json
{
  "modes": [2, 0],
  "outputs": [42, 0],
  "totalCost": 764
}
```

机组 0 运行在区间 2（[30, 45]）输出 42 t/h，机组 1 停机在区间 0（[0, 0]）输出 0 t/h，满足需求 $42 + 0 \ge 42$ t/h，总成本为 $260 + 12 \times 42 =$ **764** 万元。


<!-- section:hint1 -->
采用按机组与运行区间双重索引的分解凸包（disaggregated convex-hull）建模：为每对机组-区间声明一个表示是否启用该区间的二元变量，以及一个表示该机组在该区间内出力的非负连续变量。

<!-- section:hint2 -->
约束每台机组恰好选择一个运行区间（$\sum_k y_{ik} = 1$），并用指示变量缩放各区间的上下界：$L_{ik} y_{ik} \le x_{ik} \le U_{ik} y_{ik}$。这会迫使未选区间的 $x_{ik} = 0$，同时将所选区间的出力限制在 $[L_{ik}, U_{ik}]$ 内——既避免了松弛较弱的 Big-M，也杜绝了出力落在区间之间的禁用间隙。将所有机组和区间的 $x_{ik}$ 求和以满足 `demand`，并在返回时还原每台机组的选定区间索引与总出力 $\sum_k x_{ik}$。
