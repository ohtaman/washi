# #063. バックオーダーと機会損失を許す在庫計画

<!-- section:scenario -->
ワイヤレスイヤホンを製造する精密機器メーカーが、既知の期首在庫と初期バックオーダーゼロの状態から、複数期間にわたる生産量・出荷販売量・期末実在庫・バックオーダー（遅延出荷残）・機会損失を連続量で計画します。

- **生産能力**: 各期の生産量は非負の連続量であり、その期の生産能力上限を超えてはなりません。
- **実在庫収支**: 各期の期末実在庫は非負であり、前期末の実在庫に当期生産量を加え、当期の出荷販売量を差し引いた値に一致します。
- **バックオーダーと機会損失**: 受注して未出荷となった需要は非負のバックオーダーとして繰り越され（前期末バックオーダーに当期需要を加え、当期の出荷販売量と機会損失を差し引いた値）、各期の機会損失はその期の需要量以下、かつ最終期末のバックオーダーはゼロでなければなりません。
- **目的**: 出荷販売 1 単位あたり一定の売価を得る一方、生産・期末実在庫・バックオーダー・機会損失にはそれぞれ単位コストが発生します。すべての連続量を決め、**純利益を最大化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[]` | 各期の顧客需要量 |
| `capacities` | `number[]` | 各期の生産能力上限 |
| `prodCosts` | `number[]` | 各期の単位生産コスト |
| `unitPrice` | `number` | 出荷販売 1 単位あたりの販売単価 |
| `holdCost` | `number` | 期末実在庫 1 単位・1 期あたりの保管費 |
| `backorderCost` | `number` | 期末バックオーダー 1 単位・1 期あたりの遅延ペナルティ |
| `lostSalePenalty` | `number` | 機会損失 1 単位あたりのペナルティ |
| `initialInventory` | `number` | 第 0 期開始前の期首実在庫 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `production` | `number[]` | 各期の非負の連続生産量（各期の生産能力上限以下） |
| `sales` | `number[]` | 各期の非負の連続出荷販売量 |
| `inventory` | `number[]` | 各期の非負の連続期末実在庫 |
| `backlog` | `number[]` | 各期の非負の連続期末バックオーダー（最終期は 0） |
| `lostSales` | `number[]` | 各期の非負の連続機会損失量（各期の需要量以下） |
| `netProfit` | `number` | 最大化された純利益 |

<!-- section:example -->
**入力例**

```json
{
  "demands": [30, 50, 20, 25],
  "capacities": [35, 30, 40, 30],
  "prodCosts": [10, 12, 10, 11],
  "unitPrice": 22,
  "holdCost": 1.5,
  "backorderCost": 3,
  "lostSalePenalty": 5,
  "initialInventory": 5
}
```

**出力例**

```json
{
  "production": [35, 30, 30, 25],
  "sales": [30, 40, 30, 25],
  "inventory": [10, 0, 0, 0],
  "backlog": [0, 10, 0, 0],
  "lostSales": [0, 0, 0, 0],
  "netProfit": 1420
}
```

第 0 期に期首在庫 5 と超過生産 5 により期末実在庫 10 単位を繰り越し、第 1 期で不足する 10 単位を第 2 期へバックオーダーすると、両方の収支式と最終バックオーダー 0 を満たし、純利益は $125(22) - (350 + 360 + 300 + 275) - 10(1.5) - 10(3) =$ **1,420** となります。


<!-- section:hint1 -->
各期ごとに、生産量、出荷販売量、期末実在庫、期末バックオーダー、および機会損失の 5 種類の非負連続変数を定義します。通常のロットサイズ問題とは異なり、物理的な期末実在庫と顧客のバックオーダーを 2 つの独立した収支連鎖として追跡します。

<!-- section:hint2 -->
期末実在庫は前期末実在庫（第 0 期では `initialInventory`）に生産量を加え出荷販売量を引いた値となり、バックオーダーは初期残高ゼロから始まり新規需要を加えて出荷販売量と機会損失を引いた値になります。`lostSales[t]` を `demands[t]` 以下に抑え、最終期のバックオーダーを 0 に固定して期末までに受注残をすべて解消してください。
