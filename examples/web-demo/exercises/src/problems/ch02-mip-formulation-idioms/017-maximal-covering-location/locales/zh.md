# #017. 最大覆盖选址问题（MCLP）

<!-- section:scenario -->
市政规划部门计划从若干候选站点中挑选站点开设应急服务站，受经费约束最多只能开设固定数量的站点。每个需求区域都有既定的人口需求，只要在给定服务半径以内至少有一座已开设站点，该区域即被视为获得覆盖。

在站点总数受限、未必能覆盖所有区域的前提下，合理选择开设哪些候选站点以**最大化被覆盖区域的总需求**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `demands` | `number[]` | 各需求区 $i$ 的人口需求权重 |
| `distances` | `number[][]` | 距离矩阵，`distances[i][j]` 为区域 $i$ 到站点 $j$ 的距离 |
| `coverageRadius` | `number` | 能够覆盖需求区的最大服务半径 |
| `maxFacilities` | `number` | 允许开设的站点总数上限 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `open` | `number[]` | 各候选站点是否开设（`0` 或 `1`） |
| `covered` | `number[]` | 各需求区是否被覆盖（`0` 或 `1`） |
| `totalCoveredDemand` | `number` | 最大化后的总覆盖需求 |

<!-- section:example -->
**输入示例**

```json
{
  "demands": [40, 35, 30, 25, 22],
  "distances": [
    [2, 6, 8, 9],
    [3, 4, 7, 8],
    [6, 2, 4, 7],
    [9, 5, 3, 2],
    [8, 7, 6, 3]
  ],
  "coverageRadius": 5,
  "maxFacilities": 2
}
```

**输出示例**

```json
{
  "open": [1, 1, 0, 0],
  "covered": [1, 1, 1, 1, 0],
  "totalCoveredDemand": 130
}
```

开设站点 0 和 1（$2 \le 2$）可在半径 5 内覆盖区域 0、1、2、3，覆盖需求总和为 $40 + 35 + 30 + 25 =$ **130**。

<!-- section:hint1 -->
模型使用两组二元决策变量：一组表示开设哪些候选站点，另一组表示覆盖哪些需求区域。除了限制开设站点的总数外，还需要为每个区域建立一条耦合约束，保证仅当附近存在已开设站点时该区域才能被标记为已覆盖。

<!-- section:hint2 -->
对每个区域 $i$，筛选出满足 `distances[i][j] <= coverageRadius` 的候选站点 $j$，并要求 `covered[i]` 不超过这些可达站点的 `open[j]` 之和（若半径内无已开设站点，则强制 `covered[i] = 0`）。由于最大化被覆需求会自动激励在可行时取 `covered[i] = 1`，无需再添加下界耦合约束。
