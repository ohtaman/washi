# #084. 公平性指标与凸二次规划（QP）负载均衡

<!-- section:scenario -->
运营主管需要将固定总量连续分配给多个区域团队。每个团队有各自的单位运营成本及最小、最大分配上下限，且所有团队分配量之和必须恰好等于总需求。

若只追求总成本最小化，工作量会全部集中到低成本团队上限处。为兼顾分配公平性，请引入与各团队偏离平均分配量的平方和成正比的二次惩罚项，在满足约束下最小化线性运营成本与 L2 公平性惩罚之和。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `unitCosts` | `number[]` | 各团队每单位分配量的线性运营成本 |
| `minAlloc` | `number[]` | 各团队允许的最小分配量 |
| `maxAlloc` | `number[]` | 各团队允许的最大分配量 |
| `totalDemand` | `number` | 需要分摊的总需求量 |
| `fairnessWeight` | `number` | 施加在 $\sum_i (x_i - \bar{x})^2$ 上的非负惩罚权重 $\lambda$ |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `allocations` | `number[]` | 分配给各团队的连续工作量 |
| `totalCost` | `number` | 最小化后的线性成本与二次方差惩罚之和 |

<!-- section:example -->
**输入示例**

```json
{
  "unitCosts": [10, 2, 6],
  "minAlloc": [0, 0, 0],
  "maxAlloc": [20, 20, 20],
  "totalDemand": 30,
  "fairnessWeight": 2
}
```

**输出示例**

```json
{
  "allocations": [9, 11, 10],
  "totalCost": 176
}
```

分配方案 `allocations = [9, 11, 10]` 总和为 $9 + 11 + 10 = 30$（均值 $\bar{x} = 10$），线性成本为 $10(9) + 2(11) + 6(10) = 172$，方差惩罚为 $2 \times ((9 - 10)^2 + (11 - 10)^2 + (10 - 10)^2) = 4$，总目标值为 **176**。
