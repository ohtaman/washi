# #002. 栄養バランスの配合（下限制約と最小化）

<!-- section:scenario -->

ある食品メーカーでは、**オーツ麦**と**大豆**をブレンドした新しい栄養バー（プロテインバー）を開発しています。1本あたりに必要な栄養基準を満たしつつ、原材料の仕入れコストをできるだけ抑えたいと考えています。

オーツ麦と大豆（どちらも 0 以上の連続値）を配合し、たんぱく質の必要量 `minProtein` と食物繊維の必要量 `minFiber` をともに満たす中で、総コストが最も安くなる配合量を求めてください。各食材のコストと含まれる栄養素は以下のとおりです。

* **オーツ麦 1 単位**：コスト `30`（たんぱく質 `2`、食物繊維 `1` を含む）
* **大豆 1 単位**：コスト `50`（たんぱく質 `1`、食物繊維 `3` を含む）

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `minProtein` | `number` | 必要なたんぱく質の最低量 |
| `minFiber` | `number` | 必要な食物繊維の最低量 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `oats` | `number` | オーツ麦の配合量（$\ge 0$） |
| `beans` | `number` | 豆類の配合量（$\ge 0$） |
| `totalCost` | `number` | 最小化された総コスト |

<!-- section:example -->
**入力例**

```json
{
  "minProtein": 8,
  "minFiber": 9
}
```

**出力例**

```json
{
  "oats": 3,
  "beans": 2,
  "totalCost": 190
}
```

オーツ麦 3・豆類 2 を配合すると、たんぱく質 8・食物繊維 9 の両方をちょうど満たし、総コスト `190` が最小になります。
