# #056. 带容量约束的车辆路径问题 (CVRP)

<!-- section:scenario -->
配送中心 0 停放着最多 K 辆相同的配送车辆，每辆车具有相同的最大载重限制。每位客户都有正的配送需求，且每条路径必须从配送中心 0 出发并最终返回配送中心 0，沿途所服务客户的累计需求不得超过车载容量。

请将其建模为带载重追踪的混合整数规划（MIP）模型，在满足所有客户需求及车辆数、载重限制的同时 **最小化总行驶距离**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `dist` | `number[][]` | $(n+1) \times (n+1)$ 距离矩阵（`0` 为配送中心，`1..n` 为客户） |
| `demands` | `number[]` | 各节点需求量（`demands[0] = 0`，客户需求为正） |
| `capacity` | `number` | 每辆车的载重上限 $Q$ |
| `maxVehicles` | `number` | 最多可从配送中心 `0` 派出的车辆数 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `routes` | `number[][]` | 车辆路径列表，每条均形如 `[0, ..., 0]` |
| `totalDistance` | `number` | 最小化后的全部路径总行驶距离 |

<!-- section:example -->
**输入示例**

```json
{
  "dist": [
    [0, 5, 7, 5, 6],
    [5, 0, 3, 6, 9],
    [7, 3, 0, 9, 12],
    [5, 6, 9, 0, 4],
    [6, 9, 12, 4, 0]
  ],
  "demands": [0, 4, 5, 4, 5],
  "capacity": 10,
  "maxVehicles": 2
}
```

**输出示例**

```json
{
  "routes": [
    [0, 1, 2, 0],
    [0, 3, 4, 0]
  ],
  "totalDistance": 30
}
```

路线 `[0, 1, 2, 0]` 装载量为 $4 + 5 = 9 \le 10$、距离为 $5 + 3 + 7 = 15$，路线 `[0, 3, 4, 0]` 装载量为 $9 \le 10$、距离为 $5 + 4 + 6 = 15$，总距离为 **30**。
