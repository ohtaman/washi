# #056. 带容量约束的车辆路径问题 (CVRP)

<!-- section:scenario -->
配送中心 0 停放着一组相同的配送车辆，需要为各自具有正配送需求的全部客户送货。请按以下规则规划配送路线：

- 从配送中心 0 派出的路线最多不超过 `maxVehicles` 条。
- 每条路线都必须从配送中心 0 出发并最终返回配送中心 0。
- 每位客户都必须被恰好访问一次。
- 每条路线所服务客户的总需求不得超过车辆的载重上限。

在满足上述全部条件的前提下，**最小化总行驶距离**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `dist` | `number[][]` | $n \times n$ 距离矩阵（0 为配送中心，`1 .. n - 1` 为客户） |
| `demands` | `number[]` | 各节点需求量（`demands[0] = 0`，客户需求为正） |
| `capacity` | `number` | 每辆车的载重上限 $Q$ |
| `maxVehicles` | `number` | 最多可从配送中心 0 派出的车辆数 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `routes` | `number[][]` | 车辆路径列表，每条均形如 `[0, ..., 0]` |
| `totalDistance` | `number` | 最小化后的全部路径总行驶距离 |

<!-- section:example -->
**输入示例**

```json
{
  "dist": [
    [0, 5, 7, 5, 6],
    [5, 0, 3, 6, 9],
    [7, 3, 0, 9, 12],
    [5, 6, 9, 0, 4],
    [6, 9, 12, 4, 0]
  ],
  "demands": [0, 4, 5, 4, 5],
  "capacity": 10,
  "maxVehicles": 2
}
```

**输出示例**

```json
{
  "routes": [
    [0, 1, 2, 0],
    [0, 3, 4, 0]
  ],
  "totalDistance": 30
}
```

路线 `[0, 1, 2, 0]` 装载量为 $4 + 5 = 9 \le 10$、距离为 $5 + 3 + 7 = 15$，路线 `[0, 3, 4, 0]` 装载量为 $4 + 5 = 9 \le 10$、距离为 $5 + 4 + 6 = 15$，总距离为 $15 + 15 =$ **30**。

<!-- section:hint1 -->
为每对不同节点的有序弧定义一个二进制选择变量，并为每位客户定义一个下界为该客户需求量、上界为车辆容量的连续累计载荷变量。约束每位客户的入度和出度均为 1，并使配送中心 0 的出度等于入度且不超过 `maxVehicles`。

<!-- section:hint2 -->
在客户之间的弧上使用基于载荷的 MTZ 约束（对不同客户 $i, j$ 满足 $u_i - u_j + Q x_{ij} \le Q - d_j$）追踪累计需求。这一组约束可同时消除孤立子环路并保证每条路径总需求不超过 $Q$；求解后从配送中心 0 出发沿选中弧追踪至返回 0 即可还原各条路径。
