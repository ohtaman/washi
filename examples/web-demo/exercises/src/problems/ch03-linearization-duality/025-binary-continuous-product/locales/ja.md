# #025. 0-1変数と連続変数の積の線形化（Glover 線形化）

<!-- section:scenario -->
購買部門の担当者は、複数のサプライヤから原材料（kg、連続量）を発注し、総需要を満たす調達計画を立てています。各サプライヤには契約の有無にかかわらず守るべき最小発注量（kg）と最大供給量（kg）があり、基本単価（円/kg）が設定されています。

サプライヤごとに固定の契約料（円）を支払って割引契約を結ぶと、そのサプライヤからの発注量 1 kg あたりの割引を受けられます。契約の有無・各社への発注量・および両者の積を表す割引対象量を決定し、**総調達コスト（円）を最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `minOrders` | `number[]` | 各サプライヤ $i$ の最小発注量 $L_i$（kg） |
| `maxOrders` | `number[]` | 各サプライヤ $i$ の最大供給量 $U_i$（kg） |
| `baseCosts` | `number[]` | 各サプライヤ $i$ の基本単価 $c_i$（円/kg） |
| `discounts` | `number[]` | 契約時（$b_i = 1$）の単位割引額 $d_i$（円/kg） |
| `contractFees` | `number[]` | 契約時の固定契約料 $F_i$（円） |
| `totalDemand` | `number` | 必要な総発注量 $\sum_i x_i$ の下限（kg） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `b` | `number[]` | 割引契約の採否（0 または 1） |
| `x` | `number[]` | 各サプライヤへの発注量 $x_i \in [L_i, U_i]$（kg） |
| `z` | `number[]` | 積 $z_i = b_i x_i$ を表す割引対象量（kg） |
| `totalCost` | `number` | 最小化された総調達コスト（円） |

<!-- section:example -->
**入力例**

```json
{
  "minOrders": [10, 15, 10],
  "maxOrders": [50, 60, 40],
  "baseCosts": [20, 22, 18],
  "discounts": [5, 6, 3],
  "contractFees": [160, 220, 150],
  "totalDemand": 95
}
```

**出力例**

```json
{
  "b": [1, 0, 0],
  "x": [50, 15, 30],
  "z": [50, 0, 0],
  "totalCost": 1780
}
```

発注量 [50, 15, 30] は合計 $95 \ge 95$ kg かつ上下界を満たし、サプライヤ 0 のみ契約を締結（`z` は [50, 0, 0]）することで、総コストは $(20 \times 50 + 22 \times 15 + 18 \times 30) + 160 - 5 \times 50 =$ **1,780** 円となります。


<!-- section:hint1 -->
各サプライヤについて、割引契約を締結するかどうかを表すバイナリ変数、最小・最大発注量で上下限を設けた連続の発注量変数、およびそれらの双線形積を表す連続の補助変数の 3 つをモデル化します。

<!-- section:hint2 -->
$x_i \in [L_i, U_i]$ 上で $z_i = b_i x_i$ を厳密に線形化するため、Glover の 4 本の不等式を用います。$b_i$ による上下界（$L_i b_i \le z_i \le U_i b_i$）は $b_i = 0$ のときに $z_i = 0$ を強制し、$(1 - b_i)$ でシフトした上下界（$x_i - U_i(1 - b_i) \le z_i \le x_i - L_i(1 - b_i)$）は $b_i = 1$ のときに $z_i = x_i$ を強制します。$z_i$ は最小化目的関数に負の係数 $-d_i$ で入るため、上界側を欠くと $z_i$ が不当に大きくなる点に注意してください。総発注量が `totalDemand` 以上となる制約も忘れずに課してください。
