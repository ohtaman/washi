🐑 遊び方ガイド

🪵
1. マスをタップして柵🪵を置く

オオカミ🐺がヒツジ🐑へたどり着けないように、通り道に木の柵🪵を置いて遮断します。もう一度タップすると柵を外せます。

🍓
2. 広いまきばを作って目標スコア達成

オオカミを防いだ状態で、ヒツジ🐑が歩いて行ける範囲（安全なまきば）の合計得点が「クリア目標」に届けばステージクリアです。

🕳️
3. 石橋🌉と穴ぼこ🕳️の仕掛け

🌉石橋は通れますが柵は置けません。🕳️穴ぼこ（-5点）はまきばに入ると減点ですが、真上に丸太の柵🪵を打ち込めば穴が埋まって壁になります。
