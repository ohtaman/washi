# #061. 单品目动态批量生产计划

<!-- section:scenario -->
某工厂需要在零期初库存的基础上，连续多个周期为单一产品安排生产与库存计划。若在某周期启动生产，需支付固定开机换产成本，并可连续生产至该周期产能上限；若不开机，则该周期产量必须为零。

生产每件产品产生成本，未售出而结转至下期的期末库存需支付单位持有成本。请决策各期是否开机、生产量及期末库存量，在满足全部需求的前提下 **最小化总成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `demands` | `number[]` | 各周期 $t$ 的产品需求量 |
| `setupCosts` | `number[]` | 各周期 $t$ 开机生产的固定成本 |
| `prodCosts` | `number[]` | 各周期 $t$ 的单位生产成本 |
| `holdCosts` | `number[]` | 各周期 $t$ 期末库存的单位持有成本 |
| `capacities` | `number[]` | 各周期 $t$ 的最大生产能力上限 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `setups` | `number[]` | 各周期是否开机（`0` 或 `1`） |
| `production` | `number[]` | 各周期非负连续生产量 |
| `inventory` | `number[]` | 各周期非负期末库存量 |
| `totalCost` | `number` | 最小化后的总成本（开机 + 生产 + 持有） |

<!-- section:example -->
**输入示例**

```json
{
  "demands": [20, 50, 10, 40],
  "setupCosts": [180, 180, 180, 180],
  "prodCosts": [10, 12, 10, 14],
  "holdCosts": [2, 2, 2, 2],
  "capacities": [80, 80, 80, 80]
}
```

**输出示例**

```json
{
  "setups": [1, 0, 1, 0],
  "production": [70, 0, 50, 0],
  "inventory": [50, 0, 40, 0],
  "totalCost": 1740
}
```

仅在第 0、2 期开机生产，满足产能上限 80 并得到期末库存 `[50, 0, 40, 0]`，总成本为 $(180 \times 2) + (70 \times 10 + 50 \times 10) + (50 \times 2 + 40 \times 2) =$ **1,740**。
