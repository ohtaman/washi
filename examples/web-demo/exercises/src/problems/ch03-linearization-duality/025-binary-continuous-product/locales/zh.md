# #025. 二元变量与连续变量乘积线性化（Glover 线性化）

<!-- section:scenario -->
采购部门的负责人正在制定采购计划，需要向多家供应商订购原材料（kg，连续量）以满足总需求。无论是否签署折扣合约，每家供应商都设有必须遵守的最小订购量（kg）和最大供应量（kg），并设定了基础单价（日元/kg）。

若为某家供应商支付固定合约费（日元）签署折扣合约，则向该供应商订购的每 1 kg 原材料均可享受单价折扣。请决定是否签署合约、向各家供应商的订购量，以及对应的折扣对象量（签约时等于订购量，未签约时为 0），以**最小化总采购成本（日元）**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `minOrders` | `number[]` | 供应商 $i$ 的最小订购量 $L_i$（kg） |
| `maxOrders` | `number[]` | 供应商 $i$ 的最大供应量 $U_i$（kg） |
| `baseCosts` | `number[]` | 供应商 $i$ 的基础单价 $c_i$（日元/kg） |
| `discounts` | `number[]` | 签约时的单位折扣额 $d_i$（日元/kg） |
| `contractFees` | `number[]` | 签约时的固定合约费 $F_i$（日元） |
| `totalDemand` | `number` | 所有供应商合计需满足的最小总订购量（kg） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `b` | `number[]` | 折扣合约的签署与否（0 或 1） |
| `x` | `number[]` | 向各供应商的订购量 $x_i \in [L_i, U_i]$（kg） |
| `z` | `number[]` | 表示乘积 $z_i = b_i x_i$ 的折扣对象量（kg） |
| `totalCost` | `number` | 最小化后的总采购成本（日元） |

<!-- section:example -->
**输入示例**

```json
{
  "minOrders": [10, 15, 10],
  "maxOrders": [50, 60, 40],
  "baseCosts": [20, 22, 18],
  "discounts": [5, 6, 3],
  "contractFees": [160, 220, 150],
  "totalDemand": 95
}
```

**输出示例**

```json
{
  "b": [1, 0, 0],
  "x": [50, 15, 30],
  "z": [50, 0, 0],
  "totalCost": 1780
}
```

订购量 [50, 15, 30] 合计 $95 \ge 95$ kg 且满足上下界，仅与供应商 0 签署合约（`z` 为 [50, 0, 0]），总成本为 $(20 \times 50 + 22 \times 15 + 18 \times 30) + 160 - 5 \times 50 =$ **1,780** 日元。


<!-- section:hint1 -->
为每位供应商建模三个关联量：表示是否签订折扣合约的二元变量、受限于最小和最大订购量的连续订购量变量，以及表示二者乘积的连续辅助变量。

<!-- section:hint2 -->
在 $x_i \in [L_i, U_i]$ 上可用 Glover 的四条不等式精确线性化 $z_i = b_i x_i$：两条按 $b_i$ 缩放的上下界在 $b_i = 0$ 时将 $z_i$ 钉死为 $0$，另外两条按 $(1 - b_i)$ 平移的上下界在 $b_i = 1$ 时将 $z_i$ 钉死为 $x_i$。注意由于 $z_i$ 在最小化目标中带有负折扣系数 $-d_i$，若缺少上界约束会导致 $z_i$ 被虚增。同时不要忘记总订购量需满足 `totalDemand`。
