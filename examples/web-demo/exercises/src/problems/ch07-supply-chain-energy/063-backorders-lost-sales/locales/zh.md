# #063. 含延期交货与缺货损失的库存计划

<!-- section:scenario -->
某无线耳机精密制造企业需要从已知的期初库存和零初始积压出发，在多个周期内联合规划各项连续决策量，包括生产量、实际交付量、期末物理库存、延期积压与缺货损失。

- **生产能力**：各周期的生产量为非负连续量，且不超过该周期的产能上限。
- **物理库存平衡**：各周期的期末物理库存非负，等于上期期末物理库存加上本期产量并减去本期实际交付量。
- **延期积压与缺货损失**：未及时交付的已接订单形成非负期末延期积压（等于上期延期积压加上本期需求，再减去本期实际交付量与缺货损失）；每期缺货损失不超过该期需求，且最后一期的期末延期积压必须清零。
- **目标**：每交付 1 单位产品获得固定销售单价，而生产、期末物理库存、延期积压和缺货损失分别产生单位成本；请确定各项连续量以 **最大化净利润**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `demands` | `number[]` | 各周期的客户需求量 |
| `capacities` | `number[]` | 各周期的产能上限 |
| `prodCosts` | `number[]` | 各周期的单位生产成本 |
| `unitPrice` | `number` | 每交付 1 单位产品的销售单价 |
| `holdCost` | `number` | 每单位每期的物理库存持有成本 |
| `backorderCost` | `number` | 每单位每期的延期积压惩罚 |
| `lostSalePenalty` | `number` | 每单位缺货损失的商誉惩罚 |
| `initialInventory` | `number` | 第 0 期之前的期初物理库存 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `production` | `number[]` | 各周期非负连续生产量（不超过各期产能上限） |
| `sales` | `number[]` | 各周期非负连续实际交付量 |
| `inventory` | `number[]` | 各周期非负连续期末物理库存 |
| `backlog` | `number[]` | 各周期非负连续期末延期积压（最后一期为 0） |
| `lostSales` | `number[]` | 各周期非负连续缺货损失（不超过各期需求量） |
| `netProfit` | `number` | 最大化后的总净利润 |

<!-- section:example -->
**输入示例**

```json
{
  "demands": [30, 50, 20, 25],
  "capacities": [35, 30, 40, 30],
  "prodCosts": [10, 12, 10, 11],
  "unitPrice": 22,
  "holdCost": 1.5,
  "backorderCost": 3,
  "lostSalePenalty": 5,
  "initialInventory": 5
}
```

**输出示例**

```json
{
  "production": [35, 30, 30, 25],
  "sales": [30, 40, 30, 25],
  "inventory": [10, 0, 0, 0],
  "backlog": [0, 10, 0, 0],
  "lostSales": [0, 0, 0, 0],
  "netProfit": 1420
}
```

第 0 期凭借期初库存 5 与超额生产 5 单位结转期末物理库存 10 单位，并将第 1 期的 10 单位缺口延期至第 2 期补交，满足两条守恒方程及期末积压清零，净利润为 $125(22) - (350 + 360 + 300 + 275) - 10(1.5) - 10(3) =$ **1,420**。


<!-- section:hint1 -->
按周期建立五个非负连续变量向量：生产量、实际交付量、期末物理库存、期末延期积压和缺货损失。与标准批量计划不同，物理库存和客户订单的延期积压通过两条独立的守恒链进行追踪。

<!-- section:hint2 -->
物理库存由上期结转（第 0 期为 `initialInventory`）加上本期产量再减去实际交付量得到；延期积压从零初始积压出发，加上新增需求再减去实际交付量与缺货损失。注意将 `lostSales[t]` 限制在 `demands[t]` 以内，并将最后一期的延期积压固定为 0，以确保计划期末清空所有已接订单。
