# #092. 対称性除去とカバーカット

<!-- section:scenario -->
重みつき品目のリストを同一容量のビンに詰め込み、使用するビン数を最小化します。ビン同士は互いに区別がつかないため、単純な MIP 定式化では膨大な対称解が生じ、LP 緩和下界も総重量割るビン容量という弱い分数値に留まります。

ビンの使用順を先頭から詰める制約、品目 0 をビン 0 に固定する制約、および品目 i をビン i 以下に限定する対称性除去制約を導入してください。さらに切り上げ総容量カットと拡張極小カバー不等式を加えて LP 緩和を強化し、割当結果・使用ビン数・強化後の LP 緩和目的値を返してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `weights` | `number[]` | 各品目 $i \in \{0, \dots, n-1\}$ の重み |
| `binCapacity` | `number` | 1 つのビンに入れられる重みの上限 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `assignments` | `number[]` | 各品目を割り当てたビン番号（0 始まり、`assignments[0] = 0` の先頭連続番号） |
| `binsUsed` | `number` | 使用したビンの最小個数 |
| `lpBound` | `number` | 対称性除去・容量カット・カバーカット適用後の LP 緩和目的値 |

<!-- section:example -->
**入力例**

```json
{
  "weights": [6, 6, 6, 2],
  "binCapacity": 10
}
```

**出力例**

```json
{
  "assignments": [0, 1, 2, 2],
  "binsUsed": 3,
  "lpBound": 3
}
```

重み `[6]`、`[6]`、`[6, 2]` をビン `0, 1, 2` に配置すると各ビンの合計重みは容量 `10` 以下（`6, 6, 8 <= 10`）かつ先頭連続順序を満たし、使用ビン数 **3**、LP 緩和値 **3** となります。
