# #051. 最小費用流問題と全単模性 (TU)

<!-- section:scenario -->
供給地・中継ハブ・需要地からなる有向輸送ネットワーク上で商品を運びます。各頂点には整数の純供給量（供給地は正、需要地は負、中継点は 0）が与えられ、各方向付き枝には容量上限と 1 単位あたりの輸送コストが設定されています。

整数変数を使わず連続変数のみの線形計画問題（LP）として定式化し、各枝の容量上限と全頂点のフロー保存則を満たしながら **総輸送コストを最小化するフロー** を求めてください。整数データに対して接続行列が全単模性（Total Unimodularity）を持つため、連続 LP の最適解は自然に整数値になります。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `supplies` | `number[]` | 各頂点の整数純供給量（正：供給、負：需要、0：中継） |
| `edges` | `Array<{ from, to, cap, cost }>` | 有向枝リスト（始点 `from`、終点 `to`、容量 `cap`、単価 `cost`） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `flows` | `number[]` | `edges` の各枝のフロー量（`0 <= flow <= cap`） |
| `totalCost` | `number` | 最小化された総輸送コスト |

<!-- section:example -->
**入力例**

```json
{
  "supplies": [10, 0, 0, -10],
  "edges": [
    { "from": 0, "to": 1, "cap": 6, "cost": 2 },
    { "from": 0, "to": 2, "cap": 8, "cost": 4 },
    { "from": 1, "to": 2, "cap": 5, "cost": 1 },
    { "from": 1, "to": 3, "cap": 4, "cost": 3 },
    { "from": 2, "to": 3, "cap": 7, "cost": 2 }
  ]
}
```

**出力例**

```json
{
  "flows": [6, 4, 2, 4, 6],
  "totalCost": 54
}
```

頂点 0 の純流出は $6 + 4 = 10$、頂点 1・2 は収支 0、頂点 3 の純流入は $4 + 6 = 10$ となり、総コストは $6\times 2 + 4\times 4 + 2\times 1 + 4\times 3 + 6\times 2 =$ **54** です。

<!-- section:hint1 -->
各有向枝に対して容量を上限とする非負の連続フロー変数を 1 つずつ定義します。各頂点について流出フロー合計と流入フロー合計の差が純供給量に等しくなるようフロー保存則を課し、全枝の輸送コスト合計を最小化してください。

<!-- section:hint2 -->
有向グラフの接続行列は全単模であり、供給量と容量がすべて整数であるため、純粋な連続 LP の最適端点は自動的に整数になります（整数変数や 0-1 変数は不要です）。解は丸めずに連続値 `v.value!`（Python では `float(pulp.value(v))`）をそのまま返し、必要に応じて `-0` を `0` に正規化してください。
