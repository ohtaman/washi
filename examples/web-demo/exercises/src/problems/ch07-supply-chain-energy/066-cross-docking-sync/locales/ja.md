# #066. クロスドッキングのドック割当と荷役・出発同期

<!-- section:scenario -->
クロスドッキング施設において、入荷用ドックと出荷用ドックへのトラック割当と品目別の積替・出発時刻を統合的に決定します。

- 各入荷トラックはいずれか 1 つの入荷ドックへ、各出荷トラックはいずれか 1 つの出荷ドックへ、各ドックの収容台数上限内で割り当てます。
- 入荷トラックから出荷トラックへ非負の連続量として品目別フローを積み替え、各入荷トラックの出荷合計は品目ごとの積載量以下とし、各出荷トラックの需要量を満たします。
- 貨物の積替には、割り当てられた入出荷ドック対に応じた 1 単位あたりの荷役コストと横持ち移動時間がかかります。
- ある入荷トラックから出荷トラックへ正の貨物が流れる場合、その出荷トラックの出発時刻は入荷トラックの到着時刻にドック対間の移動時間を加えた時刻以降でなければならず、目標出発期限を超過した分には単位時間あたりの遅延ペナルティが課されます。

ドック割当・連続積替フロー・出荷トラックの出発時刻を決め、**総荷役コストと遅延ペナルティの和を最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `supplies` | `number[][]` | 入荷トラック別・品目別の積載量（$N_{\text{in}} \times K$） |
| `demands` | `number[][]` | 出荷トラック別・品目別の需要量（$N_{\text{out}} \times K$） |
| `arrivalTimes` | `number[]` | 各入荷トラックの到着時刻（長さ $N_{\text{in}}$） |
| `dueTimes` | `number[]` | 各出荷トラックの目標出発期限（長さ $N_{\text{out}}$） |
| `inDoorCaps` | `number[]` | 各入荷ドックの最大受入台数（長さ $R$） |
| `outDoorCaps` | `number[]` | 各出荷ドックの最大配車台数（長さ $S$） |
| `handlingCosts` | `number[][]` | 入出荷ドック対間の 1 単位あたり荷役コスト（$R \times S$） |
| `transferTimes` | `number[][]` | 入出荷ドック対間の移動所要時間（$R \times S$） |
| `delayCost` | `number` | 目標出発期限を超過した遅延 1 単位時間あたりのペナルティ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `inDoor` | `number[]` | 各入荷トラックに割り当てた入荷ドック番号（$0 \dots R-1$） |
| `outDoor` | `number[]` | 各出荷トラックに割り当てた出荷ドック番号（$0 \dots S-1$） |
| `flows` | `number[][][]` | 非負の連続品目別積替フロー（$N_{\text{in}} \times N_{\text{out}} \times K$） |
| `departures` | `number[]` | 各出荷トラックの非負の出発時刻（長さ $N_{\text{out}}$） |
| `totalCost` | `number` | 最小化された総荷役＋遅延コスト |

<!-- section:example -->
**入力例**

```json
{
  "supplies": [
    [20, 15],
    [15, 25],
    [25, 10]
  ],
  "demands": [
    [15, 15],
    [25, 20],
    [20, 15]
  ],
  "arrivalTimes": [1, 3, 2],
  "dueTimes": [6, 8, 7],
  "inDoorCaps": [2, 2],
  "outDoorCaps": [2, 2],
  "handlingCosts": [
    [2, 5],
    [4, 2]
  ],
  "transferTimes": [
    [2, 5],
    [4, 2]
  ],
  "delayCost": 30
}
```

**出力例**

```json
{
  "inDoor": [0, 1, 1],
  "outDoor": [1, 1, 0],
  "flows": [
    [
      [0, 0],
      [0, 0],
      [20, 15]
    ],
    [
      [15, 5],
      [0, 20],
      [0, 0]
    ],
    [
      [0, 10],
      [25, 0],
      [0, 0]
    ]
  ],
  "departures": [5, 5, 3],
  "totalCost": 220
}
```

入荷 0 と出荷 2 をドック対 (0, 0) に、入荷 1・2 と出荷 0・1 をドック対 (1, 1) に組むと、110 単位すべてが荷役単価 2 かつ出発時刻 [5, 5, 3] が目標出発期限 [6, 8, 7] 以下（遅延ゼロ）で処理でき、総コストは $110 \times 2 =$ **220** となります。


<!-- section:hint1 -->
各入荷トラックを 1 つの入荷ドックへ、各出荷トラックを 1 つの出荷ドックへ割り当てるバイナリ行列、入出荷トラック対の間に貨物が流れるかを記録するバイナリ指標、および品目別フロー・出発時刻・遅延時間を表す連続変数を定義します。

<!-- section:hint2 -->
荷役コストと移動時間はドック対 $(r, s)$ に依存する一方、貨物フローは $(i, j, k)$ で添字付けられるため、トラック対の総フローをドック対変数 $w_{i,j,r,s}$ に分解して両側のドック割当（`x[i][r]` と `y[j][s]`）に結び付けます。時刻同期は 3 つのバイナリ（`x[i][r]`、`y[j][s]`、`z[i][j]`）がすべて 1 のときのみ出荷トラック $j$ の出発時刻が `arrivalTimes[i] + transferTimes[r][s]` 以上となるよう、タイトな Big-M（`max(arrivalTimes) + max(transferTimes)`）を用いて線形化してください。
