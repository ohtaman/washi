# #017. 最大被覆立地問題（MCLP）

<!-- section:scenario -->
自治体が、複数の候補地から緊急拠点を開設する計画を立てています。予算上、開設できる拠点数には上限が設けられています。各地区には需要（人口）が設定されており、サービス半径以下の距離に開設された拠点が少なくとも 1 つあれば、その地区はカバーされたとみなされます。

限られた拠点数ですべての地区をカバーできるとは限らない状況のもと、どの候補地を開設するかを決めて**カバーされる需要の合計を最大化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[]` | 各地区 $i$ の需要（人口） |
| `distances` | `number[][]` | 地区 $i$ から候補地 $j$ までの距離行列 |
| `coverageRadius` | `number` | カバー可能とみなす最大距離 |
| `maxFacilities` | `number` | 開設できる候補地の最大数 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `open` | `number[]` | 各候補地を開設するかどうか（`0` または `1`） |
| `covered` | `number[]` | 各地区がカバーされるかどうか（`0` または `1`） |
| `totalCoveredDemand` | `number` | 最大化された被覆需要の合計 |

<!-- section:example -->
**入力例**

```json
{
  "demands": [40, 35, 30, 25, 22],
  "distances": [
    [2, 6, 8, 9],
    [3, 4, 7, 8],
    [6, 2, 4, 7],
    [9, 5, 3, 2],
    [8, 7, 6, 3]
  ],
  "coverageRadius": 5,
  "maxFacilities": 2
}
```

**出力例**

```json
{
  "open": [1, 1, 0, 0],
  "covered": [1, 1, 1, 1, 0],
  "totalCoveredDemand": 130
}
```

候補地 0 と 1 を開設すると（開設数 $2 \le 2$）、半径 5 以内にある地区 0・1・2・3 がカバーされ、被覆需要の合計は $40 + 35 + 30 + 25 =$ **130** となります。

<!-- section:hint1 -->
このモデルでは、各候補地の開設有無と各需要地区の被覆有無を表す 2 組のバイナリ変数を使います。開設数の上限制約に加え、地区ごとに到達可能な候補地が開設されているときだけ被覆できる連結制約が必要です。

<!-- section:hint2 -->
各地区 $i$ について `distances[i][j] <= coverageRadius` を満たす候補地 $j$ を抽出し、`covered[i]` がそれら到達可能な候補地の `open[j]` の和以下になるよう制約します（圏内に開設地がなければ `covered[i] = 0` が強制されます）。目的関数が被覆需要を最大化するため、下限側の連結制約は不要です。
