# #066. 交叉转运月台指派与货流时间同步

<!-- section:scenario -->
某交叉转运中心需要为进站卸货卡车与出站装货卡车分配专用泊位，并同步规划多品类商品的转运货流与发车时刻：

- 每辆进站卡车必须指派至一个进站泊位，每辆出站卡车必须指派至一个出站泊位，且各泊位停靠车辆数不得超过其容量上限。
- 进站卡车与出站卡车之间通过非负连续货流转运各品类商品：每辆进站卡车对各品类的发出总量不得超过其供货量，且每辆出站卡车对各品类的需求必须全部满足。
- 每转运 1 单位货物均按所指派的进出站泊位对计收单位搬运费用，并耗费相应的泊位间搬运时间。
- 只要某辆进站卡车与某辆出站卡车之间存在正货流，该出站卡车的发车时刻就不得早于进站卡车的到站时刻加上泊位间搬运时间；超过目标发车时间的部分按单位时间计收延迟罚金。

请统筹规划泊位指派、连续转运货流与出站发车时刻，以 **最小化搬运与延迟总成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `supplies` | `number[][]` | 进站卡车各品类供货量（$N_{\text{in}} \times K$） |
| `demands` | `number[][]` | 出站卡车各品类需求量（$N_{\text{out}} \times K$） |
| `arrivalTimes` | `number[]` | 各进站卡车的到站时刻（长度 $N_{\text{in}}$） |
| `dueTimes` | `number[]` | 各出站卡车的目标发车时间（长度 $N_{\text{out}}$） |
| `inDoorCaps` | `number[]` | 各进站泊位可停靠的最大车辆数（长度 $R$） |
| `outDoorCaps` | `number[]` | 各出站泊位可停靠的最大车辆数（长度 $S$） |
| `handlingCosts` | `number[][]` | 进出站泊位对间的单位搬运成本（$R \times S$） |
| `transferTimes` | `number[][]` | 进出站泊位对间的货物搬运耗时（$R \times S$） |
| `delayCost` | `number` | 超出目标发车时间每单位时间的延迟罚金 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `inDoor` | `number[]` | 每辆进站卡车分配的进站泊位编号（$0 \dots R-1$） |
| `outDoor` | `number[]` | 每辆出站卡车分配的出站泊位编号（$0 \dots S-1$） |
| `flows` | `number[][][]` | 非负连续转运货流张量（$N_{\text{in}} \times N_{\text{out}} \times K$） |
| `departures` | `number[]` | 每辆出站卡车的非负发车时刻（长度 $N_{\text{out}}$） |
| `totalCost` | `number` | 最小化后的搬运及延迟总成本 |

<!-- section:example -->
**输入示例**

```json
{
  "supplies": [
    [20, 15],
    [15, 25],
    [25, 10]
  ],
  "demands": [
    [15, 15],
    [25, 20],
    [20, 15]
  ],
  "arrivalTimes": [1, 3, 2],
  "dueTimes": [6, 8, 7],
  "inDoorCaps": [2, 2],
  "outDoorCaps": [2, 2],
  "handlingCosts": [
    [2, 5],
    [4, 2]
  ],
  "transferTimes": [
    [2, 5],
    [4, 2]
  ],
  "delayCost": 30
}
```

**输出示例**

```json
{
  "inDoor": [0, 1, 1],
  "outDoor": [1, 1, 0],
  "flows": [
    [
      [0, 0],
      [0, 0],
      [20, 15]
    ],
    [
      [15, 5],
      [0, 20],
      [0, 0]
    ],
    [
      [0, 10],
      [25, 0],
      [0, 0]
    ]
  ],
  "departures": [5, 5, 3],
  "totalCost": 220
}
```

将进站 0 与出站 2 配对在泊位对 (0, 0)，进站 1、2 与出站 0、1 配对在泊位对 (1, 1)，全部 110 件货均以单价 2 完成转运且发车时刻 [5, 5, 3] 不超过目标发车时间 [6, 8, 7]（零延迟），总成本为 $110 \times 2 =$ **220**。


<!-- section:hint1 -->
使用二元分配矩阵将每辆进站卡车分配到一个进站泊位、每辆出站卡车分配到一个出站泊位，用二元指示变量记录进出站卡车对之间是否存在货流，并定义各品类货流、出站发车时刻及延迟量的连续变量。

<!-- section:hint2 -->
由于搬运成本和转运时间取决于泊位对 $(r, s)$，而商品货流按 $(i, j, k)$ 索引，因此需将卡车对总货流分解为泊位对变量 $w_{i,j,r,s}$，并与两侧泊位指派（`x[i][r]` 和 `y[j][s]`）关联。时间同步方面，利用紧致的 Big-M（`max(arrivalTimes) + max(transferTimes)`），确保仅当三个二元变量（`x[i][r]`、`y[j][s]` 和 `z[i][j]`）全为 1 时，才要求出站卡车 $j$ 的发车时刻不早于 `arrivalTimes[i] + transferTimes[r][s]`。
