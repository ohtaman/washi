# #015. 最小成本集合覆盖问题

<!-- section:scenario -->
某安全运维中心需要采购若干监控服务包以保护所有关键系统组件。每个候选服务包具有固定采购成本，并可监测一组指定组件，允许不同已选服务包的监测范围发生重叠。

请选择一组监控服务包，使得每一个关键组件都**至少被一个**所选服务包覆盖，同时**最小化总采购成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `numElements` | `number` | 待覆盖要素数量（编号 `0` 到 `numElements - 1`） |
| `costs` | `number[]` | 选择各个候选子集的成本 |
| `sets` | `number[][]` | 每个候选子集 $j$ 所覆盖的要素编号列表 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selected` | `number[]` | 各候选子集是否入选（`0` 或 `1`） |
| `totalCost` | `number` | 最小化后的总成本 |

<!-- section:example -->
**输入示例**

```json
{
  "numElements": 5,
  "costs": [7, 4, 5, 6, 8],
  "sets": [
    [0, 1, 2],
    [0, 3],
    [1, 2, 4],
    [2, 3, 4],
    [0, 1, 3, 4]
  ]
}
```

**输出示例**

```json
{
  "selected": [0, 1, 1, 0, 0],
  "totalCost": 9
}
```

选择子集 1（`[0, 3]`）与子集 2（`[1, 2, 4]`）可覆盖全部要素 `{0, 1, 2, 3, 4}`，总成本为 $4 + 5 =$ **9**。

<!-- section:hint1 -->
为每个候选监控包设置一个二元选择变量。模型对每个要素建立一条覆盖约束，保证至少选中一个包含该要素的监控包，同时最小化总成本。

<!-- section:hint2 -->
将包含关系转置来看：不要按 `sets[j]` 遍历，而是对每个要素 $i \in \{0, \dots, \text{numElements} - 1\}$ 收集所有包含 $i$ 的监控包 $j$ 对应的 `selected[j]`，并约束其和 $\ge 1$。
