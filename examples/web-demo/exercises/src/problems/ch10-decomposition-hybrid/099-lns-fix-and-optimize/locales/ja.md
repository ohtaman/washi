# #099. 大近傍探索（Fix-and-Optimize 法）

<!-- section:scenario -->
製造工場において多期間の生産計画を立案します。各期には需要、段取り実施時に固定段取り費とともに生産容量を解放する 0-1 段取り決定、単位生産費、および期末在庫保管費が存在します。期間が長くなると単一の巨大 MIP では探索が停滞しやすくなります。

与えられた初期段取り計画とウィンドウ幅から Fix-and-Optimize 大近傍探索を実行し、1 周してもコストが改善しなくなるまでロットサイズ計画を反復改善して最終的な段取り・生産量・在庫量・総コストを返してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[]` | 第 $t$ 期の必要需要量 |
| `setupCosts` | `number[]` | 第 $t$ 期に段取りを行う場合の固定段取りコスト |
| `prodCosts` | `number[]` | 第 $t$ 期の単位生産コスト |
| `holdCost` | `number` | 期末在庫 1 単位あたりの在庫保管コスト |
| `capacities` | `number[]` | 第 $t$ 期の段取り実施時における生産容量上限 |
| `initialPlan` | `number[]` | 実行可能な初期 0/1 段取りベクトル |
| `windowSize` | `number` | 各 LNS 部分問題で同時に解放する連続期間数 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `setups` | `number[]` | 全期間の 0/1 段取りベクトル |
| `production` | `number[]` | 各期の連続生産量 |
| `inventory` | `number[]` | 期末在庫量（初期在庫は 0 とする） |
| `totalCost` | `number` | 固定段取り費・生産費・在庫保管費の合計 |

<!-- section:example -->
**入力例**

```json
{
  "demands": [20, 25, 15, 30, 20, 25],
  "setupCosts": [120, 120, 120, 120, 120, 120],
  "prodCosts": [4, 4, 4, 4, 4, 4],
  "holdCost": 1,
  "capacities": [60, 60, 60, 60, 60, 60],
  "initialPlan": [1, 1, 1, 1, 1, 1],
  "windowSize": 3
}
```

**出力例**

```json
{
  "setups": [1, 0, 0, 1, 0, 1],
  "production": [60, 0, 0, 50, 0, 25],
  "inventory": [40, 15, 0, 20, 0, 0],
  "totalCost": 975
}
```

6 回あった段取りを 3 回へ集約することで段取り費 `360`＋生産費 `540`＋在庫費 `75`＝ **975** を達成します。

<!-- section:hint1 -->
`initialPlan` で初期化した現在の段取りベクトルを保持し、長さ `windowSize` の重なり合うウィンドウを計画期間全体で走査します。各部分問題では現在のウィンドウ内の段取り変数だけを自由な二値変数とし、ウィンドウ外の段取りは固定したまま全期間の連続生産量・在庫量変数を自由に調整させます。

<!-- section:hint2 -->
各部分 MIP では全期間にわたって生産上限 $0 \le p_t \le C_t y_t$ と在庫収支 $I_{t-1} + p_t - d_t = I_t$（$I_{-1} = 0$）を課し、$t \notin [\text{start}, \text{start} + \text{windowSize})$ については $y_t = \bar{y}_t$ と固定します。暫定解より厳密に（$10^{-6}$ 以上）コストが下がったときだけ解を更新し、1 周して改善がなければ終了します。
