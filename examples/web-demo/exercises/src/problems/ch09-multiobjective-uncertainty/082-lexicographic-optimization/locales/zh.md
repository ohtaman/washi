# #082. 两阶段字典序优化

<!-- section:scenario -->
应急调度中心需要在有限的人力配额内，从多个候选服务单元中选出一个二进制子集来满足目标需求量。由于保障服务覆盖率严格优先于节约预算，两个目标按字典序分两阶段进行优化。

首先在人力上限下求得最小可能的需求缺口，然后将需求缺口锁定在不超过“第一阶段最小缺口加上允许的退让容差”的范围内，进一步选择单元组合以最小化次级运营总成本。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `coverage` | `number[]` | 各单元启用后提供的需求覆盖能力 |
| `crews` | `number[]` | 各单元占用的人力班组数 |
| `opCosts` | `number[]` | 各单元启用后的次级运营成本 |
| `maxCrews` | `number` | 可用班组总数上限 |
| `targetDemand` | `number` | 目标需求覆盖量 |
| `slack` | `number` | 允许相对第一阶段最小缺口额外增加的容差（严格字典序为 `0`） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selected` | `number[]` | 各单元的二进制选择结果（`0` 或 `1`） |
| `obj1` | `number` | 最终未满足需求缺口（`max(0, targetDemand - covered)`） |
| `obj2` | `number` | 在第一阶段容差约束下最小化的运营总成本 |

<!-- section:example -->
**输入示例**

```json
{
  "coverage": [10, 12, 15, 8],
  "crews": [2, 3, 4, 2],
  "opCosts": [300, 180, 260, 120],
  "maxCrews": 6,
  "targetDemand": 22,
  "slack": 0
}
```

**输出示例**

```json
{
  "selected": [0, 0, 1, 1],
  "obj1": 0,
  "obj2": 380
}
```

选择单元 2 与 3 消耗人力 $4 + 2 = 6 \le 6$，覆盖能力为 $15 + 8 = 23 \ge 22$（`obj1 = 0`），运营总成本为 $260 + 120 =$ **380**。


<!-- section:hint1 -->
使用表示各单元是否被选中的二元决策变量及班组容量约束，依次求解两个混合整数规划（MIP）模型。第一阶段引入一个非负连续短缺量变量来求得可达到的最小未满足需求；第二阶段将该最小短缺量加上允许退化松弛量作为硬约束固定下来，再最小化次级运营成本。

<!-- section:hint2 -->
不要试图用大权重将两个目标合并为单目标加权和，因为这可能破坏严格优先级或无法准确满足退化容差 `slack`。在第二阶段中施加约束 $\text{covered} \ge \text{targetDemand} - (\text{bestObj1} + \text{slack})$，并根据第二阶段求得的 `selected` 向量按 `Math.max(0, targetDemand - covered)` 计算最终的 `obj1`。在 WaSHI 中使用 `Math.round(v.value!)`、在 PuLP 中使用 `round(pulp.value(v))` 对二元解取整。
