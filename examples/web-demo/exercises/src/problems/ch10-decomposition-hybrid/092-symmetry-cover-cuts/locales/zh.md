# #092. 对称性破除与覆盖割平面

<!-- section:scenario -->
物流仓库的出货负责人需要将带有重量的零件箱等货物（单位：kg）装入具有相同载重上限（kg）的配送集装箱（箱子）中，目标是最小化使用的集装箱数量。由于集装箱之间完全等价，简单的 MIP 建模会产生大量对称解，且连续 LP 松弛下界也仅停留在“总重量 ÷ 载重上限”的弱分数值。

请引入以下约束与强化割平面，并返回分配结果、使用的集装箱数量和强化后的 LP 松弛目标值：
- **对称性破除**：按编号顺序从第 0 个集装箱开始依次启用，且每件货物只能放入编号不超过自身编号的集装箱（第一件货物固定在首个集装箱）。
- **总容量割平面**：加入“总重量 ÷ 载重上限”向上取整得到的最小集装箱数下界约束。
- **扩展极小覆盖不等式**：利用超容极小货物组及其不轻于组内元素的货物构造覆盖不等式，以强化 LP 松弛。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `weights` | `number[]` | 各货物 $i \in \{0, \dots, n-1\}$ 的重量（kg） |
| `binCapacity` | `number` | 单个集装箱允许装入的重量上限（kg） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `assignments` | `number[]` | 各货物分配的集装箱编号（从 0 开始、`assignments[0] = 0` 的连续前缀编号） |
| `binsUsed` | `number` | 使用的集装箱最小数量 |
| `lpBound` | `number` | 应用对称性破除、容量割与覆盖割后的 LP 松弛目标值 |

<!-- section:example -->
**输入示例**

```json
{
  "weights": [6, 6, 6, 2],
  "binCapacity": 10
}
```

**输出示例**

```json
{
  "assignments": [0, 1, 2, 2],
  "binsUsed": 3,
  "lpBound": 3
}
```

将重量 `[6]`、`[6]`、`[6, 2]` 分别放入集装箱 0, 1, 2，各箱负载分别为 6, 6, 8 $\le 10$，箱号连续从 0 启用，共使用 **3** 个集装箱且 LP 松弛下界达到 **3**。

<!-- section:hint1 -->
使用二元变量分别表示每个箱子是否启用以及每个物品是否放入某个箱子，以最小化启用箱子总数。除每个物品恰好放入一个箱子和箱容量约束外，还需加入箱子前缀顺序约束以及物品序号对箱号的上界限制。

<!-- section:hint2 -->
为破除对称性，要求箱子启用变量单调非增（$u_k \ge u_{k+1}$），并禁止将物品 $i$ 放入 $k > i$ 的箱子。为得到强化后的 LP 下界，加入向上取整的全局容量割 $\sum_k u_k \ge \lceil \sum_i w_i / B \rceil$，并对每个极小覆盖 $C$（$\sum_{i \in C} w_i > B$ 且去掉最轻物品后不超过 $B$）构造扩展集合 $E(C) = C \cup \{j : w_j \ge \max_{i \in C} w_i\}$，对每个箱 $k$ 添加 $\sum_{i \in E(C)} x_{ik} \le (|C| - 1) u_k$；最后在 `m.solve()` 之前通过 `m.relax()` 读取 `lpBound`。
