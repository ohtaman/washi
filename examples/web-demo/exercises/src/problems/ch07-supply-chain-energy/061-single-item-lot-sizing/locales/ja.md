# #061. 単一品目動的ロットサイズ計画

<!-- section:scenario -->
ある冷凍食品メーカーの工場で、初期在庫ゼロの状態から複数期間にわたり看板商品である冷凍讃岐うどんの生産・在庫計画を立てます。各期で生産を行う場合には固定の段取り費が発生し、その期の能力上限まで連続量で生産できますが、段取りを行わない期の生産量はゼロでなければなりません。

生産された製品には各期所定の単位生産費がかかり、需要を満たして残った期末在庫には翌期へ繰り越すための単位保管費がかかります。すべての期の需要を満たしつつ、**段取り費・生産費・保管費の総和を最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[]` | 各期 $t$ の製品需要量 |
| `setupCosts` | `number[]` | 各期 $t$ で生産を行う際の固定段取り費 |
| `prodCosts` | `number[]` | 各期 $t$ の 1 単位あたり生産費 |
| `holdCosts` | `number[]` | 各期 $t$ の期末在庫 1 単位あたり保管費 |
| `capacities` | `number[]` | 各期 $t$ の生産能力上限 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `setups` | `number[]` | 各期の段取り有無（0 または 1） |
| `production` | `number[]` | 各期の非負生産量 |
| `inventory` | `number[]` | 各期の非負期末在庫 |
| `totalCost` | `number` | 最小化された総コスト（段取り費＋生産費＋保管費） |

<!-- section:example -->
**入力例**

```json
{
  "demands": [20, 50, 10, 40],
  "setupCosts": [180, 180, 180, 180],
  "prodCosts": [10, 12, 10, 14],
  "holdCosts": [2, 2, 2, 2],
  "capacities": [80, 80, 80, 80]
}
```

**出力例**

```json
{
  "setups": [1, 0, 1, 0],
  "production": [70, 0, 50, 0],
  "inventory": [50, 0, 40, 0],
  "totalCost": 1740
}
```

第 0 期と第 2 期のみ段取りしてまとめて生産すると、能力上限 80 以内で期末在庫 [50, 0, 40, 0] となり、総コストは $(180 \times 2) + (70 \times 10 + 50 \times 10) + (50 \times 2 + 40 \times 2) =$ **1,740** となります。


<!-- section:hint1 -->
計画期間の各期について、段取りの有無を表すバイナリ変数、連続生産量変数、および非負の期末在庫変数を定義します。あるいは、どの将来期の需要に充当するかで生産量を分解したフロー変数を用意し、そこから総生産量と期末在庫を復元する構成も可能です。

<!-- section:hint2 -->
各期 $t$ の生産量は、その期の能力上限を用いて段取り変数と結び付け（`production[t] <= capacities[t] * setups[t]`）、初期在庫ゼロから始まる各期の在庫収支バランスを課します。段取り結合制約を強めたり、施設配置型の変数分解 $w_{t,k} \le d_k y_t$ を用いると、LP 緩和が大幅に引き締まります。
