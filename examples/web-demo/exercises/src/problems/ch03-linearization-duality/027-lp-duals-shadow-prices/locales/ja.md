# #027. LP の双対変数と潜在価格（Shadow Price）

<!-- section:scenario -->
電力会社の運用アナリストは、複数の発電機について各機の発電量（MW、非負の連続量）を決定し、総発電コスト（万円）を最小化する出力配分計画を解いています。各発電機には 1 MW あたりの発電単価が設定されており、1 MW あたり発電機固有の寄与率で各地域の電力需要に寄与し、同じく固有の消費率で各燃料・排出枠を消費します。

出力配分計画は次の 3 つの運転条件を満たす必要があります。
- **発電機の出力上限**: 各発電機の発電量は非負であり、定格出力上限（MW）を超えないこと
- **地域別の最低需要**: 全発電機からの寄与の合計が、各地域の最低電力需要（MW）以上であること
- **燃料・排出枠の上限**: 全発電機による消費量の合計が、各燃料・排出枠の上限以下であること

最小コストとなる各発電機の発電量だけでなく、各最低需要目標や各燃料・排出枠の上限（制約の右辺値）を 1 単位増やしたときに最適コストがどれだけ変化するかを表す潜在価格（シャドウプライス）も求められています。最小化 LP を解き、各発電機の発電量・最低需要制約と燃料・排出枠の上限制約をこの順に並べた潜在価格・最小総コストを返してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `costs` | `number[]` | 各発電機の発電単価（万円/MW） |
| `capacities` | `number[]` | 各発電機の定格出力上限（MW） |
| `yields` | `number[][]` | 1 MW あたりの地域別需要寄与係数行列（`[region][generator]` 順） |
| `minRequirements` | `number[]` | 各地域の最低電力需要（MW） |
| `resourceUsages` | `number[][]` | 1 MW あたりの燃料・排出枠消費係数行列（`[cap][generator]` 順） |
| `maxResources` | `number[]` | 各燃料・排出枠の上限 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `quantities` | `number[]` | 各発電機の最適な発電量（MW） |
| `duals` | `number[]` | 潜在価格 $\partial z^* / \partial \text{rhs}$（`minRequirements` 次に `maxResources` の順） |
| `optimalCost` | `number` | 最小化された総発電コスト $z^*$（万円） |

<!-- section:example -->
**入力例**

```json
{
  "costs": [10, 14, 25],
  "capacities": [12, 20, 25],
  "yields": [
    [1, 2, 3],
    [2, 1, 2]
  ],
  "minRequirements": [30, 22],
  "resourceUsages": [
    [2, 1, 1]
  ],
  "maxResources": [20]
}
```

**出力例**

```json
{
  "quantities": [4, 10, 2],
  "duals": [6, 5, -3],
  "optimalCost": 230
}
```

発電量 [4, 10, 2] は最低需要 [30, 22] と上限枠 20 をすべて満たし、総コスト $10 \times 4 + 14 \times 10 + 25 \times 2 =$ **230** 万円を達成します。また潜在価格 [6, 5, -3] による双対評価値 $30(6) + 22(5) + 20(-3) = 230$ と一致します。


<!-- section:hint1 -->
各発電機に対して 0 以上・出力容量上限以下の連続変数を 1 つずつ宣言します。求解後に双対変数を参照できるよう、最低需要制約と燃料・排出枠の上限制約を追加する際に制約オブジェクトへの参照を保持しておきます。

<!-- section:hint2 -->
最小化 LP を解いた後、各需要制約に続けて各上限制約の順に WaSHI では `c.dual!`（PuLP では `c.pi`）を読み取ります。WaSHI と PuLP はいずれも右辺値に対する微分係数 $\partial z^* / \partial \text{rhs}$ の符号規則に従うため、$\ge$ 需要を引き上げると最小コストは下がり得ず双対値は $\ge 0$ になり、$\le$ 上限を緩めると最小コストは上がり得ず双対値は $\le 0$ になります（正のスラックを持つ制約の双対値は 0 です）。符号を反転させず、ソルバーが返す符号付きシャドウプライスをそのまま返してください。
