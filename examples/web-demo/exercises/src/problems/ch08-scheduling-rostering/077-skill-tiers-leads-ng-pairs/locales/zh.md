# #077. 含技能覆盖、资深带班与互斥组合约束的排班

<!-- section:scenario -->
某部门为 $N$ 名员工安排 $D$ 天内每天 $S$ 个班次的排班表，每人每天至多上一班。每个有效班次不仅要满足总人数需求，还必须包含至少一名资深带班人员，并达到 $K$ 项专业技能的最低配备人数。

此外，指定的互斥员工对不能被安排在同一天的同一班次。请在满足全部条件的前提下最小化总排班成本。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `demands` | `number[][]` | 第 $d$ 天班次 $s$ 的最低总人数需求（$D \times S$） |
| `isSenior` | `number[]` | 各员工是否为资深带班人员（`0`/`1`） |
| `staffSkills` | `number[][]` | $N \times K$ 的 `0`/`1` 矩阵，表示员工 $i$ 是否具备技能 $k$ |
| `skillDemands` | `number[][]` | 班次 $s$ 所需的技能 $k$ 最低人数（$S \times K$） |
| `ngPairs` | `number[][]` | 禁止在同一 `(d, s)` 班次共事的互斥对 `[a, b]` 列表 |
| `shiftCosts` | `number[][]` | 员工 $i$ 担任班次 $s$ 的成本（$N \times S$） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `schedule` | `number[][]` | $N \times D$ 矩阵，`-1`（休息）或 `0..S-1`（所排班次） |
| `totalCost` | `number` | 最小化的总排班成本 |

<!-- section:example -->
**输入示例**

```json
{
  "demands": [
    [2, 1],
    [2, 1]
  ],
  "isSenior": [1, 1, 0, 0],
  "staffSkills": [
    [1, 0],
    [0, 1],
    [1, 1],
    [0, 1]
  ],
  "skillDemands": [
    [1, 1],
    [1, 0]
  ],
  "ngPairs": [[0, 2], [1, 3]],
  "shiftCosts": [
    [15, 20],
    [16, 18],
    [10, 14],
    [11, 15]
  ]
}
```

**输出示例**

```json
{
  "schedule": [
    [1, 1],
    [0, 0],
    [0, 0],
    [-1, -1]
  ],
  "totalCost": 92
}
```

两天中班次 0 均避开互斥对 `[0, 2]` 并安排资深 1 与员工 2 搭档，班次 1 则安排掌握技能 0 的资深 0 单独值班，总成本为 $(20+20) + (16+16) + (10+10) =$ **92**。
