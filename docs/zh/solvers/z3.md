# Z3 SMT 求解器引擎

**Z3** 是微软研究院开发的定理证明器与 SMT 求解器。在 WaSHI 中，Z3 主要用于包含 `Continuous` 或小数变量的逻辑规则、精确算术判定以及 `unsatCore` 冲突诊断。

---

## 安装

Z3 是可选的 peer dependency：

```bash
npm install z3-solver
```

---

## 何时选择 Z3、HiGHS 或 Pumpkin

| 目标 | 推荐求解器 | 原因 |
| :--- | :--- | :--- |
| **含 `Continuous` / 小数的逻辑规则** | **Z3** (`m.check({ solver: "z3" })`) | 可在 `implies`、`not`、`and`、`or` 中使用实数不等式。 |
| **含 `Continuous` 变量的冲突诊断 (`unsatCore`)** | **Z3** (`m.check({ solver: "z3" })`) | 提取不受数值尺度影响的 `unsatCore`。 |
| **有界整数/布尔模型且不希望配置 `COOP`/`COEP`** | **Pumpkin** (`@ohtaman/washi/solvers/pumpkin`) | 内置零依赖，无需 `SharedArrayBuffer` 响应头。 |
| **LP / MIP / QP 数值优化** | **HiGHS** (`m.solve()`) | 求解带目标函数的优化问题速度快得多。 |

> [!TIP]
> 常见做法是先用 `Z3`（`m.check()`）验证规则和排查冲突，再用 `HiGHS`（`m.solve()`）做成本优化。

---

## 基本用法

```typescript
import { Model, expr } from "@ohtaman/washi";
import "@ohtaman/washi/solvers/z3";

const model = new Model({ solver: "z3" });

const x = model.integer("x", { lb: 0, ub: 10 });
const y = model.integer("y", { lb: 0, ub: 10 });

model.constraint(expr`${x} + ${y} == 15`, "sum_15");
model.constraint(expr`${x} >= 8`, "x_at_least_8");

await model.solve();
console.log(`Status: ${model.status}, x = ${x.value}, y = ${y.value}`);
```

---

## 冲突诊断 (`model.check()`)

调用 `await model.check()` 可检查约束是否可满足；当不可满足（`"Unsat"`）时，返回冲突的命名约束集合（`conflicts` / `unsatCore`）：

```typescript
import { Model, expr } from "@ohtaman/washi";
import "@ohtaman/washi/solvers/z3";

const model = new Model({ solver: "z3" });
const a = model.continuous("a");

model.constraint(expr`${a} >= 10`, "req_A");
model.constraint(expr`${a} <= 5`, "req_B");

const result = await model.check();

if (result.status === "Unsat") {
  console.log("冲突约束:", result.conflicts); // 也可通过 model.conflicts / model.unsatCore 读取
  // ["req_A", "req_B"]
}
```

## 浏览器要求与线程清理

在浏览器中，Z3 依赖 `SharedArrayBuffer` 和 pthreads，因此服务器必须返回 `COOP` / `COEP` 响应头（详见 [Cross-Origin Isolation 配置](../getting-started/cross-origin.md)）。如果无法配置这些响应头且模型仅使用有界整数和布尔值，请改用 [Pumpkin](./pumpkin.md)。

如果 Z3 Worker 遇到致命运行时错误，当前 Promise 会被 reject 并丢弃损坏的实例，下次调用 `solve()` 或 `check()` 时会自动重新初始化。如需在卸载页面时显式关闭 Z3 线程，请调用：

```typescript
import { killZ3Threads } from "@ohtaman/washi/solvers/z3";

await killZ3Threads();
```
