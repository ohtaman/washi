# #012. 固定費つき輸送ネットワーク設計

<!-- section:scenario -->
物流会社が複数の倉庫から複数の店舗へ商品を配送するために、候補となる輸送ルートの中から利用するものを設計します。各ルートを使うには最初に契約固定費を支払ってルートを開設する必要があり、開設したルートではその容量上限まで連続量で輸送できます。逆に、開設しないルートの輸送量はゼロでなければなりません。

各倉庫の供給上限と各店舗の必要需要を満たしつつ、すべての開設ルートにかかる固定費と輸送量に比例する変動費の合計を**最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `supplies` | `number[]` | 各倉庫 $i$ の供給在庫上限 |
| `demands` | `number[]` | 各店舗 $j$ の必要需要量 |
| `fixedCosts` | `number[][]` | ルート $(i, j)$ を開設する固定費 |
| `unitCosts` | `number[][]` | ルート $(i, j)$ の 1 単位あたりの輸送費 |
| `capacities` | `number[][]` | ルート $(i, j)$ 開設時の最大輸送容量 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `open` | `number[][]` | 各ルートを開設するかどうかの `0`/`1` 行列 |
| `shipments` | `number[][]` | 各ルート $(i, j)$ の非負連続輸送量 |
| `totalCost` | `number` | 最小化された固定費＋輸送費の合計 |

<!-- section:example -->
**入力例**

```json
{
  "supplies": [65, 60],
  "demands": [30, 35, 25],
  "fixedCosts": [
    [120, 40, 260],
    [250, 280, 90]
  ],
  "unitCosts": [
    [4, 5, 8],
    [3, 2, 3]
  ],
  "capacities": [
    [40, 40, 30],
    [35, 45, 40]
  ]
}
```

**出力例**

```json
{
  "open": [
    [1, 1, 0],
    [0, 0, 1]
  ],
  "shipments": [
    [30, 35, 0],
    [0, 0, 25]
  ],
  "totalCost": 620
}
```

ルート `(0, 0)`・`(0, 1)`・`(1, 2)` を開設すると、容量上限・倉庫供給上限（`65 <= 65`, `25 <= 60`）・店舗需要 `[30, 35, 25]` をすべて満たし、総コストは $(120 + 40 + 90) + (30 \times 4 + 35 \times 5 + 25 \times 3) =$ **620** となります。
