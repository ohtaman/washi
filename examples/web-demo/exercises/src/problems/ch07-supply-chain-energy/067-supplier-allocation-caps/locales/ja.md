# #067. 発注シェア上限と取引量上下限つきサプライヤー配分

<!-- section:scenario -->
複数の工場を運営する製造業者が、候補サプライヤー群からの原材料調達を計画します。サプライヤーを採用すると固定契約費が発生し、半連続発注制約（不採用なら発注量ゼロ、採用時は全工場向け合計発注量が規定の最小発注量以上・最大供給能力以下）が課されます。

さらに供給途絶リスクを避けるため、各工場の需要に対する単一サプライヤーからの調達比率を一定割合以下に抑えるシェア上限と、採用社数の下限・上限も守らなければなりません。全工場の需要を満たしつつ、**固定契約費と調達・輸送費の合計を最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `demands` | `number[]` | 工場 $p$ の需要量 $D_p$ |
| `unitCosts` | `number[][]` | サプライヤー $s \to$ 工場 $p$ の単位調達費 $c_{s,p}$ |
| `fixedCosts` | `number[]` | サプライヤー $s$ を採用する際の固定契約費 $F_s$ |
| `minOrders` | `number[]` | サプライヤー $s$ 採用時の最小合計発注量 $L_s$ |
| `maxOrders` | `number[]` | サプライヤー $s$ 採用時の最大供給能力 $U_s$ |
| `maxShare` | `number` | 各工場で 1 社から調達できる需要比率の上限 $\alpha$ |
| `minSuppliers` | `number` | 採用サプライヤー社数の下限 |
| `maxSuppliers` | `number` | 採用サプライヤー社数の上限 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `active` | `number[]` | 各サプライヤーの採用有無（`0` または `1`） |
| `allocations` | `number[][]` | 各サプライヤーから各工場への発注量（$S \times P$） |
| `totalCost` | `number` | 最小化された総コスト（固定費＋調達費） |

<!-- section:example -->
**入力例**

```json
{
  "demands": [100, 80, 120],
  "unitCosts": [
    [12, 15, 18],
    [14, 11, 16],
    [16, 14, 12],
    [13, 13, 14]
  ],
  "fixedCosts": [300, 260, 320, 280],
  "minOrders": [60, 50, 70, 50],
  "maxOrders": [160, 140, 170, 130],
  "maxShare": 0.6,
  "minSuppliers": 2,
  "maxSuppliers": 3
}
```

**出力例**

```json
{
  "active": [0, 0, 1, 1],
  "allocations": [
    [0, 0, 0],
    [0, 0, 0],
    [50, 48, 72],
    [50, 32, 48]
  ],
  "totalCost": 4674
}
```

サプライヤー 2・3 の 2 社を採用すると、各工場の 60% 上限（`[60, 48, 72]`）と各社の発注範囲（`170 in [70, 170]`, `130 in [50, 130]`）を満たし、総コストは $(320 + 280) + 4074 =$ **4,674** となります。
