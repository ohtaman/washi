# #024. 線形分数計画の比率最大化（Charnes-Cooper 変換）

<!-- section:scenario -->
精密部品工場の生産計画担当者は、複数の精密部品の生産量（個、非負）を、原材料や加工時間などの共有資源容量および各部品の生産上限のもとで決定します。今回は利益額そのものではなく、固定収入を含む「総純リターン（万円）」と基本維持費を含む「総投入コスト（万円）」の比率である**投資効率比を最大化**したいと考えています。

分母の逆数で全体をスケールして線形化する Charnes-Cooper 変換の考え方を用い、すべての資源制約と生産上限を満たしながら**効率比を最大化**する生産量と最大比率を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `numCoeffs` | `number[]` | 分子の部品 1 個あたり純リターン係数ベクトル $c$（万円/個） |
| `numConst` | `number` | 分子の固定収入項 $c_0$（万円） |
| `denCoeffs` | `number[]` | 分母の部品 1 個あたり投入コスト係数ベクトル $d$（万円/個、非負） |
| `denConst` | `number` | 分母の正の基本維持費 $d_0 > 0$（万円） |
| `usages` | `number[][]` | 部品 1 個あたりの資源消費行列 $A$ |
| `capacities` | `number[]` | 共有資源の容量上限ベクトル $b$ |
| `upperBounds` | `number[]` | 各部品の生産上限 $u$（個） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `x` | `number[]` | 元の尺度での部品生産量ベクトル（個） |
| `maxRatio` | `number` | 最大化された効率比 $(c^\top x + c_0) / (d^\top x + d_0)$ |

<!-- section:example -->
**入力例**

```json
{
  "numCoeffs": [12, 9],
  "numConst": 10,
  "denCoeffs": [4, 2],
  "denConst": 8,
  "usages": [
    [1, 1]
  ],
  "capacities": [8],
  "upperBounds": [5, 6]
}
```

**出力例**

```json
{
  "x": [0, 6],
  "maxRatio": 3.2
}
```

`x` が [0, 6] のとき、資源消費 $0 + 6 \le 8$ および個別上限 [5, 6] を満たし、分子 $9 \times 6 + 10 = 64$、分母 $2 \times 6 + 8 = 20$ から効率比は $64 / 20 =$ **3.2** となります。


<!-- section:hint1 -->
元の生産量変数で直接解く代わりに Charnes-Cooper 変換を適用します。分母の逆数を表す非負のスカラー同次化変数と、そのスカラーを元の生産量変数に掛けた非負のスケール済み変数群を導入します。

<!-- section:hint2 -->
陥りやすい点は、各部品の元の生産上限を同次化し忘れることです。スケール後のモデルでは、資源制約だけでなく各部品の生産上限にも分母スカラー変数を掛けて比例させる必要があり、元の定数上限のままにしてはなりません。分母の定数項によりスカラー変数が正にとどまるため、最適解では割り算によって元の生産量を復元できます。
