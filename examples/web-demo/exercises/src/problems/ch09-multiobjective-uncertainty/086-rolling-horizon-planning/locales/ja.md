# #086. ローリングホライズン計画（モデル予測制御 MPC）

<!-- section:scenario -->
ある工場では、モデル予測制御（MPC）を用いて多期間の生産・在庫運用を行います。各期の開始時点で、現在の実在庫水準を確認し、直近の予測ウィンドウ内の予測需要に基づく先読み線形計画問題を解きます。各期には生産能力上限、期末在庫の保管費、欠品ペナルティが設定されています。

ただし、各ステップで確定・実行するのは当期の生産量のみです。その後、当期の実需が確定して実際の期末在庫と欠品量が更新され、ウィンドウを 1 期先へずらして次の計画へ進みます。実行された各期の生産量・実在庫・実欠品量と累積実績コストの合計を返してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `actualDemands` | `number[]` | 生産決定後に観測される各期の実需要 |
| `forecastDemands` | `number[]` | 先読み計画内で参照する各期の予測需要 |
| `prodCosts` | `number[]` | 各期 $t$ の生産単価 |
| `prodCap` | `number` | 1 期あたりの最大生産能力 |
| `holdCost` | `number` | 期末在庫 1 単位あたりの保管コスト |
| `shortfallPenalty` | `number` | 未充足需要 1 単位あたりの欠品ペナルティ |
| `initialInventory` | `number` | 第 0 期開始前の初期在庫 |
| `windowLen` | `number` | 各ステップで参照する先読みウィンドウ長 $H$ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `produced` | `number[]` | 各期 $t$ で確定した生産量 |
| `inventories` | `number[]` | 各期 $t$ の実需適用後の期末在庫 |
| `shortfalls` | `number[]` | 各期 $t$ の実需に対する欠品量 |
| `totalCost` | `number` | 累積された実績生産費・保管費・欠品ペナルティの総和 |

<!-- section:example -->
**入力例**

```json
{
  "actualDemands": [10, 10, 30, 10],
  "forecastDemands": [10, 10, 30, 10],
  "prodCosts": [9, 13, 25, 11],
  "prodCap": 20,
  "holdCost": 2,
  "shortfallPenalty": 100,
  "initialInventory": 0,
  "windowLen": 2
}
```

**出力例**

```json
{
  "produced": [20, 20, 10, 10],
  "inventories": [10, 20, 0, 0],
  "shortfalls": [0, 0, 0, 0],
  "totalCost": 860
}
```

ウィンドウ長 `windowLen = 2` で各期を順次実行すると生産量 `[20, 20, 10, 10]`・在庫 `[10, 20, 0, 0]`・欠品ゼロとなり、実績総コストは $(20 \times 9 + 20 \times 13 + 10 \times 25 + 10 \times 11) + 2 \times (10 + 20) =$ **860** となります。


<!-- section:hint1 -->
実現在庫を次の期へ繰り越しながら、計画期間を 1 期ずつ順にシミュレーションします。各期では、有界な先読みウィンドウ内の各期に対する生産量・期末在庫・不足量の決定変数を持つ新しい LP を構築して解きます。

<!-- section:hint2 -->
各ステップの先読み LP では（計画期間末尾で打ち切った）`forecastDemands` のみを使い、`actualDemands` を先読みしてはなりません。LP の解からは先頭期の生産量だけを確定採用し、その期の真の期末在庫・不足量・実現コストは `actualDemands[t]` を使って更新・集計してください。
