# #010. 产线启停与混合生产计划

<!-- section:scenario -->
某瓶装饮料灌装工厂需要同时决定开启哪些候选产线，以及在已开启的产线上生产多少饮料（千瓶）。开启某条产线会产生固定的开机准备费，并允许在该产线最大产能以内进行连续生产；反之，**未开启的产线无法进行任何生产**。

各产线每生产 1 千瓶都能获得固定的毛利润，同时会消耗全厂共享的树脂颗粒（kg）库存。请在不超过树脂颗粒库存上限的前提下，最大化总毛利减去总固定成本后的**净利润**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `margins` | `number[]` | 各产线每千瓶的毛利润 |
| `fixedCosts` | `number[]` | 开启各产线时产生的固定成本 |
| `capacities` | `number[]` | 各产线的最大产能上限（千瓶） |
| `materialUsages` | `number[]` | 各产线每千瓶消耗的树脂颗粒量（kg） |
| `materialCap` | `number` | 全厂共享的树脂颗粒库存上限（kg） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `open` | `number[]` | 各产线的开启选择（0 或 1） |
| `quantities` | `number[]` | 各产线的生产量（千瓶，连续值） |
| `netProfit` | `number` | 最大化后的净利润（总毛利减去固定成本之和） |

<!-- section:example -->
**输入示例**

```json
{
  "margins": [50, 40, 35],
  "fixedCosts": [600, 300, 250],
  "capacities": [30, 40, 25],
  "materialUsages": [2, 1.5, 1],
  "materialCap": 70
}
```

**输出示例**

```json
{
  "open": [0, 1, 1],
  "quantities": [0, 30, 25],
  "netProfit": 1525
}
```

开启产线 1、2 并配置产量 `quantities = [0, 30, 25]` 满足启停与产能上限，原材料消耗为 $30 \times 1.5 + 25 \times 1 = 70 \le 70$，净利润为 $(40 \times 30 + 35 \times 25) - (300 + 250) =$ **1,525**。
