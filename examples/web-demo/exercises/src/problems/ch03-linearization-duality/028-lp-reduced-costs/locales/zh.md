# #028. LP 检验数（Reduced Cost）与入基门槛

<!-- section:scenario -->
化工厂的生产计划负责人正在制定成本最小化的混合生产计划，需要组合多种化学工艺并决定各工艺的运行量（t，非负连续量），以满足最低生产要求。在当前单价下，部分工艺在经济上不划算，因而在最优计划中运行量为 0。

现场团队希望了解：“对于每个未使用的工艺，若强行让其运行 1 t，最小成本会增加多少（或者单价需降低多少才能被采用）？”请将问题建模为最小化 LP，并返回各工艺的运行量、检验数（reduced cost）以及最小总成本。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `costs` | `number[]` | 工艺 $j$ 的单位成本 $c_j$ |
| `yields` | `number[][]` | 产出矩阵 $A$，$A_{kj}$ 为单位工艺 $j$ 对指标 $k$ 的贡献 |
| `minRequirements` | `number[]` | 最低指标要求 $r_k$（$\sum_j A_{kj} x_j \ge r_k$） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `quantities` | `number[]` | 各工艺的非负投入量 $x_j$ |
| `reducedCosts` | `number[]` | 各变量 $x_j$ 的检验数 $\bar{c}_j$ |
| `optimalCost` | `number` | 最小化后的总成本 $z^*$ |

<!-- section:example -->
**输入示例**

```json
{
  "costs": [10, 14, 24, 30],
  "yields": [
    [1, 2, 2, 3],
    [2, 1, 3, 1]
  ],
  "minRequirements": [17, 16]
}
```

**输出示例**

```json
{
  "quantities": [5, 6, 0, 0],
  "reducedCosts": [0, 0, 6, 10],
  "optimalCost": 134
}
```

运行量 [5, 6, 0, 0] 恰好满足要求 [17, 16] 且成本为 $10 \times 5 + 14 \times 6 =$ **134**，由对偶解 [6, 2] 可求得两个未选用工艺的检验数分别为 $24 - (6 \times 2 + 2 \times 3) = 6$ 与 $30 - (6 \times 3 + 2 \times 1) = 10$。


<!-- section:hint1 -->
为每个工艺引入一个非负连续决策变量，表示该工艺的运行水平。

<!-- section:hint2 -->
求解 LP 后，通过 WaSHI 的 `v.reducedCost!`（或 PuLP 的 `v.dj`）读取各变量的检验数。不要直接使用原始单价或手动取反：在带非负变量的最小化 LP 中，基变量（$x_j > 0$）的检验数为 0，而未启用变量的检验数为非负值，表示该变量进入基所需降低的成本幅度。请直接返回求解器的精确结果，不要人为舍入。
