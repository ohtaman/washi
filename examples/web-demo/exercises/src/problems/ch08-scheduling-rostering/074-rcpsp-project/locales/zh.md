# #074. 资源受限项目调度问题 (RCPSP)

<!-- section:scenario -->
一个项目包含若干不可抢占的整数工期任务，任务之间通过有向无环紧前关系相连。任务在执行期间会持续占用 1 至 2 种共享可再生资源。

任一时刻每种资源的总占用量都不能超过其容量上限。请为所有任务安排非负整数开工时间，使项目的最大完工时间最小。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `durations` | `number[]` | 各任务 $i$ 的整数工期 $d_i$ |
| `demands` | `number[][]` | 任务 $i$ 对资源 $r$ 的占用需求 $q_{r,i}$ |
| `capacities` | `number[]` | 各可再生资源 $r$ 的容量上限 $C_r$ |
| `precedences` | `number[][]` | 紧前边列表 `[u, v]`，要求 $S_u + d_u \le S_v$ |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `starts` | `number[]` | 各任务的整数开工时间 $S_i \ge 0$ |
| `makespan` | `number` | 最小化的项目总工期 $\max_i (S_i + d_i)$ |

<!-- section:example -->
**输入示例**

```json
{
  "durations": [3, 3, 4, 2, 2],
  "demands": [
    [2, 2, 2, 1, 2]
  ],
  "capacities": [3],
  "precedences": [[0, 1], [0, 3], [1, 4], [2, 4], [3, 4]]
}
```

**输出示例**

```json
{
  "starts": [0, 7, 3, 5, 10],
  "makespan": 12
}
```

各任务按 `T0: [0,3)`、`T2: [3,7)`、`T3: [5,7)`（并发资源需求 $2 + 1 = 3 \le 3$）、`T1: [7,10)`、`T4: [10,12)` 执行时满足全部紧前关系与资源容量限制，总工期为 **12**。
