# #067. 带份额上限与起订量约束的供应商分配

<!-- section:scenario -->
某多工厂制造企业需要向一批候选供应商采购原材料。若启用某家供应商，需支付固定合同管理费并遵守半连续订购量约束：未启用时总供应量为零；启用后向全部工厂供货的总量必须介于最小起订量与最大产能之间。

为分散断供风险，任何一家供应商在任一工厂所占的供货份额均不能超过给定比例上限，同时启用的供应商总数也必须处于指定区间内。请在满足各工厂需求的前提下 **最小化固定合同费与采购运输成本之和**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `demands` | `number[]` | 工厂 $p$ 的需求量 $D_p$ |
| `unitCosts` | `number[][]` | 供应商 $s$ 发往工厂 $p$ 的单位采购成本 $c_{s,p}$ |
| `fixedCosts` | `number[]` | 启用供应商 $s$ 的固定合同费用 $F_s$ |
| `minOrders` | `number[]` | 供应商 $s$ 启用时的最小总订购量 $L_s$ |
| `maxOrders` | `number[]` | 供应商 $s$ 启用时的最大总供应上限 $U_s$ |
| `maxShare` | `number` | 单个供应商占任一工厂需求的最大比例 $\alpha \in (0, 1]$ |
| `minSuppliers` | `number` | 允许启用的最少供应商数量 |
| `maxSuppliers` | `number` | 允许启用的最多供应商数量 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `active` | `number[]` | 供应商启用决策（`0` 或 `1`） |
| `allocations` | `number[][]` | 供应商至工厂的采购分配量矩阵（$S \times P$） |
| `totalCost` | `number` | 最小化后的固定与采购总成本 |

<!-- section:example -->
**输入示例**

```json
{
  "demands": [100, 80, 120],
  "unitCosts": [
    [12, 15, 18],
    [14, 11, 16],
    [16, 14, 12],
    [13, 13, 14]
  ],
  "fixedCosts": [300, 260, 320, 280],
  "minOrders": [60, 50, 70, 50],
  "maxOrders": [160, 140, 170, 130],
  "maxShare": 0.6,
  "minSuppliers": 2,
  "maxSuppliers": 3
}
```

**输出示例**

```json
{
  "active": [0, 0, 1, 1],
  "allocations": [
    [0, 0, 0],
    [0, 0, 0],
    [50, 48, 72],
    [50, 32, 48]
  ],
  "totalCost": 4674
}
```

启用供应商 2 和 3（共 2 家，位于 `[2, 3]`），满足各厂 60% 配额上限（`[60, 48, 72]`）及最小/最大总单量限制（`170 in [70, 170]`、`130 in [50, 130]`），总成本为 $(320 + 280) + 4074 =$ **4,674**。


<!-- section:hint1 -->
为每个供应商定义二元启用变量，并定义表示从各供应商到各工厂采购量的连续 $S \times P$ 矩阵。模型同时刻画供应商层面的半连续订货量规则与工厂层面的供应分散限制。

<!-- section:hint2 -->
单一供应商的份额上限可以直接作为每个分配变量 $q_{s,p}$ 的变量上界 `maxShare * demands[p]` 来设置。将每个供应商对所有工厂的总订货量与其二元变量 `active[s]` 关联，同时施加下界（`minOrders[s] * active[s]`）和上界（`maxOrders[s] * active[s]`），并约束 `active` 之和介于 `minSuppliers` 与 `maxSuppliers` 之间。
