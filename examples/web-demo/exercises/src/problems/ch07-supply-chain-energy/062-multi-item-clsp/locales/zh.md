# #062. 多品目带产能约束批量计划 (CLSP)

<!-- section:scenario -->
某工厂使用同一台共享机器在多个周期内生产多种产品（各品目的期初库存均为零）。只要在某一期生产某种产品，就必须为该产品进行开机换产，产生固定开机成本并占用固定换产工时。

在每个周期，所有产品消耗的总加工工时与换产工时之和不能超过该期的机器可用总工时。请决策各期各品目的开机开关、连续生产量及期末库存量，在满足全部需求的前提下 **最小化总开机成本与库存持有成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `demands` | `number[][]` | 品目 $i$ 在周期 $t$ 的需求量 $d_{i,t}$ |
| `setupCosts` | `number[]` | 品目 $i$ 每次开机的固定成本 $F_i$ |
| `holdCosts` | `number[]` | 品目 $i$ 每单位每期的库存持有成本 $h_i$ |
| `unitTimes` | `number[]` | 品目 $i$ 单位产量的机台加工工时 $a_i$ |
| `setupTimes` | `number[]` | 品目 $i$ 开机一次占用的换产工时 $s_i$ |
| `capacities` | `number[]` | 周期 $t$ 的机台可用总工时上限 $H_t$ |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `setups` | `number[][]` | $I \times T$ 的 `0`/`1` 开机矩阵 |
| `production` | `number[][]` | $I \times T$ 的非负生产量矩阵 |
| `inventory` | `number[][]` | $I \times T$ 的非负期末库存矩阵 |
| `totalCost` | `number` | 最小化后的总开机与持有成本 |

<!-- section:example -->
**输入示例**

```json
{
  "demands": [
    [20, 30, 15, 25],
    [10, 25, 30, 15]
  ],
  "setupCosts": [120, 150],
  "holdCosts": [2, 2.5],
  "unitTimes": [1.5, 2.0],
  "setupTimes": [12, 15],
  "capacities": [110, 100, 115, 100]
}
```

**输出示例**

```json
{
  "setups": [
    [1, 1, 1, 1],
    [1, 1, 1, 1]
  ],
  "production": [
    [20, 30, 15, 25],
    [21, 14, 30, 15]
  ],
  "inventory": [
    [0, 0, 0, 0],
    [11, 0, 0, 0]
  ],
  "totalCost": 1107.5
}
```

在第 0 期提前多生产 11 件品目 1，使第 1 期机台负荷恰好为 $12 + 15 + 1.5(30) + 2.0(14) = 100 \le 100$，总成本为 $4(120 + 150) + 11 \times 2.5 =$ **1,107.5**。
