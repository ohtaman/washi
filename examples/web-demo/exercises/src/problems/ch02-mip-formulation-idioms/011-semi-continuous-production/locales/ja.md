# #011. 半連続変数による最小ロット醸造計画

<!-- section:scenario -->
あるクラフトビール醸造所では、共通のモルト（kg）を分け合いながら複数の候補銘柄（IPA、ペールエール、スタウトなど）を連続量（リットル）で醸造します。各銘柄は仕込みを見送って生産量をゼロにするか、あるいは仕込んで最小バッチ量以上かつ最大タンク容量以下の範囲で生産するかのいずれかを選ばなければなりません。

各銘柄は 1 リットルあたりの粗利益とモルト消費量が決まっています。共通モルトの在庫上限を超えないように仕込む銘柄と醸造量を決め、**総粗利益を最大化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `margins` | `number[]` | 各銘柄 1 リットルあたりの粗利益 |
| `minBatches` | `number[]` | 各銘柄を仕込むときの最小バッチ量（リットル） |
| `maxBatches` | `number[]` | 各銘柄の最大タンク容量（リットル） |
| `resourceUsages` | `number[]` | 各銘柄 1 リットルあたりのモルト消費量（kg） |
| `resourceCap` | `number` | 共通モルトの総在庫上限（kg） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `active` | `number[]` | 各銘柄を仕込むかどうかの選択（0 または 1） |
| `quantities` | `number[]` | 各銘柄の醸造量（リットル）：0 または区間 `[minBatches[i], maxBatches[i]]` |
| `totalMargin` | `number` | 最大化された総粗利益 |

<!-- section:example -->
**入力例**

```json
{
  "margins": [30, 24, 18],
  "minBatches": [8, 15, 5],
  "maxBatches": [20, 30, 15],
  "resourceUsages": [1, 1, 1],
  "resourceCap": 30
}
```

**出力例**

```json
{
  "active": [1, 1, 0],
  "quantities": [15, 15, 0],
  "totalMargin": 810
}
```

銘柄 0・1 を仕込んで `quantities = [15, 15, 0]` とすると、それぞれ `[8, 20]` と `[15, 30]` の醸造範囲（銘柄 2 は 0）とモルト上限 $15 + 15 = 30 \le 30$ を満たし、総粗利益は $30 \times 15 + 24 \times 15 =$ **810** となります。

<!-- section:hint1 -->
各銘柄には仕込みを表すバイナリ変数と連続量の醸造量変数があります。仕込まない銘柄は醸造量ゼロ、仕込む銘柄は決められたバッチ範囲内に収まるよう各ペアを連結し、あわせて共通モルトの上限を課します。

<!-- section:hint2 -->
醸造量変数をバイナリ変数で上下両側から挟み込みます。`minBatches[i]` と `maxBatches[i]` にそれぞれ `active[i]` を掛けると、非稼働時（0）は醸造量も 0 に固定され、稼働時（1）のみ `[minBatches[i], maxBatches[i]]` の範囲が有効になります。あわせて共通モルトの上限と総粗利益の最大化を設定してください。
