# #034. 後継ノード変数と順位配列による巡回セールスマン問題

<!-- section:scenario -->
配送車がデポ 0 を出発し、顧客拠点 1 から n - 1 まですべてをちょうど 1 回ずつ訪問してデポ 0 へ戻る単一の巡回路を求めます。distances[i][j] は拠点 i から拠点 j へ直接移動する際の整数距離を表します。

各拠点 i の直後に訪れる後継拠点 next[i] を決定し、切り離された部分巡回路（サブツアー）を作らず全拠点を 1 本の閉路で巡る中で、総移動距離を最小化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `distances` | `number[][]` | `n × n` の整数距離行列（`distances[i][j]` は拠点 `i` から `j` への移動距離） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `next` | `number[]` | 拠点 `i` の直後に訪問する後継拠点番号（`0` 〜 `n - 1`） |
| `totalDistance` | `number` | 最小化された総巡回距離 `sum(distances[i][next[i]])` |

<!-- section:example -->
**入力例**

```json
{
  "distances": [
    [0, 2, 7, 9],
    [2, 0, 4, 8],
    [7, 4, 0, 2],
    [6, 8, 2, 0]
  ]
}
```

**出力例**

```json
{
  "next": [1, 2, 3, 0],
  "totalDistance": 14
}
```

`next = [1, 2, 3, 0]` を辿ると全頂点を通る単一閉路 `0 -> 1 -> 2 -> 3 -> 0` となり、総距離は $2 + 4 + 2 + 6 =$ **14** です。

<!-- section:hint1 -->
各頂点に対して `[0, n - 1]` の範囲で自己ループのない互いに異なる後続頂点変数を 1 つずつ定義します。非連結な部分巡回（サブツアー）を防ぐために、デポ 0 を起点とする訪問順序（ランク）の補助整数変数を各頂点に導入します。

<!-- section:hint2 -->
`distinct(next)` と `distinct(rank)` に加え、`rank[0] == 0` および `at(rank, next[0]) == 1` を課します。各顧客頂点 $i \ge 1$ には `implies(expr\`${next[i]} != 0\`, expr\`at(${rank}, ${next[i]}) == ${rank[i]} + 1\`)` で訪問順序を連結し、`sum(input.distances.map((row, i) => at(row, next[i])))` を最小化して `solver: "pumpkin"` で解いてください。
