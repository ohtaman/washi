# #057. 時間枠制約付き配送計画問題 (VRPTW)

<!-- section:scenario -->
最大 K 台の車両が時刻 earliest[0] にデポ 0 を出発し、すべての顧客を 1 回ずつ訪問してデポ 0 へ時刻 latest[0] までに戻ります。各顧客には受付時間枠 [earliest[i], latest[i]] と作業時間 service[i] があり、早く着いた場合は earliest[i] まで待機できますが、latest[i] より遅く到着することは禁止されます。

Big-M を用いた到達時刻の伝播制約により時間枠と部分巡回路排除を同時に表現し、**総移動コストを最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `dist` | `number[][]` | $(n+1) \times (n+1)$ の移動時間兼移動コスト行列（`0` がデポ） |
| `earliest` | `number[]` | 各頂点の最早サービス開始時刻（`earliest[0] = 0`） |
| `latest` | `number[]` | 各顧客の最遅開始時刻（`latest[0]` はデポへの帰着期限） |
| `service` | `number[]` | 各頂点での作業時間（`service[0] = 0`） |
| `maxVehicles` | `number` | デポ `0` から出発できる最大車両台数 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `routes` | `number[][]` | 各車両の配送ルート配列（`[0, ..., 0]`） |
| `totalCost` | `number` | 最小化された全ルート総移動コスト |

<!-- section:example -->
**入力例**

```json
{
  "dist": [
    [0, 3, 6, 5, 4],
    [3, 0, 4, 4, 6],
    [6, 4, 0, 4, 8],
    [5, 4, 4, 0, 5],
    [4, 6, 8, 5, 0]
  ],
  "earliest": [0, 10, 4, 2, 12],
  "latest": [40, 16, 12, 8, 22],
  "service": [0, 2, 2, 3, 2],
  "maxVehicles": 2
}
```

**出力例**

```json
{
  "routes": [
    [0, 1, 0],
    [0, 3, 2, 4, 0]
  ],
  "totalCost": 27
}
```

ルート `[0, 1, 0]` は顧客 1 で `t = 10` まで待機して距離 6、ルート `[0, 3, 2, 4, 0]` は `t = [5, 12, 22]` に作業を開始して時刻 `28 <= 40` にデポへ帰着し（距離 21）、総移動コストは $6 + 21 =$ **27** となります。
