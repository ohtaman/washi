# #011. 半連続変数による最小ロット生産計画

<!-- section:scenario -->
ある工場では、共通の原材料を分け合いながら複数の候補製品を連続量で生産します。各製品は完全に生産停止して生産量をゼロにするか、あるいは稼働させて所定の最小ロット以上かつ最大能力以下の範囲で生産するかのいずれかを選ばなければなりません。

各製品は 1 単位あたりの粗利益と原材料消費量が決まっています。共通原材料の上限を超えないように稼働する製品と生産量を決め、**総粗利益を最大化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `margins` | `number[]` | 各製品の 1 単位あたりの粗利益 |
| `minBatches` | `number[]` | 各製品を稼働させたときの最小生産ロット |
| `maxBatches` | `number[]` | 各製品を稼働させたときの最大生産能力 |
| `resourceUsages` | `number[]` | 各製品 1 単位あたりの共有資源消費量 |
| `resourceCap` | `number` | 共有資源の総利用上限 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `active` | `number[]` | 各製品の稼働有無（`0` または `1`） |
| `quantities` | `number[]` | 各製品の生産量（`0` または区間 `[minBatches[i], maxBatches[i]]`） |
| `totalMargin` | `number` | 最大化された総粗利益 |

<!-- section:example -->
**入力例**

```json
{
  "margins": [30, 24, 18],
  "minBatches": [8, 15, 5],
  "maxBatches": [20, 30, 15],
  "resourceUsages": [1, 1, 1],
  "resourceCap": 30
}
```

**出力例**

```json
{
  "active": [1, 1, 0],
  "quantities": [15, 15, 0],
  "totalMargin": 810
}
```

製品 0・1 を稼働させて `quantities = [15, 15, 0]` とすると、それぞれ `[8, 20]` と `[15, 30]` の稼働範囲（製品 2 は 0）と資源上限 $15 + 15 = 30 \le 30$ を満たし、総粗利益は $30 \times 15 + 24 \times 15 =$ **810** となります。
