# #012. 固定成本运输网络设计

<!-- section:scenario -->
某物流公司需要规划从多个仓库向多个零售门店调拨货物的运输网络。使用任意一条候选运输线路前，必须先支付一笔一次性线路开通固定成本，此后该线路即可在线路容量上限内承运连续货量；未开通线路的运量必须为零。

在满足各仓库供应上限及各门店最低需求的前提下，同时决策开通哪些线路以及各线路的运输量，以**最小化固定开通成本与运输成本之和**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `supplies` | `number[]` | 各仓库 $i$ 的可用供应上限 |
| `demands` | `number[]` | 各门店 $j$ 的最低需求量 |
| `fixedCosts` | `number[][]` | 开通线路 $(i, j)$ 的固定成本 |
| `unitCosts` | `number[][]` | 线路 $(i, j)$ 运输单位货物的运费 |
| `capacities` | `number[][]` | 线路 $(i, j)$ 开通后的最大运输容量 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `open` | `number[][]` | 各线路是否开通的 `0`/`1` 矩阵 |
| `shipments` | `number[][]` | 各线路 $(i, j)$ 上的非负连续运量 |
| `totalCost` | `number` | 最小化后的固定成本与运费总额 |

<!-- section:example -->
**输入示例**

```json
{
  "supplies": [65, 60],
  "demands": [30, 35, 25],
  "fixedCosts": [
    [120, 40, 260],
    [250, 280, 90]
  ],
  "unitCosts": [
    [4, 5, 8],
    [3, 2, 3]
  ],
  "capacities": [
    [40, 40, 30],
    [35, 45, 40]
  ]
}
```

**输出示例**

```json
{
  "open": [
    [1, 1, 0],
    [0, 0, 1]
  ],
  "shipments": [
    [30, 35, 0],
    [0, 0, 25]
  ],
  "totalCost": 620
}
```

开通线路 `(0, 0)`、`(0, 1)` 与 `(1, 2)` 满足线路容量、仓库供应上限（`65 <= 65`，`25 <= 60`）以及门店需求 `[30, 35, 25]`，总成本为 $(120 + 40 + 90) + (30 \times 4 + 35 \times 5 + 25 \times 3) =$ **620**。
