# #008. 輸送計画問題（2部グラフの需給モデル）

<!-- section:scenario -->
複数の焙煎工場から複数のカフェ店舗へコーヒー豆（kg）を配送する物流ネットワークを考えます。各工場には出荷可能な在庫量があり、各店舗には必要な需要量があり、工場と店舗の各ルートには 1 kg あたりの輸送単価が設定されています。

どの工場の出荷上限も超えずにすべての店舗の需要を満たし、**総輸送コストを最小化する各ルートの配送量**（0 以上の連続値）を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `supplies` | `number[]` | 各焙煎工場 $i$ の出荷可能量 (kg) |
| `demands` | `number[]` | 各カフェ店舗 $j$ の必要需要量 (kg) |
| `unitCosts` | `number[][]` | 工場 $i$ から店舗 $j$ への 1 kg あたりの輸送単価 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `shipments` | `number[][]` | 工場 $i$ から店舗 $j$ への非負配送量 (kg) の行列（`unitCosts` と同サイズ） |
| `totalCost` | `number` | 最小化された総輸送コスト |

<!-- section:example -->
**入力例**

```json
{
  "supplies": [60, 80],
  "demands": [40, 50, 40],
  "unitCosts": [
    [4, 6, 8],
    [5, 3, 2]
  ]
}
```

**出力例**

```json
{
  "shipments": [
    [40, 10, 0],
    [0, 40, 40]
  ],
  "totalCost": 420
}
```

各焙煎工場の出荷量は $40 + 10 = 50 \le 60$、$40 + 40 = 80 \le 80$、各カフェ店舗の受取量は `[40, 50, 40]` で需要を満たし、総輸送コストは $4 \times 40 + 6 \times 10 + 3 \times 40 + 2 \times 40 =$ **420** となります。
