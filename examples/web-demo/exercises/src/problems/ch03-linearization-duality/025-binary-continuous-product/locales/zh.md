# #025. 二元变量与连续变量乘积线性化（Glover 线性化）

<!-- section:scenario -->
采购团队需要向多家合格供应商订购连续数量的产品以满足总需求。无论是否签署折扣合约，每家供应商都规定了严格正的最低起订量与最大供应上限，并按基础单价计费。

团队可以为每家供应商选择是否支付一笔固定合约费来激活折扣合约，一旦激活即可对向该供应商购买的每一单位数量享受单价折扣。请决定签约方案、采购数量及线性化乘积项，以**最小化净采购总成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `minOrders` | `number[]` | 供应商 $i$ 的最低起订量 $L_i$ |
| `maxOrders` | `number[]` | 供应商 $i$ 的最大供应上限 $U_i$ |
| `baseCosts` | `number[]` | 供应商 $i$ 的基础单价 $c_i$ |
| `discounts` | `number[]` | 激活合约（$b_i = 1$）后的单位折扣额 $d_i$ |
| `contractFees` | `number[]` | 激活合约的固定签约费 $F_i$ |
| `totalDemand` | `number` | 所需最低采购总量 $\sum_i x_i$ |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `b` | `number[]` | 折扣合约选择（`0` 或 `1`） |
| `x` | `number[]` | 各供应商采购量 $x_i \in [L_i, U_i]$ |
| `z` | `number[]` | 线性化双线性乘积 $z_i = b_i x_i$ |
| `totalCost` | `number` | 最小化后的净采购总成本 |

<!-- section:example -->
**输入示例**

```json
{
  "minOrders": [10, 15, 10],
  "maxOrders": [50, 60, 40],
  "baseCosts": [20, 22, 18],
  "discounts": [5, 6, 3],
  "contractFees": [160, 220, 150],
  "totalDemand": 95
}
```

**输出示例**

```json
{
  "b": [1, 0, 0],
  "x": [50, 15, 30],
  "z": [50, 0, 0],
  "totalCost": 1780
}
```

采购量 `[50, 15, 30]` 总计 $95 \ge 95$ 且满足上下界，仅签约供应商 0（`z = [50, 0, 0]`），总成本为 $(20 \times 50 + 22 \times 15 + 18 \times 30) + 160 - 5 \times 50 =$ **1,780**。
