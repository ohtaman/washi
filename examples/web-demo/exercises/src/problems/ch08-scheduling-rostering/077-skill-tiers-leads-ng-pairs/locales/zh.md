# #077. 含技能覆盖、资深带班与互斥组合约束的排班

<!-- section:scenario -->
某急诊科的护理与急救团队需要为 $N$ 名员工安排 $D$ 天内每天 $S$ 个班次的排班表，在满足以下所有规则的前提下最小化总排班成本：

- 每名员工每天至多上一个班次。
- 每个有效班次（总人数需求为正的班次）必须满足其最低总人数需求。
- 每个有效班次必须包含至少一名资深带班。
- 每个有效班次必须满足 $K$ 项专业技能（如分诊与急救处置等）各自的最低人数要求。
- 指定的互斥员工对不能被安排在同一天的同一班次。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `demands` | `number[][]` | 第 $d$ 天班次 $s$ 的最低总人数需求（$D \times S$） |
| `isSenior` | `number[]` | 各员工是否为资深带班（长度为 $N$ 的 0/1 数组） |
| `staffSkills` | `number[][]` | $N \times K$ 的 0/1 矩阵，表示员工 $i$ 是否具备技能 $k$ |
| `skillDemands` | `number[][]` | 有效班次 $s$ 所需的技能 $k$ 最低人数（$S \times K$） |
| `ngPairs` | `number[][]` | 禁止在同一 `(d, s)` 班次共事的互斥对 `[a, b]` 列表 |
| `shiftCosts` | `number[][]` | 员工 $i$ 担任班次 $s$ 的成本（$N \times S$） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `schedule` | `number[][]` | $N \times D$ 矩阵（-1：休息，0 至 $S-1$：所排班次） |
| `totalCost` | `number` | 最小化的总排班成本 |

<!-- section:example -->
**输入示例**

```json
{
  "demands": [
    [2, 1],
    [2, 1]
  ],
  "isSenior": [1, 1, 0, 0],
  "staffSkills": [
    [1, 0],
    [0, 1],
    [1, 1],
    [0, 1]
  ],
  "skillDemands": [
    [1, 1],
    [1, 0]
  ],
  "ngPairs": [[0, 2], [1, 3]],
  "shiftCosts": [
    [15, 20],
    [16, 18],
    [10, 14],
    [11, 15]
  ]
}
```

**输出示例**

```json
{
  "schedule": [
    [1, 1],
    [0, 0],
    [0, 0],
    [-1, -1]
  ],
  "totalCost": 92
}
```

两天中班次 0 均避开互斥对 [0, 2] 并安排资深 1 与员工 2 搭档，班次 1 则安排掌握技能 0 的资深 0 单独值班，总成本为 $(20+20) + (16+16) + (10+10) =$ **92**。

<!-- section:hint1 -->
引入关于员工 $i$、第 $d$ 天与班次 $s$ 的三维二元变量，并限制每人每天至多上一个班次。每个有效班次槽位都必须同时满足总人数、资深带班人数、各技能覆盖人数以及互斥员工对约束。

<!-- section:hint2 -->
请注意仅对 `demands[d][s] > 0` 的有效班次施加资深带班与技能覆盖不等式，以免在需求为 0 的班次上强行排班。对于每对互斥员工 `[a, b]`，在每个 `(d, s)` 槽位施加 $x_{a,d,s} + x_{b,d,s} \le 1$，从而禁止他们同班，但仍允许他们在同一天上不同的班次。
