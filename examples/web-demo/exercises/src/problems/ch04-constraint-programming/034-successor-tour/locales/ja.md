# #034. 後継ノード変数と順位配列による巡回セールスマン問題

<!-- section:scenario -->
配送計画担当者は、配送車がデポ（拠点 0）を出発し、すべての顧客拠点をちょうど 1 回ずつ訪問してデポへ戻る単一の巡回路を求めます。任意の 2 拠点間には向きに応じた整数移動距離（km）が定められており、行きと帰りで距離が異なる（非対称な）場合があります。

切り離された部分巡回路（サブツアー）を作らず全拠点を 1 本の閉路で巡るように各拠点の直後に訪れる後継拠点を決定し、総移動距離（km）を最小化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `distances` | `number[][]` | `n × n` の有向整数距離行列（`distances[i][j]` は拠点 `i` から `j` への移動距離［km］。非対称で `distances[i][j]` と `distances[j][i]` が異なる場合あり） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `next` | `number[]` | 拠点 `i` の直後に訪問する後継拠点番号（0 〜 `n - 1`） |
| `totalDistance` | `number` | 最小化された総巡回距離 `sum(distances[i][next[i]])`（km） |

<!-- section:example -->
**入力例**

```json
{
  "distances": [
    [0, 2, 7, 9],
    [2, 0, 4, 8],
    [7, 4, 0, 2],
    [6, 8, 2, 0]
  ]
}
```

**出力例**

```json
{
  "next": [1, 2, 3, 0],
  "totalDistance": 14
}
```

`next` が [1, 2, 3, 0] のとき、全拠点を通る単一閉路 0 -> 1 -> 2 -> 3 -> 0 となり、総距離は $2 + 4 + 2 + 6 =$ **14** km です。

<!-- section:hint1 -->
各拠点に対して `[0, n - 1]` の範囲で自己ループのない互いに異なる後継拠点変数を 1 つずつ定義します。非連結な部分巡回（サブツアー）を防ぐために、デポ 0 を起点とする訪問順序（ランク）の補助整数変数を各拠点に導入します。

<!-- section:hint2 -->
`distinct(next)` と `distinct(rank)` に加え、`rank[0] == 0` および `at(rank, next[0]) == 1` を課します。各顧客拠点 $i \ge 1$ には ``implies(expr`${next[i]} != 0`, expr`at(${rank}, ${next[i]}) == ${rank[i]} + 1`)`` で訪問順序を連結し、`sum(input.distances.map((row, i) => at(row, next[i])))` を最小化して `solver: "pumpkin"` で解いてください。
