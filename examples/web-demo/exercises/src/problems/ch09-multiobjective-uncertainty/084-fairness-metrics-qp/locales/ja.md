# #084. 公平性指標と凸二次計画法（QP）による負荷平準化

<!-- section:scenario -->
運用管理者は、所定の総作業量を複数のチームへ連続量で配分します。各チームには 1 単位あたりの運用コストと配分量の最小・最大上限があり、全チームの配分量の合計は総需要に厳密に一致しなければなりません。

単純にコスト最小化だけをすると、最も安価なチームに上限いっぱいまで負荷が偏ります。負荷の公平性を保つため、平均配分量からの二乗偏差和に比例する二次ペナルティを加え、線形コストと L2 公平性ペナルティの和を最小化してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `unitCosts` | `number[]` | 各チームの 1 単位あたり線形運用コスト |
| `minAlloc` | `number[]` | 各チームの最小割当量 |
| `maxAlloc` | `number[]` | 各チームの最大割当量 |
| `totalDemand` | `number` | 全チームで分担する総需要量 |
| `fairnessWeight` | `number` | $\sum_i (x_i - \bar{x})^2$ に掛ける非負ペナルティ重み $\lambda$ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `allocations` | `number[]` | 各チームへの連続配分量 |
| `totalCost` | `number` | 最小化された「線形コスト＋二次公平性ペナルティ」 |

<!-- section:example -->
**入力例**

```json
{
  "unitCosts": [10, 2, 6],
  "minAlloc": [0, 0, 0],
  "maxAlloc": [20, 20, 20],
  "totalDemand": 30,
  "fairnessWeight": 2
}
```

**出力例**

```json
{
  "allocations": [9, 11, 10],
  "totalCost": 176
}
```

`allocations = [9, 11, 10]` は総和 $9 + 11 + 10 = 30$（平均 $\bar{x} = 10$）を満たし、線形コスト $10(9) + 2(11) + 6(10) = 172$ と分散ペナルティ $2 \times ((9-10)^2 + (11-10)^2 + (10-10)^2) = 4$ の合計 **176** を達成します。


<!-- section:hint1 -->
各チームの上下限付き連続割当量を決定変数とし、総需要を満たしつつ運用コストとチーム間のばらつきペナルティを両立させるモデルを組みます。

<!-- section:hint2 -->
総需要が固定されているため、目標となる平均割当量は変数に依存しない既知の定数として扱えます。WaSHI の `expr` テンプレートタグは凸 2 次項を HiGHS QP 向けにそのままコンパイルできるため区分線形近似は不要であり、`m.objectiveValue!` には二乗展開に伴う定数項も含まれた値が返ります。
