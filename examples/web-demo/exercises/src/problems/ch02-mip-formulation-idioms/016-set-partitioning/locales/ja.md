# #016. 最小コスト集合分割問題

<!-- section:scenario -->
配車担当者が、すべての配送タスクを候補ルートへ割り当てます。各候補ルートには運行コストと担当タスクの集合が決まっていますが、運用規程により、どのタスクも未割当にできず、同時に複数の選ばれたルートで重複して担当することも厳禁です。

すべてのタスクが**ちょうど 1 つ**の選択ルートに含まれるようにルートを選び、**総運行コストを最小化**してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `numTasks` | `number` | タスク総数（インデックス `0` 〜 `numTasks - 1`） |
| `costs` | `number[]` | 各候補ルートの運行コスト |
| `routes` | `number[][]` | 各候補ルート $j$ が担当するタスク番号の配列 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `selected` | `number[]` | 各候補ルートの採択有無（`0` または `1`） |
| `totalCost` | `number` | 最小化された総運行コスト |

<!-- section:example -->
**入力例**

```json
{
  "numTasks": 5,
  "costs": [5, 5, 6, 9, 8, 10],
  "routes": [
    [0, 1, 2],
    [2, 3, 4],
    [0, 1],
    [2, 3, 4],
    [1, 2, 3],
    [0, 4]
  ]
}
```

**出力例**

```json
{
  "selected": [0, 1, 1, 0, 0, 0],
  "totalCost": 11
}
```

ルート 1（`[2, 3, 4]`）とルート 2（`[0, 1]`）を選ぶと、全タスク `{0, 1, 2, 3, 4}` を重複も漏れもなくちょうど 1 回ずつ分割でき、総コストは $5 + 6 =$ **11** となります。
