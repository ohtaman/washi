# #026. 0-1 变量乘积线性化（协同与冲突选择）

<!-- section:scenario -->
研发团队需要在固定预算内从若干候选模块中挑选一个子集进行开发。每个模块拥有独立价值与开发成本；此外，某些模块对若同时上线会产生交互效应——正值为协同加成，负值为功能冲突或自相蚕食惩罚。

请在满足预算上限的前提下决定选中模块及配对激活指示变量，以**最大化独立价值与交互效应的总收益**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `values` | `number[]` | 模块 $i$ 的独立价值 $r_i$ |
| `costs` | `number[]` | 模块 $i$ 的成本 $c_i$ |
| `budget` | `number` | 总预算上限 $B$ |
| `pairs` | `number[][]` | 交互对列表 `[i, j, s]`（$s > 0$ 为协同加成，$s < 0$ 为冲突惩罚） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selected` | `number[]` | 各模块的 0-1 选择向量 $x_i$ |
| `pairProducts` | `number[]` | 各配对的同时激活乘积 $w_k = x_i x_j$ |
| `totalValue` | `number` | 最大化后的总价值 |

<!-- section:example -->
**输入示例**

```json
{
  "values": [40, 35, 30, 25],
  "costs": [30, 25, 20, 15],
  "budget": 60,
  "pairs": [
    [0, 1, 25],
    [1, 2, -20],
    [0, 3, 10],
    [2, 3, 15]
  ]
}
```

**输出示例**

```json
{
  "selected": [1, 1, 0, 0],
  "pairProducts": [1, 0, 0, 0],
  "totalValue": 100
}
```

选择模块 0 与 1（`[1, 1, 0, 0]`）耗费预算 $30 + 25 = 55 \le 60$，仅激活配对 `(0, 1)`（`pairProducts = [1, 0, 0, 0]`），总收益为 $40 + 35 + 25 =$ **100**。
