# #024. 線形分数計画の比率最大化（Charnes-Cooper 変換）

<!-- section:scenario -->
事業部門では、各活動の非負の稼働水準を資源上限および個別上界のもとで決定します。今回は利益額そのものではなく、線形関数で表される「純リターン（定数項含む）」と「投入コスト（正の固定基準値含む）」の比率である**効率比を最大化**したいと考えています。

すべての資源制約と個別上限を満たしながら、**線形分数で表される効率比を最大化**する稼働水準と最大比率を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `numCoeffs` | `number[]` | 分子の係数ベクトル $c$ |
| `numConst` | `number` | 分子の定数項 $c_0$ |
| `denCoeffs` | `number[]` | 分母の非負係数ベクトル $d$ |
| `denConst` | `number` | 分母の正の定数項 $d_0 > 0$ |
| `usages` | `number[][]` | 資源消費行列 $A$ |
| `capacities` | `number[]` | 資源容量の上限ベクトル $b$ |
| `upperBounds` | `number[]` | 各活動の個別上限 $u$ |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `x` | `number[]` | 元の尺度での稼働水準ベクトル |
| `maxRatio` | `number` | 最大化された比率 $(c^\top x + c_0) / (d^\top x + d_0)$ |

<!-- section:example -->
**入力例**

```json
{
  "numCoeffs": [12, 9],
  "numConst": 10,
  "denCoeffs": [4, 2],
  "denConst": 8,
  "usages": [
    [1, 1]
  ],
  "capacities": [8],
  "upperBounds": [5, 6]
}
```

**出力例**

```json
{
  "x": [0, 6],
  "maxRatio": 3.2
}
```

`x = [0, 6]` は $0 + 6 \le 8$ および個別上限 `[5, 6]` を満たし、分子 $9 \times 6 + 10 = 64$、分母 $2 \times 6 + 8 = 20$ から効率比は $64 / 20 =$ **3.2** となります。
