# #024. 线性分式效率比最大化（Charnes-Cooper 变换）

<!-- section:scenario -->
精密零件工厂的生产计划负责人需要在原材料、加工工时等共享资源容量以及各零件生产上限的约束下，决定多种精密零件的非负连续产量（个，允许小数）。本次关注的目标并非利润总额本身，而是含固定净回报偏移量（万元，正值表示固定收入、负值表示固定开销）在内的“总净回报”与含正基本维护费（万元）在内的“总投入成本”之比——**最大化投资效率比**。

请运用 Charnes-Cooper 变换，在满足所有资源约束与各零件生产上限的前提下，求出使效率比最大的产量与最大比率。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `numCoeffs` | `number[]` | 零件 $j$ 的单位净回报 $c_j$（万元/个） |
| `numConst` | `number` | 带符号固定净回报偏移量 $c_0$（万元，正值为固定收入，负值为固定开销） |
| `denCoeffs` | `number[]` | 零件 $j$ 的单位投入成本 $d_j$（万元/个，非负） |
| `denConst` | `number` | 严格为正的基本维护费 $d_0 > 0$（万元） |
| `usages` | `number[][]` | 资源消耗矩阵 $A$（`usages[k][j]` 表示生产 1 个零件 $j$ 消耗的资源 $k$ 数量） |
| `capacities` | `number[]` | 共享资源 $k$ 的容量上限 $b_k$ |
| `upperBounds` | `number[]` | 零件 $j$ 的生产上限 $u_j$（个） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `x` | `number[]` | 各零件的产量（个） |
| `maxRatio` | `number` | 最大化后的效率比 $(c^\top x + c_0) / (d^\top x + d_0)$ |

<!-- section:example -->
**输入示例**

```json
{
  "numCoeffs": [12, 9],
  "numConst": 10,
  "denCoeffs": [4, 2],
  "denConst": 8,
  "usages": [
    [1, 1]
  ],
  "capacities": [8],
  "upperBounds": [5, 6]
}
```

**输出示例**

```json
{
  "x": [0, 6],
  "maxRatio": 3.2
}
```

当 `x` 为 [0, 6] 时，满足资源消耗 $0 + 6 \le 8$ 与个体上限 [5, 6]，此时分子为 $9 \times 6 + 10 = 64$，分母为 $2 \times 6 + 8 = 20$，效率比为 $64 / 20 =$ **3.2**。


<!-- section:hint1 -->
不要直接在原始零件产量变量中求解，而是应用 Charnes-Cooper 变换：引入一个表示分母倒数的非负标量缩放变量，以及一组表示该缩放变量与各零件产量乘积的非负缩放产量变量。

<!-- section:hint2 -->
最常见的陷阱是忘记对各零件的生产上限进行同步缩放：在变换后的模型中，除了将分母归一化为 1 之外，共享资源容量和每个零件的生产上限都必须乘以缩放变量 $t$，而不能保留原来的常数上界。由于原始可行域有界（$0 \le x \le u$）且分母恒严格为正（$d \ge 0, d_0 > 0$），变换后的任意可行解都满足 $t > 0$，因此可以通过 $x = y / t$ 精确还原原产量。
