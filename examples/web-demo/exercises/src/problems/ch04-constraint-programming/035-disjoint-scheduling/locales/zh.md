# #035. 互斥机器调度（disjoint 全局约束）

<!-- section:scenario -->
半导体制造工厂的生产计划负责人正在为多道晶圆加工工序（清洗、光刻、刻蚀等）制定调度方案，使各工序在各自负责的设备上不中断地连续执行。每道工序都指定了加工时长（分钟）、最早可开始时间（分钟）以及负责设备编号。

使用同一台设备的工序在时间上不能重叠，且对于给定了先后约束的工序对，必须等前道工序完全结束后才能开始后继工序。请确定各道工序的开始时间，以最小化最大完工时间（makespan，分钟）。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `durations` | `number[]` | 各工序的加工时长（整数，分钟） |
| `releaseTimes` | `number[]` | 各工序的最早可开始时间（分钟） |
| `machines` | `number[]` | 各工序使用的从 0 开始的设备编号 |
| `precedences` | `number[][]` | 要求工序 `u` 完成后才能开始工序 `v` 的先后工序对 `[u, v]` |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `starts` | `number[]` | 各工序的开始时间（整数，分钟） |
| `makespan` | `number` | 最小化后的最大完工时间 `max(starts[i] + durations[i])`（分钟） |

<!-- section:example -->
**输入示例**

```json
{
  "durations": [4, 3, 5, 2],
  "releaseTimes": [0, 2, 0, 4],
  "machines": [0, 0, 0, 0],
  "precedences": [
    [0, 3]
  ]
}
```

**输出示例**

```json
{
  "starts": [0, 6, 9, 4],
  "makespan": 14
}
```

设备 0 上依次无重叠地执行工序 0（[0, 4)）→ 工序 3（[4, 6)）→ 工序 1（[6, 9)）→ 工序 2（[9, 14)），同时满足最早可开始时间与先后关系 0 → 3。最大完工时间为 $\max(0 + 4, 6 + 3, 9 + 5, 4 + 2) = \max(4, 9, 14, 6) =$ **14** 分钟。

<!-- section:hint1 -->
为每道工序定义一个下界为最早可开始时间、上界为 `horizon - durations[i]` 的整数开始时间变量。除先后约束外，按负责设备对工序分组，并对每台设备施加不重叠析取约束。

<!-- section:hint2 -->
对每台设备收集分配给它的工序列表 `{ start: starts[i], duration: input.durations[i] }` 并施加 `disjoint(tasks)` 约束。以各工序完工时间 `starts[i] + durations[i]` 的 `minimize(max(...))` 为目标，并通过 `solver: "pumpkin"` 求解。
