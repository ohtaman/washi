# #006. 防災設備の導入計画（0-1 バイナリ変数）

<!-- section:scenario -->
ある自治体が、限られた総予算（万円）の中で複数の候補となる防災設備（防犯カメラ、非常用電源、AED など）から導入する設備を選定します。各設備は半分だけ導入することはできず、「導入する」か「導入しない」かの二択です。導入した設備は所定の費用（万円）がかかり、期待される防災効果（スコア）を生み出します。

総費用が予算を超えない範囲で、**導入する設備の合計スコアを最大化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `budget` | `number` | 利用可能な総予算（万円） |
| `costs` | `number[]` | 各防災設備の必要費用（万円） |
| `values` | `number[]` | 各防災設備の期待スコア |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `selected` | `number[]` | 各設備の導入フラグ（`0` または `1`） |
| `totalValue` | `number` | 最大化された合計スコア |

<!-- section:example -->
**入力例**

```json
{
  "budget": 15,
  "costs": [4, 5, 7, 3, 6],
  "values": [10, 12, 16, 8, 13]
}
```

**出力例**

```json
{
  "selected": [0, 1, 1, 1, 0],
  "totalValue": 36
}
```

設備 1・2・3（`[0, 1, 1, 1, 0]`）を選ぶと総費用は $5 + 7 + 3 = 15 \le 15$（予算以内）となり、合計スコアは $12 + 16 + 8 =$ **36** となります。
