# #028. LP の被約費用（Reduced Cost）と参入閾値

<!-- section:scenario -->
化学プラントの生産計画担当者は、複数の化学プロセスを組み合わせて各プロセスの稼働量（t、非負の連続量）を決定し、すべての最低生産要求を満たすコスト最小化ブレンド計画を立てています。各プロセスには 1 t あたりの単位コストが設定されており、プロセス固有の 1 t あたり産出率で各最低生産要求に寄与します。現在の単位コストのもとでは採算が合わず、最適計画で稼働量 0 となるプロセスも含まれています。

現場からは「未使用の各プロセスを無理に稼働させると最小総コストは 1 t あたりどれだけの限界増加率で増えるか（言い換えれば、単位コストがいくら下がれば採用されるようになるか）」という指標が求められています。最小化 LP を解き、各プロセスの稼働量・被約費用（reduced cost）・最小総コストを返してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `costs` | `number[]` | 各プロセスの単位コスト（1 t あたり） |
| `yields` | `number[][]` | 1 t あたりの産出量行列（`[requirement][process]` 順） |
| `minRequirements` | `number[]` | 各要求の最低生産要求量 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `quantities` | `number[]` | 各プロセスの非負稼働量（t） |
| `reducedCosts` | `number[]` | 各プロセスの被約費用 $\bar{c}_j$（1 t あたり） |
| `optimalCost` | `number` | 最小化された総コスト $z^*$ |

<!-- section:example -->
**入力例**

```json
{
  "costs": [10, 14, 24, 30],
  "yields": [
    [1, 2, 2, 3],
    [2, 1, 3, 1]
  ],
  "minRequirements": [17, 16]
}
```

**出力例**

```json
{
  "quantities": [5, 6, 0, 0],
  "reducedCosts": [0, 0, 6, 10],
  "optimalCost": 134
}
```

稼働量 [5, 6, 0, 0] は要求 [17, 16] を満たして総コスト $10 \times 5 + 14 \times 6 =$ **134** となり、双対解 [6, 2] から未使用プロセスの被約費用は $24 - (6 \times 2 + 2 \times 3) = 6$ および $30 - (6 \times 3 + 2 \times 1) = 10$ と求まります。


<!-- section:hint1 -->
各プロセスをどれだけ稼働させるかを表す非負の連続決定変数を 1 つずつ導入します。

<!-- section:hint2 -->
LP を解いた後、各変数の被約費用を WaSHI では `v.reducedCost!`（PuLP では `v.dj`）で読み取ります。元の単位コストをそのまま返したり符号を反転したりしないでください。非負変数を持つ最小化 LP では、最適基底で稼働している基底変数（$x_j > 0$）の被約費用は 0、下界に留まる非基底変数では基底に入るために必要なコスト改善量を表す非負値になります。ソルバーの返す値を整数に丸めずにそのまま返してください。
