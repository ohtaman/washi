# #065. 多段階サプライチェーン・ネットワーク設計

<!-- section:scenario -->
飲料メーカーのボトリング工場候補・地域配送センター（DC）候補・小売エリア（顧客）からなる 2 段階のサプライチェーンネットワークを設計します。工場または DC を開設するとそれぞれの固定開設費が発生し、能力上限まで出荷・中継を行えるようになりますが、開設しない拠点には一切フローを流せません。

各 DC は純粋な中継ノードとして工場からの総流入量と顧客への総流出量が一致する必要があり、すべての顧客需要を満たさなければなりません。開設する工場・DC と両段階の非負の連続輸送量を決めて、**固定開設費と輸送費の合計を最小化** してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `plantFixedCosts` | `number[]` | 各工場候補の固定開設費（長さ $P$） |
| `plantCaps` | `number[]` | 各工場候補の最大供給能力（長さ $P$） |
| `dcFixedCosts` | `number[]` | 各 DC 候補の固定開設費（長さ $D$） |
| `dcCaps` | `number[]` | 各 DC 候補の最大中継能力（長さ $D$） |
| `demands` | `number[]` | 各顧客の需要量（長さ $C$） |
| `plantDcCosts` | `number[][]` | 工場 $\to$ DC の 1 単位あたり輸送費（$P \times D$） |
| `dcCustomerCosts` | `number[][]` | DC $\to$ 顧客の 1 単位あたり配送費（$D \times C$） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `openPlants` | `number[]` | 各工場の開設選択（0 または 1、長さ $P$） |
| `openDcs` | `number[]` | 各 DC の開設選択（0 または 1、長さ $D$） |
| `plantToDc` | `number[][]` | 工場 $\to$ DC の非負の連続輸送量行列（$P \times D$） |
| `dcToCustomer` | `number[][]` | DC $\to$ 顧客の非負の連続輸送量行列（$D \times C$） |
| `totalCost` | `number` | 最小化された総コスト（固定費＋輸送費） |

<!-- section:example -->
**入力例**

```json
{
  "plantFixedCosts": [500, 420],
  "plantCaps": [120, 100],
  "dcFixedCosts": [250, 200, 280],
  "dcCaps": [90, 80, 100],
  "demands": [30, 40, 35, 25],
  "plantDcCosts": [
    [4, 6, 8],
    [7, 5, 3]
  ],
  "dcCustomerCosts": [
    [3, 5, 9, 7],
    [6, 2, 4, 8],
    [8, 7, 3, 2]
  ]
}
```

**出力例**

```json
{
  "openPlants": [1, 1],
  "openDcs": [1, 0, 1],
  "plantToDc": [
    [70, 0, 0],
    [0, 0, 60]
  ],
  "dcToCustomer": [
    [30, 40, 0, 0],
    [0, 0, 0, 0],
    [0, 0, 35, 25]
  ],
  "totalCost": 2355
}
```

両工場と DC 0・2 を開設すると、能力上限・DC 流量保存（70 = 30 + 40、60 = 35 + 25）・顧客需要を満たし、総コストは $1450 + 460 + 445 =$ **2,355**（固定費 1450、工場→DC 輸送費 460、DC→顧客配送費 445）となります。


<!-- section:hint1 -->
各工場候補および各配送センター（DC）候補に対する開設の有無を表すバイナリ変数と、工場から DC へ、DC から顧客への非負連続輸送量行列を導入します。ネットワークは DC を中継点として工場側と顧客側の 2 段階が結合された構造を持ちます。

<!-- section:hint2 -->
各工場からの総出荷量は「工場能力 × 工場開設変数」で抑え、各 DC の総通過量も同様に「DC 能力 × DC 開設変数」で制限します。また、各 DC では工場からの流入合計と顧客への流出合計が一致するフロー保存則を課し、各顧客の流入合計が需要を満たすように制約してください。
