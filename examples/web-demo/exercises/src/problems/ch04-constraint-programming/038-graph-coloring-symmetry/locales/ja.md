# #038. 対称性破壊によるグラフ彩色

<!-- section:scenario -->
電波管理の設計者は、干渉し合う無線基地局（頂点）のペアを結んだ無向グラフに対し、利用可能な個数分の周波数チャネル（0 から順に振られた整数番号）から各基地局へチャネルを割り当てます。互いに干渉する（辺で結ばれた）どの 2 つの基地局にも異なるチャネル番号を割り当てる必要があります。

干渉制約を満たす彩色の中で、使用される異なるチャネル（色）の総数を最小にしてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `numNodes` | `number` | 基地局（頂点）の個数（`0` 〜 `numNodes - 1`） |
| `maxColors` | `number` | 利用可能なチャネル（色）番号の個数（`0` 〜 `maxColors - 1`） |
| `edges` | `number[][]` | 互いに干渉する基地局ペア（0 始まりの無向辺 `[u, v]`）のリスト |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `colors` | `number[]` | 各頂点に割り当てた色番号（`[0, maxColors - 1]`） |
| `usedColors` | `number` | 使用した異なる色数の最小値 |

<!-- section:example -->
**入力**

```json
{
  "numNodes": 5,
  "maxColors": 5,
  "edges": [
    [0, 1],
    [1, 2],
    [2, 0],
    [2, 3],
    [3, 4]
  ]
}
```

**出力**

```json
{
  "colors": [0, 1, 2, 0, 2],
  "usedColors": 3
}
```

すべての辺 (0, 1), (1, 2), (2, 0), (2, 3), (3, 4) の両端が異なるチャネル番号になっており、使われている番号は {0, 1, 2} の **3** 種類です。

<!-- section:hint1 -->
各頂点の色を表す整数変数と、使われた最大色番号を追跡する整数変数を用意します。色のラベルは入れ替え可能で対称性があるため、先頭から順に新しい色番号が飛び番なく現れる正規順序を課して対称性を壊し、使用色数を最小化します。

<!-- section:hint2 -->
各辺に `colors[u] != colors[v]` を課し、`colors[0] == 0` および `i >= 1` に対して `colors[i] <= 1 + max(colors.slice(0, i))` で色置換の対称性を破壊します。さらにすべての `i` で `colors[i] <= maxColor` とし、`maxColor + 1` を `solver: "pumpkin"` で最小化してください。
