# #093. 反復部分巡回路除去カット（DFJ 法 TSP）

<!-- section:scenario -->
複数の配送拠点（都市）間の対称距離行列が与えられたとき、すべての都市をちょうど 1 回ずつ訪問して出発点に戻る最短ハミルトン閉路を反復 Dantzig-Fulkerson-Johnson（DFJ）部分巡回路除去ループで求めます。各都市の接続本数（次数）が 2 になることだけを課した緩和問題（2 次マッチング緩和）から出発し、分離された部分巡回路を反復的に除去して 1 つの連結巡回路に収束させます。

最適な巡回路、総距離、および実行した MIP 求解回数を返してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `distances` | `number[][]` | 対称な $n \times n$ 都市間距離行列（$n \in [5, 8]$） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `tour` | `number[]` | ハミルトン閉路の訪問順を表す $0 \dots n-1$ の順列 |
| `totalDistance` | `number` | 最小化された閉路総距離 |
| `iterations` | `number` | 反復 DFJ カットループで実行した MIP 求解回数 |

<!-- section:example -->
**入力例**

```json
{
  "distances": [
    [0, 3, 4, 25, 26, 27],
    [3, 0, 5, 24, 25, 26],
    [4, 5, 0, 26, 24, 25],
    [25, 24, 26, 0, 4, 3],
    [26, 25, 24, 4, 0, 5],
    [27, 26, 25, 3, 5, 0]
  ]
}
```

**出力例**

```json
{
  "tour": [0, 1, 3, 5, 4, 2],
  "totalDistance": 63,
  "iterations": 2
}
```

都市 `[0, 1, 3, 5, 4, 2]` を巡って 0 に戻る経路は全 6 都市を 1 回ずつ訪問し、総距離は $3 + 24 + 3 + 5 + 24 + 4 =$ **63**、反復回数は **2** 回となります。

<!-- section:hint1 -->
異なる都市の無向ペアごとに辺を選択する二値変数を置き、総移動距離を最小化します。次数制約のみを含む緩和モデルから始めて、非連結な閉路が見つかるたびにカットを追加し、単一の巡回路が得られるまで反復する切除平面ループとして構成してください。

<!-- section:hint2 -->
無向辺は $i < j$ のペア $(i, j)$ で添字付けし、各都市に次数 2 の制約を課します。すべての頂点の次数が 2 であるため、非連結な整数解は必ず互いに素な閉路 $S$ に分解されます。$|S| < n$ となる各部分巡回路 $S$ に対して DFJ カット $\sum_{i, j \in S,\, i < j} x_{ij} \le |S| - 1$ を同じモデルに追加して再求解し、`solve()` を呼ぶたびに反復回数をカウントしてください。
