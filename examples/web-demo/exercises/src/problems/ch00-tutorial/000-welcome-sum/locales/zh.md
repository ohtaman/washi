# #000. 热身练习：返回两数之和

<!-- section:scenario -->
给定两个数字 a 与 b，请实现一个返回两数之和 a + b 的 solve 函数。

在本题集的所有练习中，都需要按以下约定编写 solve 函数，判题器会根据其返回值进行验证（本题只需熟悉格式，无需调用优化求解器，直接计算并返回相加结果即可）：

- TypeScript：实现接收 P000Input 类型输入并返回 P000Output 类型对象的 solve 函数。
- Python：实现 solve(a, b) 函数，直接将输入字段作为参数接收并返回对应输出字典（dict）。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `a` | `number` | 第一个整数 |
| `b` | `number` | 第二个整数 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `sum` | `number` | 两数之和 `a + b` |

<!-- section:example -->
**输入示例**

```json
{
  "a": 2,
  "b": 3
}
```

**输出示例**

```json
{
  "sum": 5
}
```
