# #089. 预算不确定性鲁棒优化（Bertsimas-Sim 对偶重构）

<!-- section:scenario -->
某化工厂需要确定多种产品（如树脂颗粒、溶剂、添加剂等）的连续非负产量（单位：吨），每种产品均有各自的产量上限（吨），目标是最大化总利润。各产品每吨占用的共享设备工时（小时/吨）通常为名义基准值，但受原料品质波动等因素影响，实际单耗最多可能增加一个规定的上浮幅度。

给定不确定性预算 `gamma`（可为小数）：每种产品均可能出现其最大上浮幅度的 $[0, 1]$ 区间内任意比例的增量，且所有产品的比例之和不超过 `gamma`。请确定产量方案，在保证该预算范围内最坏波动发生时总工时仍不超过 `capacityCap` 的前提下，**最大化总利润**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `profits` | `number[]` | 各产品每吨的利润 |
| `nominalUsages` | `number[]` | 各产品每吨的名义（基准）设备工时 |
| `deviations` | `number[]` | 各产品每吨的最大工时上浮幅度 |
| `maxUnits` | `number[]` | 各产品的产量上限（吨） |
| `capacityCap` | `number` | 最坏情况下也必须严格遵守的设备总工时上限 |
| `gamma` | `number` | 不确定性保护预算（0 到产品总数之间，可为小数） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `quantities` | `number[]` | 满足鲁棒约束的各产品产量（吨） |
| `totalProfit` | `number` | 最大化后的总利润 |

<!-- section:example -->
**输入示例**

```json
{
  "profits": [12, 16, 10],
  "nominalUsages": [2, 3, 2],
  "deviations": [1, 1, 0.5],
  "maxUnits": [8, 6, 8],
  "capacityCap": 30,
  "gamma": 1
}
```

**输出示例**

```json
{
  "quantities": [3, 3, 6],
  "totalProfit": 144
}
```

生产 `[3, 3, 6]` 的名义工时为 $2(3) + 3(3) + 2(6) = 27$，$\Gamma = 1$ 下最坏上浮为 $\max(1 \cdot 3, 1 \cdot 3, 0.5 \cdot 6) = 3$，合计 $30 \le 30$，利润为 $12(3) + 16(3) + 10(6) =$ **144**。


<!-- section:hint1 -->
除了带上下界的连续产量变量外，为对不确定性预算 `gamma` 下的最坏情况保护子问题进行对偶化，引入一个非负标量对偶变量以及一组按产品索引的非负对偶变量。它们共同构成容量约束的精确线性鲁棒对等式。

<!-- section:hint2 -->
关键在于对内层 $\Gamma$-预算最坏情况保护子问题取线性规划对偶：对偶化会引入一个非负标量阈值变量和按产品索引的非负超额变量，用线性约束界定各产品的最坏偏差，并将对偶目标直接并入容量约束左侧，从而无需枚举或非线性项即可消去内层最大化。
