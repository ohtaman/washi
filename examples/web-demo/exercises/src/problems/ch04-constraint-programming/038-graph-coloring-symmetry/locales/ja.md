# #038. 対称性破壊によるグラフ彩色

<!-- section:scenario -->
頂点数 numNodes の無向グラフと辺リスト edges が与えられます。各頂点に 0 から maxColors - 1 までの整数色を 1 つ割り当て、辺で結ばれたどの 2 頂点も異なる色になるようにしてください。

条件を満たす彩色の中で、使用される異なる色の総数を最小にしてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `numNodes` | `number` | グラフの頂点数（`0` ～ `numNodes - 1`） |
| `maxColors` | `number` | 利用可能な色番号の個数（`0` ～ `maxColors - 1`） |
| `edges` | `number[][]` | `colors[u] != colors[v]` を課す無向辺 `[u, v]` のリスト |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `colors` | `number[]` | 各頂点に割り当てた色番号（`[0, maxColors - 1]`） |
| `usedColors` | `number` | 使用した異なる色数の最小値 |

<!-- section:example -->
**入力**

```json
{
  "numNodes": 5,
  "maxColors": 5,
  "edges": [
    [0, 1],
    [1, 2],
    [2, 0],
    [2, 3],
    [3, 4]
  ]
}
```

**出力**

```json
{
  "colors": [0, 1, 2, 0, 2],
  "usedColors": 3
}
```

すべての辺 `(0, 1)`, `(1, 2)`, `(2, 0)`, `(2, 3)`, `(3, 4)` の両端が異なる色になっており、使われている色は `{0, 1, 2}` の **3** 色です。

<!-- section:hint1 -->
各頂点の色を表す整数変数と、使われた最大色番号を追跡する整数変数を用意します。色のラベルは入れ替え可能で対称性があるため、先頭から順に新しい色番号が飛び番なく現れる正規順序を課して対称性を壊し、使用色数を最小化します。

<!-- section:hint2 -->
各辺に `colors[u] != colors[v]` を課し、`colors[0] == 0` および `i >= 1` に対して `colors[i] <= 1 + max(colors.slice(0, i))` で色置換の対称性を破壊します。さらにすべての `i` で `colors[i] <= maxColor` とし、`maxColor + 1` を `solver: "pumpkin"` で最小化してください。
