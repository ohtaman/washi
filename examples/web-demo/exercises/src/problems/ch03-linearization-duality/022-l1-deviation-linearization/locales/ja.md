# #022. 重み付き L1 偏差の線形化（目標追従）

<!-- section:scenario -->
電力会社の運用担当者は、複数の発電ユニット（火力・ガス・水力など）への発電出力配分（MW、非負）を決定します。各発電ユニットの定格上限以下かつ総コスト（万円）が予算上限以下という条件のもとで、総出力を指定された要求値（MW）にぴったり一致させる必要があります。各発電ユニットの理想目標値は予算制約や総出力条件とそのままでは両立しない場合があるため、一部を増減させて調整します。

目標出力からの上方・下方のズレには発電ユニットごとの重み付きペナルティが課されます。すべての制約を満たしながら、目標値からのズレの大きさ（絶対値の重み付き合計＝**重み付き L1 偏差**）を最小化する出力配分を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `targets` | `number[]` | 各発電ユニット $i$ の目標出力 $\tau_i$（MW） |
| `weights` | `number[]` | 目標出力からの 1 MW あたりペナルティ重み $w_i$ |
| `upperBounds` | `number[]` | 各発電ユニット $i$ の最大出力上限 $u_i$（MW） |
| `costs` | `number[]` | 各発電ユニット $i$ の単位発電コスト $c_i$（万円/MW） |
| `budget` | `number` | 許容される総コスト上限（万円） |
| `totalOutput` | `number` | 必要な総出力の合計（MW） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `allocations` | `number[]` | 各発電ユニットの出力配分 $x_i$（MW） |
| `totalDeviation` | `number` | 最小化された重み付き L1 偏差 $\sum_i w_i \lvert x_i - \tau_i \rvert$ |

<!-- section:example -->
**入力例**

```json
{
  "targets": [40, 30, 30],
  "weights": [3, 2, 1],
  "upperBounds": [60, 60, 60],
  "costs": [5, 2, 1],
  "budget": 230,
  "totalOutput": 100
}
```

**出力例**

```json
{
  "allocations": [25, 30, 45],
  "totalDeviation": 60
}
```

出力配分 [25, 30, 45] は合計 100 MW、総コスト $5 \times 25 + 2 \times 30 + 1 \times 45 = 230 \le 230$ 万円を満たし、重み付き L1 偏差は $3 \lvert 25 - 40 \rvert + 2 \lvert 30 - 30 \rvert + 1 \lvert 45 - 30 \rvert =$ **60** です。


<!-- section:hint1 -->
各発電ユニットに対して 0 から上限までの連続出力変数を宣言します。バイナリ変数を使わずに絶対偏差を線形化するため、目標値からの上振れ（超過）と下振れ（不足）を表す非負の補助変数のペアも発電ユニットごとに用意します。

<!-- section:hint2 -->
各発電ユニットの目標からの符号付き偏差を上振れ変数と下振れ変数の差として表し、目的関数では両者の和にペナルティを課します。ペナルティ重みが非負であるため、最適解では 2 つの補助変数のうち少なくとも一方が自動的に 0 になり、バイナリ変数を使わずに絶対値を線形化できます。
