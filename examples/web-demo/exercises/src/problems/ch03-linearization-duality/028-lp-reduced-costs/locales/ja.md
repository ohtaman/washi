# #028. LP の被約費用（Reduced Cost）と参入閾値

<!-- section:scenario -->
化学プラントでは、複数の非負プロセスを組み合わせて最低生産要求を満たすコスト最小化ブレンド計画を立てています。現在の単価のもとでは採算が合わず、最適計画で稼働量ゼロとなるプロセスも含まれています。

現場からは「未使用の各プロセスを 1 単位だけ無理に稼働させると最小コストがどれだけ増えるか（また単価がいくら下がれば採用されるようになるか）」という指標が求められています。最小化 LP を解き、各プロセスの稼働量・被約費用（reduced cost）・最小総コストを返してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `costs` | `number[]` | プロセス $j$ の単位コスト $c_j$ |
| `yields` | `number[][]` | プロセス $j$ の成分寄与行列 $A$（$A_{kj}$） |
| `minRequirements` | `number[]` | 各要求 $k$ の最低必要量 $r_k$（$\sum_j A_{kj} x_j \ge r_k$） |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `quantities` | `number[]` | 各プロセスの非負稼働量 $x_j$ |
| `reducedCosts` | `number[]` | 各変数 $x_j$ の被約費用 $\bar{c}_j$ |
| `optimalCost` | `number` | 最小化された総コスト $z^*$ |

<!-- section:example -->
**入力例**

```json
{
  "costs": [10, 14, 24, 30],
  "yields": [
    [1, 2, 2, 3],
    [2, 1, 3, 1]
  ],
  "minRequirements": [17, 16]
}
```

**出力例**

```json
{
  "quantities": [5, 6, 0, 0],
  "reducedCosts": [0, 0, 6, 10],
  "optimalCost": 134
}
```

稼働量 `[5, 6, 0, 0]` は要求 `[17, 16]` を満たして総コスト $10 \times 5 + 14 \times 6 =$ **134** となり、双対解 `[6, 2]` から未使用プロセスの被約費用は `24 - (6*2 + 2*3) = 6` および `30 - (6*3 + 2*1) = 10` と求まります。
