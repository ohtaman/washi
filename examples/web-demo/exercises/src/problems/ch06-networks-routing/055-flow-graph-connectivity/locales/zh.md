# #055. 基于单商品流的连通子图选择

<!-- section:scenario -->
规划从根节点 0 出发的区域网络扩展方案（根节点 0 必须始终启用）。每个站点具有启用收益（可正可负），每条无向候选链路具有建设费用，且仅当链路两端的站点同时启用时才允许建设该链路。

请选择一组站点与链路，使所有启用站点与根节点 0 构成单个连通子图（不允许出现孤立飞地），并 **最大化净收益**（启用站点收益之和减去所选链路建设费用之和）。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `prizes` | `number[]` | 启用节点 `0 .. n - 1` 获得的收益 |
| `edges` | `Array<{ u, v, cost }>` | 无向候选链路及其建设费用 `cost` |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selectedNodes` | `number[]` | 节点启用标记（`0` 或 `1`，且 `selectedNodes[0] = 1`） |
| `selectedEdges` | `number[]` | 与 `edges` 对应的链路启用标记（`0` 或 `1`） |
| `netValue` | `number` | 最大化后的净收益（节点收益和减去链路费用和） |

<!-- section:example -->
**输入示例**

```json
{
  "prizes": [0, 3, 2, 12, 10],
  "edges": [
    { "u": 0, "v": 1, "cost": 6 },
    { "u": 0, "v": 2, "cost": 7 },
    { "u": 2, "v": 3, "cost": 3 },
    { "u": 3, "v": 4, "cost": 2 },
    { "u": 1, "v": 3, "cost": 9 }
  ]
}
```

**输出示例**

```json
{
  "selectedNodes": [1, 0, 1, 1, 1],
  "selectedEdges": [0, 1, 1, 1, 0],
  "netValue": 12
}
```

启用节点 `{0, 2, 3, 4}` 及链路 `0-2-3-4` 构成以 `0` 为根的连通树，节点收益之和为 $0 + 2 + 12 + 10 = 24$，扣除链路费用 $7 + 3 + 2 = 12$ 后净收益为 **12**。

<!-- section:hint1 -->
为节点激活和无向边建设分别定义二进制变量，并将根节点 0 固定为激活状态。为保证与根节点的连通性，将每条无向边拆分为两个方向的连续流变量，从根 0 向每个被激活的非根节点输送单商品流。

<!-- section:hint2 -->
只有当边两端点均被激活时才允许建边（$w_e \le y_u, y_v$），且边 $e$ 上任一方向的流量仅在 $w_e = 1$ 时才可为正（上界为 $n - 1$）。根节点 0 为每个激活的非根节点发出 1 单位流量（$\text{outflow}(0) - \text{inflow}(0) = \sum_{v \ge 1} y_v$），而每个非根节点消耗 $y_v$ 单位流量（$\text{inflow}(v) - \text{outflow}(v) = y_v$），从而彻底杜绝高收益的孤立节点岛。
