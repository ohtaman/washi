# #089. 预算不确定性鲁棒优化（Bertsimas-Sim 对偶重构）

<!-- section:scenario -->
某工厂需要决定多种产品的连续非负产量，每种产品均有个体产量上限并贡献单位利润。在正常情况下，产品按名义单耗占用资源，但实际单耗最多可能额外增加一个已知的波动幅度。

为了不过度保守地假设全部产品同时取到最坏上浮，管理层设定不确定性预算参数 Gamma 来限制同时发生的加权波动总量。请确保在允许的最坏波动下总资源消耗仍不超过产能上限，并最大化总利润。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `profits` | `number[]` | 各产品的单位利润 |
| `nominalUsages` | `number[]` | 各产品的名义单位资源消耗 |
| `deviations` | `number[]` | 各产品单位资源消耗的最大上浮波动量 |
| `maxUnits` | `number[]` | 各产品产量的个体上界 |
| `capacityCap` | `number` | 最坏情形下也必须满足的总产能上限 |
| `gamma` | `number` | 不确定性保护预算 $\Gamma \in [0, n]$（可为小数） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `quantities` | `number[]` | 满足鲁棒保护的各产品产量 |
| `totalProfit` | `number` | 预算鲁棒保护下的最大总利润 |

<!-- section:example -->
**输入示例**

```json
{
  "profits": [12, 16, 10],
  "nominalUsages": [2, 3, 2],
  "deviations": [1, 1, 0.5],
  "maxUnits": [8, 6, 8],
  "capacityCap": 30,
  "gamma": 1
}
```

**输出示例**

```json
{
  "quantities": [3, 3, 6],
  "totalProfit": 144
}
```

生产 `[3, 3, 6]` 的名义资源占用为 $2(3) + 3(3) + 2(6) = 27$，$\Gamma = 1$ 下最坏上浮为 $\max(1 \cdot 3, 1 \cdot 3, 0.5 \cdot 6) = 3$，合计 $30 \le 30$，利润为 $12(3) + 16(3) + 10(6) =$ **144**。


<!-- section:hint1 -->
除了带上下界的连续产量变量外，为对预算 $\Gamma$ 下的最坏情况保护子问题进行对偶化，引入一个非负标量对偶变量以及一组按产品索引的非负对偶变量。它们共同构成容量约束的精确线性鲁棒对等式。

<!-- section:hint2 -->
关键在于对内层 $\Gamma$-预算最坏情况保护子问题取线性规划对偶：对偶化会引入一个非负标量阈值变量和按产品索引的非负超额变量，用线性约束界定各产品的最坏偏差，并将对偶目标直接并入容量约束左侧，从而无需枚举或非线性项即可消去内层最大化。
