# #094. 列生成法による 1 次元カッティングストック問題

<!-- section:scenario -->
製紙工場において、一定幅の標準原反ロールを指定された複数の小幅品目へと切り出し、各品目の需要本数を満たしながら消費する原反ロール総数を最小化します。実行可能な切断パターンの総数は品目数に対して組合せ的に増大するため、全パターンを事前に列挙する定式化は実用的ではありません。

単一品目のみを切り出す初期パターンから制約付き主問題（RMP）を構成し、WaSHI の列生成機能を用いて主問題 LP 緩和の双対価格からナップサック価格付け子問題を繰り返し解いて有望パターンを追加したうえで、最終的に整数計画（MIP）として解を確定してください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `rollWidth` | `number` | 標準原反ロール 1 本の幅 |
| `widths` | `number[]` | 各品目 $i$ の切り出し幅 |
| `demands` | `number[]` | 各品目 $i$ の必要最小本数 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `patterns` | `number[][]` | 採用した整数切断パターンの配列（各要素の長さは `widths.length`） |
| `counts` | `number[]` | 各パターンを切り出す原反本数（非負整数） |
| `totalRolls` | `number` | 使用した原反ロールの合計本数（`sum(counts)`） |

<!-- section:example -->
**入力例**

```json
{
  "rollWidth": 100,
  "widths": [45, 36, 16],
  "demands": [10, 14, 20]
}
```

**出力例**

```json
{
  "patterns": [
    [0, 2, 1],
    [1, 1, 1],
    [0, 1, 4]
  ],
  "counts": [1, 10, 3],
  "totalRolls": 14
}
```

各パターンは幅上限 `100` 以内（`88, 97, 100 <= 100`）であり、切り出し合計 `[10, 15, 23] >= [10, 14, 20]` を達成し、使用本数は `1 + 10 + 3 =` **14** 本となります。
