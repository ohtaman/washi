# #016. 最小成本集合划分问题

<!-- section:scenario -->
某调度规划师需要将全部配送任务分配给候选车辆路线，每条候选路线具有固定运营成本以及固定的服务任务集合。运营规范严格禁止遗漏任何任务，也不允许同一任务被多条已选路线重复执行。

请选出一组路线，使每项任务**恰好被执行一次**，同时**最小化总运营成本**。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `numTasks` | `number` | 任务数量（编号 0 到 `numTasks - 1`） |
| `costs` | `number[]` | 每条候选路线的运营成本 |
| `routes` | `number[][]` | 每条候选路线所执行的任务编号列表 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `selected` | `number[]` | 各候选路线是否选中（0 或 1） |
| `totalCost` | `number` | 最小化后的总运营成本 |

<!-- section:example -->
**输入示例**

```json
{
  "numTasks": 5,
  "costs": [5, 5, 6, 9, 8, 10],
  "routes": [
    [0, 1, 2],
    [2, 3, 4],
    [0, 1],
    [2, 3, 4],
    [1, 2, 3],
    [0, 4]
  ]
}
```

**输出示例**

```json
{
  "selected": [0, 1, 1, 0, 0, 0],
  "totalCost": 11
}
```

选择路线 1（`[2, 3, 4]`）与路线 2（`[0, 1]`）恰好将全部任务 `{0, 1, 2, 3, 4}` 无重叠无遗漏地划分完毕，总成本为 $5 + 6 =$ **11**。

<!-- section:hint1 -->
为每条候选路线设置一个二元选择变量。对每个任务在包含该任务的所有路线上建立一条约束，确保既不遗漏任务也不重复执行，同时最小化总运营成本。

<!-- section:hint2 -->
对每个任务 $i \in \{0, \dots, \text{numTasks} - 1\}$，将所有包含 $i$ 的路线 $j$ 对应的 `selected[j]` 求和并施加等式约束 $= 1$。若改用不等式 $\ge 1$，可能会通过路线重叠得到成本更低的解，但这会违反每项任务只能执行一次的规范。
