# #087. 带追索权的两阶段随机规划

<!-- section:scenario -->
某食品与日用品批发商需要在不确定的客户需求明朗之前的第一阶段，在共享仓库容量上限（单位：箱）范围内确定多种商品的连续非负订货量（箱，允许小数箱），并按各商品的初期采购单价（日元/箱）支付订货费用。

随后，各需求情景按给定概率发生，进入第二阶段追索调整：库存不足以应对需求的部分需支付高额紧急补货罚金（日元/箱），未售出的剩余库存则可按较低残值回收部分价值（日元/箱）。请确定最小化初期订货费与第二阶段期望净成本之和的第一阶段订货量。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `orderCosts` | `number[]` | 各商品的第一阶段采购单价（日元/箱） |
| `shortageCosts` | `number[]` | 各商品第二阶段每箱缺货惩罚（日元） |
| `salvageValues` | `number[]` | 各商品未售出每箱的回收残值（日元） |
| `warehouseCap` | `number` | 第一阶段总订货量的共享仓库容量上限（箱） |
| `probs` | `number[]` | 各情景的发生概率（总和为 1） |
| `demands` | `number[][]` | 按 [情景][商品] 索引的需求矩阵（箱） |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `orders` | `number[]` | 第一阶段订货量向量（非负值，箱） |
| `expectedCost` | `number` | 所有情景下的最小化期望总成本（日元） |

<!-- section:example -->
**输入示例**

```json
{
  "orderCosts": [4, 6],
  "shortageCosts": [14, 18],
  "salvageValues": [1, 2],
  "warehouseCap": 30,
  "probs": [0.5, 0.5],
  "demands": [
    [10, 8],
    [20, 16]
  ]
}
```

**输出示例**

```json
{
  "orders": [14, 16],
  "expectedCost": 184
}
```

订货 `[14, 16]` 满足仓库上限 $14 + 16 = 30 \le 30$，前期采购成本 $4(14) + 6(16) = 152$，情景 0 回收残值 $1 \times 4 + 2 \times 8 = 20$，情景 1 缺货罚金 $14 \times 6 = 84$，期望总成本为 $152 + 0.5(-20) + 0.5(84) =$ **184**。


<!-- section:hint1 -->
构建包含全情景共享的非负第一阶段订货量向量，以及按情景索引的非负第二阶段短缺量与剩余库存向量的确定性等价线性规划。用仓库容量限制第一阶段总订货量，将每个情景的追索变量与情景需求关联，并最小化初期订货成本与按概率加权的期望净追索成本之和。

<!-- section:hint2 -->
注意两点：第一阶段订货量必须是不分情景的共享决策向量（非预期性）；在最小化目标中，残值回收收入必须带负号减去而非相加。由于 `shortageCosts` 高于 `salvageValues`，同一商品在同一情景下不会同时出现短缺与剩余。
