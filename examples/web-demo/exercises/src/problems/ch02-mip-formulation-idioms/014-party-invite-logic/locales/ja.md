# #014. パーティー招待と論理パズル

<!-- section:scenario -->
あなたはディナーパーティーを企画しており、総予算内で誰を招待し、招待した各ゲストにいくらのギフト予算を割り当てるかを決めます。ゲストを招待すると基本の楽しさスコアに加えて、ギフト予算 1 ドルあたりの追加スコアが得られます。

招待計画は次の条件をすべて満たす必要があります。
- **ギフト予算の範囲**: 招待したゲストには下限以上・上限以下のギフト予算を割り当てる（招待しない場合は 0）
- **総予算の上限**: 全ゲストのギフト予算の合計が総予算を超えない
- **同行条件**: あるゲストを招待するなら別のゲストも必ず招待する組がある
- **同時招待の禁止**: 同時に招待できないゲストの組がある
- **グループの最低人数**: 指定されたグループごとに、決められた人数以上を招待する

すべての条件を満たしながら、**楽しさの合計を最大化**する招待計画を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `budget` | `number` | 全ゲスト合計のギフト予算上限（ドル） |
| `baseEnjoyment` | `number[]` | 各ゲスト（0 〜 $n - 1$ の $n$ 人）を招待したときの基本の楽しさ |
| `bonusRates` | `number[]` | 各ゲストのギフト予算 1 ドルあたりの追加の楽しさ |
| `minSpend` | `number[]` | 招待したときのギフト予算の下限（ドル） |
| `maxSpend` | `number[]` | 招待したときのギフト予算の上限（ドル） |
| `implications` | `number[][]` | ゲスト `a` を招待するならゲスト `b` も必ず招待するペア `[a, b]` |
| `conflicts` | `number[][]` | 同時に招待できないペア `[u, v]` |
| `groupRules` | `{ guests: number[]; minCount: number }[]` | `guests` のうち `minCount` 人以上を招待するグループ下限ルール |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `invite` | `number[]` | 各ゲストを招待するかどうかのバイナリ値（0 または 1） |
| `giftBudget` | `number[]` | 各ゲストに割り当てる連続値のギフト予算（ドル） |
| `totalEnjoyment` | `number` | 最大化された楽しさの合計 |

<!-- section:example -->
**入力**

```json
{
  "budget": 55,
  "baseEnjoyment": [10, 25, 30, 15, 22],
  "bonusRates": [2, 5, 6, 3, 4],
  "minSpend": [8, 12, 10, 10, 14],
  "maxSpend": [15, 20, 18, 14, 22],
  "implications": [[1, 0]],
  "conflicts": [[2, 4]],
  "groupRules": [
    { "guests": [0, 2, 3], "minCount": 1 }
  ]
}
```

**出力**

```json
{
  "invite": [1, 1, 1, 1, 0],
  "giftBudget": [8, 19, 18, 10, 0],
  "totalEnjoyment": 329
}
```

ゲスト `{0, 1, 2, 3}` を招待し `giftBudget = [8, 19, 18, 10, 0]` とすると、同行条件 `1 -> 0`、同時招待禁止 `[2, 4]` の回避、グループ `{0, 2, 3}` から 3 人（1 人以上）の招待、総予算 $8 + 19 + 18 + 10 = 55 \le 55$ ドルをすべて満たし、楽しさの合計は $(10 + 25 + 30 + 15) + (2 \cdot 8 + 5 \cdot 19 + 6 \cdot 18 + 3 \cdot 10) =$ **329** となります。

<!-- section:hint1 -->
各ゲストについて、招待するかどうかのバイナリ変数と、ギフト予算を表す連続変数を組にします。各ゲストのギフト予算の範囲を招待フラグに連動させ、合計予算の上限と、3種類の論理ルール（含意・競合・グループ下限）をバイナリ変数の線形不等式として表現します。

<!-- section:hint2 -->
`giftBudget[i]` と招待のバイナリ変数 $y_i$（`invite[i]`）の連動には、インスタンス固有のタイトな上下界（`minSpend[i]` と `maxSpend[i]`）を使います。論理ルールは、含意 $a \implies b$ を $y_a \le y_b$、競合を $y_u + y_v \le 1$、グループ下限を `rule.guests` に含まれる $y_i$ の和が `rule.minCount` 以上として線形化します。
