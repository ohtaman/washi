# #052. 最大流・最小カット定理

<!-- section:scenario -->
データセンター間の光ファイバー通信網において、送信元サーバー（始点）からバックアップ拠点（終点）へ最大限のデータ流量（Gbps）を送る問題を考えます。各通信回線（有向枝）の流量は帯域幅の上限以下でなければならず、始点・終点以外の中継ルーター（中間頂点）では流入量と流出量が一致する必要があります。

線形計画（LP）により始点から終点への最大流量を求めるとともに、始点から終点へのすべての有向パスを遮断し、かつ容量合計が最大流量と一致する最小 s-t カット辺集合を求めてください。

<!-- section:io -->
### 入力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `nodeCount` | `number` | 頂点数（`0 .. nodeCount - 1`） |
| `source` | `number` | 始点インデックス $s$ |
| `sink` | `number` | 終点インデックス $t$ |
| `edges` | `Array<{ from, to, cap }>` | 始点 `from`、終点 `to`、帯域幅上限 `cap`（Gbps）を持つ有向枝 |

### 出力

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `flows` | `number[]` | 各枝の非負フロー量（`0 <= flow <= cap`） |
| `cutEdges` | `number[]` | 最小 s-t カットを構成する `edges` の重複なしインデックス配列（0 始まり） |
| `maxFlow` | `number` | 最大流量（`cutEdges` の容量合計と一致） |

<!-- section:example -->
**入力例**

```json
{
  "nodeCount": 4,
  "source": 0,
  "sink": 3,
  "edges": [
    { "from": 0, "to": 1, "cap": 10 },
    { "from": 0, "to": 2, "cap": 5 },
    { "from": 1, "to": 2, "cap": 4 },
    { "from": 1, "to": 3, "cap": 4 },
    { "from": 2, "to": 3, "cap": 10 }
  ]
}
```

**出力例**

```json
{
  "flows": [8, 5, 4, 4, 9],
  "cutEdges": [1, 2, 3],
  "maxFlow": 13
}
```

始点 0 からの流出は $8 + 5 =$ **13**、中間頂点 1・2 は収支 0 を満たし、`cutEdges = [1, 2, 3]` を除くと頂点 0 から頂点 3 への道がすべて遮断され、カット容量和も $5 + 4 + 4 =$ **13** となります。

<!-- section:hint1 -->
各有向枝に対して容量を上限とする非負の連続フロー変数を定義します。`source` と `sink` を除くすべての中間頂点で流出と流入の差が 0 になるよう保存則を課し、`source` からの純流出フローを最大化してください。

<!-- section:hint2 -->
飽和した枝を無作為に集めても最小カットになるとは限りません（閉路や別のボトルネックの背後にある飽和枝が含まれるため）。最適フローの残余グラフ上で `source` から BFS/DFS を行い（`flow < cap - 1e-6` の順方向 `from -> to` と `flow > 1e-6` の逆方向 `to -> from` を辿る）、到達可能集合 $S$ を求めて $S$ から $V \setminus S$ へ向かう元の枝を抽出してください。
