# #052. 最大流与最小 s-t 割

<!-- section:scenario -->
考虑数据中心之间的光纤通信网络，目标是从源服务器（源点）向备份站点（汇点）传输尽可能大的数据流量（Gbps）。每条通信链路（有向边）的流量不能超过其带宽上限，除源点与汇点外的中继路由器（中间节点）都必须保持流入量等于流出量。

请使用线性规划（LP）求出从源点到汇点的最大流量，并同时提取一组最小 s-t 割边索引，使其容量之和等于最大流且切断所有从源点到汇点的有向路径。

<!-- section:io -->
### 输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `nodeCount` | `number` | 节点数（`0 .. nodeCount - 1`） |
| `source` | `number` | 源点编号 $s$ |
| `sink` | `number` | 汇点编号 $t$ |
| `edges` | `Array<{ from, to, cap }>` | 带容量有向边列表 |

### 输出

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `flows` | `number[]` | 每条边的非负流量（`0 <= flow <= cap`） |
| `cutEdges` | `number[]` | 构成最小 s-t 割的无重复边索引数组 |
| `maxFlow` | `number` | 最大流量（等于 `cutEdges` 的容量之和） |

<!-- section:example -->
**输入示例**

```json
{
  "nodeCount": 4,
  "source": 0,
  "sink": 3,
  "edges": [
    { "from": 0, "to": 1, "cap": 10 },
    { "from": 0, "to": 2, "cap": 5 },
    { "from": 1, "to": 2, "cap": 4 },
    { "from": 1, "to": 3, "cap": 4 },
    { "from": 2, "to": 3, "cap": 10 }
  ]
}
```

**输出示例**

```json
{
  "flows": [8, 5, 4, 4, 9],
  "cutEdges": [1, 2, 3],
  "maxFlow": 13
}
```

源点 0 净流出为 $8 + 5 =$ **13**，中间节点 1 与 2 保持流入等于流出，移除 `cutEdges = [1, 2, 3]` 可阻断从 0 到 3 的全部路径且割容量之和为 $5 + 4 + 4 =$ **13**。

<!-- section:hint1 -->
为每条有向边定义以容量为上界的非负连续流量变量。在除 `source` 和 `sink` 外的所有中间节点上施加净流量为零的守恒约束，并最大化从 `source` 净流出的总流量。

<!-- section:hint2 -->
不要盲目收集所有满载边——位于环路内或其他瓶颈之后的满载边未必属于最小割。应在最优流的残余网络中从 `source` 出发做 BFS/DFS（当 `flow < cap - 1e-6` 时沿正向 `from -> to` 遍历，当 `flow > 1e-6` 时沿反向 `to -> from` 遍历），求出可达点集 $S$，再收集所有从 $S$ 指向 $V \setminus S$ 的原始有向边。
